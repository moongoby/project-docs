# 유튜브 다주제 멀티채널 활성화 기획서
> **버전:** v1.0
> **최초 작성:** 2026-02-24
> **최종 갱신:** 2026-02-24
> **상태:** Phase 1 착수

---

## 1. 기획 배경
ShortFlow v3.0의 영상 자동 생성 파이프라인(10-Layer 회피 엔진 + FFmpeg + TTS 이중 엔진 + YouTube Data API 업로드 워커)을
쇼핑 쇼츠뿐 아니라 다양한 주제의 콘텐츠 채널로 확장하여, 구독자 증가 → 수익화 → 쇼핑 제휴 확대의 선순환 구조를 구축한다.

## 2. YouTube AI 콘텐츠 정책 대응 (2025.07.15 강화)
- **금지:** 단순 AI TTS + 스톡 슬라이드쇼 대량 업로드, 템플릿 반복, 인간 기여 없는 콘텐츠
- **허용:** AI를 보조 도구로 활용 + 인간의 독자적 해설·분석·스토리텔링·편집
- **필수:** AI 사용 시 업로드 공시 토글 체크, 채널당 일일 업로드 2편 이내 권장
- **위반 시:** 수익화 해제, 채널 경고, 반복 시 YPP 퇴출

## 3. 채널 운영 구조
### 3.1 계정 전략
- Google 계정 1개당 최대 100개 브랜드 채널 생성 가능
- 리스크 분산을 위해 2개 계정으로 분리 운영 권장:
  - **계정 A (쇼핑군):** 시크블랙, 린다샵, 단하루, 로그데이
  - **계정 B (콘텐츠군):** 경제, 건강, 역사 + 향후 확장 채널

## 4. 콘텐츠 제작 파이프라인
[LLM 대본 초안] → [인간 검수·관점 추가] → [ShortFlow 엔진] ├─ 이미지 소싱 (Unsplash/Pexels API) ├─ TTS 음성 (Google Cloud / Edge-TTS) ├─ 자막 생성 ├─ BGM 합성 ├─ 10-Layer 변환 └─ FFmpeg 최종 렌더링 ↓ [YouTube Data API 업로드]


## 5. 채널별 콘텐츠 전략

### 5.1 경제이야기 (3분 경제)
- **포맷:** 인포그래픽 + 차트 + TTS 나레이션 + 자막
- **주제 예시:** "오늘의 환율 왜 올랐나", "ETF vs 개별주식", "2026 부동산 전망", "월급쟁이 절세법"
- **업로드:** Shorts 주 5편 + 롱폼(5-10분) 주 2편
- **제휴:** 재테크 도서, 가계부 앱, 금융 관련 상품
- **수익화 목표:** 3개월 내 구독 1,000 + 시청 4,000시간

### 5.2 건강이야기 (건강 한입)
- **포맷:** 건강정보 카드 + 식품 이미지 + TTS + 자막
- **주제 예시:** "40대 이후 꼭 먹어야 할 음식", "걷기 운동의 놀라운 효과", "혈압 낮추는 생활습관"
- **업로드:** Shorts 주 5편 + 롱폼 주 2편
- **제휴:** 영양제, 건강식품, 운동기구 (쿠팡 파트너스)
- **면책:** 모든 영상에 "의학적 조언이 아닙니다" 고지 삽입

### 5.3 역사이야기 (역사 5분)
- **포맷:** 역사 일러스트/고지도 + 타임라인 애니메이션 + TTS + 자막
- **주제 예시:** "조선시대 최악의 왕", "세계사 미스터리 TOP5", "알렉산더 대왕의 최후"
- **업로드:** Shorts 주 5편 + 롱폼 주 2편
- **제휴:** 역사 도서, 다큐멘터리 관련 상품
