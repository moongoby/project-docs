## 3. 사업 모델 전체 목록 (10개)

### BIZ-01: 자체 YouTube 쇼핑 쇼츠 채널 운영
- **활용 기술**: T1~T7 전체
- **수익 모델**: 쿠팡 파트너스 3% → YouTube Shopping 태그 6.7% → 광고 RPM
- **타겟**: 구독자 500 → 1,000 → 10,000 단계별 성장
- **예상 수익**: 월 100~200만 (6개월 후)
- **추가 개발**: 제목/태그 최적화 모듈
- **우선순위**: ★★★★★ (즉시)

### BIZ-02: 4채널 릴스 자동 영상 공급
- **활용 기술**: T2(FFmpeg) + T3(TTS) + T5(NAS) + T6(상품DB)
- **수익 모델**: 기존 4개 인스타 쇼핑몰 매출 증대 (직접 판매)
- **타겟**: 시크블랙, 린다샵, 단하루, 로그데이
- **현재 문제**: 릴스 영상 수동 제작 → 자동화로 일 생산량 10배 증가
- **예상 효과**: 채널당 릴스 일 3~5편 자동 생성, 월 매출 20~30% 증가
- **추가 개발**: 채널별 템플릿/톤 설정, Instagram Graph API 업로드
- **우선순위**: ★★★★★ (즉시)

### BIZ-03: 뉴톡 쇼핑몰 상품 영상화 (내부 활용)
- **활용 기술**: T2 + T3 + T6
- **수익 모델**: 상품 상세페이지 전환율 향상 (간접 매출)
- **예상 효과**: 영상 있는 상품 전환율 +80%
- **추가 개발**: 1~2주 (상세페이지 임베드)
- **우선순위**: ★★★★☆

### BIZ-04: AI 상품 리뷰 영상 자동 생성
- **활용 기술**: T1 + T2 + T3 + LLM(Claude/GPT)
- **수익 모델**: 리뷰형 제휴 마케팅 (쿠팡 파트너스 + YouTube Shopping)
- **추가 개발**: 1~2주 (스크립트 생성 모듈)
- **우선순위**: ★★★★☆

### BIZ-05: 멀티플랫폼 숏폼 배포 (인스타 + TikTok + 네이버)

## 5. 4채널 릴스 연동 설계

### 5.1 채널별 설정 구조
```
/data/shortflow/config/channels/
├── sikblack.json       # 시크블랙
├── lindashop.json      # 린다샵
├── danharu.json        # 단하루
└── logday.json         # 로그데이
```

### 5.2 채널 설정 JSON 스키마
```json
{
    "channel_id": "sikblack",
    "channel_name": "시크블랙",
    "platform": "instagram",
    "brand_tone": "모던·시크·블랙톤",
    "target_audience": "20~30대 여성",
    "daily_video_count": 3,
    "video_duration_sec": [15, 30],
    "template_style": "minimal_black",
    "tts_voice": "ko-KR-SunHiNeural",
    "bgm_mood": "chill_electronic",
    "product_filter": {
        "categories": ["33238"],
        "price_min": 20000,
        "price_max": 80000,
        "brand_keywords": ["시크", "블랙", "모던"]
    },
    "hashtags": ["#시크블랙", "#데일리룩", "#패션추천", "#ootd"],
    "coupang_fallback_url": "",
    "output_path": "/data/styleflow/output/sikblack/",
    "nas_source_path": "/data/styleflow/raw/sikblack/",
    "upload_schedule": ["10:00", "14:00", "19:00"],
    "enabled": true
}
```

### 5.3 파이프라인 흐름
```
[NAS 이미지] → [채널별 필터링] → [템플릿 선택]
    → [LLM 스크립트 생성] → [TTS 음성]
    → [FFmpeg 합성 (1080x1920)]
    → [10-Layer 오리지널리티 검사]
    → [채널별 출력 폴더]
    → [Instagram/YouTube/TikTok 업로드 워커]
```

### 5.4 DB 상품 매칭 쿼리 (채널별)
```sql
-- 시크블랙: 블랙/모던 키워드, 2~8만원대
SELECT id, GoodsName, GoodsImage, GoodsPrice
FROM goods
WHERE activated = 'Y'
  AND GoodsImage IS NOT NULL
  AND GoodsImage != ''
  AND GoodsPrice BETWEEN 20000 AND 80000
  AND (GoodsName LIKE '%블랙%' OR GoodsName LIKE '%시크%' OR GoodsName LIKE '%모던%')
ORDER BY created DESC
LIMIT 10;
```
