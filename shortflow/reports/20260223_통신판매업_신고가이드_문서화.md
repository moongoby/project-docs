## 4. 면제 기준 해당 여부 분석

| 기준 | 내용 | ShortFlow 적용 |
|------|------|----------------|
| 연 영업금액 1.5억 미만 | 해당 시 신고 면제 가능 | 초기에는 해당 가능 |
| 연 거래 50회 미만 | 해당 시 신고 면제 가능 | 초기에는 해당 가능 |

- **결론:** 초기에는 면제 가능하나, SaaS 확장(구독 수·매출 증가) 시 **신고 필수** 권장. 미신고 시 과태료 최대 1,000만원이므로 사전 신고 진행 권장.
