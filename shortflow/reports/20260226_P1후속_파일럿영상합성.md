## 3. TASK B — 대본 형식 확인 및 변환

### 3.1 신규 대본 형식 (output/scripts/economy, health)

- **형식:** 단일 `script` 필드 + 메타데이터  
- **키:** `title`, `description`, `tags`, `script`, `hook`, `cta`, `disclaimer`, `estimated_duration_sec`, `channel`, `subject`, `generated_at`, `provider`  
- **특징:** `script_segments` 없음. `script`는 전체 나레이션 한 덩어리 문자열.

### 3.2 파이프라인 요구 형식

- **pilot_video_e2e.sh**, **tts_3fallback_video_synth.sh**, **run_gemini_3ch.py** 는 모두 **`script_segments`** 배열 사용.
- 세그먼트 키: `order`, `text`, `duration_sec`, `image_keyword`.

### 3.3 변환 대응

- **추가 파일:** `scripts/pilot_video_e2e.py`  
  - `--script`, `--channel` 로 단일 대본 JSON 경로 지정 후 E2E 실행.
  - **단일 `script` → `script_segments` 변환:**  
    - 문장 단위 분할 (`. ! ?` 뒤 공백 기준), 괄호 지시어 `(강조)` 등 제거 후 분할.
    - `estimated_duration_sec`을 세그먼트 수로 나누어 `duration_sec` 배분.
    - `image_keyword`는 `subject` 또는 `title` 기반으로 생성.
  - TTS: CLOVA → Google Cloud TTS → Edge-TTS 순 폴백.
  - 영상: 세그먼트별 단색 배경 이미지 + FFmpeg concat → 1080x1920, H.264, AAC, ≤60초.

## 4. TASK C — 파일럿 영상 6편 E2E 합성

### 4.1 실행 방법

```bash
cd /data/shortflow
# economy 최신 3편
for script in $(ls -t output/scripts/economy/*.json | head -3); do
  venv/bin/python scripts/pilot_video_e2e.py --script "$script" --channel economy
done
# health 최신 3편
for script in $(ls -t output/scripts/health/*.json | head -3); do
  venv/bin/python scripts/pilot_video_e2e.py --script "$script" --channel health
done
```

| 항목 | 내용 |
