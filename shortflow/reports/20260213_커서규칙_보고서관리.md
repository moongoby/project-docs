# 커서 규칙 – 보고서·일시_제목 관리 반영

**작성일시:** 2026-02-13
**작업 유형:** 설정 변경
**상태:** 완료
**관련 파일:** `.cursor/rules/report-and-file-management.mdc`, `.cursorrules`

---

## 1. 작업 개요

Cursor에서 작업 완료 시 보고서를 필수로 작성·저장하고, 보고서 파일을 **일시_제목** 형식으로 관리하도록 규칙을 추가하고 .cursorrules에 반영했다.

## 2. 변경 사항

- **`.cursor/rules/report-and-file-management.mdc`** (신규)
  - `alwaysApply: true` 로 전역 적용.
  - 원칙: 모든 작업이 끝나면 보고서 작성·저장·관리, 파일은 일시_제목 형식.
  - 파일 명명: `reports/{YYYYMMDD}_{제목}.md`.
  - 작업 완료 시 절차: 보고서 작성 → INDEX 갱신, 본문 형식(작성일시, 유형, 상태, 관련 파일, 개요·변경 사항·테스트·주의사항) 명시.
- **`.cursorrules`** (수정)
  - 보고서 규칙 문단을 "작업 완료 시 보고서 필수 작성·관리"로 정리.
  - "일시_제목" 예시 및 INDEX 갱신 안내 추가.
  - `.cursor/rules/report-and-file-management.mdc` 참조 문구 추가.

## 3. 테스트 결과

- 규칙 파일 생성 및 .cursorrules 수정만 수행. 별도 실행 테스트 없음.

## 4. 주의사항 / 후속 작업

- Cursor 재시작 또는 새 채팅 시 규칙이 자동 적용됨.
- 보고서는 기존대로 `reports/INDEX.md` 테이블에 한 줄씩 추가해 관리.
