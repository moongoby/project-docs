# 영상 품질 개선 — 채널별 맞춤 스톡 + 세그먼트별 배경 전환 (v4)

## 1. 목표

- **채널별 맞춤 스톡 영상:** economy / health 채널에 맞는 키워드 프리셋으로 Pexels 스톡 검색.
- **세그먼트별 배경 전환:** segment 1 → keyword[0], segment 2 → keyword[1], … 순서대로 다른 배경 적용.
- **캐시 재사용:** 이미 다운로드된 키워드는 재다운로드하지 않음.
- **폴백:** 다운로드 실패 시 다음 키워드 시도 → 최종 폴백은 채널별 그라데이션 배경.
- **자막:** 화면 하단 20% 영역(y=h*0.75), 반투명 검정 박스, 폰트 40px·흰색·테두리 2px 검정.

## 2. STEP 1 — 현재 문제 분석 (v3 기준)

### 2-1. v3 키워드/스톡/pexels 관련 코드

- **키워드 산출:** `script_to_segments()`에서 `keyword_base = data.get("subject") or data.get("title") or "abstract"` 로 **대본당 하나**의 키워드만 사용. 모든 세그먼트에 동일한 `image_keyword` 부여.
- **스톡 다운로드:** `create_video_v3()`에서 세그먼트마다 `download_stock_video(keyword, output_path=work_dir/stock_{order}.mp4)` 호출. **work_dir은 실행마다 새로 생성**되므로 캐시 경로가 아님 → 동일 키워드라도 매번 재다운로드 가능성.
- **엔진:** `engine/stock_video_downloader.py` — Pexels API 우선, 실패 시 Pixabay 폴백. `output_path`가 없을 때만 `cache/stock_videos/{keyword}.mp4` 사용.

### 2-2. 캐시 디렉터리 (v4 테스트 후)

| 파일명 | 비고 |
|--------|------|
| `dollar_exchange_rate.mp4` | v3 시절 economy 대본 제목 기반 키워드 |
| `healthy_food_nutrition.mp4` | v3 시절 health 대본 제목 기반 키워드 |
| `economy_us_dollar_bills_close_up.mp4` ~ `economy_bank_vault_money.mp4` | v4 economy 프리셋 7종 |
| `health_fresh_fruits_vegetables_table.mp4` ~ `health_organic_food_market.mp4` | v4 health 프리셋 7종 |

### 2-3. 채널별 키워드 사용 (v3 로그 정리)

- **v3:** 세그먼트 구분 없이 **동일 키워드**만 사용. economy 예: "달러 환율" → `dollar_exchange_rate` 등 제목/주제 기반 1개. health 예: "건강 음식" → `healthy_food_nutrition` 등 1개.
- **v4:** 아래 프리셋대로 **세그먼트 순서별로 다른 키워드** 사용.

## 3. STEP 2 — 채널별 키워드 프리셋

`scripts/pilot_video_e2e_v4.py` 내 `CHANNEL_KEYWORD_PRESETS`:

| 채널 | 키워드 목록 |
|------|-------------|
| **economy** | us dollar bills close up, stock market trading screen, financial chart graph, korean won currency, wall street new york, gold bars investment, bank vault money |
| **health** | fresh fruits vegetables table, healthy meal preparation, fitness exercise workout, vitamin supplement pills, green salad bowl, morning yoga meditation, organic food market |

세그먼트 인덱스 `i`에 대해 `keyword = presets[channel][i % len(presets)]` 로 순환 적용.

---

## 4. STEP 3 — 세그먼트별 배경 전환 로직

- 각 세그먼트마다 프리셋에서 **순서대로** 키워드 사용 (segment 1 → keyword[0], segment 2 → keyword[1], …).
- **캐시:** `cache/stock_videos/{channel}_{safe_keyword}.mp4` 에 있으면 재다운로드하지 않고 해당 경로 사용.
- **다운로드 실패 시:** 같은 세그먼트에 대해 프리셋 내 **다음 키워드**로 순차 시도.
- **최종 폴백:** 채널별 그라데이션 배경  
  - economy: `#1a237e` → `#0d47a1`  
  - health: `#1b5e20` → `#2e7d32`  
  FFmpeg `blend=all_expr='A*(1-Y/H)+B*Y/H'` 로 세로 그라데이션 생성.
