# 이미지 생성 Google Imagen 전환

**작성일시:** 2026-02-13  
**작업 유형:** 설정 변경 / 리팩터링  
**상태:** 완료  
**관련 파일:** worker/config.py, worker/requirements.txt, worker/services/image_generator.py

---

## 1. 작업 개요

E2E 파이프라인 테스트에서 OpenAI DALL-E 3 결제 한도(billing_hard_limit_reached)로 이미지 생성 단계가 실패한 것을 우회하기 위해, 이미지 생성기를 **Google Imagen 4**를 1차로 사용하고, API 키가 없을 때만 DALL-E 3로 fallback 하도록 전환했다.

---

## 2. 변경 사항

### 2.1 config.py

- `Settings` 클래스에 **Google AI (Imagen)** 섹션 추가.
- `google_ai_api_key: str = ""` 필드 추가 (환경변수 `GOOGLE_AI_API_KEY` 매핑).

### 2.2 worker/requirements.txt

- **google-genai>=1.0.0** 추가 (Google Imagen SDK).
- Pillow는 기존 10.4.0 유지 (>=10.0.0 조건 충족).

### 2.3 worker/services/image_generator.py (전체 교체)

- **Primary:** `GOOGLE_AI_API_KEY` 설정 시 Google Imagen (`imagen-4.0-generate-001`) 사용.
  - 9:16 비율, 동기 SDK는 `asyncio.run_in_executor`로 실행.
  - safety/blocked 시 단순화된 프롬프트로 1회 재시도.
- **Fallback:** Google 키 없고 `OPENAI_API_KEY` 있으면 기존 DALL-E 3 사용 (1024x1792, content policy 시 재시도).
- **generate_batch:** Google 사용 시 순차 생성(레이트 리밋 대응), DALL-E 사용 시 기존처럼 `asyncio.gather` 병렬.

## 3. 테스트 결과

### 3.1 Docker 리빌드 및 기동

- `docker compose down` → `docker compose build worker` → `docker compose up -d` 성공.
- `curl http://localhost:8000/health` → `{"status":"ok","service":"shortflow-worker"}` 정상.

### 3.2 파이프라인 재테스트 (Job 2)

- **Job 생성:** `POST /api/v1/jobs/create` (pick_id=1) → job_id=2 생성 성공.
- **파이프라인 실행:** `POST /api/v1/pipeline/run` (job_id=2) → Pipeline started 성공.
- **Worker 로그:**
  - `ImageGenerator: using Google Imagen` → Google Imagen 경로 사용 확인.
  - 스크립트 생성(Claude) 성공.
  - **이미지 생성:** 5장 모두 `Google Imagen generated: .../20260213_1_sceneN.png` 로 성공 (약 45초).
- **최종 Job 상태:** DEAD_LETTER (원인: TTS 단계에서 **ElevenLabs API key invalid**, 이미지와 무관).
- **생성 파일:** `data/images/20260213_1_scene1.png` ~ `scene5.png` 5개 확인.

| 단계           | 결과   | 비고                          |
|----------------|--------|-------------------------------|
| 스크립트 생성  | 성공   | Claude, 5 scenes             |
| 이미지 생성    | **성공** | Google Imagen 5장 생성        |
| TTS 생성       | 실패   | ElevenLabs API 키 미설정/오류 |
| 이후 단계      | 미진입 | TTS 실패로 중단               |

**결론:** 이미지 생성 Google Imagen 전환은 정상 동작하며, E2E에서 이전에 실패하던 DALL-E 결제 한도 문제는 Imagen 사용으로 우회된 상태이다.

---

## 4. 주의사항 / 후속 작업

- **GOOGLE_AI_API_KEY:** 운영 환경 `.env`에 Google AI API 키 설정 필요. 미설정 시 자동으로 DALL-E 3 fallback.
- **ElevenLabs:** 전체 E2E 완료를 위해 `ELEVENLABS_API_KEY`(및 필요 시 `ELEVENLABS_VOICE_ID`) 설정 후 재테스트 권장.
- Dockerfile 수정 없음 (requirements.txt 변경만으로 pip 설치에 google-genai 포함됨).
