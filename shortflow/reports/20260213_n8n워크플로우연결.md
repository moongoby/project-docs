## 1. 작업 개요

n8n이 Worker를 HTTP로 호출할 수 있도록 FastAPI REST 엔드포인트를 추가하고, 매일 자동 실행용 n8n 워크플로우 JSON 템플릿 및 API 테스트를 작성하였다.

---

## 2. 변경 사항

### 2-1. worker/main.py

- **Request/Response 모델 추가:** TriggerCollectRequest, TriggerScoringRequest, CreateJobRequest, CreateBatchJobsRequest, RunPipelineRequest, RunBatchRequest, JobStatusResponse, ApiResponse (Pydantic BaseModel).
- **Health:** 기존 `/api/health` 유지, n8n/로드밸런서용 `GET /health` 추가 (`{"status": "ok", "service": "shortflow-worker"}`).
- **엔드포인트 추가:**
  - `POST /api/v1/trends/collect` — 트렌드 수집 (BackgroundTasks)
  - `POST /api/v1/scoring/run` — 스코어링 준비 상태(키워드/픽 수) 반환
  - `POST /api/v1/jobs/create` — 단일 Job 생성
  - `POST /api/v1/jobs/create-batch` — 당일 pending picks 기준 일괄 Job 생성
  - `POST /api/v1/pipeline/run` — 단일 Job 파이프라인 실행 (백그라운드)
  - `POST /api/v1/pipeline/run-batch` — 대기 Job 일괄 파이프라인 실행 (백그라운드)
  - `GET /api/v1/jobs/{job_id}/status` — Job 상태 조회
  - `GET /api/v1/stats` — 파이프라인 통계 (state_counts 등)

### 2-2. n8n_workflows/daily_production.json (신규)

- **구성:** Schedule Trigger(매일 21:00 UTC = 6AM KST) → Collect Trends → Wait 5분 → Run Scoring → Create Batch Jobs → Run Batch Pipeline → Wait 30분 → Get Stats.
- **Worker URL:** Docker 네트워크 내 `http://worker:8000` (shortflow-net).
- n8n UI에서 Import from File로 불러와 사용.

### 2-3. n8n_workflows/README.md

- daily_production.json 목적, Import 방법, 전제 조건 정리.
- Worker API 엔드포인트 목록 표로 정리.

### 2-4. worker/tests/test_api.py (신규)

- pytest + httpx AsyncClient 사용. 서비스/DB는 mock.
- **테스트 6개:** test_health_check, test_create_job, test_create_batch_jobs, test_get_job_status, test_get_job_status_not_found, test_get_stats.

## 3. 테스트 결과

- `worker/tests/test_api.py`는 pytest 및 pytest-asyncio 설치 후 `cd worker && python -m pytest tests/test_api.py -v` 로 실행 가능.
- 실행 환경 미구비로 인해 실제 pytest 실행은 미수행. 코드 및 mock 구조는 검토 완료.

## 4. 주의사항 / 후속 작업

- **jobs 테이블:** 001 스키마에는 `product_name` 컬럼 없음. 필요 시 마이그레이션으로 추가 후 `Job.save_to_db`에서 저장.
- **n8n Wait 노드:** 5분/30분 대기는 워크플로우 실행 시간을 길게 함. 필요 시 단축 또는 이벤트 기반으로 전환 검토.
- **DEAD_LETTER 알림:** daily_production에는 IF + Slack 노드 미포함. Get Stats 이후 조건 분기 및 Slack 전송은 n8n UI에서 추가 가능.
