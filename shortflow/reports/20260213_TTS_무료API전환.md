# TTS 무료 API 전환

**작성일시:** 2026-02-13  
**작업 유형:** 리팩터링  
**상태:** 완료  
**관련 파일:** worker/services/tts_generator.py, worker/workers/pipeline_worker.py

---

## 1. 작업 개요

ElevenLabs **with-timestamps** 엔드포인트는 유료 플랜에서만 사용 가능한 경우가 있어, **일반 TTS** (`/v1/text-to-speech/{voice_id}`)로 전환하고, 응답은 raw MP3로 저장한다. alignment는 API에서 받지 않고 **오디오 길이 기반 균등 분배**로 자동 생성하도록 변경했다.

---

## 2. 변경 사항

### 2.1 tts_generator.py

- **API 엔드포인트:** `/v1/text-to-speech/{voice_id}/with-timestamps` → `/v1/text-to-speech/{voice_id}` (timestamps 제거).
- **응답 처리:** JSON + base64 디코딩 제거. `response.content`를 그대로 파일에 저장 (raw MP3).
- **균등 분배 alignment:** `_build_even_alignment(audio_path, scene_texts)` 추가.
  - `_get_audio_duration`으로 전체 길이 조회 후, `scene_texts` 기준 전체 문자 수로 균등 분할.
  - 반환 형식: `characters`, `character_start_times_seconds`, `character_end_times_seconds` (TimingEngine 호환).
- **generate:** `scene_texts` 파라미터 추가. TTS 생성 후 `_build_even_alignment(path, scene_texts or [text])`로 alignment 생성하여 반환.
- **generate_with_split:** 청크별 생성 후 concat까지 동일. `_merge_alignments` 대신 `_build_even_alignment(merged_path, scene_texts or chunks)` 사용. `_merge_alignments`는 유지(향후 유료 플랜 전환 시 재사용).

### 2.2 pipeline_worker.py

- **TTS 호출:** `_call_tts_gen`에서 `scene_texts=job.artifacts.scene_texts`를 전달하도록 수정.

## 4. 주의사항 / 후속 작업

- **ElevenLabs:** 402 발생 시 결제 정보 또는 크레딧 확인 후 재시도.
- **균등 분배:** 실제 발화 타이밍과 차이가 있을 수 있음. 유료 플랜 사용 시 `_merge_alignments` 및 with-timestamps API 재적용 가능.
- **scene_texts:** 파이프라인에서 항상 전달되므로, 장문 분할 시에도 최종 alignment는 씬 단위로 균등 분배됨.
