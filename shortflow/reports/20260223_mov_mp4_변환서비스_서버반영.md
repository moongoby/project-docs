### 3.1 Phase 2-5 마무리 검수

| 항목 | 요구 규격 | 확인 방법 |
|------|-----------|-----------|
| 해상도 | 1080x1920 | ffprobe 출력에서 `Video: ... 1080x1920` |
| 비디오 코덱 | H.264 (libx264) | ffprobe `Video: ... h264` |
| 오디오 코덱 | AAC | ffprobe `Audio: ... aac` |
| FPS | 29.97 | ffprobe 또는 스트림 메타 |
| 최대 길이 | 60초 이내 | ffprobe `Duration:` |

- **ffprobe 검수 결과 (샘플 1건):** 서버에서 변환된 MP4 1건에 대해 `ffprobe -v quiet -print_format json -show_format -show_streams` 실행 결과 반영.
  - **검증 파일:** `IMG_3043.mp4` (경로: `chicblack/20260122/`)
  - **비디오:** codec_name=h264, 1080×1920, r_frame_rate=2997/100 (≈29.97 fps), duration≈8.51초, bit_rate=4,743,370
  - **오디오:** codec_name=aac, sample_rate=44100, channels=2, bit_rate=127,904
  - **포맷:** duration=8.544초, bit_rate=4,861,500
  - **참조 보고서:** [Phase 2 마무리 ffprobe 상세](20260223_phase2_마무리_검수.md), [Phase 3-3 쿠팡약관 ffprobe 검수](20260223_phase3-3_쿠팡약관_ffprobe검수.md)
- **변환 건수:** 성공 / 스킵 / 실패 — 변환 스크립트 요약 출력 또는 `find /data/styleflow/output/ -name "*.mp4" | wc -l` 결과 기재.
- **crontab 등록:** `crontab -l \| grep convert` 결과 등록 여부 확인.
