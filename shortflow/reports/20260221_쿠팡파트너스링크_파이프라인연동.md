## 1. 작업 개요

쿠팡 파트너스 제휴 링크를 daily_picks에 저장하고, YouTube 업로드 시 설명란에 구매 링크 블록을 자동으로 붙이도록 파이프라인을 연동했다.  
또한 API 승인 후 사용할 수 있도록 쿠팡 파트너스 Open API 기반 서비스 모듈과 .env 플레이스홀더를 추가했다.

---

## 2. 변경 사항

### 2단계: Supabase daily_picks 테이블

- **마이그레이션:** `sql/002_daily_picks_coupang_url.sql`  
  - `daily_picks` 테이블에 `coupang_url TEXT` 컬럼 추가 (IF NOT EXISTS).
- **적용 방법:** Supabase 대시보드 → SQL Editor에서 해당 파일 내용 실행.

### 3단계: 파이프라인 코드

- **youtube_uploader.py**
  - `_append_coupang_block(description, coupang_url)` 추가:  
    `coupang_url`이 있으면 설명 하단에  
    `---\n🛒 구매 링크: {url}\n\n※ 이 포스팅은 쿠팡 파트너스 활동의 일환으로...\n---` 블록 추가.
  - `upload_video(..., coupang_url=None)` 인자 추가;  
    `coupang_url`이 비어 있으면 블록 미추가.

- **pipeline_worker.py**
  - `job.artifacts`에 `coupang_url`, `product_name` 반영 (스크립트 단계에서 daily_picks 로드 시 설정).
  - 업로드 단계:  
    - 제목 형식: `{상품명} | {channel_name}` (기본 채널명 `오늘의쇼핑픽`).  
    - 기본 태그: `쇼핑`, `추천`, `핫딜`, `오늘의쇼핑픽` 항상 포함 후 스크립트 태그 병합.  
    - `upload_video(..., coupang_url=job.artifacts.coupang_url)` 로 전달.

- **state_machine.py (JobArtifacts)**
  - `coupang_url`, `product_name` 필드 추가; `to_dict` / `from_dict` 반영.

- **script_generator.py**
  - `load_product_from_pick()` 반환 `product_info`에 `coupang_url` 포함 (daily_picks 조회 시).

- **config.py**
  - `channel_name: str = "오늘의쇼핑픽"` 추가.

- **.env.example**
  - `CHANNEL_NAME=오늘의쇼핑픽`  
  - `COUPANG_ACCESS_KEY=`, `COUPANG_SECRET_KEY=` 플레이스홀더 추가.

### 4단계: API 자동화 대비

- **worker/services/coupang_partners.py** 신규 생성
  - `has_api_credentials()`: API 키 설정 여부.
  - `search_products(keyword, limit)`: 쿠팡 파트너스 Open API 상품 검색 (HMAC 인증).
  - `get_affiliate_url_for_product(product_name)`: API로 검색 후 첫 상품 제휴 URL 반환.
  - `resolve_coupang_url(product_name, manual_url)`:  
    API 키 있으면 API 결과 사용, 없으면 `manual_url`(수동 입력/DB) 사용.

- **.env**
  - `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` 없으면 수동 링크만 사용;  
    있으면 추후 파이프라인에서 `resolve_coupang_url` 등으로 자동 생성 전환 가능.

### 1단계: 쿠팡 링크 수집 (수동 + 스크립트 보조)

- 브라우저 자동화는 쿠팡 파트너스 **로그인**이 필요해, 현재 환경에서는 로그인 페이지로 리다이렉트됨.
- **수동 절차:**
  1. https://partners.coupang.com/#affiliate/ws/link 에 로그인된 상태로 접속.
  2. Supabase `daily_picks`의 상품명(또는 제공된 6종)으로 각각 검색 후 제휴 링크 생성.
  3. 생성된 링크를 `data/coupang_links.json`에 `[{"pick_id": 1, "coupang_url": "https://..."}, ...]` 형식으로 저장.
- **스크립트:** `scripts/coupang_links_update.py`
  - `python scripts/coupang_links_update.py list [--limit 6]`:  
    업데이트 대상 pick 목록(id, product_name) 출력 및 JSON 예시 출력.
  - `python scripts/coupang_links_update.py update [--file data/coupang_links.json]`:  
    JSON 파일 기준으로 `daily_picks.coupang_url` 일괄 업데이트.
- 실행 위치: 프로젝트 루트 `/data/shortflow`. `.env`에 Supabase 설정 필요.

## 4. 주의사항 / 후속 작업

- **Supabase:** `002_daily_picks_coupang_url.sql` 반드시 실행 후 사용.
- **1단계:** 로그인된 브라우저에서 수동으로 6개 상품 링크 생성 → `data/coupang_links.json` 작성 →  
  `python scripts/coupang_links_update.py update` 실행.
- **API 전환:** 쿠팡 파트너스 Open API 승인 후 `.env`에 `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` 설정하고  
  파이프라인에서 `coupang_partners.resolve_coupang_url(product_name, manual_url)` 사용 시  
  키 있으면 API 자동 생성, 없으면 수동 링크 사용하도록 연동 가능.
- **채널명:** `.env`에 `CHANNEL_NAME=오늘의쇼핑픽` 추가 시 업로드 제목에 반영됨.
