1. GitHub.com 로그인
2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
3. Repository access: `moongoby/shortflow`, `moongoby/project-docs`
4. Permissions: Contents → Read and Write
5. 토큰 발급 후 아래 실행:

