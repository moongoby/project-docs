## 1. 작업 개요

ShortFlow 핵심 엔진인 FFmpeg 합성 모듈을 설계서대로 구현하였다. 이미지 + 나레이션 + 자막 + BGM을 합성해 YouTube Shorts용 1080x1920 영상을 생성하며, Ken Burns 효과·ASS 자막·CTA 오버레이·썸네일 추출까지 한 번에 수행한다.

## 2. 변경 사항

### 2.1 데이터 모델 (Pydantic v2)

- **MotionEffect** / **TransitionType**: Enum (zoom_in, zoom_out, pan, fade 등)
- **VideoConfig**: width/height 1080x1920, fps 30, codec/preset/crf/threads, BGM 볼륨 등 (config.settings 연동)
- **SceneAsset**: scene_number, image_path, narration_text, duration, start_time, motion_effect, transition
- **SubtitleWord**: word, start, end, is_keyword
- **CompositionPlan**: scenes, subtitle_words, narration_path, bgm_path(optional), title, cta_text, output_filename, pick_id(optional)
- **CompositionResult**: video_path, thumbnail_path, duration, file_size_mb, scene_count

### 2.2 TimingEngine

- ElevenLabs character-level alignment → word-level **SubtitleWord** 리스트 생성
- 단어별 **keyword_markers** 매칭으로 is_keyword 설정 (최저가, 할인, 무료배송 등)
- scenes_text 순서대로 씬별 duration·start_time 계산, 씬 사이 0.3초 페이드 반영

### 2.3 KenBurnsGenerator

- FFmpeg **zoompan** 필터로 이미지 → 비디오 클립 생성
- 효과별 z/x/y 표현식: ZOOM_IN, ZOOM_OUT, PAN_LEFT/RIGHT/UP/DOWN, ZOOM_IN_PAN_RIGHT, ZOOM_OUT_PAN_LEFT, STATIC
- 입력 이미지 scale+pad로 1080x1920 맞춤 후 zoompan 적용

### 2.4 SubtitleGenerator

- **ASS** 파일 생성: [Script Info], [V4+ Styles] (Default, Keyword), [Events] Dialogue
- Noto Sans CJK KR, 42pt, 키워드 노란색+Bold, 하단 margin 180, \fad(150,100)
- 한 줄 12자·최대 2줄 줄바꿈

### 2.5 VideoComposer

- **compose(plan)** (async):  
  1) 씬별 Ken Burns 클립 병렬 생성 (asyncio.gather)  
  2) concat demuxer로 클립 연결  
  3) 나레이션 + BGM(선택) amix  
  4) ASS 자막 하드코딩  
  5) CTA 텍스트 오버레이 (마지막 3초, drawtext), 실패 시 복사만  
  6) 3초 구간 썸네일 추출  
  7) 임시 파일 정리
- **_run_ffmpeg**: subprocess.run, timeout 300초, stderr 로깅, returncode != 0 시 ComposerError
- **_get_duration** / **_get_file_size_mb**: ffprobe 및 os.path.getsize
- **_load_config_from_settings**: settings.render_preset, render_crf, render_threads 연동
- 출력: `data_path/videos/{날짜}_{pick_id}_video.mp4`, 썸네일 `thumbnails/{날짜}_{pick_id}_thumb.jpg`
- 임시 디렉터리: `data_path/temp/{uuid}/`

### 2.6 예외 및 테스트

- **core/exceptions.py**: ShortFlowError, ComposerError
- **test_ffmpeg_composer.py**: VideoConfig/SceneAsset/CompositionPlan/SubtitleWord 검증, TimingEngine 키워드·빈 입력, Ken Burns 효과별 파라미터, ASS 형식, _run_ffmpeg/_get_duration/_get_file_size_mb 동작 및 에러 케이스. FFmpeg 미설치 시 해당 테스트 skip

## 4. 주의사항 / 후속 작업

- CTA drawtext 폰트 경로는 Noto CJK 기준으로 설정됨. Dockerfile에 fonts-noto-cjk 포함되어 있음.
- 씬이 여러 개일 때 현재는 concat demuxer만 사용 (xfade 필터 체인은 미적용). 필요 시 filter_complex로 xfade 체인 추가 가능.
- Phase 3: script_generator / image_generator / tts_generator 연동 후 end-to-end 파이프라인에서 compose() 호출 검증 권장.
