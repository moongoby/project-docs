# ShortFlow 관리 대시보드 전면 개편

**작성일시:** 2026-02-13
**작업 유형:** 신규 개발
**상태:** 완료
**관련 파일:** `dashboard/app.py`, `dashboard/db.py`, `dashboard/api.py`, `dashboard/requirements.txt`, `docker-compose.yml`

---

## 1. 작업 개요

Streamlit 기반 ShortFlow 관리 대시보드를 전면 개편하여, 웹에서 영상/상품/파이프라인 모니터링 및 Job 실행·로그 조회가 가능하도록 5개 페이지(Overview, Products, Videos, Pipeline, Logs)를 구현하였다.

## 2. 변경 사항

### 2.1 대시보드 앱 (dashboard/app.py)

- **페이지 설정:** `page_title="ShortFlow AI Dashboard"`, `page_icon="🎬"`, `layout="wide"`, `initial_sidebar_state="expanded"`, 다크 테마 CSS, 한국어 UI.
- **데이터 경로:** `DATA_PATH`(기본 `/data/shortflow/data`), `VIDEOS_DIR`, `THUMBNAILS_DIR`, `LOGS_DIR` 사용.
- **Overview:** Worker API `get_stats()`로 총 Job 수·성공률·상태별 파이차트, 로컬 영상 디렉터리에서 오늘 생성 영상 수, DB에서 활성 상품 수, 최근 10개 Job 테이블(상품명·소요시간 포함).
- **Products:** `daily_picks` 목록, 카테고리 필터(전체/electronics/beauty/health/fashion/food/baby), 상품별 생성 영상 수, 신규 상품 등록 폼(상품명/URL/가격/커미션/플랫폼/카테고리) → Supabase insert.
- **Videos:** `data/videos` 내 mp4 목록, 썸네일(`data/thumbnails`), 카테고리 필터, 카드형 갤러리, 확장 시 `st.video` 재생 및 다운로드 버튼.
- **Pipeline:** 활성 상품 멀티셀렉트, "Job 생성 + 파이프라인 실행" 시 각 pick에 대해 Worker API `create_job` → `run_pipeline`, 실행 중 Job 목록을 세션에 저장 후 상태 표시·새로고침 안내.
- **Logs:** `DATA_PATH/logs/worker.log` 파일 읽기 표시, 에러만 보기·Job ID 필터. 파일 없을 시 `docker compose logs worker` 안내.

### 2.2 DB·API 모듈

- **dashboard/db.py:** `get_client()`(SUPABASE_URL/SUPABASE_KEY), `get_all_jobs()`, `get_all_picks()`, `get_videos()` 구현. Supabase 미연결 시 빈 결과 반환.
- **dashboard/api.py:** `WORKER_URL`(기본 `http://worker:8000`), `create_job(pick_id)`, `run_pipeline(job_id)`, `get_job_status(job_id)`, `get_stats()` 구현.

### 2.3 의존성·컨테이너

- **dashboard/requirements.txt:** `plotly>=5.18.0`, `requests>=2.31.0` 추가.
- **docker-compose.yml:** dashboard 서비스에 `environment`(SUPABASE_URL, SUPABASE_KEY, WORKER_URL, DATA_PATH), `volumes`(`/data/shortflow/data:/data/shortflow/data:ro`) 반영.

## 3. 테스트 결과

- `docker compose build dashboard` 성공.
- `docker compose up -d` 후 `curl -sf http://localhost:8501 | head -20` 로 Streamlit HTML 수신 확인.
- 대시보드 접속 URL: `http://114.207.244.86:8501` (호스트 포트 8501).

## 4. 주의사항 / 후속 작업

- Worker API(`/api/v1/jobs/create`, `/api/v1/pipeline/run`, `/api/v1/jobs/{id}/status`, `/api/v1/stats`)가 실제 worker 서비스와 일치하는지 배포 환경에서 확인 필요.
- 로그는 worker가 파일로 출력할 때만 Logs 페이지에서 표시됨. stdout만 사용 시 `docker compose logs worker` 사용 안내만 노출됨.
- Pipeline 실행 중 상태 갱신은 사용자가 "새로고침" 또는 페이지 재진입으로 수행.
