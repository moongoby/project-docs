## 4. STEP 2–3: v2 파이프라인 구현 내역

### 4-1. AI 이미지 배경 생성

- **API:** `google-genai` (`from google import genai`), 모델 `imagen-4.0-generate-001`.
- **환경:** `GEMINI_API_KEY` 또는 `GOOGLE_AI_API_KEY` / `GOOGLE_API_KEY`.  
  **주의:** `google-genai` 패키지는 **Python 3.10+** 필요. 기본 venv가 3.8이면 `venv_test/bin/python` (3.11) 사용 권장.
- **프롬프트 규칙:**
  - `"YouTube Shorts background, vertical, high quality, illustration related to {keyword}. No text in image."`
  - 텍스트 포함 금지(자막은 FFmpeg drawtext로 처리).
  - 비율: 9:16 → FFmpeg에서 1080x1920으로 scale/pad.

### 4-2. 폴백(실패 시)

- **fallback_gradient_bg():** 단색 배경(0x1a1a2e) + 키워드 텍스트 drawtext.  
  Imagen 403/실패 시 자동 사용.

### 4-3. FFmpeg 합성 파이프라인(v2)

1. 세그먼트별 이미지(AI 또는 폴백) → `-loop 1 -t duration` 으로 정지 영상화.
2. 각 스트림: `scale=1080:1920:force_original_aspect_ratio=decrease` + `pad=1080:1920:...` → 1080x1920.
3. **자막:** `drawtext=textfile=<세그먼트 텍스트 파일>:fontsize=42:fontcolor=white:x=(w-text_w)/2:y=h*0.75` (한글 폰트 경로 있으면 `fontfile` 지정).
4. 세그먼트 concat → TTS 오디오와 `-shortest` 합성.
5. **규격:** 1080x1920, H.264, AAC 128k, 29.97fps, ≤60초.

## 8. 에러 발생 시 참고

- **403 PERMISSION_DENIED / API key reported as leaked**  
  → .env 의 API 키 교체 후 재실행. 그동안은 폴백만 사용됨.

- **ModuleNotFoundError: No module named 'genai'**  
  → `venv_test/bin/pip install google-genai` 후 `venv_test/bin/python` 으로 실행.

- **drawtext 한글 깨짐**  
  → 서버에 한글 폰트 설치 후 `fontfile` 경로 지정. (예: `/usr/share/fonts/truetype/nanum/NanumGothic.ttf`)
