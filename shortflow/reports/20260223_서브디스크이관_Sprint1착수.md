## 2. 변경 사항

### Step 1–4: 서브 디스크 이관
- **SUBDISK:** `/home/danharoo/www/data/files/goods/goodscode`
- `shortflow`, `styleflow` 디렉토리 생성 후 `cp -a /data/shortflow/*`, `cp -a /data/styleflow/*` 복사.
- `/data/shortflow` → `shortflow_old` 백업 후 `ln -s ${SUBDISK}/shortflow /data/shortflow` (동일하게 styleflow 적용).
- 이관 검증 후 `rm -rf /data/shortflow_old /data/styleflow_old` 실행.
- **결과:** 루트 사용량 636G → 630G, 가용 195G → 201G (77% → 76%).

### Step 5: 기획서·컨텍스트 저장
- `mkdir -p docs sql templates/script_archetypes templates/structural_patterns` 실행.
- **저장 파일:**
  - `docs/shortflow_v3.0_plan.md` – ShortFlow v3.0 기획서 (2-Track, 10-Layer, 상수, 파일 역할)
  - `docs/styleflow_v1.0_plan.md` – StyleFlow v1.0 기획서 (raw/output, DB, 파이프라인)
  - `.cursorrules` – Cursor AI 프로젝트 컨텍스트 (동일 내용 유지)

### Step 6: Sprint 1 – 10-Layer 엔진
- **engine/anti_inauthentic.py:** 기존 오케스트레이터 유지 (VisualVariation + OriginalityScorer 연동).
- **engine/originality_scorer.py:**  
  - `OriginalityInput`, `OriginalityResult` 및 `score(current, recent_layouts=..., recent_scripts=..., ...)` API 추가 (오케스트레이터 호환).  
  - `score_simple(video_path, layer_results)` 유지.
- **engine/visual_variation.py:** 기존 Layer 1 (VisualVariation, get_layout) 유지.
- **동작 확인:** `AntiInauthenticEngine().evaluate(AntiInauthenticInput(...))` → action, originality_score 정상 반환.

## 4. 주의사항 / 후속 작업

- `/data/shortflow`, `/data/styleflow`는 goodscode 볼륨을 가리키는 심볼릭 링크이므로, 해당 경로를 쓰는 모든 프로세스(Docker, cron, 스크립트)는 변경 없이 동일 경로 사용 가능.
- 10-Layer 엔진: Layer 2~6, 8~10은 추후 구현. 로그는 `/data/styleflow/logs/` 사용.
