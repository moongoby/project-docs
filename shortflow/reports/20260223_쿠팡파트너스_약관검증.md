## 1. 작업 개요

ShortFlow SaaS 모델에서 쿠팡 파트너스 링크 사용 시 약관 준수 가능성을 검토하고, 가이드 문서를 보강·정리하였다. .env 쿠팡 키 현황을 확인하고, 권장 운영 방안 및 project-docs 동기화까지 수행하였다.

## 2. 약관 핵심 요약

- **링크 생성·배포:** 파트너스에 등록된 미디어(채널/사이트)에서만 광고 노출 허용. 링크·광고 형태 임의 조작 금지.
- **SaaS/자동화:** 자기 계정·자기 채널에서 도구로 링크 생성·배포는 일반적으로 허용 범위. 제3자 대신 링크 생성·대리 노출은 "등록되지 않은 미디어 노출"로 볼 여지 있어 위험.
- **제3자(B2C SaaS):** 고객 채널에 우리가 대리 업로드·링크 삽입 시 약관 위반 소지. 고객이 자기 채널에 파트너스 등록 후, 고객이 직접 우리 도구로 링크만 생성·본인 채널에 게시하는 구조는 허용 가능성 높음(단, 쿠팡 사전 확인 권장).
- **금지 행위:** 자기/지인 클릭·구매 유도, 허위·과장 광고, 스팸성 배포, 기밀정보 외부 공개.
- **수익 분배:** 유효 클릭/구매 기준 정산. 정산 주기·최소 금액·수수료율은 파트너스 사이트에서 확인.

## 3. SaaS 모델 리스크 분석

| 구분 | 리스크 |
|------|--------|
| 사업자 본인 채널(korea_walker, moongoby)만 운영 | **낮음** – 등록 미디어에서의 정상 활동 |
| 고객 채널에 대리 업로드·링크 삽입 | **높음** – 권장하지 않음 |
| 고객이 직접 업로드(도구만 제공) | **상대적으로 낮음** – 쿠팡 사전 확인 권장 |
| 1인 다수 채널 운영 | **주의** – 채널별 미디어 등록·1인 다수 제한 여부 사전 확인 권장 |

## 4. 권장 운영 방안

- **Phase 1:** 자체 채널만 쿠팡 파트너스 링크 사용. 대리 업로드·제3자 채널 노출 없이 운영.
- **Phase 2:** 고객에게 도구만 제공(API/대시보드). 고객이 자기 채널에 직접 업로드·설명란 입력. 고객 채널 대리 업로드 서비스는 제공하지 않는 것을 권장.
- **필수:** 쿠팡 파트너스 고객센터에 SaaS 모델(고객이 직접 게시하는 구조) 사전 확인 요청.
- **권장:** 통신판매업 신고 후 진행. 전자상거래법·세무 요건은 관할 관청·세무사 확인.
