## 1. 실행 결과 요약

| 단계 | 결과 | 비고 |
|------|------|------|
| 1. 워크플로우 파일 확인 | 성공 | `-rw-r--r-- 1 root root 2941 ... daily_workflow.json` |

## 2. n8n API 인증

- `POST http://localhost:5678/api/v1/workflows` 호출 시 **401** 반환.
- 응답 메시지: `'X-N8N-API-KEY' header required`
- Basic Auth(N8N_AUTH_USER/PASSWORD)만으로는 API 호출 불가. n8n이 **API 키**를 요구하는 설정으로 동작 중.

## 3. 수동 임포트 및 활성화 방법

1. **브라우저:** http://114.207.244.86:5678 접속 후 로그인(N8N_AUTH_USER / N8N_AUTH_PASSWORD).
2. **임포트:** 우측 상단 메뉴(⋮) → **Import from File** → `/data/shortflow/n8n/daily_workflow.json` 선택.
3. **저장:** Save(또는 Ctrl+S).
4. **활성화:** 워크플로우 상단 **Active** 토글을 On.

## 4. API로 임포트하려면 (선택)

- n8n 웹 UI: **Settings** → **API** 에서 API Key 생성.
- 생성한 키를 `.env`에 `N8N_API_KEY=...` 로 추가한 뒤, `import_workflow.sh`에서 `-H "X-N8N-API-KEY: $N8N_API_KEY"` 로 전달하도록 스크립트 수정 가능.

## 5. Worker daily 테스트

    "message": "Daily pipeline started",
    "data": {
