## 2. 변경 사항

### 2.1 Step 0 – 디스크 확인 + 백업

- **디스크:**  
  - `/`: 77% 사용 (634G/875G) → 경고 임계값 85% 미만  
  - `/data/shortflow` 구간은 루트 파티션 사용
- **백업:**  
  - 디렉터리: `/data/shortflow/backups/20260223_184617`  
  - `upload_monitor.sh`, `crontab_backup.txt` 저장

### 2.2 Step 1 – 일일 리포트 스크립트 (`scripts/daily_report.sh`)

- **역할:** 매일 23:30 KST에 `logs/daily_reports/daily_YYYYMMDD.md` 생성  
- **포함 내용:**  
  1. 업로드 현황 (성공/스킵/에러)  
  2. 누적 현황 (`uploaded_videos.json` 기반, 채널별 건수)  
  3. MOV→MP4 변환 (오늘 변환, MP4 총, MOV 잔여)  
  4. NAS 동기화 (오늘 수신)  
  5. 디스크 현황 (`df -h`)  
  6. **디스크 경고:** 루트 사용률 > 85% 시 ⚠️ 문구 출력  
  7. YouTube API 할당량 (일일 10,000 units, 업로드당 1,600, 오늘 사용/잔여 추정)  
  8. crontab 상태 (주석/공백 제외)  
- **crontab:**  
  `30 23 * * * /bin/bash /data/shortflow/scripts/daily_report.sh >> /data/shortflow/logs/maintenance.log 2>&1`

### 2.3 Step 2 – 에러 알림 스크립트 (`scripts/alert_on_error.sh`)

- **역할:** 당일 업로드 로그에서 error/fail/exception/traceback 감지 시 이메일 알림  
- **수신:** moongoby@gmail.com  
- **중복 방지:** `logs/.alert_sent_YYYYMMDD` 플래그로 1일 1회만 발송  
- **발송 방식:**  
  - `mail` 명령 있으면 `mail` 사용  
  - 없으면 `scripts/send_alert_email.py` (Gmail SMTP) 호출  
- **crontab:**  
  `10 9,13,18 * * * /bin/bash /data/shortflow/scripts/alert_on_error.sh >> /data/shortflow/logs/maintenance.log 2>&1`  
  (업로드 09/13/18시 실행 후 10분 뒤 점검)

### 2.4 Step 3 – Python 이메일 알림 (`scripts/send_alert_email.py`)

- **역할:** Gmail SMTP(smtplib)로 제목·본문 발송  
- **환경 변수:**  
  - `ALERT_EMAIL_FROM`, `ALERT_EMAIL_TO` (기본: moongoby@gmail.com)  
  - `ALERT_EMAIL_PASSWORD`: Gmail 앱 비밀번호(2단계 인증 후 발급)  
- **사용:**  
  - `alert_on_error.sh`에서 `mail` 없을 때 자동 호출  
  - 수동 테스트:  
    `python3 scripts/send_alert_email.py "제목" "본문"`  
- **.env.example 추가:**  
  - `ALERT_EMAIL_FROM`, `ALERT_EMAIL_TO`, `ALERT_EMAIL_PASSWORD` 주석 설명

### 2.5 Step 4 – crontab 등록

- **추가된 라인:**  
  - `30 23 * * *` → `daily_report.sh`  
  - `10 9,13,18 * * *` → `alert_on_error.sh`  
- **중복 방지:** 기존 crontab에 동일 항목 없을 때만 추가 후 `crontab` 적용  
- **검증:** `crontab -l` 출력에 위 두 라인 포함 확인
