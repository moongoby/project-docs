## 1. 작업 개요

Phase 3-4 검수 결과에 따라 치명적·중요·경미 이슈를 반영하여 6개 파일을 수정하였다. with_retry 적용 범위 조정, mock 활성화 시점 통일, 쿼터/전이/리소스/파일명 등 런타임 오동작을 제거했다.

---

## 2. 변경 사항

### 2-1. worker/core/retry_engine.py
- **미사용 import 제거**: `import logging` 삭제 (logger는 utils.logger 사용).

### 2-2. worker/core/state_machine.py
- **VALID_TRANSITIONS**: `JobState.QA_PENDING`에서 `JobState.UPLOADING` 제거 → QA 필수 흐름 유지.  
  변경 후: `JobState.QA_PENDING: [JobState.QA_APPROVED, JobState.FAILED]`
- **supabase 동기 호출 주석**: `save_to_db`, `load_from_db`, `get_pending_jobs` docstring에  
  `NOTE: supabase-py is synchronous; wrap in run_in_executor for true async (Phase 11)` 추가.

### 2-3. worker/services/script_generator.py
- **generate()**: `AsyncAnthropic` 클라이언트를 for 루프 밖에서 1회 생성, `async with AsyncAnthropic(...) as client:` 로 감싸 커넥션 재사용 및 정리.
- **_save_to_db → save_to_db**: 메서드명을 public으로 변경. pipeline_worker에서 `script_gen.save_to_db` 호출로 통일.

### 2-4. worker/services/image_generator.py
- **generate_batch 내부 one()**: except 블록에서 빈 파일(0바이트 PNG) 생성 제거. 실패 시 예외를 그대로 전파하여 파이프라인에서 FAILED/재시도 처리.

### 2-5. worker/services/tts_generator.py
- **generate()**: `chunk_index: Optional[int] = None` 파라미터 추가.  
  파일명: `suffix = f"_chunk{chunk_index}" if chunk_index is not None else ""`,  
  `filename = f"{today}_{pick_id}_narration{suffix}.mp3"` 로 청크별 파일 충돌 방지.
- **generate_with_split()**: `await self.generate(chunk, pick_id, chunk_index=i)` 로 호출.

### 2-6. worker/workers/pipeline_worker.py
- **with_retry 적용 위치**: step 메서드 전체가 아닌 API 호출만 데코레이터 적용.
  - `_step_generate_script`: 상태 가드 후 `_call_script_gen(job)` 호출. `@with_retry("claude")` → `_call_script_gen`.
  - `_step_generate_images`: 동일 패턴, `_call_image_gen(job)` + `@with_retry("dalle")`.
  - `_step_generate_tts`: `_call_tts_gen(job)` + `@with_retry("elevenlabs")`.
  - `_step_compose_video`: `_call_compose(plan)` + `@with_retry("ffmpeg")`.
  - `_step_upload`: `_call_upload(job)` + `@with_retry("youtube_upload")`.
- **상태 가드**: 각 step에서 `if job.state != TargetState:` 일 때만 `transition_to` 및 `save_to_db` 호출하여 재시도 시 중복 전이 방지.
- **run_batch**: `for job in jobs: async with semaphore: await process_job` 순차 실행 제거.  
  `_run_one(job)` 람다로 `asyncio.gather(*[_run_one(j) for j in jobs])` 사용해 실제 동시 실행.
- **_step_generate_clips**: docstring에 "Timing is computed in _step_compose_video; this step validates readiness only" 명시.
- **script_gen._save_to_db** → **script_gen.save_to_db**.
- **RetryContext** import 제거 (미사용).

### 2-7. worker/tests/test_pipeline.py
- **단일 with 블록**: 모든 서비스 mock을 하나의 `with (patch(...), patch(...), ...):` 안에 두고, 그 안에서 `worker = PipelineWorker()` 생성 후 `process_job`/`run_batch` 호출.  
  Python 3.10+ parenthesized context managers 사용.
- **TimingEngine mock 추가**: `process_timestamps` 반환값 `([], [5.0, 5.0], [0.0, 5.0])` 등 설정.
- **_save_to_db → save_to_db**: MockSG.return_value.save_to_db, step 테스트의 script_gen.save_to_db 로 변경.
