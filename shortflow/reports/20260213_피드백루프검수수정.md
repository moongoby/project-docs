## 1. 작업 개요

Phase 8 피드백 루프 엔진 검수 결과에 따라 json import 중복 제거, 당일 이미 수집한 영상 건너뛰기 로직 추가, _calculate_weight_adjustments docstring 보완을 반영하였다.

---

## 2. 변경 사항

### 2-1. feedback_engine.py — import json 중복 제거 (경미)

- **문제:** collect_performance 내부에서 `import json as json_mod` 후 `json_mod.loads` 사용. 파일 상단에 이미 `import json` 있음.
- **수정:** 내부 import 제거, `json.loads(channels_json)` 로 통일.

### 2-2. feedback_engine.py — 이미 수집한 영상 건너뛰기 (중요)

- **문제:** run_feedback_loop에서 매번 COMPLETED job 전체를 대상으로 성과 수집. 이미 수집한 영상도 반복 수집되어 API 비용·중복 데이터 증가.
- **수정:** video_items 구성 후, collect_batch 호출 전에 video_analytics에서 당일(collected_at >= date.today()) 수집된 video_id 목록 조회 후 video_items에서 제외. 조회 실패 시 경고 로그만 남기고 전체 수집 진행.

### 2-3. feedback_engine.py — _calculate_weight_adjustments docstring 보완

- **문제:** adjustment 델타를 그대로 적용하면 가중치 합이 1.0을 벗어날 수 있음. 향후 ProductScorer 자동 적용 시 정규화 필요.
- **수정:** docstring 끝에 NOTE 추가. "Adjustments are deltas only. When applying to ProductScorer, normalize all weights to sum=1.0 after adding deltas."

## 3. 테스트 결과

## 4. 주의사항 / 후속 작업

- **당일 기준:** "이미 수집"은 collected_at >= date.today() 기준. 자정 경계·타임존은 서버 기준 적용.
- **가중치 적용:** weight_adjustments를 ProductScorer에 반영할 때 델타 적용 후 합 1.0으로 정규화 필요.
