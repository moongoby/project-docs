# Veo 파이프라인 통합 + 전체 쇼츠 생성 테스트

**작성일시:** 2026-02-13
**작업 유형:** 신규 개발 / 통합
**상태:** 완료
**관련 파일:** `worker/services/ffmpeg_composer.py`, `worker/services/script_generator.py`, `worker/workers/pipeline_worker.py`, `worker/config.py`, `worker/services/video_generator.py`, `worker/core/state_machine.py`

---

## 1. 작업 개요

Veo 3.1 Fast 씬 영상 생성을 파이프라인에 통합하고, 일일 비용 한도(VEO_DAILY_LIMIT)와 ffmpeg fallback을 적용하였다. 스크립트에는 이미지용 `image_prompt`와 Veo용 `visual_prompt`를 구분해 요청하도록 반영하였다.

## 2. 변경 사항

### 2.1 ffmpeg_composer.py

- **SceneAsset:** `visual_prompt: Optional[str] = None` 추가.
- **클립 생성 분기:** `video_provider == "veo"` 이고 `can_use_veo()` 일 때만 Veo 사용.
  - 씬별로 `generate_scene_video(image_path, scene.visual_prompt or 기본 프롬프트, aspect_ratio="9:16")` 호출 후, `_fit_veo_clip_to_duration(raw_path, scene.duration, out_path)` 로 TTS 길이에 맞춤.
- **trim/speed:**  
  - 나레이션 < 8초: Veo 클립을 해당 길이로 trim.  
  - 나레이션 > 8초: `setpts` 로 8초 클립을 목표 길이로 늘림(slow-mo).
- **fallback:** Veo 실패(API 오류·한도 등) 시 해당 씬만 Ken Burns로 생성.
- **헬퍼:** `_can_use_veo()`, `_fit_veo_clip_to_duration()` 추가.

### 2.2 script_generator.py

- **SceneSchema:** `image_prompt: Optional[str] = None` 추가(스틸 이미지용), `visual_prompt`는 Veo용(시네마틱, 카메라 움직임, 9:16)으로 유지.
- **시스템 프롬프트:** JSON 예시에 `image_prompt`, `visual_prompt` 모두 포함.  
  - image_prompt: DALL-E/Imagen용 스틸.  
  - visual_prompt: Veo 이미지→영상용, cinematic, camera movement 등 명시.

### 2.3 pipeline_worker.py / state_machine

- **JobArtifacts:** `image_prompts: list[str]` 추가.  
  - 스크립트 단계에서 `image_prompts = [s.image_prompt or s.visual_prompt for s in script.scenes]`,  
  - `visual_prompts = [s.visual_prompt for s in script.scenes]` 유지.
- **이미지 생성:** `_call_image_gen`에서 `image_prompts` 우선 사용, 없으면 `visual_prompts` 사용.
- **Compose:** `SceneAsset` 생성 시 `visual_prompt=job.artifacts.visual_prompts[i]` 전달.

### 2.4 config.py

- **veo_daily_limit:** `veo_daily_limit: int = 10` 추가 (.env: `VEO_DAILY_LIMIT`).

### 2.5 video_generator.py

- **일일 한도:** `data/temp/veo_daily_count.txt`에 날짜별 사용 횟수 기록.  
  - `can_use_veo()`: API 키 존재 + 오늘 사용량 < veo_daily_limit.  
  - `increment_veo_usage()`: 호출 후 카운트 증가 및 로그.
- **로그:** `[VEO COST] $1.20 per clip, today: N/10 used` 형식으로 기록.
- **한도 초과:** `generate_scene_video` 진입 전 `can_use_veo()` 검사; False면 composer에서 Veo를 시도하지 않고 Ken Burns만 사용.

## 3. 설정 (.env)

```env
VIDEO_PROVIDER=veo
VEO_DAILY_LIMIT=10
```

기본값은 `video_provider=ffmpeg`, `veo_daily_limit=10`.

## 4. 테스트 방법

```bash
cd /data/shortflow
docker compose down
docker compose build worker
docker compose up -d
sleep 10

# pick_id=2 (달바 뷰티) 로 Veo 전체 테스트
JOB_RESP=$(curl -sf -X POST http://localhost:8000/api/v1/jobs/create \
  -H "Content-Type: application/json" \
  -d '{"pick_id": 2}')
echo "$JOB_RESP" | python3 -m json.tool
JOB_ID=$(echo "$JOB_RESP" | python3 -c "import sys,json; print(json.load(sys.stdin).get('job_id',''))")

# 파이프라인 실행 (Veo 5씬 생성에 약 5분 소요 예상)
curl -sf -X POST http://localhost:8000/api/v1/pipeline/run \
  -H "Content-Type: application/json" \
  -d "{\"job_id\": \"$JOB_ID\"}" | python3 -m json.tool

# 상태 확인 (대기 후)
sleep 360
curl -sf "http://localhost:8000/api/v1/jobs/$JOB_ID/status" | python3 -m json.tool
docker compose logs worker --tail 120
find data/ -type f -name "*.mp4" -newer docker-compose.yml 2>/dev/null | head -20
```

## 5. 주의사항 / 후속 작업

- Veo 1클립당 약 $1.20 (720p 8초 Fast). 일일 한도로 비용 제한.
- worker 실행 디렉터리에서 `services.video_generator` import 가능해야 함 (Docker 이미지 내 경로 기준).
- 스크립트 스키마에 `image_prompt`가 없던 기존 DB/캐시는 `visual_prompt`만으로 동작 (image_prompts 비어 있으면 visual_prompts 사용).
