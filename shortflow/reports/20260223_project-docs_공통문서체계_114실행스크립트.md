# project-docs 공통 문서 체계 구축 (114 서버 실행 스크립트)

**작성일시:** 2026-02-23
**작업 유형:** 설정 변경
**상태:** 완료
**관련 파일:** `/data/project-docs/setup_full.sh`, `common/*.md`, `scripts/new_project.sh`, `ONBOARDING.md`, `README.md`

---

## 1. 작업 개요

114 서버에서 실행할 project-docs 전체 설정 명령을 하나의 스크립트로 정리하고, 문법 오류를 수정한 뒤 실제로 실행하여 공통 문서 체계를 구축·push까지 완료하였다.

## 2. 변경 사항

### 2.1 생성·수정된 항목 (project-docs)

| 항목 | 설명 |
|------|------|
| `ONBOARDING.md` | 새 대화/신규 프로젝트 온보딩, 등록 프로젝트 표, 공통 템플릿 링크, 사용법 |
| `common/CONTEXT_TEMPLATE.md` | 프로젝트 CONTEXT 작성 템플릿 |
| `common/CURSORRULES_TEMPLATE.md` | Cursor Rules 템플릿 |
| `common/HANDOVER_TEMPLATE.md` | 인계서 템플릿 |
| `common/REPORT_TEMPLATE.md` | 보고서 템플릿 |
| `common/GIT_CONVENTION.md` | Git 커밋/브랜치 규칙 |
| `common/SECURITY_RULES.md` | .env·키·코드 보안 규칙 |
| `common/SYNC_GUIDE.md` | 로컬/원격 서버 동기화 스크립트 예시 및 등록 스크립트 표 |
| `scripts/new_project.sh` | 신규 프로젝트 문서 구조 자동 생성 (폴더명, 설명 인자) |
| `README.md` | 등록 프로젝트·공통 문서 표, 새 대화 시작법, 신규 프로젝트 추가 명령 |
| `setup_full.sh` | 위 전체를 한 번에 적용하는 114 서버용 실행 스크립트 |

### 2.2 스크립트 수정 사항 (원본 명령 대비)

- **`new_project.sh`**: `BASE`, `FOLDER`, `DESC` 변수 사용처를 `${BASE}`, `${FOLDER}`, `${DESC}`로 통일. `mkdir`/`cp` 경로 보정.
- **`SYNC_GUIDE.md`**: 로컬 서버용·원격 서버(NAS)용 코드 블록을 하나의 문서로 통합. 중간에 끼어 있던 "Copy" 문구 제거.
- **Git**: 변경 없으면 커밋 생략, push 실패 시 메시지로 안내하도록 처리.

## 3. 테스트 결과

- `bash /data/project-docs/setup_full.sh` 실행 성공.
- 로컬 커밋 생성: `[config] 공통 문서 체계 구축: ONBOARDING, 7개 공통 템플릿, 신규 프로젝트 스크립트, README 전면 갱신`
- 원격에 선행 커밋 존재로 1차 push 거부 → `git pull --rebase origin master` 후 `git push origin master` 성공.
