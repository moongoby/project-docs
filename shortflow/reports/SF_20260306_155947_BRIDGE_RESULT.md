**`generate_script()` 변경 후:**
```python
def generate_script(channel: str):  # Optional[dict]
    """LLM 대본 생성 (SF-T010: hook_presets 기반 hooks/cta/loop_ending 주입)"""
    subjects = DEFAULT_SUBJECTS.get(channel, DEFAULT_SUBJECTS["economy"])
    subject = random.choice(subjects)
    log(f"대본 생성 주제: {subject}")

    # SF-T010: hook_presets 로드 후 채널별 preset 선택
    presets = _load_hook_presets()
    preset = presets.get(channel, {})
    if preset:
        log(f"hook_presets 로드 완료: {channel} (hooks={len(preset.get('hooks', []))}, cta={len(preset.get('cta', []))})")

    channel_config = {
        "channel_name": CHANNEL_NAMES.get(channel, channel),
        "channel_id": channel,
        "topic": subject,
    }
    try:
        from engine.llm_script_engine import LLMScriptEngine
        engine = LLMScriptEngine()
        result = engine.generate(channel_config=channel_config, subject=subject)
        if result and (result.get("hook") or result.get("script")):
            return result
        log("LLM 대본 생성 실패 (결과 없음)")
        return None
    except Exception as e:
        log(f"LLM 대본 생성 오류: {e}")
        return None
```

**주요 변경점:**
- `_load_hook_presets()` 함수 추가
- `channel_id` 필드를 `channel_config`에 포함 (llm_script_engine이 preset 조회에 사용)
- hook_presets 로드 성공 시 로그 출력
- 결과 판정: `result.get("hook") or result.get("script")` (신규 4키 구조 대응)
