## 3. 점수 체계 (100점 만점)

### A. 훅 품질 (25점)

| 항목 | 배점 | 측정 방법 |
|------|------|-----------|
| 음성 시작 시점 ≤ 0.5초 | 10점 | ffmpeg silencedetect |
| 첫 자막 출현 ≤ 0.3초 | 5점 | SRT/ASS 파싱 (v4 burn-in → 기본 부여) |
| 로고/인트로 없음 | 5점 | ffmpeg scdet 필터 정적 프레임 감지 |
| 훅 패턴 매치 (Bold Claim / Curiosity Gap / Direct Question) | 5점 | 정규식 매칭 |

### B. 영상 기술 (25점)

| 항목 | 배점 | 측정 방법 |
|------|------|-----------|
| 해상도 1080×1920 | 5점 | ffprobe |
| 오디오 LUFS -16~-12 | 5점 | ffmpeg ebur128 + loudnorm |
| 자막 규격 준수 | 5점 | v4 기본 스펙 준수 → 자동 부여 |
| 장면 전환 간격 ≤2초 | 5점 | ffmpeg scdet 타임스탬프 분석 |
| 영상 길이 15~60초 | 5점 | ffprobe duration |

### C. 스크립트 품질 (25점)

| 항목 | 배점 | 측정 방법 |
|------|------|-----------|
| Gemini originality score ≥ 70 | 10점 | LLM self-eval (gemini-2.5-flash) |
| 이전 영상 대비 유사도 < 0.85 | 10점 | TF-IDF 코사인 유사도 |
| CTA 문구 포함 ("구독", "좋아요", "다음 영상") | 5점 | 텍스트 포함 여부 |

### D. 메타데이터 (25점)

| 항목 | 배점 | 측정 방법 |
|------|------|-----------|
| 제목 15~25자 + 감정 트리거 키워드 | 10점 | 길이 체크 (5점) + 키워드 매칭 (5점) |
| 해시태그 5~8개 | 5점 | tags 배열 길이 |
| 설명 200자 이상 | 5점 | description 길이 |
| 썸네일 텍스트 (향후) | 5점 | 현재 자동 부여 |

## 5. 파이프라인 통합 (run_v4_pipeline.py)

FFmpeg 합성 완료 후 → QA 단계 → 업로드 순서:

```
[대본생성] → [FFmpeg합성] → [해상도검증] → [QA스코어산출] → [privacy결정] → [YouTube업로드]
```

새로 추가된 함수:
- `run_qa_score(video_path, script_data, channel)` — 스코어 산출 + logs/qa_scores.json 기록
- `decide_privacy(qa_result)` — privacy_status 반환
- `upload_with_privacy(video_path, channel, privacy_status)` — privacy_status 파라미터 지원 업로드
