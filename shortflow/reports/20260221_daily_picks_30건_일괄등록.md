# daily_picks 30건 일괄 등록 (스크립트·SQL)

**작성일시:** 2026-02-21
**작업 유형:** 신규 개발 / 설정 변경
**상태:** 완료
**관련 파일:** `scripts/seed_daily_picks_30.py`, `sql/seed_daily_picks_30_products.sql`

---

## 1. 작업 개요

제공된 30개 상품(뷰티 8, 식품 7, 패션 5, 건강 4, 생활 3, 육아 3)을 Supabase `daily_picks` 테이블에 일괄 등록하기 위해 Python 스크립트와 SQL 시드 파일을 추가했다.

## 2. 변경 사항

- **scripts/seed_daily_picks_30.py**
  - `.env`에서 `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`(또는 `SUPABASE_KEY`) 로드 후 `daily_picks`에 30건 insert.
  - 실행: 프로젝트 루트에서 `pip install -r worker/requirements.txt` 후 `python3 scripts/seed_daily_picks_30.py`.
- **sql/seed_daily_picks_30_products.sql**
  - 동일 30건을 `INSERT INTO daily_picks (product_name, category, price, video_mode, coupang_url)` 형태로 작성.
  - Supabase Dashboard → SQL Editor에서 실행 가능.
- 전 상품 `video_mode = 'ai_generate'`, `coupang_url`은 NULL(나중에 쿠팡 링크 등록 가능).

## 3. 테스트 결과

- 로컬에서 `supabase` 패키지 미설치로 Python 스크립트 실행은 미실행. SQL 파일은 스키마(002·004 적용) 전제로 작성되어 Supabase SQL Editor 실행 시 30건 등록 가능.

## 4. 주의사항 / 후속 작업

- SQL 실행 전 `coupang_url`, `video_mode` 컬럼이 있어야 함 → `002_daily_picks_coupang_url.sql`, `add_daily_picks_video_source_columns.sql`(또는 004) 선행 적용.
- 쿠팡 제휴 링크는 추후 `scripts/coupang_links_update.py` 또는 대시보드에서 `coupang_url` 업데이트 가능.
