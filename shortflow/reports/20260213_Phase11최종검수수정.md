## 3. 빌드 테스트 결과

- **환경:** 현재 실행 환경에 Docker 미설치로 `docker compose build` 미실행.
- **권장:** 배포 서버 또는 로컬에서 아래로 빌드·기동 확인 후 사용.

```bash
cd /data/shortflow
docker compose build
docker compose up -d
curl -f http://localhost:8000/health
```

## 4. 주의사항

- worker/dashboard는 이제 각각 **context: ./worker**, **context: ./dashboard** 이므로, 해당 디렉터리 내에 Dockerfile과 requirements.txt가 있어야 함.
- **PYTHONPATH** 설정으로 `from config import settings`, `from main import app` 등이 컨테이너 내에서 정상 동작하도록 맞춤.
- n8n 비밀번호는 `.env`의 `N8N_AUTH_PASSWORD` 또는 기본값 `shortflow` 사용. `.env.example`에는 `N8N_AUTH_PASSWORD=changeme` 추가됨.
