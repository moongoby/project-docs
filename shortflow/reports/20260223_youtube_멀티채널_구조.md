# YouTube 멀티채널 구조 구현

**작성일시:** 2026-02-23
**작업 유형:** 신규 개발 / 설정 변경
**상태:** 완료
**관련 파일:** `.env`, `.env.example`, `scripts/youtube_auth.py`, `scripts/youtube_channel_check.py`, `scripts/youtube_upload_test.py`, `scripts/scheduled_upload.sh`, `scripts/youtube_channels.py` (신규)

---

## 1. 작업 개요

- 서버 [SERVER-HOSTNAME], 프로젝트 `/data/shortflow` 기준으로 YouTube 멀티채널 구성을 적용했습니다.
- `korea_walker`, `moongoby` 두 채널에 대해 채널별 토큰 경로·일일 한도·스케줄 분배를 설정하고, 기존 단일 채널 설정은 하위 호환용으로 유지했습니다.

## 2. 변경 사항

### Step 1 – .env 멀티채널 설정
- `YOUTUBE_CHANNELS_JSON` 추가(한 줄 JSON): 채널별 `name`, `channel_id`, `token_path`, `daily_limit`, `enabled` 정의.
- 기존 `YOUTUBE_CHANNEL_ID`, `YOUTUBE_TOKEN_PATH`는 유지.
- `.env.example` 주석을 멀티채널 형식에 맞게 수정(값은 비움).

### Step 2 – scripts/youtube_auth.py
- `--channel` 옵션: 지정 시 해당 채널의 `token_path` 사용(korea_walker / moongoby).
- `--list` 옵션: `YOUTUBE_CHANNELS_JSON` 채널 목록 출력 후 종료.
- `--force`, `--noauth_local_webserver` 기존 동작 유지.

### Step 3 – scripts/youtube_channel_check.py
- `--channel` 옵션: 지정 채널 토큰으로만 채널 정보 조회.
- `--all` 옵션: JSON에 정의된 모든 채널 순회하며 정보 출력.
- 채널별 토큰 경로는 `YOUTUBE_CHANNELS_JSON`에서 로드.

### Step 4 – scripts/youtube_upload_test.py
- `--channel` 옵션 추가: 지정 채널 토큰으로 업로드 테스트.
- `--delete` 옵션 유지.

### Step 5 – scripts/scheduled_upload.sh
- 시간대별 채널 분배: 09시 → korea_walker, 13시 → moongoby, 18시 → korea_walker.
- 채널별 일일 한도 6건 적용, 해당 채널 당일 업로드 수로 스킵 판단.
- 로그 형식: `[채널명] 업로드 성공`, `[채널명] 스케줄 실행 완료`.
- 환경변수 `YOUTUBE_SCHEDULED_CHANNEL`로 실행 시 채널 전달.

### Step 6 – scripts/youtube_channels.py (신규)
- 전체 채널 상태 조회 유틸: 채널별 이름, ID, 구독자, 영상 수, 토큰 유효 여부, 당일 업로드 수 출력.

## 3. 테스트 결과

- `ls -la credentials/token*.pickle`: token_korea_walker.pickle, token_moongoby.pickle, token.pickle 존재 확인.
- `grep YOUTUBE_CHANNELS .env`: `YOUTUBE_CHANNELS_JSON` 설정 확인.
- `python3 scripts/youtube_channel_check.py --all`: 두 채널 정상 출력  
  - korea_walker: 구독자 6, 영상 22  
  - moongoby: 구독자 0, 영상 0  
- Git push origin main 성공.

## 4. 주의사항 / 후속 작업

- `token*.pickle`, `.env` 실제 값은 Git 커밋·보고서에 노출하지 말 것.
- 실제 업로드 워커 연동 시 `YOUTUBE_SCHEDULED_CHANNEL`을 읽어 `--channel`로 전달하고, 성공 시 `[채널명] 업로드 성공` 한 줄을 로그에 출력하도록 구현할 것.
- Crontab에서 09:00, 13:00, 18:00에 `scheduled_upload.sh` 실행 시 위 시간대별 채널이 적용됨.
