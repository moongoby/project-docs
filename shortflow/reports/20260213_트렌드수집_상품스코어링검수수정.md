**작성일시:** 2026-02-13

**상태:** 완료

## 1. 작업 개요

Phase 9 검수 결과에 따라 트렌드 score 값 통일, Coupang 봇 차단 주석 추가, Google Trends 네임스페이스 fallback, 상품 스코어링 price=0 처리 반영하였다.

---

## 2. 변경 사항

### 2-1. trend_collector.py — save_trends_to_db score 통일 (중요)

- **문제:** `growth_rate`(퍼센트 변화율)와 `rank`(순위)를 같은 score 컬럼에 혼용하면 정렬/필터 시 의미가 없음.
- **수정:** score 계산을 통일. `growth_rate` 우선 → `search_volume` → 없으면 rank 역수 점수 `max(0, MAX_TRENDS_PER_SOURCE - rank + 1)`.

### 2-2. trend_collector.py — Coupang 봇 차단 주석

- **문제:** Coupang은 봇 차단으로 httpx 직접 요청 시 403/CAPTCHA 가능성, 실질적으로 빈 리스트 반환.
- **수정:** `_collect_coupang_bestseller` docstring에 NOTE 추가. Coupang Partners API 또는 Playwright 등 대안 고려 안내.

### 2-3. trend_collector.py — Google Trends 네임스페이스 fallback

- **문제:** BeautifulSoup xml 파서에서 `ht:approx_traffic` 네임스페이스 태그가 파서에 따라 동작하지 않을 수 있음.
- **수정:** `entry.find("ht:approx_traffic") or entry.find("approx_traffic")` 로 fallback 추가.

### 2-4. product_scorer.py — price=0 처리 (중요)

- **문제:** 가격 정보 없음(price=0)인 경우에도 price_score=10으로 계산되어 점수 산정이 부적절함.
- **수정:** `price <= 0` 이면 `price_score = 0` (No price info available)으로 별도 처리 후, 기존 구간 로직 유지.
