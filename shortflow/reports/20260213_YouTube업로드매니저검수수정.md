# Phase 5 YouTube 업로드 매니저 검수 수정

**작성일시:** 2026-02-13  
**작업 유형:** 버그 수정 / 리팩터링  
**상태:** 완료  
**관련 파일:** worker/services/youtube_manager.py, worker/tests/test_youtube_manager.py

---

## 1. 작업 개요

Phase 5 YouTube Upload Manager 검수 결과에 따라 import 경로·logger·Slack 래퍼·파일 업로드 방식·테스트 mock을 수정하였다. Docker WORKDIR 및 런타임 오동작을 방지하고 프로젝트 패턴과 통일했다.

---

## 2. 변경 사항

### 2-1. youtube_manager.py — import 경로 통일
- **변경 전**: `from worker.config import settings`, `from worker.utils.logger import setup_logger`, `from worker.utils.slack_notifier import send_slack`, `get_logger = setup_logger`
- **변경 후**: `from config import settings`, `from utils.logger import logger`, `from utils.slack_notifier import send_slack`
- Phase 3-4 서비스(script_generator, image_generator, tts_generator, pipeline_worker)와 동일 패턴. WORKDIR `/app/worker/` 기준 동작.

### 2-2. youtube_manager.py — logger 사용 방식
- 각 클래스에서 `self.logger = get_logger(...)` 제거.
- 모든 `self.logger.info/warning/error` → `logger.info/warning/error` 로 변경.
- 로그 메시지에 컴포넌트 접두사 추가: `[QuotaManager]`, `[YouTubeAuth]`, `[UploadPost]`, `[YouTubeUpload]`.

### 2-3. youtube_manager.py — SlackNotifier 제거
- `SlackNotifier` 클래스 삭제.
- `YouTubeUploadManager.__init__`에서 `self.slack = SlackNotifier()` 삭제.
- 업로드 실패 시 `await self.slack.send_error(...)` → `await send_slack(...)` 직접 호출.

### 2-4. youtube_manager.py — UploadPostBackup.upload 파일 전송
- **변경 전**: `with open(request.video_path, "rb") as f:` 후 `form.add_field("video", f, ...)` 및 `async with session.post(...)` (파일 핸들 유지).
- **변경 후**: `video_data = Path(request.video_path).read_bytes()` 후 `form.add_field("video", video_data, ...)`. 쇼츠 규격(5–20MB) 기준 메모리 부담 최소화.

### 2-5. youtube_manager.py — token_path 우선순위
- `load_channels` 내 ChannelAccount 생성 시:  
  `token_path=ch.get("token_path") or str(TOKEN_DIR / f"{ch['channel_id']}_token.pickle")`  
  JSON에 `token_path`가 있으면 사용, 없으면 기존 기본값.

### 2-6. test_youtube_manager.py — test_upload_via_api_success
- `next_chunk`를 **동기 함수**로 변경 (`async def` → `def`). `run_in_executor`가 동기 콜백을 기대하므로 코루틴 전달 시 unpack 오류 방지.
- 테스트용 임시 파일: `Path("/tmp/real_video.mp4").touch()` 후 `try: ... finally: unlink(missing_ok=True)`.
- `patch("services.youtube_manager.MediaFileUpload")` 추가. `_upload_via_api` 내 `MediaFileUpload(request.video_path, ...)` 호출 시 실제 파일 불필요하도록 mock.

### 2-7. test_youtube_manager.py — test_upload_all_methods_failed
- SlackNotifier 제거에 따라 `patch.object(YouTubeUploadManager, "slack")` + `mock_slack.send_error` 제거.
- `patch("services.youtube_manager.send_slack", new_callable=AsyncMock) as mock_slack` 로 교체, assertion은 `mock_slack.assert_called_once()`.

### 2-8. test_youtube_manager.py — test_upload_api_quota_exceeded
- `Path("/tmp/v.mp4").touch()` 및 `try/finally` + `unlink(missing_ok=True)` 추가.
- `patch("services.youtube_manager.MediaFileUpload")` 추가. `_upload_via_api` 진입 시 `MediaFileUpload` 생성 구간에서 파일 존재 보장.

## 4. 주의사항 / 후속 작업

- **Quota 리셋 시각**: 현재 `date.today()`(서버 로컬) 기준. YouTube Quota는 Pacific Time 자정 리셋이므로, 장기적으로 Pacific Time 기준 비교로 변경 검토.
- **실행 경로**: `python -m worker.services.youtube_manager --auth CHANNEL_ID` 실행 시 프로젝트 루트가 PYTHONPATH에 포함되어야 하며, worker 내 다른 스크립트와 동일하게 `config`/`utils` 기준으로 동작.
