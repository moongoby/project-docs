## 4. Step 2 – Nginx 리버스 프록시 설정

### 4.1 설정 파일

### 4.2 nginx -t 결과

```

```

### 4.3 Nginx 설정 전문 (/etc/nginx/sites-available/shotflow.newtalk.kr)

```nginx
# shotflow.newtalk.kr → SaaS 대시보드(Next.js :3000) 리버스 프록시
# 설치: sudo cp /data/shortflow/deploy/nginx-shotflow.newtalk.kr.conf /etc/nginx/sites-available/shotflow.newtalk.kr
#       sudo ln -sf /etc/nginx/sites-available/shotflow.newtalk.kr /etc/nginx/sites-enabled/
#       sudo nginx -t && sudo systemctl reload nginx

server {
    listen 80;
    server_name shotflow.newtalk.kr;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;

        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    location /_next/static/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_cache_valid 200 365d;
        add_header Cache-Control "public, max-age=31536000, immutable";
    }

    location /api/health {
        proxy_pass http://127.0.0.1:8000/api/health;
    }
}
```

### 4.4 Nginx 서비스 상태

- **reload 결과:** `nginx.service is not active, cannot reload`
- **80/443 포트:** 현재 **Apache2**가 리스닝 중 (Nginx 미기동)
- **결론:** Nginx 설정은 문법 검사 통과·파일 반영 완료. 실제 80 수신은 Apache가 하고 있음.

## 5. Apache 사용 시 (현재 서버 구성)

80/443을 Apache가 사용 중이므로, **shotflow.newtalk.kr**을 Next.js(3000)로 연결하려면 Apache VirtualHost에서 프록시 설정이 필요하다.

- **예시 설정:** `/data/shortflow/deploy/apache-shotflow.newtalk.kr.conf.example`
- **조치:** Apache에 `shotflow.newtalk.kr` 전용 VirtualHost 추가 후 `ProxyPass / http://127.0.0.1:3000/`, `ProxyPassReverse / http://127.0.0.1:3000/` 적용 및 `systemctl reload apache2`

**현재 동작:** `https://shotflow.newtalk.kr` 접속 시 302 → `https://shotflow.newtalk.kr/main` (기존 PHP/CodeIgniter 앱). ShortFlow 대시보드를 노출하려면 위 Apache 프록시로 **shotflow.newtalk.kr**을 127.0.0.1:3000으로 연결해야 함.

## 6. SSL 모드

- **Cloudflare:** Proxied(주황 구름) 사용 중.
- **권장:** SSL Mode **Flexible** 유지 시 오리진(본 서버)은 80만 수신. Cloudflare 엣지에서 HTTPS 처리.
- **Full 전환 시:** 오리진 443 + 서버 인증서 필요 (Let's Encrypt 또는 Cloudflare Origin Certificate).
