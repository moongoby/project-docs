# Phase 13: YouTube 업로드 자동화

**작성일시:** 2026-02-13
**작업 유형:** 신규 개발
**상태:** 완료
**관련 파일:** `worker/services/youtube_uploader.py`, `worker/workers/pipeline_worker.py`, `worker/config.py`, `worker/core/state_machine.py`, `worker/requirements.txt`

---

## 1. 작업 개요

Google OAuth 2.0(client_secret.json + token pickle) 기반 단일 채널 YouTube 업로드를 추가하고, QA 통과 후 자동 업로드 옵션(auto_upload)과 연동하였다.

## 2. 변경 사항

### 2.1 Google OAuth 설정 (수동)

- Google Cloud Console에서 YouTube Data API v3 활성화, OAuth 2.0 클라이언트 ID(데스크톱 앱) 생성.
- `client_secret.json` 다운로드 후 `/data/shortflow/credentials/client_secret.json` 에 저장.

### 2.2 worker/services/youtube_uploader.py (신규)

- **YouTubeUploader:** `credentials_dir` 기본값 `youtube_credentials_dir` 설정 사용.
- **authenticate():** `youtube_token.pickle` 로드 또는 갱신, 없으면 `InstalledAppFlow.run_local_server(port=8888)` 로 최초 인증.
- **upload():** async, blocking API는 `run_in_executor`로 실행. snippet(title, description, tags), status(privacyStatus, selfDeclaredMadeForKids), categoryId 22(People & Blogs). 썸네일 선택 업로드.
- **참고:** API v3는 `status.shorts` 미지원으로 요청에서 제외(Shorts는 영상 비율/길이로 판별).

### 2.3 pipeline_worker.py

- **_step_upload / _call_upload:** `settings.auto_upload` 가 True이면 `YouTubeUploader().upload(...)` 호출, 실물 업로드 후 `youtube_video_id` 설정. False이면 기존처럼 placeholder ID만 설정.
- 업로드 시 사용 메타: `job.artifacts.script_title`, `script_description`, `script_tags`, `video_path`, `thumbnail_path`.

### 2.4 JobArtifacts / _step_generate_script

- **script_title, script_description, script_tags** 필드 추가 및 DB(JSONB) 직렬화/역직렬화 반영.
- 스크립트 생성 단계에서 `script.title`, `script.description`, `script.tags` 저장.

### 2.5 config.py

- **auto_upload:** `bool = False` (env: AUTO_UPLOAD, 테스트 시 False 권장).
- **youtube_credentials_dir:** `str = "/data/shortflow/credentials"`.

### 2.6 의존성 및 디렉터리

- **worker/requirements.txt:** `google-auth>=2.0`, `google-auth-oauthlib>=1.0` 명시.
- **credentials 디렉터리:** `mkdir -p /data/shortflow/credentials` 생성.

## 3. 테스트 결과

- 린트 오류 없음. 실제 업로드 테스트는 `client_secret.json` 배치 및 최초 OAuth(port 8888) 후 `AUTO_UPLOAD=true` 로 파이프라인 실행 시 확인 필요.

## 4. 주의사항 / 후속 작업

- 최초 1회: worker 실행 환경에서 브라우저로 `http://localhost:8888` 접속해 OAuth 동의 후 `youtube_token.pickle` 생성.
- Docker 사용 시 credentials 볼륨 마운트: `-v /data/shortflow/credentials:/data/shortflow/credentials` 및 포트 8888 노출(최초 인증용).
- 기존 `youtube_manager.py`(멀티채널·쿼터·Upload-Post 백업)는 그대로 두었으며, 단순 OAuth 업로드는 `youtube_uploader.py`만 사용.
