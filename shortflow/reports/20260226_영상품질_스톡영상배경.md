## 1. 개요

- **목적:** 파일럿 영상의 배경을 단색/이미지에서 **스톡 영상**으로 전환하여 품질을 높이고, Pexels/Pixabay API 기반 검색·다운로드 모듈과 v3 E2E 파이프라인을 구축.
- **변경 요약:**
  - `engine/stock_video_downloader.py` 신규: 키워드 기반 Pexels → Pixabay 폴백 검색 및 캐시 다운로드.
  - `scripts/pilot_video_e2e_v3.py` 신규: 세그먼트별 스톡 영상(또는 단색 폴백) → 1080×1920 크롭/스케일 → concat + TTS 오디오 합성.

## 3. STEP 1: 스톡 영상 다운로드 모듈

### 3-1. 구현 내역 (`engine/stock_video_downloader.py`)

- **Pexels API:** `query`, `orientation=portrait`, `per_page`, `size=medium` 로 세로형 영상 검색. `height >= 1080` 이고 세로 비율인 비디오 파일만 사용.
- **Pixabay API:** Pexels 실패 시 폴백. `q`, `per_page`, `video_type=film`, `videos.medium.url` 사용.
- **캐시:** `cache/stock_videos/{keyword}.mp4` 에 저장, 10KB 이상 존재 시 재다운로드 스킵.
- **의존성:** `requests`, `python-dotenv` (기존 venv에 requests 설치됨).

### 3-2. API 키 보유 여부

| 키 | .env 상태 | 비고 |
|----|-----------|------|
| `PEXELS_API_KEY` | **미설정** | [Pexels API](https://www.pexels.com/api/) 무료 가입 후 발급 |
| `PIXABAY_API_KEY` | **미설정** | [Pixabay API](https://pixabay.com/api/docs/) 무료 가입 후 발급 |

- **대표님 액션:** 품질 개선을 위해 Pexels 또는 Pixabay 중 하나 이상 API 키 발급 후 `.env`에 추가 권장.
- 키가 없으면 스톡 검색 결과 없음 → v3는 **단색 배경 폴백**으로 동작(기존과 동일 품질).

### 3-3. 검색/다운로드 테스트 결과

- **테스트 명령:** `venv/bin/python engine/stock_video_downloader.py "dollar exchange rate"`
- **결과:** API 키 미설정으로 `⚠️ 스톡 영상 없음: dollar exchange rate` → `결과: None` (정상 폴백).

## 4. STEP 2–3: v3 파이프라인 구현 상태

### 4-1. `scripts/pilot_video_e2e_v3.py` 요약

- **입력:** 기존과 동일 `--script`, `--channel`, `--no-tts`.
- **플로우:**
  1. 대본 JSON → `script_segments` 확보.
  2. TTS 생성(또는 기존 MP3 사용).
  3. **세그먼트별:** `image_keyword`로 `download_stock_video()` 호출.
     - 성공 시: `ffmpeg -stream_loop -1 -i stock.mp4 -t {duration} -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920" -an segment_bg.mp4` 로 클립 생성.
     - 실패 시: 단색 배경 이미지 생성 후 기존처럼 `-loop 1 -t {duration}` 사용.
  4. 모든 세그먼트 클립 concat 후 TTS 오디오 매핑, `_v3.mp4` 출력.

### 4-2. 구현 상태

| 항목 | 상태 |
|------|------|
| 스톡 다운로더 모듈 | ✅ 완료 |
| v3 스크립트 (스톡/단색 폴백) | ✅ 완료 |
| 1080×1920 크롭/스케일 | ✅ 완료 |
| segment duration만큼 자르기(루프) | ✅ 완료 |
| 자막(drawtext) 오버레이 | ⏳ 미구현 (추후 별도 작업 가능) |

## 6. 스톡 영상 라이선스 및 의견

- **Pexels:** 무료 상업적 사용, 출처 표기 불필요.
- **Pixabay:** Pixabay License 동일, 상업적 사용 가능.
- **AI 이미지 vs 스톡 영상:**  
  스톡 영상은 실제 영상감과 일관된 품질을 주어 쇼트폼에 적합함. API 키 발급 후 키워드만 맞추면 세그먼트별 배경 다양화가 가능하며, 없을 때는 기존 단색 배경으로 안정적으로 폴백됨.
