## 1. 작업 개요

10-Layer 양산형 회피 엔진 Sprint 1의 Step 5~8을 진행하였다. Layer 3(Voice), Layer 4(BGM), Layer 5(Metadata), Layer 6(Upload Pattern)을 스펙에 맞게 구현하고, 오케스트레이터(anti_inauthentic.py)에 연동하였다. Work Rules에 따라 백업 후 개발·테스트·보고서를 수행하였다.

## 2. 변경 사항

### 2.1 Step 5: engine/voice_variation.py (Layer 3)

- **VOICE_PRESETS:** 3개 보이스 프리셋 딕셔너리 추가  
  - `google_A` (google-cloud, ko-KR-Chirp3-HD-Kore), `google_B` (google-cloud, ko-KR-Standard-A), `elevenlabs_A` (elevenlabs, voice_id)
- **VoiceParamsResult** dataclass: `voice_id`, `provider`, `rate`, `pitch`, `pause`, `to_dict()`, `signature()` (voice_id + rate + pitch + pause 조합)
- **get_voice_params(recent_params):** 최근 5개와 다른 보이스 선택, rate 0.95~1.15(0.05 단위), pitch -2~+2(1 단위), pause 0.3~0.8s(0.1 단위), `VoiceParamsResult` 반환
- **오케스트레이터:** `VoiceVariation` import, `AntiInauthenticInput.recent_voice_params`, `evaluate()` 재생성 시 `suggested_voice` 설정, `AntiInauthenticResult.suggested_voice`, `suggest_voice()` 메서드 추가

### 2.2 Step 6: engine/bgm_variation.py (Layer 4)

- **BGM_LIBRARY:** 카테고리 beauty, food, fashion, health, living, parenting, default, 각 5곡 placeholder (예: bgm_beauty_01.mp3)
- **BGMResult** dataclass: `bgm_file`, `category`, `volume`, `start_offset`, `to_dict()`, `signature()` (bgm_file + volume + start_offset)
- **select_bgm(category, recent_bgms):** 최근 5곡 제외 후 선택, volume 0.2~0.4(0.05 단위), start_offset 0~30초(1초 단위)
- **오케스트레이터:** `BGMVariation` import, `AntiInauthenticInput.product_category`, `recent_bgms`, 재생성 시 `suggested_bgm`, `AntiInauthenticResult.suggested_bgm`

### 2.3 Step 7: engine/metadata_variation.py (Layer 5)

- **FIXED_TAGS:** 고정 5개 (쇼츠, shorts, 쿠팡, 추천, 리뷰)
- **EMOTION_TRIGGERS:** 감정트리거 키워드 (미친, 끝판왕, 모르면손해, 역대급, 충격, 가성비갑 등)
- **MetadataResult:** `formula_used`, `signature()` 추가
- **generate_metadata:** title ≤100자·#Shorts 포함, description CTA + 쿠팡링크 placeholder + 해시태그, tags 고정 5개 + 동적 10~15개
- **오케스트레이터:** `MetadataVariation` import, `AntiInauthenticInput.product_name`, `product_price`, `product_brand`, `recent_titles`, 재생성 시 `suggested_metadata`, `AntiInauthenticResult.suggested_metadata`

### 2.4 Step 8: engine/upload_pattern.py (Layer 6)

- **BASE_SLOTS:** `[datetime.time(9,0), time(13,0), time(18,0)]`, **OFFSET_RANGE:** 30(분)
- **get_next_slot(current_date, recent_uploads, ref_time=None):** 기본 슬롯 ±30분 오프셋, 주말 1~2건, 휴일 0건, 지난 슬롯 건너뛰기
- **get_daily_schedule(target_date):** 해당 날짜 전체 스케줄 → `List[UploadSlotResult]`
- **UploadSlotResult** dataclass: `scheduled_time`, `is_weekend`, `is_holiday`, `offset_applied`
- **오케스트레이터:** `UploadPattern`, `UploadSlotResult` import, `get_upload_schedule(target_date)` 메서드 추가 (evaluate에 직접 연결하지 않음)

## 3. 테스트 결과

- **Step 5:** `VoiceVariation.get_voice_params()`, `suggested_voice` 키 확인, `suggest_voice()` 동작 확인
- **Step 6:** `BGMVariation.select_bgm('beauty')`, `suggested_bgm` (product_category 전달 시) 확인
- **Step 7:** `MetadataVariation.generate_metadata()`, 제목 #Shorts·formula_used·signature, `suggested_metadata` 확인
- **Step 8:** `UploadPattern.get_daily_schedule()`, `get_next_slot()`, `BASE_SLOTS`/`OFFSET_RANGE` 확인
- **통합:** `AntiInauthenticEngine.evaluate()` 재생성 시 suggested_voice, suggested_bgm, suggested_metadata 출력, `get_upload_schedule(date)` 호출 성공

## 4. 주의사항 / 후속 작업

- 파이프라인에서 `recent_voice_params`, `recent_bgms`, `product_category`, `product_name`/`product_price`/`product_brand`, `recent_titles`를 채워 넣으면 재생성 제안 품질이 향상된다.
