파일 내용:
```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from api.routes.health import router as health_router

app = FastAPI(title="ShortFlow API", version="1.0")
app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"], allow_headers=["*"])
app.include_router(health_router)

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## Part D — API 서버 실행

### 포트 충돌 발견

```
ss -tlnp | grep 8000
LISTEN  0        4096             0.0.0.0:8000           0.0.0.0:*
LISTEN  0        4096                [::]:8000              [::]:*
```

기존 프로세스:
```
ps aux | grep uvicorn
root  2089488  0.0  0.2 165236 38376 ?  Ssl  16:51  0:08
/usr/local/bin/python3.11 /usr/local/bin/uvicorn main:app --host 0.0.0.0 --port 8000 --workers 1
```

기존 서버는 `worker/main.py`를 기반으로 `main:app` 실행 중 (루트 소유, 종료 불가).
기존 `/api/health`는 단순 응답만 반환: `{"status":"healthy","disk_usage_gb":4812.37,"version":"0.1.0"}`

### 해결책: 포트 8001에 신규 서버 실행

```
cd /data/shortflow && nohup python3.9 -m uvicorn api.main:app --host 0.0.0.0 --port 8001 > logs/api_server.log 2>&1 &
echo $! > /data/shortflow/api_server.pid
```

출력:
```

INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8001 (Press CTRL+C to quit)
```

**상태**: ✅ 완료 (포트 8001에서 실행 중)
- PID 파일: `/data/shortflow/api_server.pid`

## 이슈 및 참고

1. **포트 충돌**: 기존 worker 서버(root 소유 PID 2089488)가 포트 8000 점유 → 포트 8001로 신규 서버 실행
2. **Docker 권한**: claudebot 사용자는 docker.sock 접근 불가 → docker 섹션에 error 표시됨 (정상)
3. **DATABASE_URL 미설정**: Supabase DB 직접 연결 불가 (SUPABASE_URL/KEY는 SET)
4. **Git push BLOCKED**: SSH 키 미등록 상태 지속 (CEO PAT 등록 필요)
5. **worker/main.py 통합**: 다음 서버 재시작 시 포트 8000에서도 상세 헬스체크 엔드포인트 제공 가능
