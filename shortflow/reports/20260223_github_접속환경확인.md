## 1. 작업 개요

GitHub 전용 디렉토리 및 문서 저장소 구축을 위해, 현재 서버의 GitHub 접속 환경(SSH, HTTPS, gh CLI)을 확인하였다.

---

## 2. 명령 실행 결과 (전체 출력)

### 2.1 GitHub SSH 연결 테스트

```bash
ssh -T git@github.com 2>&1 || echo "SSH 불가"
```

**출력:**
```
Hi moongoby! You've successfully authenticated, but GitHub does not provide shell access.
SSH 불가
```

- SSH 인증은 **성공** (GitHub 계정: moongoby).
- GitHub는 shell 접근을 제공하지 않아 종료 코드가 0이 아니므로 `|| echo "SSH 불가"`가 실행되어 "SSH 불가" 문구가 함께 출력됨. **실제 SSH push/pull은 사용 가능.**

### 2.5 GitHub 토큰 / credential 확인

```bash
git config --global credential.helper 2>/dev/null
```

**출력:**
```
store
```

- 전역 credential helper가 **store**로 설정됨. HTTPS 사용 시 자격 증명이 평문 저장될 수 있음.

## 3. GitHub 접속 방식 정리

| 방식 | 가능 여부 | 비고 |
|------|-----------|------|
| **SSH** | ✅ 가능 | `ssh -T git@github.com` 인증 성공 (moongoby). clone/push/pull 사용 가능. |
| **HTTPS** | ✅ 가능 | credential.helper=store 설정됨. 토큰/비밀번호 저장 시 HTTPS 사용 가능. |
| **gh CLI** | ✅ 가능 | gh 2.87.2 설치됨. `gh auth status` 등으로 추가 확인 가능. |

**결론:** 현재 환경에서 SSH, HTTPS, gh CLI 모두 사용 가능. 저장소 동기화에는 **SSH** 사용을 권장(키 기반 인증, 별도 토큰 관리 불필요).
