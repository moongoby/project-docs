## 5. 적용한 개선 사항

1. **daily_report.sh**
   - 업로드 현황: `upload_YYYYMMDD.log` + `upload_economy.log` + `upload_health.log` 합산 반영.
   - 누적 현황: `uploaded_videos.json`(worker) + `uploaded_shortflow.json`(economy/health) 구분 표기.
2. **upload_monitor.sh**
   - 오늘 로그: 채널별(worker / economy / health) 성공·에러 건수 출력.
   - 누적: worker / economy·health 구분 표기.
   - API 할당량: 전체 성공 건수 합산 기준으로 계산.
3. **alert_on_error.sh**
   - 에러 검사 대상에 `upload_economy.log`, `upload_health.log` 추가.
   - 로그 파일이 없어도 다른 채널 로그만으로 알림 가능하도록 변경.
