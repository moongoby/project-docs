# Phase 5 - YouTube Upload Manager 구현

**작성일시:** 2026-02-13  
**작업 유형:** 신규 개발  
**상태:** 완료  
**관련 파일:** worker/services/youtube_manager.py, worker/tests/test_youtube_manager.py, worker/config.py, worker/requirements.txt

---

## 1. 작업 개요

YouTube Data API v3 기반 멀티채널 업로드, 일일 Quota 관리, Quota 소진 시 Upload-Post.com 백업 업로드를 지원하는 **YouTube Upload Manager**를 구현하였다. `.cursorrules` 및 기존 config/exceptions/logger/slack 규칙을 준수한다.

---

## 2. 변경 사항

### 2-1. worker/services/youtube_manager.py (신규 구현)

- **상수**: `SCOPES`, `QUOTA_PER_DAY`(10000), `QUOTA_PER_UPLOAD`(1600), `MAX_UPLOADS_PER_PROJECT`(6), `MAX_RETRIES`, `RETRY_BASE_DELAY`, `UPLOAD_TIMEOUT`, `TOKEN_DIR`.
- **Data Models**
  - `UploadStatus`: PENDING, UPLOADING, PROCESSING, COMPLETED, FAILED, QUOTA_EXHAUSTED.
  - `ChannelAccount`: channel_id, channel_name, gcp_project_id, client_secrets_path, token_path, daily_quota_used, quota_reset_date, is_active, `reset_quota_if_needed()`, `remaining_uploads`, `can_upload`.
  - `UploadRequest`: job_id, video_path, title, description, tags, category_id, privacy_status, made_for_kids, shorts, thumbnail_path, scheduled_time, product_url, notify_subscribers.
  - `UploadResult`: job_id, status, video_id, video_url, channel_id, upload_method, error_message, uploaded_at, quota_used.
- **QuotaManager**: `load_channels()`(YOUTUBE_CHANNELS_JSON 파싱), `get_available_channel()`(round-robin), `consume_quota()`, `get_total_remaining_uploads()`, `get_quota_status()`.
- **YouTubeAuthManager**: `get_credentials()`(로드/리프레시), `run_initial_auth()`(로컬 OAuth), `_save_token()`, `build_youtube_service()`.
- **UploadPostBackup**: Upload-Post.com API 호출, `is_configured`, `upload(request, channel_id)`.
- **YouTubeUploadManager**: `initialize()`, `upload(request)`(API 시도 → 실패/쿼터 소진 시 백업), `_upload_via_api()`, `_execute_resumable_upload()`(재시도), `_set_thumbnail()`, `upload_batch()`, `get_status()`.
- **CLI**: `python -m worker.services.youtube_manager --auth CHANNEL_ID` 로 채널별 최초 OAuth 실행.

### 2-2. worker/tests/test_youtube_manager.py (신규)

- `test_channel_quota_reset`: quota_reset_date 어제 → remaining_uploads 리셋 후 MAX_UPLOADS_PER_PROJECT 확인.
- `test_channel_quota_exhausted`: daily_quota_used == QUOTA_PER_DAY → can_upload False.
- `test_quota_manager_round_robin`: 3채널 로드 후 1번 채널 쿼터 소진 → get_available_channel 이 2번 채널 반환.
- `test_upload_via_api_success`: youtube.videos().insert mock → _upload_via_api → COMPLETED, video_id 확인.
- `test_upload_api_quota_exceeded`: HttpError 403 quotaExceeded → QUOTA_EXHAUSTED 및 채널 daily_quota_used 마킹.
- `test_upload_fallback_to_backup`: get_available_channel None + Upload-Post 성공 mock → upload_method "upload_post".
- `test_upload_all_methods_failed`: API 쿼터 소진 + 백업 실패 → QUOTA_EXHAUSTED 및 send_error 호출.
- `test_upload_batch_concurrency`: 5건, max_concurrent=2 → 동시 실행 2 이하 확인.
- `test_upload_video_not_found`: 존재하지 않는 video_path → FAILED, "not found" 메시지.

외부 API(googleapiclient, aiohttp)는 `unittest.mock.patch` / `AsyncMock`으로 mock.

- `upload_post_api_key: str = ""` (환경변수: UPLOAD_POST_API_KEY)

## 4. 주의사항 / 후속 작업

- **채널 설정**: `YOUTUBE_CHANNELS_JSON` 에 `[{"channel_id","channel_name","gcp_project_id","client_secrets_path","token_path"}]` 형식으로 채널 배열 설정. `token_path` 는 코드에서 `TOKEN_DIR / "{channel_id}_token.pickle"` 로도 생성 가능.
- **최초 인증**: 채널별 1회 `python -m worker.services.youtube_manager --auth CHANNEL_ID` 실행 후 브라우저 OAuth 완료 필요.
- **Upload-Post**: 쿼터 소진 시 백업용. `UPLOAD_POST_API_KEY` 설정 시에만 사용.
- **파이프라인 연동**: pipeline_worker에서 UPLOADING 단계 시 `YouTubeUploadManager().upload(UploadRequest(...))` 호출 및 Job/DB 업데이트 연동은 별도 작업으로 진행 가능.
