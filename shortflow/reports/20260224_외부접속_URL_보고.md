## 2. 외부 접속 URL

### 2.1 공식 도메인 (shotflow.newtalk.kr)

| 서비스 | 접속 URL | 용도 |
|--------|-----------|------|
| **SaaS 대시보드** (Next.js) | **https://shotflow.newtalk.kr** | 회원 랜딩·로그인·대시보드 (권장) |

DNS A 레코드 `shotflow` → [SERVER-IP] 반영 완료(Proxied). 리버스 프록시(443 → 3000) 및 Supabase 리다이렉트 URL 등록 필요(아래 5절 참고).

### 2.2 IP·포트 직접 접속 (동일 서버)

| 서비스 | 포트 | 접속 URL | 용도 |
|--------|------|-----------|------|
| **SaaS 대시보드** (Next.js) | 3000 | http://[SERVER-IP]:3000 | 도메인 미사용 시 대안 |
| **내부 대시보드** (Streamlit) | 8501 | http://[SERVER-IP]:8501 | 운영 모니터링(Overview, Script/Video QA, Analytics) |

## 5. DNS 반영 후 나머지 적용 사항

| 순서 | 항목 | 내용 |
|------|------|------|
| 1 | **리버스 프록시** | Nginx/Caddy에서 `shotflow.newtalk.kr` 443 수신 → `http://127.0.0.1:3000`으로 프록시. Cloudflare Proxied 사용 시 오리진은 80/443 또는 3000 직접 허용. |
| 2 | **SSL** | Cloudflare Proxied면 엣지에서 HTTPS 처리. 오리진이 80만 열 경우 Flexible; 오리진에 인증서 설치 시 Full. |
| 3 | **Supabase 리다이렉트 URL** | Supabase 대시보드 → Authentication → URL Configuration → Redirect URLs에 `https://shotflow.newtalk.kr`, `https://shotflow.newtalk.kr/**`, `https://shotflow.newtalk.kr/dashboard` 추가. |
| 4 | **환경 변수** | 서버·빌드 시 `NEXT_PUBLIC_APP_URL=https://shotflow.newtalk.kr` 설정 후 SaaS 대시보드 재빌드/재시작. |
