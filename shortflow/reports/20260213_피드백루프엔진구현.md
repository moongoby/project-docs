# Phase 8: 피드백 루프 엔진 구현

**작성일시:** 2026-02-13  
**작업 유형:** 신규 개발  
**상태:** 완료  
**관련 파일:** worker/services/feedback_engine.py, worker/tests/test_feedback_engine.py, worker/main.py, n8n_workflows/daily_production.json, sql/003_feedback_tables.sql

---

## 1. 작업 개요

YouTube 업로드 영상의 성과를 수집·분석하고, 스코어링 가중치 조정 인사이트를 생성하는 피드백 루프 엔진을 구현하였다. Worker API 엔드포인트 추가, n8n 일일 워크플로우에 Run Feedback 노드 연결, 피드백용 DB 테이블 스키마를 추가하였다.

---

## 2. 변경 사항

### 2-1. worker/services/feedback_engine.py (신규)

- **데이터 모델:** VideoPerformance(views, likes, comments, engagement_rate, view_to_like_ratio 등), FeedbackInsight(period, avg_views, avg_engagement_rate, weight_adjustments 등).
- **PerformanceCollector:** YouTube Data API v3 videos.list로 영상별 조회수/좋아요/댓글 수 수집. collect_performance(단일), collect_batch(다수), save_performance_to_db(video_analytics 테이블).
- **FeedbackAnalyzer:** video_analytics 기간 조회 후 평균·집계, _calculate_weight_adjustments(수익/engagement 휴리스틱으로 가중치 델타 제안), save_insight_to_db(feedback_insights).
- **FeedbackEngine:** COMPLETED job의 artifacts에서 youtube_video_id/channel_id 추출 → 수집 → 분석 → 인사이트 저장 → Slack 요약 전송.
- **run_feedback():** API에서 호출용 편의 함수.

### 2-2. worker/tests/test_feedback_engine.py (신규)

- test_video_performance_engagement_rate, test_video_performance_zero_views (VideoPerformance 연산).
- test_collect_performance_success (YouTube API mock), test_collect_performance_no_channel (채널 미설정 시 None).
- test_generate_insights_empty (supabase 빈 데이터 → total_videos=0).
- test_weight_adjustments_low_engagement (낮은 engagement 시 content_fit 조정 확인).

### 2-3. worker/main.py

- `POST /api/v1/feedback/run` 추가. BackgroundTasks로 FeedbackEngine.run_feedback_loop() 실행.

### 2-4. n8n_workflows/daily_production.json

- Get Stats 다음에 Run Feedback 노드 추가. POST http://worker:8000/api/v1/feedback/run. Get Stats → Run Feedback 연결.

### 2-5. sql/003_feedback_tables.sql (신규)

- video_analytics: job_id, pick_id, video_id, channel_id, 통계·engagement_rate, collected_at, UNIQUE(video_id, collected_at).
- feedback_insights: period_start/end, total_videos, avg_views, avg_engagement_rate, avg_watch_duration, avg_ctr, total_revenue, weight_adjustments(JSONB), generated_at.
- 인덱스: video_analytics(video_id, collected_at), feedback_insights(period_end).

## 4. 주의사항 / 후속 작업

- **YouTube Analytics API:** 현재는 Data API v3만 사용(views, likes, comments). CTR·watch_time·revenue는 Analytics API 스코프 연동 후 확장.
- **video_analytics upsert:** Supabase upsert(on_conflict="video_id,collected_at") 사용. 003 스키마 적용 후 동작 확인.
- **가중치 자동 반영:** weight_adjustments는 DB/인사이트에만 저장. ProductScorer 가중치에 자동 적용하려면 설정 로드 로직 추가 필요.
