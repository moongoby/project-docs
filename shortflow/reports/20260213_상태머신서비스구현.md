## 1. 작업 개요

상태 머신·재시도 엔진(A), 외부 API 서비스(B), 파이프라인 워커(C), 테스트(D)를 그룹별로 구현·연동하였다. Job은 CREATED부터 스크립트(Claude) → 이미지(DALL-E) → TTS(ElevenLabs) → 클립/타이밍 → 합성(FFmpeg) → QA대기 → 업로드(placeholder) → COMPLETED까지 진행된다.

## 3. 그룹 B: 외부 API 서비스

### B-1 script_generator.py
- **SceneSchema**, **ScriptSchema** (Pydantic).
- **ScriptGenerator**: `generate(product_name, product_info, category, versions, template_id)` → Claude API 호출, JSON 파싱, ScriptSchema 검증. `_build_prompt`, `_parse_script_json`, `_save_to_db` (Supabase scripts 테이블) 구현.

### B-2 image_generator.py
- **ImageGenerator**: `generate(prompt, pick_id, scene_number, style)` → OpenAI DALL-E 3, 이미지 다운로드·저장. content_policy 시 `_sanitize_prompt` 후 1회 재시도. `generate_batch(prompts, pick_id)` → asyncio.gather 병렬 생성. `_sanitize_prompt`: 브랜드/로고 제거, 1000자 제한.

### B-3 tts_generator.py
- **TTSGenerator**: `generate(text, pick_id, ...)` → ElevenLabs `/with-timestamps` 호출, MP3 저장 및 alignment 반환. 5000자 초과 시 `generate_with_split` (문장 단위 `_split_text`). `generate_with_split`: 청크별 TTS, 현재는 첫 청크만 반환(concat/offset 병합은 TODO).

---

## 4. 그룹 C: 파이프라인 워커

### pipeline_worker.py
- **PipelineWorker**: script_gen, image_gen, tts_gen, video_composer, timing_engine 주입.
- **_step_generate_script**: ScriptGenerator.generate → _save_to_db, artifacts.script_id, scene_texts, visual_prompts.
- **_step_generate_images**: ImageGenerator.generate_batch(visual_prompts) → artifacts.image_paths.
- **_step_generate_tts**: " ".join(scene_texts) → TTSGenerator.generate → tts_path, tts_alignment.
- **_step_generate_clips**: TimingEngine.process_timestamps만 사용, clip_paths는 compose 단계에서 처리.
- **_step_compose_video**: TimingEngine으로 subtitle_words·scene_durations·start_times 계산 → SceneAsset 리스트·CompositionPlan 구성 → VideoComposer.compose → video_path, thumbnail_path.
- **_step_upload**: placeholder `yt_{pick_id}`, youtube_channel_id.
- run_batch, run_continuous, stop. process_job while 루프 및 실패 시 mark_failed·Slack 동일.
