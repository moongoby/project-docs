# 영상 품질 1단계 개선 – 자막 + TTS 속도 수정

**작성일시:** 2026-02-13  
**작업 유형:** 리팩터링 / 품질 개선  
**상태:** 완료  
**관련 파일:** worker/services/ffmpeg_composer.py, worker/services/tts_generator.py, worker/config.py

---

## 1. 작업 개요

쇼츠 영상의 자막 가독성과 TTS 톤을 조정하기 위해 (1) ASS 자막의 폰트 크기·위치·배경·줄바꿈을 수정하고, (2) CTA 오버레이 폰트를 축소·Bold로 통일했으며, (3) Edge TTS에 rate/pitch를 적용해 쇼츠에 맞는 빠른 템포와 밝은 톤을 적용했다.

---

## 2. 변경 사항

### 2.1 자막 (ASS – ffmpeg_composer.py SubtitleGenerator)

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 폰트 크기 | 42 | **28** (약 60% 축소) |
| 자막 위치 | margin_bottom=180 | **int(config.height * 0.2)** (화면 하단 20% 영역, 1920 기준 384px) |
| 자막 배경 | BackColour &H80000000 | **&HB3000000** (반투명 검정 ~70% 불투명도) |
| 줄바꿈 | max_chars_per_line=12 | **15** (한글 기준 14~16자) |
| 폰트 | Noto Sans CJK KR | **Noto Sans CJK KR** (Bold=-1 유지; CTA는 Bold.ttc 사용) |

- 가운데 정렬(Alignment=2), outline_width=3, shadow_depth=2 유지.

### 2.2 CTA 오버레이 (drawtext)

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 폰트 파일 | NotoSansCJK-Regular.ttc | **NotoSansCJK-Bold.ttc** |
| 폰트 크기 | 48 | **28** |
| 박스 | boxcolor=black@0.5 | **boxcolor=black@0.7** |

- 위치: 기존처럼 화면 중앙 유지 (마지막 3초).

### 2.3 TTS 속도/피치 (tts_generator.py, config.py)

- **config.py:**  
  - `edge_tts_rate: str = "+15%"` (환경변수 `EDGE_TTS_RATE`)  
  - `edge_tts_pitch: str = "+5Hz"` (환경변수 `EDGE_TTS_PITCH`)
- **tts_generator.py:**  
  - `_generate_edge()`에서 `edge_tts.Communicate(text, voice, rate=..., pitch=...)` 호출 시  
    `settings.edge_tts_rate`, `settings.edge_tts_pitch` 사용.

## 4. 주의사항 / 후속 작업

- **rate/pitch:** `EDGE_TTS_RATE`, `EDGE_TTS_PITCH`로 환경변수 조정 가능 (예: "+10%", "+3Hz").
- **ASS 폰트:** 시스템에 "Noto Sans CJK KR"이 있어야 하며, Docker 이미지에는 Phase 11 폰트 설치로 포함됨.
- **CTA 폰트 경로:** `/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc` (opentype). 없을 경우 Phase 11 폰트 패키지 또는 fallback 경로 확인 필요.
