## 1. 작업 개요

StyleFlow 원본 영상(MOV)을 MP4로 일괄 변환하는 서비스를 구현하였다. NAS 동기화 후 cron으로 주기 실행되며, 날짜 서브폴더 구조를 유지하고 이미 변환된 파일은 스킵한다.

## 2. 변경 사항

### 2.1 변환 스크립트 `scripts/convert_mov_to_mp4.py`

- **입력:** `.env`의 `STYLEFLOW_RAW_PATH`(기본 `/data/styleflow/raw`) 아래 MOV/mov 파일 재귀 탐색
- **출력:** `STYLEFLOW_OUTPUT_PATH`(기본 `/data/styleflow/output`)에 MP4 저장
- **스킵 조건:** output에 동일 상대경로의 `.mp4`가 이미 있으면 스킵
- **날짜 서브폴더 유지:** `raw/20260220/IMG_xxx.MOV` → `output/20260220/IMG_xxx.mp4`
- **로그:** stdout/stderr는 배치 스크립트에서 `logs/convert_YYYYMMDD.log`로 리다이렉트
- **요약 출력:** 성공/스킵/실패 건수 및 실패 시 에러 메시지

### 2.2 FFmpeg 옵션

| 항목 | 값 |
|------|-----|
| 해상도 | 1080x1920 (비율 유지 후 패딩) |
| 프레임레이트 | 29.97 fps |
| 비디오 코덱 | H.264 (libx264), CRF 23 |
| 오디오 코덱 | AAC |
| 최대 길이 | 60초 (`-t 60`) |
| 메타데이터 | 스트립 (`-map_metadata -1`) |

- CRF, 최대 길이, FPS, 해상도는 `.env`에서 `STYLEFLOW_CONVERT_CRF`, `STYLEFLOW_MAX_DURATION`, `STYLEFLOW_TARGET_FPS`, `STYLEFLOW_TARGET_RESOLUTION`로 설정 가능.

### 2.3 .env / .env.example

다음 키를 `.env.example`에 추가하고, 서버 `.env`에는 동일 키로 실제 경로/값 설정.

- `STYLEFLOW_RAW_PATH`
- `STYLEFLOW_OUTPUT_PATH`
- `STYLEFLOW_CONVERT_CRF`
- `STYLEFLOW_MAX_DURATION`
- `STYLEFLOW_TARGET_FPS`
- `STYLEFLOW_TARGET_RESOLUTION`

(실제 값은 보고서에 노출하지 않음.)

### 2.4 배치 래퍼 `scripts/convert_batch.sh`

- `set -euo pipefail`, 프로젝트 루트로 이동, venv 활성화
- `python3 scripts/convert_mov_to_mp4.py` 실행 후 `logs/convert_$(date +%Y%m%d).log`에 append
- 실행 권한: 서버에서 `chmod +x scripts/convert_batch.sh` 권장

### 2.5 crontab 등록 (서버에서 수행)

- NAS 동기화(매 :00, :30) 후 10분 뒤 변환 실행:
- `10,40 * * * * /bin/bash /data/shortflow/scripts/convert_batch.sh >> /data/shortflow/logs/cron.log 2>&1`

## 3. 테스트 결과

- **로컬/작업 환경:** 스크립트 및 배치 파일 생성·문법 검증 완료.
- **서버 테스트:** rfree-0009.cafe24.com에서 다음 순서로 진행 권장.
  1. Step 0 사전 확인 (ffmpeg, ffprobe, raw/output 경로, 디스크)
  2. Step 1 디렉토리 생성: `mkdir -p /data/styleflow/output /data/shortflow/logs`
  3. MOV 없을 때: `ffmpeg -f lavfi -i color=c=blue:s=1080x1920:r=29.97:d=5 -f lavfi -i anullsrc=r=44100:cl=stereo -t 5 /data/styleflow/raw/test_input.MOV` 로 테스트 MOV 생성
  4. `python3 /data/shortflow/scripts/convert_mov_to_mp4.py` 실행
  5. `ls -la /data/styleflow/output/`, `ffprobe /data/styleflow/output/test_input.mp4 2>&1 | grep -E "Duration|Video|Audio"` 로 검증
  6. 테스트 파일 정리: `rm -f /data/styleflow/raw/test_input.MOV /data/styleflow/output/test_input.mp4`
