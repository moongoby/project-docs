# 1단계: Docker 설치 + 환경 준비 — 실행 보고서

**작성일시:** 2026-02-13  
**작업 유형:** 설정 변경 / 환경 구축  
**상태:** 완료  
**관련 파일:** 없음 (시스템·디렉터리·env 설정)

---

## 1. 작업 개요

E2E 테스트 및 Docker 배포를 위한 1단계 지시문에 따라, Docker 설치·data 디렉터리 생성·.env 파일 생성을 순서대로 실행한 결과를 보고한다. 실행 중 apt 의존성 충돌(php7.4-gd)이 있어 `apt --fix-broken install`로 해결한 뒤 Docker 설치를 진행하였다.

---

## 2. 실행 결과 요약

| 단계 | 항목 | 결과 | 비고 |
|------|------|------|------|
| 1 | Docker 설치 | 완료 | docker-ce, docker-compose-plugin 등 설치 |
| 1 | docker / docker compose 버전 | 완료 | 28.1.1 / v2.35.1 |
| 2 | data 디렉터리 생성 | 완료 | videos, images, audio, temp, thumbnails, logs, tokens |
| 3 | .env 파일 생성 | 완료 | .env.example → .env 복사, 키 목록 안내 |

---

## 3. 상세 결과

### 3-1. Docker 설치 (Step 1)

- **기존 패키지 제거:** `docker docker-engine docker.io containerd runc` 제거 시도(없음으로 스킵).
- **필수 패키지:** ca-certificates, curl, gnupg, lsb-release 설치 시도 → **의존성 오류** 발생  
  - 원인: `php7.4-gd` ↔ `php7.4-common` 버전 불일치.  
  - 조치: `sudo apt-get install -y --fix-broken` 실행 → php7.4-gd 제거로 해결.
- **Docker GPG 키·저장소:** `/etc/apt/keyrings/docker.gpg`, `/etc/apt/sources.list.d/docker.list` 추가 완료.
- **Docker 설치:** docker-ce, docker-ce-cli, containerd.io, docker-buildx-plugin, docker-compose-plugin 설치 완료.
- **docker 그룹:** `sudo usermod -aG docker $USER` 실행. (sudo 없이 docker 사용하려면 재로그인 필요할 수 있음.)

**버전 확인 출력:**

```
Docker version 28.1.1, build 4eba377
Docker Compose version v2.35.1
```

### 3-2. data 디렉터리 생성 (Step 2)

- **명령:** `mkdir -p /data/shortflow/data/{videos,images,audio,temp,thumbnails,logs,tokens}`
- **확인:** `ls -la /data/shortflow/data/` 실행 결과, 하위 디렉터리 7개 생성 확인.

```
drwxr-xr-x 2 root root 4096  audio
drwxr-xr-x 2 root root 4096  images
drwxr-xr-x 2 root root 4096  logs
drwxr-xr-x 2 root root 4096  temp
drwxr-xr-x 2 root root 4096  thumbnails
drwxr-xr-x 2 root root 4096  tokens
drwxr-xr-x 2 root root 4096  videos
```

### 3-3. .env 파일 생성 (Step 3)

- **명령:** `cp /data/shortflow/.env.example /data/shortflow/.env`
- **결과:** .env 파일 생성 완료. 실제 API 키·값은 사용자가 직접 입력해야 함.
- **편집 안내:** `nano /data/shortflow/.env` 로 편집.

**.env에 설정할 키 목록 (값은 ??? 로 안내):**

- SUPABASE_URL, SUPABASE_KEY, SUPABASE_SERVICE_KEY  
- ANTHROPIC_API_KEY, OPENAI_API_KEY, ELEVENLABS_API_KEY, ELEVENLABS_VOICE_ID  
- CLAUDE_MODEL  
- YOUTUBE_CHANNELS_JSON, UPLOAD_POST_API_KEY  
- NAVER_CLIENT_ID, NAVER_CLIENT_SECRET  
- SLACK_WEBHOOK_URL  
- DATA_PATH  

(.env.example에 N8N_AUTH_USER, N8N_AUTH_PASSWORD가 있으면 동일하게 .env에서 설정.)

## 4. 확인 사항 (요청 3가지)

1. **docker --version / docker compose version**  
   → Docker version 28.1.1, Docker Compose version v2.35.1 출력 확인.

2. **/data/shortflow/data/ 하위 디렉터리**  
   → videos, images, audio, temp, thumbnails, logs, tokens 생성 확인.

3. **.env 파일 생성**  
   → .env.example을 복사한 .env 파일 존재 확인. 키 값은 미입력 상태로, 사용자 편집 필요.

## 6. 주의사항

- **docker 그룹:** `usermod -aG docker $USER` 적용 후, sudo 없이 docker를 쓰려면 **해당 계정으로 로그아웃 후 재로그인**이 필요할 수 있음.
- **php7.4-gd:** 의존성 수정 과정에서 제거됨. PHP GD 이미지 처리가 필요하면 별도 설치 검토.
