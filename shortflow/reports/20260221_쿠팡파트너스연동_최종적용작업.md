## 1. 작업 개요

쿠팡 파트너스 연동을 서버에 최종 적용하기 위해 Supabase 마이그레이션, 쿠팡 링크 임시 처리, .env 업데이트, Docker 재빌드·테스트, 영상 업로드 테스트를 수행했다. 마이그레이션은 Supabase 대시보드에서 직접 실행해야 하며, 업로드 테스트는 OAuth 토큰 만료로 실패했다.

## 2. 변경 사항

### 2.1 Supabase 마이그레이션 (수동 실행 필요)

- **상태:** `daily_picks` 테이블에 `coupang_url` 컬럼이 없음 확인됨 (update 스크립트 실행 시 `PGRST204` 스키마 캐시 오류).
- **조치:** Supabase 대시보드 → SQL Editor에서 아래 SQL을 **직접 실행**해야 함.

```sql
-- sql/002_daily_picks_coupang_url.sql
ALTER TABLE daily_picks
ADD COLUMN IF NOT EXISTS coupang_url TEXT;

COMMENT ON COLUMN daily_picks.coupang_url IS 'Coupang Partners affiliate link for this product';
```

- 실행 후 **쿠팡 링크 임시 등록**을 위해 아래 명령 한 번 더 실행:

```bash
cd /data/shortflow && docker compose run --rm -v /data/shortflow:/data/shortflow -w /data/shortflow -e PYTHONPATH=/data/shortflow/worker worker python3 scripts/coupang_links_update.py update --file data/coupang_links.json
```

### 2.2 쿠팡 링크 임시 등록

- **스크립트 수정:** `scripts/coupang_links_update.py`에서 `coupang_url`이 빈 문자열이어도 DB 업데이트하도록 수정 (기존: 빈 값이면 해당 행 스킵).
- **데이터 파일:** `data/coupang_links.json` 생성. pick_id 1~6에 대해 `coupang_url: ""` 설정.
- **list 실행 결과:** 6개 pick 정상 조회 (pick_id, product_name, category).
- **update:** 마이그레이션 미실행 상태에서 실행하여 0건 업데이트. 위 2.1 SQL 실행 후 동일 update 명령 재실행 필요.

### 2.3 .env 업데이트

- **추가/유지 내용 (기존 값 삭제 없음):**
  - `CHANNEL_NAME=오늘의쇼핑픽`
  - `COUPANG_ACCESS_KEY=` (빈 값, API 승인 후 입력)
  - `COUPANG_SECRET_KEY=` (빈 값, API 승인 후 입력)
- `AUTO_UPLOAD=false`, `VIDEO_PROVIDER=ffmpeg` 등 기존 설정 유지.

### 2.4 Docker 재빌드 및 테스트

- `docker compose down` → `docker compose build worker` → `docker compose up -d` 실행 완료.
- **컨테이너:** shortflow-worker(healthy), shortflow-n8n, shortflow-dashboard 정상 기동.
- **헬스체크:** `curl http://localhost:8000/health` → `{"status":"ok","service":"shortflow-worker"}`.
- **파이프라인:** `curl -X POST http://localhost:8000/api/v1/pipeline/daily` → `{"success":true,"message":"Daily pipeline started","data":{"job_id":32,"pick_id":3,"status":"started"}}`.
- Worker 로그에서 Job 32 SCRIPTING 단계 정상 진행 확인.

### 2.5 영상 업로드 테스트

- **결과:** 실패. 원인: YouTube OAuth 토큰 만료/폐기 (`google.auth.exceptions.RefreshError: invalid_grant: Token has been expired or revoked`).
- **조치:** 서버 또는 로컬에서 OAuth 재인증 후 `token.pickle` 갱신 필요. 이후 동일 업로드 스크립트로 재테스트. 테스트 시 `privacy_status='private'` 유지.

## 4. 주의사항 / 후속 작업

1. **Supabase:** 위 2.1 SQL을 SQL Editor에서 실행한 뒤, `coupang_links_update.py update --file data/coupang_links.json` 다시 실행하여 6건 coupang_url을 빈 문자열로 설정.
2. **YouTube 업로드:** OAuth 재인증 후 동일 업로드 명령으로 재테스트. `AUTO_UPLOAD=false` 유지.
3. **쿠팡 API:** 승인 후 `.env`에 `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` 입력하고 필요 시 파이프라인에서 자동 링크 생성 전환.
