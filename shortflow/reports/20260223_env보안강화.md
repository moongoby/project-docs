## 2. 변경 사항

### Step 1 – 현황 파악 결과

- **.env 키:** Supabase, AI API(Anthropic/OpenAI/ElevenLabs), Claude 모델, YouTube/채널, 쿠팡/네이버/Slack, n8n, TTS, Daily Picks 기본값, Newtalk(autoda) DB 등 전부 확인. (값은 미노출 원칙으로 보고서에 기입하지 않음.)
- **.gitignore:** `.env`, `credentials/` 포함 확인. 추가로 `.env.*`, `*.key`, `*.pem`, `client_secret*.json`, `token*.json`, `*.pack`, `.next/cache/` 반영.
- **Git 추적:** .env 및 credentials 내 민감 파일은 추적되지 않음 확인.
- **credentials 폴더:** 존재함. `client_secret.json`, `gcloud-tts-key.json`, `token.pickle` 등 보관 중. `.gitkeep`만 Git 등록.
- **.env.example:** 기존 없음 → 신규 생성.
- **빈 값/플레이스홀더:** `UPLOAD_POST_API_KEY`, `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY`, `N8N_AUTH_PASSWORD`(changeme), `NEWTALK_DB_PASSWORD`(환경에서확인필요) 등.

### Step 2 – 보안 조치

- **git rm --cached:** .env·credentials는 원래 미추적 상태였음. 추가 제거 없음.
- **.gitignore 보강:**  
  `.env.*`, `!.env.example`, `!credentials/.gitkeep`, `*.key`, `*.pem`, `client_secret*.json`, `token*.json`, `*.pack`, `.next/cache/` 추가.
- **.env.example:** .env의 모든 키를 주석(용도)과 함께 빈 값으로 정리해 등록.
- **credentials:** `credentials/.gitkeep` 생성 후 Git에만 등록.

### Step 3 – .env 값 세팅 가이드

- **파일:** `docs/guides/env_setup_guide.md`
- **내용:** DB(Newtalk/autoda), Supabase, YouTube/채널, NAS(참고), TTS, LLM/AI API, 쿠팡 파트너스, 기타(네이버, Slack, n8n, DATA_PATH 등)별 키 설명 및 획득 방법. 빈 값 정리·보안 수칙 포함.
- **DB 접속 확인:** `NEWTALK_DB_*` 기준으로 MySQL 접속 테스트 수행. **결과: 실패** (비밀번호 플레이스홀더/미설정 상태). .env의 `NEWTALK_DB_PASSWORD`를 실제 DB 비밀번호로 설정 후 재검증 필요.

- **백업:** `/data/shortflow/backups/20260223_103046/`에 .env, .gitignore 복사 완료.

## 4. 주의사항 / 후속 작업

- **.env 실제 값**은 보고서·커밋·로그·문서에 절대 기입하지 말 것.
- **NEWTALK_DB_PASSWORD:** 서버/운영 담당자에게 실제 MySQL 비밀번호 확인 후 .env에 반영하고, `mysql -u pigupuser -p -e "SELECT 1" autoda`로 접속 재확인.
- **UPLOAD_POST_API_KEY, COUPANG_ACCESS_KEY/SECRET_KEY, N8N_AUTH_PASSWORD:** 사용 전 각 서비스에서 발급·설정 후 .env에 입력.
