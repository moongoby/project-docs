# 통신판매업 신고 가이드 (ShortFlow SaaS 운영용)

> 작성일: 2026-02-23 KST

---

## 1. 신고 필요 사유

- **ShortFlow**: 월 구독형 SaaS (29k / 59k / 99k원)
- **StyleFlow**: B2B SaaS (149k / 349k / 690k원)
- 전자상거래법상 **통신판매** 해당 → 신고 의무
- 미신고 시 **과태료 최대 1,000만원**

### ★ 면제 기준

- **연 영업금액 1.5억 미만** 또는 **연 거래 50회 미만** → 신고 면제 가능
- 초기에는 면제 가능하나, SaaS 확장 시 **신고 필수** 권장

## 2. 사전 준비물

| # | 준비물 | 비고 |
|---|--------|------|
| 1 | [ ] **사업자등록증** | 뉴톡 기존 등록 확인 |
| 2 | [ ] **법인등기부등본** | '통신판매업' 목적 기재 여부 확인 → 미기재 시 목적 변경 등기 선행 필요 |

| 5 | [ ] **구매안전서비스(에스크로) 이용 확인증** | PG사(카카오페이/토스/이니시스 등) 계약 후 발급 |

---

## 3. 온라인 신고 절차 (정부24)

1. https://www.gov.kr/ 접속 → 간편인증/공동인증서 로그인
2. 검색: **'통신판매업신고'** → 해당 서비스 선택
3. **업체 정보** 입력 (상호, 대표자, 사업자번호)
4. **대표자 정보** 입력
5. **판매정보** 입력 (도메인, 서버 소재지)
6. **구비서류** 첨부 (사업자등록증, 에스크로 확인증)
7. **등록면허세** 납부 (40,500원 ~ 지역별 상이)
8. **처리기간**: 3~7 영업일
9. **신고증** 출력 (정부24 My gov → 신청내역)

## 4. 신고 후 필수 조치

- [ ] SaaS 사이트 하단에 **통신판매업 신고번호 표기**
- [ ] **이용약관**, **개인정보처리방침** 게시
- [ ] **PG사 연동** (구독 결제)
- [ ] **쿠팡 파트너스** 신고번호 등록 (필요 시)
