# ShortFlow 영상 편집 파이프라인 테스트

**작성일시:** 2026-02-21 16:35  
**작업 유형:** 신규 개발 / 테스트  
**상태:** 완료  
**관련 파일:** `worker/services/video_editor.py`, `worker/Dockerfile`, `data/videos/test_*.mp4`

---

## 1. 작업 개요

외부 소스(가로 16:9) 영상을 다운로드 → 쇼츠용 9:16 편집 → TTS 합성까지의 파이프라인을 구현하고, 테스트 A~E를 순차 실행하여 검증했다.

## 2. 변경 사항

### 2.1 테스트용 샘플 영상

- Pexels / file-examples 등 외부 직접 URL은 AccessDenied·HTML 응답으로 실패.
- 호스트에 ffmpeg 설치 후 **ffmpeg testsrc**로 16:9(1920×1080, 60초) 테스트 영상 생성: `data/videos/sample_source.mp4`.

### 2.2 영상 편집 서비스 `worker/services/video_editor.py`

- **crop_to_vertical**: 가로 → 9:16 세로 크롭(중앙 기준), 1080×1920.
- **change_speed**: 영상·오디오 속도 변경(atempo + setpts).
- **add_text_overlay**: 상품명·가격 자막 오버레이(NanumGothicBold, 상단 제목 / 하단 가격).
- **add_blur_background**: 가로 영상을 블러 배경 위에 중앙 배치해 세로 변환.
- **trim_video**: 시작·길이 기준 트림(쇼츠 60초 이내).
- **full_edit_pipeline**: 트림 → 세로 변환(crop 또는 blur) → 속도 변경(선택) → 자막. 임시 파일 자동 정리.

### 2.3 Dockerfile(worker)

- `fonts-nanum` 패키지 추가하여 한글 자막(NanumGothicBold) 지원.

- `test_final_complete.mp4`: **1080×1920**, 비디오(h264) + 오디오(aac) 트랙 포함, TTS 나레이션 합성 완료.
- `ls -la data/videos/test_*.mp4` 및 `ffprobe`로 해상도·스트림 검증 완료.

## 4. 주의사항 / 후속 작업

- **샘플 영상**: 실제 운영 시에는 쿠팡/카페24 등에서 HTML 파싱으로 영상 URL 추출 후 다운로드하거나, Pexels/Pixabay 등 무료 소스 정책에 맞는 URL을 사용할 것. 현재는 테스트용으로 ffmpeg testsrc 사용.
- **자막 폰트**: Docker 이미지에 `fonts-nanum` 필수. 없으면 `add_text_overlay` 실패.
- **테스트 영상**: 비공개 유지, 공개 업로드 금지.
- 성공한 기능(video_editor 모듈·전체 파이프라인·TTS 합성)을 기존 ShortFlow 파이프라인(외부 소스 → 쇼츠 편집 → 업로드)에 통합하면 된다.
