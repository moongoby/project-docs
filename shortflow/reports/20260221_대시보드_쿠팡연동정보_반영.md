# 대시보드 쿠팡·연동 정보 반영

**작성일시:** 2026-02-21
**작업 유형:** 신규 개발 (대시보드 기능)
**상태:** 완료
**관련 파일:** `dashboard/app.py`

---

## 1. 작업 개요

쿠팡 파트너스 연동 최종 적용에서 다루었던 정보(채널명, 쿠팡 API 설정 여부, 상품별 쿠팡 링크 등)를 **ShortFlow AI 대시보드(Streamlit)**에서 한눈에 확인할 수 있도록 반영했다.  
(참고: 본 프로젝트에는 "뉴톡 어드민"이라는 별도 대시보드는 없으며, **ShortFlow 대시보드 = 어드민 대시보드**로 간주하고 여기에 반영했다. 별도의 뉴톡 어드민 시스템이 있다면 해당 시스템과의 연동이 추가로 필요하다.)

## 2. 변경 사항

### 2.1 Overview(📊) — 연동 상태 섹션 추가

- **위치:** 메트릭(총 Job 수, 성공률, 오늘 생성 영상, 활성 상품 수) 아래, Job 상태별 파이차트 위.
- **표시 내용 (🔗 연동 상태):**
  - **채널명:** `CHANNEL_NAME` 환경 변수 값 (예: 오늘의쇼핑픽). 미설정 시 "-".
  - **쿠팡 파트너스 API:** `COUPANG_ACCESS_KEY` 존재 여부만 표시. 설정됨 / 미설정 (API 승인 후 .env 입력). 키 값은 노출하지 않음.
  - **Worker API:** Worker `/health`·통계 조회 성공 시 "연동됨", 실패 시 "연동 실패".
  - **Supabase:** 클라이언트 생성 및 jobs 조회 성공 시 "연동됨", 실패 시 "연동 실패".

### 2.2 Products(🛍️ 상품 관리) — 쿠팡 링크 컬럼 및 상세

- **테이블 컬럼 추가:** 상품 목록 테이블에 **"쿠팡 링크"** 컬럼 추가.
  - `daily_picks.coupang_url`이 비어 있지 않으면 **"등록됨"**, 비어 있으면 **"미등록"** 표시.
  - Supabase에 `coupang_url` 컬럼이 아직 없어도 `.get("coupang_url")`로 조회하므로 오류 없이 "미등록"으로 표시된다.
- **상세 블록:** 쿠팡 링크가 등록된 상품이 1건이라도 있으면, **"🛒 쿠팡 파트너스 링크 상세"** expander를 표시하고, 해당 상품명·id·URL(클릭 가능한 링크)을 나열.

## 3. 테스트 결과

- `dashboard/app.py` 수정 후 린트 오류 없음.
- Docker 대시보드 컨테이너는 `env_file: .env`로 기동하므로 `CHANNEL_NAME`, `COUPANG_ACCESS_KEY` 등이 환경 변수로 주입되며, 별도 설정 없이 연동 상태에 반영된다.

## 4. 주의사항 / 후속 작업

- **Supabase 마이그레이션:** `daily_picks.coupang_url` 컬럼을 추가한 후에는 상품 관리 테이블에서 실제 링크 등록 여부가 "등록됨/미등록"으로 구분되고, 링크 상세 expander에 URL이 표시된다.
- **별도 "뉴톡 어드민" 시스템:** 다른 제품명의 뉴톡 어드민 대시보드가 별도로 있다면, 해당 시스템에 ShortFlow API(Worker API, Supabase 읽기 등)를 연동하거나, 동일한 연동 상태·쿠팡 링크 정보를 그쪽 UI에 노출하려면 별도 개발이 필요하다.
