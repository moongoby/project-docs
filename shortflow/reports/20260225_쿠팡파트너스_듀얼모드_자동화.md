## 1. 개요

SaaS 회원이 쿠팡 파트너스 API 발급 전에도 affiliate 링크를 자동 생성할 수 있는 **듀얼모드** 시스템 구현.

| 모드 | 입력 | 방식 | 대상 |
|------|------|------|------|
| **API 모드** | access_key + secret_key | 쿠팡 공식 Open API (HMAC-SHA256) | API 발급 완료 회원 |
| **브라우저 모드** | 쿠팡 파트너스 ID/PW | Playwright headless Chromium 자동화 | API 미발급 초보 회원 |
| **수동 모드** | - | daily_picks.coupang_url 직접 입력 | 미설정 회원 |

### Fallback Chain (우선순위)
```
1. 테넌트 API 키 → 공식 API
2. 테넌트 ID/PW → Playwright 브라우저 자동화
3. 서버 글로벌 API 키 (settings)
4. daily_picks.coupang_url (수동)
5. fallback 문구 ("쿠팡에서 검색")
```

## 4. DB 스키마

### coupang_credentials 테이블

```sql
CREATE TABLE coupang_credentials (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id UUID NOT NULL UNIQUE REFERENCES tenants(id) ON DELETE CASCADE,
    login_id TEXT,                  -- 쿠팡 파트너스 로그인 이메일
    login_pw_encrypted TEXT,        -- Fernet(AES) 암호화된 비밀번호
    api_access_key TEXT,
    api_secret_key TEXT,
    api_partner_id TEXT,
    mode TEXT DEFAULT 'manual' CHECK (mode IN ('browser', 'api', 'manual')),
    last_verified_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ DEFAULT now(),
    updated_at TIMESTAMPTZ DEFAULT now()
);
```

- RLS 정책: `tenant_id IN (SELECT id FROM tenants WHERE owner_id = auth.uid())`
- Supabase SQL Editor에서 실행 완료

## 6. 보안

- **비밀번호 암호화:** Python `cryptography` 라이브러리 Fernet (AES-128-CBC + HMAC)
- **암호화 키:** `CREDENTIAL_ENCRYPT_KEY` 환경변수 (서버 `.env`에만 보관, git 미포함)
- **DB 저장:** 암호문만 저장 (`login_pw_encrypted`), 평문 미보관
- **API 응답:** 이메일·키 마스킹 처리 (`a***@example.com`, `abc********`)
- **RLS:** Supabase Row Level Security로 본인 테넌트 데이터만 접근

```

  → job.artifacts.coupang_url에 저장
  → YouTube 업로드 시 Description에 삽입
```
