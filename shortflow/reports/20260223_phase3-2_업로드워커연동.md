## 1. 작업 개요

- YouTube 스케줄 업로드를 placeholder에서 **실제 upload_worker.py 파이프라인**으로 전환.
- `--channel`(korea_walker / moongoby), 채널별 토큰·일일 한도, 미업로드 MP4 탐색, 10-Layer 오리지널리티 체크, 비공개 업로드, `uploaded_videos.json` 추적, `--dry-run`/`--skip-originality-check` 지원.

## 2. 변경 사항

### upload_worker.py 기능 목록

1. **--channel**  
   `korea_walker` / `moongoby` 등. `YOUTUBE_CHANNELS_JSON`에서 해당 채널의 `token_path`, `daily_limit` 로드.
2. **YOUTUBE_CHANNELS_JSON**  
   채널별 토큰 경로·일일 한도 로드.
3. **미업로드 MP4 탐색**  
   `/data/styleflow/output/` 재귀 탐색, `logs/uploaded_videos.json`에 기록된 파일 제외.
4. **업로드 추적**  
   `logs/uploaded_videos.json`에 `file`, `channel`, `video_id`, `uploaded_at`, `status` 저장.
5. **10-Layer anti_inauthentic 호출**  
   `originality_score >= 70` 이면 업로드 진행, `< 70` 이면 스킵 후 로그.
6. **YouTube Data API videos.insert**  
   `privacyStatus: private`로 업로드.
7. **메타데이터**  
   title(파일명 기반), description(쿠팡 파트너스 문구), tags(ShortFlow/리뷰/추천), categoryId 26(Howto & Style).
8. **업로드 성공 시**  
   `[채널명] 업로드 성공` 로그 및 Video ID/URL 출력.
9. **일일 한도**  
   채널당 6건(설정 가능) 체크.
10. **--dry-run**  
    실제 업로드 없이 대상 파일 수·메타데이터 미리보기·originality_score 출력.
11. **--skip-originality-check**  
    테스트용 오리지널리티 체크 생략(1건 검증용).

### scheduled_upload.sh 변경 내역

- **기존:** `python3 -c "..."` placeholder(트리거 메시지만 출력).
- **변경:** `python3 "${PROJECT_DIR}/scripts/upload_worker.py" --channel "${CHANNEL_FOR_RUN}"` 로 실제 워커 호출.
- 시간대별 채널 분배·일일 한도·랜덤 오프셋 로직은 유지(09→korea_walker, 13→moongoby, 18→korea_walker).

### uploaded_videos.json

- **경로:** `/data/shortflow/logs/uploaded_videos.json`
- **구조:**  
  `[{"file":"20260113/IMG_4628.mp4","channel":"korea_walker","video_id":"xxx","uploaded_at":"2026-02-23T16:22:55","status":"private"}]`
- `.gitignore`: `logs/` 포함으로 버전 관리 제외.

## 4. 주의사항 / 후속 작업

- 실제 스케줄 실행 시에는 `--skip-originality-check` 사용하지 않음. 오리지널리티 70 미만은 스킵.
- 출력 폴더 MP4는 메타데이터만으로 스코어 시 50이 기본이라, 파이프라인에서 레이어 결과를 넘기거나 ORIGINALITY_THRESHOLD 조정 검토 가능.
- 쿠팡 파트너스 링크는 `YOUTUBE_DESCRIPTION_COUPANG` 또는 후속에 상품·DB 연동으로 보강 가능.
- 대량 업로드 금지. 1건 검증 완료 후 스케줄은 1회당 1건 처리(현재 워커는 첫 성공 건 후 break).
