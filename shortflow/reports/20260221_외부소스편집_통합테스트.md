## 1. 작업 개요

외부 소스 편집(edit_source) 통합 테스트를 순서대로 수행했다. .env 추가, file:// 로컬 파일 지원 패치, Docker 재빌드, video_mode 컬럼 없을 때 폴백 처리까지 반영했으며, **edit_source 테스트를 완료하려면 Supabase에서 004 마이그레이션 실행이 선행**되어야 한다.

---

## 2. 변경 사항

### 2.1 .env 추가
- `DEFAULT_VIDEO_MODE=ai_generate`
- `DEFAULT_EDIT_SPEED=1.1`
- `DEFAULT_EDIT_STYLE=crop`
- `DEFAULT_EDIT_DURATION=55`

### 2.2 pipeline_worker.py
- **file:// 로컬 파일 지원:** `video_source_url`이 `file://` 또는 절대 경로(`/...`)일 때 `httpx` 대신 `shutil.copy`로 소스 복사.
- **video_mode 컬럼 폴백:** `daily_picks`에 `video_mode`/`video_source_url` 컬럼이 없을 때(004 미적용) `APIError`를 잡아 `product_name, price`만 조회하고 기본값 `ai_generate`, `None`으로 진행하도록 수정. 기존 DB에서도 파이프라인 동작.

### 2.3 Docker
- `docker compose down && docker compose build worker && docker compose up -d` 수행.
- `curl http://localhost:8000/health` → `{"status":"ok","service":"shortflow-worker"}` 확인.

### 2.4 테스트 샘플
- `data/videos/sample_source.mp4` 존재 확인 (약 2MB).

## 3. 테스트 결과

### 3.1 Supabase 마이그레이션(004) 미적용 시
- `daily_picks`에 `video_mode`/`video_source_url` 컬럼이 없으면:
  - 테스트 상품 insert 시 `PGRST204` (description 없음) → description 제거 후 재시도.
  - 그다음 `video_mode` 컬럼 없음으로 insert 실패.
  - 파이프라인 트리거 시 worker가 `video_mode` 조회에서 `42703`(undefined column)로 실패 → **폴백 적용 후** 동일 쿼리 실패 시 `product_name, price`만 조회해 기본값으로 진행하도록 수정함.

### 3.2 폴백 적용 후
- 파이프라인 트리거: `POST /api/v1/pipeline/daily` → job_id 34, pick_id 2 시작.
- Job 34: SCRIPTING → SCRIPTED → GENERATING_IMAGES 정상 진행(Google Imagen 생성까지 확인).

### 3.3 edit_source E2E (완료 조건)
- **선행 조건:** Supabase 대시보드 SQL Editor에서 `sql/004_daily_picks_video_source.sql` 실행.
- 실행 후 테스트 상품 등록 및 파이프라인 트리거 시, `video_mode=edit_source`, `video_source_url=file:///data/shortflow/data/videos/sample_source.mp4`인 pick이 선택되면 외부 소스 편집 → TTS → `*_final.mp4` 생성까지 검증 가능.

## 4. 주의사항 / 후속 작업

### 4.1 Supabase에서 004 마이그레이션 실행 (필수)

Supabase 대시보드 → SQL Editor에서 아래 SQL 실행:

```sql
-- Add video source and mode columns for edit_source flow
-- Run after 001_initial_schema.sql, 002_daily_picks_coupang_url.sql

ALTER TABLE daily_picks
ADD COLUMN IF NOT EXISTS video_source_url TEXT;

ALTER TABLE daily_picks
ADD COLUMN IF NOT EXISTS video_mode TEXT DEFAULT 'ai_generate';

COMMENT ON COLUMN daily_picks.video_source_url IS '외부 소스 영상 URL (있으면 편집 모드)';
COMMENT ON COLUMN daily_picks.video_mode IS 'ai_generate 또는 edit_source';
```

### 4.2 004 실행 후 테스트 상품 등록

```bash
docker compose exec worker python3 -c "
import os
from supabase import create_client
sb = create_client(os.environ['SUPABASE_URL'], os.environ['SUPABASE_KEY'])
result = sb.table('daily_picks').insert({
    'product_name': '테스트 외부편집 상품',
    'category': '전자기기',
    'price': 99000,
    'video_mode': 'edit_source',
    'video_source_url': 'file:///data/shortflow/data/videos/sample_source.mp4',
    'coupang_url': ''
}).execute()
print('Inserted pick_id:', result.data[0]['id'])
"
```

### 4.3 파이프라인 트리거 및 결과 확인

```bash
curl -X POST http://localhost:8000/api/v1/pipeline/daily
docker compose logs worker --tail 100 -f
# 생성 영상 확인
ls -la /data/shortflow/data/videos/*_edited.mp4 /data/shortflow/data/videos/*_final.mp4
ffprobe -v quiet -print_format json -show_format -show_streams /data/shortflow/data/videos/*_final.mp4
```

**성공 기준:** `*_final.mp4`가 1080x1920, h264+aac, 55초 이내.
