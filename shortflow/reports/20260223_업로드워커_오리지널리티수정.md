## 1. 작업 개요

upload_worker에서 10-Layer anti_inauthentic.evaluate() 호출 시, MP4 파일만으로는 레이어 데이터(layout_signature, script_text 등)가 없어 originality_scorer가 기본 score=50을 반환하고, ORIGINALITY_THRESHOLD=70 때문에 모든 영상이 업로드 스킵되던 문제를 수정하였다. 자체 채널(korea_walker, moongoby) 운영 Phase에서는 경량 평가(self_channel 모드)를 적용해 기본 70점 + cross_video 유사도만 검사하도록 변경하였다.

## 2. 문제 원인 분석

- **engine/originality_scorer.py**  
  `score(current, recent_*)`는 `current.layout_signature`, `current.script_text` 등이 있을 때만 가감점을 적용한다. 둘 다 비어 있으면 `total = 50`으로 유지된다.
- **upload_worker.py**  
  MP4 경로만으로 `AntiInauthenticInput(metadata_title=stem, metadata_tags=[])`만 전달하므로 레이아웃/스크립트 정보가 없고, 엔진은 항상 50점을 반환한다.
- **결과**  
  ORIGINALITY_THRESHOLD=70 이하이므로 모든 후보가 스킵되어 자체 채널에서 업로드가 한 건도 진행되지 않음.

## 3. 해결 방안 상세

### A. UPLOAD_MODE 도입

- **.env / .env.example**  
  `UPLOAD_MODE=self_channel` 또는 `saas`  
  - **self_channel**: 자체 채널용 경량 평가 (기본 70 + cross_video 감점)  
  - **saas**: 기존 풀 10-Layer anti_inauthentic 평가

### B. self_channel 모드 경량 평가 (upload_worker.py)

- 기본 점수 **70** (자체 촬영 원본 가정).
- **CrossVideoChecker**로 `uploaded_videos.json`에 기록된 최근 업로드 영상 경로와 유사도 비교.
- 유사도 ≥ 0.85이면 감점(25점) 적용 → score=45 → 70 미만이므로 스킵.
- 유사도 < 0.85이면 score=70 유지 → 업로드 진행.
- `get_recent_uploaded_absolute_paths()`로 업로드 이력에서 최근 N개 절대 경로 조회(디스크에 존재하는 파일만).

### C. saas 모드

- 기존과 동일하게 `AntiInauthenticEngine.evaluate()` 호출 (레이어 데이터 확보 시 풀 평가용).

### D. 변경 파일

- **scripts/upload_worker.py**  
  - `UPLOAD_MODE`, `SELF_CHANNEL_BASE_SCORE`, `CROSS_VIDEO_PENALTY_IF_SIMILAR` 상수 추가  
  - `get_recent_uploaded_absolute_paths()` 추가  
  - `_originality_self_channel()` 추가 (CrossVideoChecker 직접 호출)  
  - `originality_check()`에서 UPLOAD_MODE 분기 및 `recent_uploaded_paths` 인자 추가  
  - dry-run/실제 업로드 루프에서 `recent_uploaded_paths` 구성 후 전달  
- **.env.example**  
  - `UPLOAD_MODE=self_channel`, `ORIGINALITY_THRESHOLD=70` 주석과 함께 추가

## 4. 드라이런 결과 (score 변화)

- **UPLOAD_MODE=self_channel** 적용 확인.
- **최근 업로드 1건 존재 시**: 해당 영상과 오디오 유사도 1.0으로 판정되어 감점(45점) → pass=False. (기대된 동작)
- **최근 업로드 경로 0건인 경우**: `recent_uploaded_paths=[]`로 호출 시 score=70, pass=True 확인됨.
- 로직: 기본 70 + cross_video 유사도 ≥ 0.85 시 25점 감점 → 45점, 70 미만이면 스킵.

## 5. 실제 업로드 결과

- 실제 업로드 1건 테스트는 미실행(지시서상 private 1건 제한, 필요 시 `--channel moongoby` 등으로 실행 가능).
- 업로드 이력이 없는 채널/디렉터리에서는 score=70으로 통과하여 업로드 가능한 상태임.

## 7. 주의사항 / 후속 작업

- 실제 업로드는 private 1건만 테스트 권장. `.env` 값은 보고서에 노출하지 않음.
