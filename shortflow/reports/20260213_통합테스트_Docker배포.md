## 2. 변경 사항

### 2-1. docker-compose.yml

- **version:** 3.8
- **networks:** shortflow-net (bridge)
- **volumes:** n8n_data (named volume, n8n 전용)
- **n8n:** image n8nio/n8n:latest, 포트 5678, N8N_BASIC_AUTH 기본값(admin/shortflow), TZ=Asia/Seoul, cpus 1 / memory 2G, restart unless-stopped
- **worker:** build context `.`, dockerfile `worker/Dockerfile`, 포트 8000, env_file `.env`, 볼륨 `/data/shortflow/data:/data/shortflow/data`, cpus 3 / memory 4G, **healthcheck** `curl -f http://localhost:8000/health` (interval 30s, retries 3, start_period 30s), command `uvicorn main:app --host 0.0.0.0 --port 8000 --workers 1`, restart unless-stopped
- **dashboard:** build context `.`, dockerfile `dashboard/Dockerfile`, 포트 8501, env_file `.env`, 볼륨 read-only, cpus 0.5 / memory 1G, **depends_on worker condition: service_healthy**, restart unless-stopped

### 2-2. worker/Dockerfile

- Base: python:3.11-slim
- 시스템 패키지: ffmpeg, fonts-noto-cjk, curl
- WORKDIR /app/worker
- COPY worker/requirements.txt, pip install
- COPY worker/ . (프로젝트 루트를 build context로 사용)
- /data/shortflow/data 하위 디렉터리(videos, images, audio, temp, thumbnails, logs, tokens) 생성
- CMD uvicorn (--reload 제거, --workers 1)

### 2-3. dashboard/Dockerfile

- Build context를 프로젝트 루트(.)로 통일: COPY dashboard/requirements.txt, COPY dashboard/ .

### 2-4. .env.example

- Supabase (URL, KEY, SUPABASE_SERVICE_KEY), AI APIs (Anthropic, OpenAI, ElevenLabs), CLAUDE_MODEL, YouTube (YOUTUBE_CHANNELS_JSON, UPLOAD_POST_API_KEY), Naver (NAVER_CLIENT_ID, NAVER_CLIENT_SECRET), Slack, n8n (N8N_AUTH_USER, N8N_AUTH_PASSWORD), DATA_PATH

### 2-5. worker/tests/test_integration.py (신규)

- **8개 테스트:** test_full_health_check, test_trend_collection_endpoint, test_scoring_endpoint, test_job_lifecycle_create_and_status, test_batch_job_creation, test_pipeline_run_endpoint, test_stats_endpoint, test_feedback_endpoint
- httpx AsyncClient + pytest-asyncio, 외부 API(Supabase, TrendCollector, Job, ProductScorer, PipelineWorker 등) mock

### 2-6. docs/runbook.md

- 사전 준비(.env, Supabase 스키마, YouTube OAuth), Docker 기동, 상태 확인
- 일일 운영(자동 n8n, 수동 curl 예시)

## 4. Docker 기동 절차

```bash
cd /data/shortflow
# .env 생성 후
docker compose up -d --build
curl http://localhost:8000/health
# Dashboard: http://서버IP:8501, n8n: http://서버IP:5678
```

- dashboard는 worker healthcheck 통과 후 기동(depends_on: service_healthy)

---

## 5. 주의사항 / 후속 작업

- **볼륨 경로:** worker/dashboard 볼륨은 `/data/shortflow/data` 절대 경로. 로컬 개발 시 동일 경로 또는 compose 오버라이드로 조정.
- **.env:** docker-compose는 `.env` 파일을 읽음. 없으면 n8n 기본 인증만 적용되고 Worker/Dashboard는 키 미설정 시 오류 가능.
- **YouTube OAuth:** 최초 1회 `docker exec -it shortflow-worker python -m services.youtube_manager --auth CHANNEL_ID` 등으로 토큰 발급 필요.
- **통합 테스트:** E2E(실제 DB/API 연동)는 별도 환경에서 실행 권장.
