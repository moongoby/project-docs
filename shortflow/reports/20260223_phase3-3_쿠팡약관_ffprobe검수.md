## 3. Part 2 – 쿠팡 파트너스 약관 검증

### 3.1 약관 핵심 요약

- **링크 생성·배포:** 파트너스에 등록된 미디어(채널/사이트)에서만 광고 노출 허용. 링크·형태 조작 금지.
- **SaaS/자동화:** 자기 채널에서 도구 사용은 활동 범위로 볼 수 있음. 제3자 채널에 대리 노출 시 위험.
- **제3자 제공(B2C SaaS):** “등록되지 않은 미디어에 광고 노출” 금지 가능. 고객이 자기 채널에 직접 사용(도구만 제공)하는 구조는 허용 가능성 높음. 사전 확인 권장.
- **금지:** 부정 클릭, 허위·과장 광고, 스팸, 기밀정보 외부 공개 등.

### 3.2 SaaS 모델 리스크 분석 결과

| 구분 | 리스크 |
|------|--------|
| 사업자 본인 채널(korea_walker, moongoby)만 사용 | **낮음** |
| 고객 채널에 대리 업로드 | **높음** – 권장하지 않음 |
| 고객이 직접 업로드(도구만 제공) | **상대적으로 낮음** – 쿠팡 사전 확인 권장 |

### 3.3 권장 운영 방안

- **Phase 1:** 자체 채널만 쿠팡 파트너스 링크 사용.
- **Phase 2:** 고객에게 API/대시보드 등 도구만 제공, 고객이 자기 채널에 직접 업로드.
- **필수:** 쿠팡 파트너스 고객센터에 SaaS 모델(도구 제공·고객 직접 게시) 사전 확인 요청 권장.

### 3.4 쿠팡 키 설정 상태

- **COUPANG_ACCESS_KEY:** 존재, 값 **미설정**
- **COUPANG_SECRET_KEY:** 존재, 값 **미설정**
