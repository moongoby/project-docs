# Veo 3.1 이미지→영상 변환 테스트

**작성일시:** 2026-02-13
**작업 유형:** 테스트 / 신규 개발
**상태:** 완료
**관련 파일:** `worker/services/video_generator.py`, `worker/config.py`, `worker/core/exceptions.py`

---

## 1. 작업 개요

Google Veo 3.1 Fast API로 기존 생성 이미지를 8초 영상 클립으로 변환하는 테스트를 수행하고, 성공 시 파이프라인 연동을 위한 `video_generator` 모듈 및 설정을 추가하였다.

## 2. 1단계: Veo API 테스트 (curl)

- **이미지:** `/data/shortflow/data/images/20260213_2_scene1.png` 사용.
- **API:** `https://generativelanguage.googleapis.com/v1beta/models/veo-3.1-fast-generate-preview:predictLongRunning`
- **수정 사항:** 요청 body의 `image` 객체에 `mimeType: "image/png"` 필수. 미포함 시 `INVALID_ARGUMENT` 발생.
- **결과:** `name: "models/veo-3.1-fast-generate-preview/operations/ytwtiefihe7c"` 반환 (Long Running 작업 시작 성공).

## 3. 2단계: 생성 완료 대기 및 다운로드

- **폴링:** 15초 간격으로 operation 상태 조회. 약 4번째 폴링(약 60초 후)에 `done: true` 수신.
- **응답 구조:** `response.generateVideoResponse.generatedSamples[0].video.uri` 에 다운로드 URL 포함.
- **다운로드:** `x-goog-api-key` 헤더로 GET 요청 후 `/data/shortflow/data/videos/veo_test.mp4` 저장.
- **검증:** 파일 크기 약 1.1MB, `file` 명령으로 ISO Media MP4 확인. (호스트에 ffprobe 미설치로 상세 스트림 정보는 생략.)

## 4. 3단계: 파이프라인 통합용 코드

### 4.1 worker/services/video_generator.py (신규)

- **함수:** `generate_scene_video(image_path, prompt, aspect_ratio="9:16", output_path=None) -> str`
  - 이미지 base64 + `mimeType` 포함하여 predictLongRunning 호출.
  - 최대 10분 폴링 후 비디오 URI 추출 및 다운로드.
  - 반환: 생성된 MP4의 절대 경로.
- **설정:** `settings.google_ai_api_key` (Imagen과 동일), `settings.veo_model` 사용.
- **예외:** `VideoGenerationError` (core/exceptions.py에 추가).

### 4.2 worker/config.py 추가

- `video_provider: str = "ffmpeg"` — `"veo"` 시 씬 클립 생성에 Veo 사용.
- `veo_model: str = "veo-3.1-fast-generate-preview"`
- `veo_resolution: str = "720p"` (추후 API 파라미터 연동 가능).

### 4.3 통합 방향 (미구현)

- `ffmpeg_composer.py`의 Step 1에서 `video_provider == "veo"`일 때 Ken Burns 대신 `video_generator.generate_scene_video(scene.image_path, scene.visual_prompt 또는 기본 프롬프트)` 호출하여 클립 경로 확보 후, 기존 concat/자막/TTS 합성 흐름 그대로 사용 가능.
- `SceneAsset`에 `visual_prompt`(또는 `veo_prompt`) 필드 추가 시 pipeline_worker에서 스크립트의 `visual_prompts`를 넘겨주면 됨.

## 5. 비용 관리

- Veo Fast 720p 기준 8초 클립 약 **$1.20** 수준. 테스트 1건만 실행 권장.
- 상시 사용 시 `video_provider=ffmpeg` 유지, 필요 시에만 `veo`로 전환.

## 6. 주의사항 / 후속 작업

- 실제 파이프라인에서 Veo 경로 사용 시: composer에서 Veo 클립 길이(약 8초)와 TTS/자막 구간 정렬(trim 또는 패딩) 검토 필요.
- `.env`에 `GOOGLE_AI_API_KEY` 또는 `GOOGLE_API_KEY` 설정 필요.
