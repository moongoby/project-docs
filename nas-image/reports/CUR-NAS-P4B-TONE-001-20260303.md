## 2. 구현 내용

### 보정 엔진 (`app/workers/auto_tone.py`)

| 항목 | 함수 | 설명 |
|---|---|---|
| 노출(Exposure) | `_gamma_correction` | 히스토그램 평균 → target_mean 조정 |
| 화이트밸런스(WB) | `_gray_world_wb` | Gray-World 알고리즘, ±10% clamp |

| 샤프닝 | `_unsharp_mask` | 언샤프마스크, ±10% clamp |

### 프리셋 8종

| ID | 특성 |
|---|---|
| natural | 기본 유지 (gamma only) |
| studio | 표준 스튜디오 보정 |
| warm | 따뜻한 색온도 |
| cool | 차가운 색온도 |
| bright | 어두운 이미지 밝기 강화 |
| soft | 부드러운 저채도 |
| vivid | 선명 고채도 |
| clean | 깔끔 밝은 화이트 |

### 경로 및 파일명

| 항목 | 내용 |
|---|---|
| 입력 | `/data/processed/{코디}/_cropped/` 또는 `_acut_v2/` |
| 출력 | `/data/processed/{코디}/_toned/` |
| 보정 이미지 | `{원본stem}_toned.jpg` |
| 메타데이터 | `{원본stem}_tone_meta.json` |

### FastAPI 엔드포인트 (`app/api/tone_router.py`)

```
POST /api/v1/tone         — 단건 톤보정 (preset_id 파라미터)
POST /api/v1/tone/batch   — 배치 톤보정
GET  /api/v1/tone/presets — 프리셋 목록 조회
```
