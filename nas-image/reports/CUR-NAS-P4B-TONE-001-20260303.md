## 2. 구현 내용

### app/workers/auto_tone.py (개선)

**프리셋 8종 (기존 3 + 신규 5):**

| preset_id | 특성 |
|-----------|------|
| natural | 기본, 최소 보정 |
| studio | 표준 스튜디오 |
| warm | 따뜻한 색감 |
| cool | 차가운 색감 (신규) |
| bright | 밝은 톤 (신규) |
| soft | 부드러운 톤 (신규) |
| vivid | 선명한 색감 (신규) |
| clean | 깔끔한 밝기 (신규) |

**10% clamp 강제:**
- `_clamp(value, max_delta=0.10)` 함수로 모든 보정 강도 제한
- 감마: 1.0 ± 10%, 채도: 1.0 ± 10%, WB 스케일: 1.0 ± 10%, 선명도: max 10%

**sidecar JSON 생성:**
- 출력: `{파일명}_tone_meta.json`
- 내용: preset_id, exposure_delta, wb_shift, saturation_delta, contrast_delta, sharpen_amount
- 모든 delta 절대값 ≤ 10% 보장

**출력 파일명:** `{원본파일명}_toned.jpg` (기존 `{원본파일명}.jpg`에서 변경)

### app/api/tone_router.py (엔드포인트 갱신)
- GET /api/v1/tone/presets — 프리셋 목록 8개 조회
- POST /api/v1/tone — 단건 (코디폴더 + preset_id)
- POST /api/v1/tone/batch — 배치 (복수 코디폴더)
- 응답: total, adjusted, preset_used, failed, elapsed_sec
