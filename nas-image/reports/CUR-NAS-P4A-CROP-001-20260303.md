## 1. 작업 개요

A컷 선별된 이미지(`_acut_v2/`)를 MediaPipe Pose 기반으로 1:1 크롭(600×600) + 3:4 크롭(900×1200)으로 자동 처리.  
처리 결과는 `/data/processed/{코디}/_cropped/` 단일 폴더에 저장.

---

## 2. 구현 내용

### 크롭 엔진 (`app/workers/auto_cropper.py`)

| 항목 | 내용 |
|---|---|
| 입력 | `/data/photos/{코디}/_acut_v2/*.jpg, *.jpeg, *.png, *.heic` |
| 출력 | `/data/processed/{코디}/_cropped/` |
| 1:1 파일명 | `{원본stem}_crop_1x1.jpg` (600×600) |
| 3:4 파일명 | `{원본stem}_crop_3x4.jpg` (900×1200) |
| 인체 감지 | MediaPipe Pose (complexity=1, min_confidence=0.5) |
| Fallback | 인체 미검출 시 이미지 중앙 기준 크롭 |
| HEIF/HEIC | `pillow-heif` 등록으로 지원 |
| 원본 보존 | 원본 절대 수정/삭제 금지 (copy 방식) |

### FastAPI 엔드포인트 (`app/api/crop_router.py`)

```
POST /api/v1/crop         — 단건 크롭 (코디폴더 지정)
POST /api/v1/crop/batch   — 배치 크롭 (복수 코디폴더)
```
