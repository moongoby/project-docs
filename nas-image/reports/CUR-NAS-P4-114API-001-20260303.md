## 2. 구현 내용

### 2-1. `api/goods.php` (핵심 API)

순수 PHP REST API. CI 프레임워크 없이 직접 실행.

**기능**:
- X-API-Key 헤더 인증
- mysqli 준비문(Prepared Statement) → SQL Injection 방지
- begin_transaction / commit / rollback 트랜잭션
- 기존 값 백업 로그: `application/logs/image_api/backup_YYYYMMDD.log`

### 2-2. `api/goods/.htaccess` (URL 라우팅)

```
GET  /api/goods/healthcheck     → api/goods.php/healthcheck
GET  /api/goods/getImages/{id}  → api/goods.php/getImages/{id}
POST /api/goods/updateImages    → api/goods.php/updateImages
```

### 2-3. `application/config/image_api.php` (API 키 설정)

```php
$key = getenv('NAS_IMAGE_API_KEY');
$config['image_api_key'] = $key ?: 'nas-img-api-' . md5('newtalk-nas-key-2026');
```

운영 환경에서 `export NAS_IMAGE_API_KEY=값` 으로 덮어쓰기 가능.
