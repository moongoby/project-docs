### 핵심 병목
- 7단계: ZIP 다운로드 → NAS 수동 업로드 (불필요한 수작업)
- 10단계: 수백 장 사진을 코디별로 수동 분류 (시간 소요 큼)
- 11단계: A컷 수동 선별 (주관적, 시간 소요)
- 12단계: 외주 웹디자이너 포토샵 수동 보정 (가장 큰 병목, 비용 발생)
- 13단계: 상세페이지 이미지 정렬 수동 작업

## 4. 자동화 대상 상세

### 4.1 [P1] 모델사진폴더 NAS 직접 생성
- **현재:** 116서버 `POST /content/createModelShootingFolder` → ZIP 다운로드
- **변경:** 동일 API에서 NAS `★제품사진/` 아래에 SSH/SMB로 직접 폴더 생성
- **폴더명 규칙:** `{codyNumber}번코디 - {codyCode}_{상품정보}+...`
- **DB:** contents_msg, cody_msg, cody_product_msg
- **난이도:** 중

### 4.2 [P2] 코디폴더 매칭 자동분류
- **현재:** EXIF 시간 기반 그룹 분류만 (180초 임계값)
- **추가:** 촬영된 사진을 NAS의 코디 폴더에 자동 매칭
- **방식:** EXIF 촬영시간 + 코디 등록 순서 → 폴더 자동 이동
- **난이도:** 중

### 4.3 [P3] A컷 자동 선별
- **현재:** MD가 수동으로 A컷 분류
- **방식 후보:**
  - (A) AI 기반: 구도/초점/표정 점수화 → 상위 N장 자동 선택
  - (B) 규칙 기반: 파일 크기/해상도/EXIF 정보로 필터 + QC UI에서 최종 승인
- **QC UI:** 기존 승인/반려 UI 활용, A컷 추천 표시
- **난이도:** 상

### 4.4 [P4] 배너/인트로/부가설명 이미지 자동생성
- **현재:** 외주 웹디가 포토샵으로 제작
- **자동화 범위:**
  - 인트로 이미지: 모델컷 + 브랜드 로고/텍스트 합성
  - 사이즈표: 템플릿 기반 자동 생성
  - 소재/세탁 정보: 템플릿 기반 자동 생성
  - 배너: 모델컷 크랍 + 텍스트 오버레이
- **방식:** 템플릿 엔진 (Pillow/HTML→이미지)
- **난이도:** 상

### 4.5 [P5] 114서버 DB 자동 업데이트
- **현재:** rsync로 이미지만 동기화 (DB 수동)
- **추가:** goods_detail 테이블 자동 업데이트
  - GoodsEtc60~74: 이미지 URL 자동 입력
  - GoodsSortImg1~4: 정렬 순서 자동 입력
- **방식:** 114서버 MySQL 직접 또는 116서버 API 호출
- **난이도:** 중

### 4.6 [P6] 상세페이지 자동 조합/정렬/저장
- **현재:** 116서버 `goods_img_sorting_test1/2`에서 수동 드래그 정렬 → 저장
- **자동화:**
  - 인트로(GoodsSortImg1): 인트로 이미지 자동 배치
  - 모델사진(GoodsSortImg2): A컷 모델컷 순서 자동 배치
  - 제품사진(GoodsSortImg3): 제품컷 순서 자동 배치
  - MO(GoodsSortImg4): 모바일용 순서 자동 배치
- **방식:** DB 직접 UPDATE (`||` 구분 문자열)
- **난이도:** 중

## 5. 시스템 연동 구조

```
[116서버 어드민]     [NAS DS1821+]              [114서버]
코디등록             Docker: newtalk-image-auto
폴더생성 ──SSH/SMB──→ ★제품사진/{코디폴더}/
     ↑
[아이폰 촬영] ──Synology앱──→ home/실무자폴더/
     │
     │ 자동분류 → 코디폴더 매칭
     │ A컷 자동선별 → QC UI 승인
     │ 자동보정/크랍/배너생성
     │ rsync ──────────→ goodscode/img/{GoodsCode}/
     │                   DB UPDATE (goods_detail)
     │ [상세페이지 자동 정렬/저장]
     └──────────────────────────→ [상품 노출]
```
