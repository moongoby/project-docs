## Part A. 범용 프레임워크 (전 DESK 공통 적용)

### 1. 핵심 원칙: 발굴은 "무엇이 움직이는가", 전략은 "어떻게 돈을 버는가"

DESK 시스템은 5개 계층(Layer 0~4)으로 구성되어 있습니다. 이 중 **Layer 1(발굴)**과 **Layer 2(전략)**의 역할이 침범 없이 명확히 분리되어야 합니다.

- **Layer 1 – 발굴(Discovery)의 정의:**  
  "지금 이 시간, 이 종목이 비정상적으로 움직이고 있다. 그 움직임의 유형과 강도를 분류하여 전략들에게 전달한다."  
  발굴은 종목의 **현재 상태(State)**를 식별하고 점수화하는 것이지, 매매 방법이나 진입 타이밍을 판단하는 것이 아닙니다.

- **Layer 2 – 전략(Strategy)의 정의:**  
  "발굴이 추천한 종목을 지속 모니터링하면서, 나만의 기준에 따라 최적의 진입 시점을 포착하고, 최대 수익을 확보하여 청산한다."  
  전략은 종목의 **매매 행위(Action)**를 결정합니다.

**비유:**  
- 발굴 = 정찰병. "저기 적군(기회)이 이동 중입니다. 병력 규모는 이 정도이고, 방향은 이쪽입니다."  
- 전략 = 전투 지휘관. "정찰 보고를 받았다. 내 전술(피보나치, VWAP, 돌파 등)에 따라 최적의 공격 시점과 방법을 결정하겠다."

---

### 2. 역할 분담 테스트: 이것이 발굴인가 전략인가?

어떤 조건이 발굴에 속하는지 전략에 속하는지 판단하는 기준표입니다. **모든 DESK에서 동일하게 적용**합니다.

#### 발굴이 해야 할 것 (State 판단)

| 항목 | 설명 |
|------|------|
| 이 종목이 오늘 평소와 다르게 움직이는가? | 거래량 폭발, 가격 급변 |
| 움직임의 유형은 무엇인가? | 갭 상승, 장중 급등, 급락, VI 발동 등 |
| 움직임의 크기는 어느 정도인가? | 상승률, 거래량 배율, 시가총액 |
| 외부 촉매가 있는가? | 뉴스, 수급 방향, 업종 동반 |
| 이 종목은 지금 어떤 상태인가? | 급등 중, 조정 중, 급락 중, 횡보 중 |

#### 전략이 해야 할 것 (Action 판단)

| 항목 | 설명 |
|------|------|
| 이 종목에 언제 진입할 것인가? | 피보나치 되돌림, VWAP 터치, EMA 지지, 돌파 시점 |
| 어떤 가격에 진입할 것인가? | 지정가, 시장가, 호가 분석 |
| 손절은 어디인가? | ATR 기반, 구간 저점, 비율 |
| 목표가는 어디인가? | 피보나치 확장, R:R 비율, 트레일링 |
| 부분 익절은 어떻게 할 것인가? | 50%+50%, 33%×3 등 |
| 보유 시간은 얼마인가? | 타임아웃 설정 |

#### 금지선

발굴이 **"피보나치 50% 되돌림 도달"**, **"VWAP 상향 돌파"**, **"볼린저밴드 하단 반등"** 같은 판단을 하면 안 됩니다. 이것들은 전부 **전략의 영역**입니다.

---

### 3. 발굴 신호(DiscoverySignal) 표준 구조

모든 DESK에서 발굴이 전략에 전달하는 신호의 표준 포맷입니다.

```
DiscoverySignal {
  stock_code: str           # 종목코드
  stock_name: str           # 종목명
  discovery_type: enum      # 움직임 유형 (GAP_UP, INTRADAY_SURGE, PULLBACK_READY,
                            #   VI_TRIGGERED, SECTOR_FOLLOW, OVERSOLD, OPENING_STRONG 등)
  desk_score: int (0-100)   # 종목 주목도 점수 (움직임의 질)
  timestamp: datetime       # 발굴 시각
  market_regime: str        # 현재 시장 레짐
  time_slot: str            # 발굴 시간대 (PRE_MARKET, OPENING, MORNING, MIDDAY, AFTERNOON, CLOSING)

  # 상태 정보 (전략이 참고하는 팩트)
  state_data: {
    price_change_pct: float       # 현재 등락률
    volume_ratio: float           # 거래량 배율 (RVOL)
    market_cap: int               # 시가총액
    adx: float                    # 추세 강도
    current_price: float          # 현재가
    prev_close: float             # 전일 종가
    day_high: float               # 당일 고가
    day_low: float                # 당일 저가
    vwap: float                   # 당일 VWAP
    sector_code: str              # 업종코드
    news_flag: bool               # 뉴스 유무
    foreign_net_buy: float        # 외국인 순매수 (있으면)
    inst_net_buy: float           # 기관 순매수 (있으면)
  }

  # 메타데이터
  eligible_strategies: list[str]  # 이 유형에 도전 가능한 전략 목록 (복수)
  priority: int                   # 같은 시간대 내 우선순위
}
```

**핵심:** `state_data`입니다. 발굴은 종목의 **현재 상태 팩트만** 전달합니다. "피보나치 몇 % 되돌림"이나 "VWAP 크로스 발생"은 여기에 없습니다. 대신 현재가, VWAP, 고가, 저가 등 **원시 데이터**를 주면, 전략이 이 데이터로 자기만의 판단을 합니다.

`eligible_strategies`는 **복수**입니다. 하나의 발굴 종목에 여러 전략이 동시에 도전할 수 있습니다.

### 4. 전략의 수신 및 독립 판단 흐름

전략은 `DiscoverySignal`을 받은 후 다음 과정을 **독립적으로** 수행합니다.

| 단계 | 내용 |
|------|------|
| **1 – 수신 및 관심 목록 등록** | 발굴에서 신호가 오면, 해당 전략의 watchlist에 종목을 등록합니다. 이 시점에서 **진입하지 않습니다**. |
| **2 – 지속 모니터링(Stalking)** | watchlist에 등록된 종목의 실시간 데이터를 계속 관찰하면서, 자기만의 진입 조건 충족 여부를 매 봉(1분/5분)마다 체크합니다. ("뚫어지게 쳐다보다가"의 구현) |
| **3 – 진입 시그널 생성** | 모든 진입 조건이 충족되면 **CS Score**(Confidence Score, 0~100)를 계산하고, CS ≥ 50이면 `TradeSignal`을 Layer 3 오케스트레이션으로 전달합니다. |
| **4 – 경쟁 및 선택** | 같은 종목에 대해 여러 전략이 동시에 `TradeSignal`을 보낼 수 있습니다. Layer 3 오케스트레이션에서 **종합 점수(DESK Score × CS Score ÷ 100)**가 가장 높은 전략을 선택합니다. |

---

### 5. 발굴 점수(DESK Score) 표준 구성

모든 DESK에서 발굴 점수는 **종목의 상태 품질만** 평가합니다.

| 점수 항목 | 배점 | 평가 내용 |
|-----------|------|-----------|
| 움직임 크기 | 25점 | 가격 변동률 (유형별 최적 구간 상이) |
| 거래량 폭발도 | 25점 | RVOL (평소 대비 거래량 배율) |
| 시장 적합성 | 15점 | 현재 레짐에서 이 유형이 유효한가 |
| 외부 촉매 | 15점 | 뉴스, 수급, 업종 동반 등 |
| 종목 기본 품질 | 10점 | 시가총액, 유동성, 스프레드 |
| 추세 강도(ADX) | 10점 | 해당 종목의 현재 추세 존재 여부 |
| **합계** | **100점** | |

**60점 이상**만 전략에 전달합니다. 이 점수에는 "피보나치 정밀도", "VWAP 돌파 여부", "볼린저밴드 위치" 같은 **전략적 판단이 포함되지 않습니다**.

## 다른 DESK 적용 가이드 (참고)

이 프레임워크는 DESK1·3·4·5에도 동일하게 적용 가능합니다.

| DESK | 발굴 역할 | 전략 역할 |
|------|-----------|-----------|
| **DESK1** (초단타/스캘핑) | 틱 레벨에서 비정상적 움직임 감지 | 1분 이내 진입·청산 |
| **DESK3** (단기스윙 3~10일) | 일봉 기준 추세 전환·돌파 종목 감지 | 일봉 기반 진입 타이밍·보유·청산 |
| **DESK4** (중기스윙 20~40일) | 주봉 기준 추세 형성·업종 변화 종목 감지 | 주봉 기반 포지션 구축·관리 |
| **DESK5** (장기 90~120일) | 펀더멘탈+기술적 저점 종목 감지 | 분할 매수·장기 보유·목표가 관리 |

각 DESK에서 **역할 분담 테스트(섹션 2)**를 동일하게 적용하면, 역할 침범을 방지할 수 있습니다.
