### 3-2. backend/app/services/feature_engine.py — BjScoreEngine 클래스

**위치**: 파일 말미(~1398라인 이후)에 추가

**주요 메서드 6개:**

| 메서드 | 반환 | 설명 |
|--------|------|------|
| `score_major_shareholder(symbol)` | 0~20 | 대주주 지분율: ideal_range(20~50%) 만점, min 미만 0점 |
| `score_material_theme(symbol)` | 0~20 | 뉴스 30일 건수 + THEME_CYCLE_SCORE 보너스 |
| `score_financial_numbers(symbol)` | 0~20 | 매출성장(7점)+영업이익률(7점)+ROE(6점) |
| `score_sentiment_indicator(symbol, date)` | 0~20 | RSI(7점)+VP(7점)+외인연속매수(6점) |
| `score_chart_ma(symbol, date)` | 0~20 | MA 정배열(12점)+close>MA60(8점) |
| `calculate_bj_score(symbol, date)` | dict | 5축 합산 + 등급 A/B/C/D |

**등급 기준:**
- A: 80점 이상
- B: 60~79점
- C: 40~59점
- D: 0~39점

**데이터 소스:**
- `stock_universe.major_shareholder_pct`: 대주주 지분율
- `v4_news_summary`: 30일 뉴스 카운트
- `ThemeCycleEngine`: THEME_CYCLE_SCORE 활용
- `v4_fundamental_quarterly`: 재무 데이터 (매출성장/영업이익률/ROE)
- `ohlcv_daily`: RSI(14)/VP 계산, MA5/10/20/60 계산
- `v4_investor_daily`: 외인 연속 순매수 일수

**Graceful Fallback:**
- 데이터 없을 때 각 축 0점 반환 (Exception catch → 로깅)
- `calculate_bj_score` 반환에서 각 축 독립적으로 처리

### 3-3. backend/app/services/funnel_score_engine.py — L3 BJ_SCORE 보너스 통합

```python
def score_l3(self, symbol: str, date: Optional[str] = None) -> float:
    ...
    # T-121: BJ_SCORE(배진한 5원칙) 보너스
    bj_bonus = 0.0
    if date is not None:
        bj_result = BjScoreEngine().calculate_bj_score(symbol, date)
        bj_total = bj_result.get("total", 0)
        bj_grade = bj_result.get("grade", "D")
        if bj_total >= 80:
            bj_bonus = 0.20
        elif bj_total >= 60:
            bj_bonus = 0.10
        logger.info("[BJ_SCORE] symbol=%s, total=%s, grade=%s, bonus=%.2f",
                    symbol, bj_total, bj_grade, bj_bonus)
```

**변경 포인트:**
1. `score_l3` 시그니처: `date: Optional[str] = None` 파라미터 추가 (하위호환성 유지)
2. `calculate_funnel_score`에서 `l3 = self.score_l3(symbol, date)` 로 date 전달
3. BJ_SCORE ≥60 → +0.10, ≥80 → +0.20 보너스

## 5. 배진한 5원칙 구현 로직

### 대주주 (20점)
- 지분율 20~50% (ideal_range) → 20점 만점
- 5% 미만 → 0점
- 5~20% → 선형 비례 (최대 20점 미만)
- 50% 초과 → 대주주 독점 위험으로 점수 감소

### 재료/테마 (20점)
- 30일 뉴스 0건: 0점
- 5건 이상: 10점 기본 + 초과분 가산 (최대 15점)
- THEME_CYCLE_SCORE 보너스: 최대 5점 추가
- 합산 최대 20점

### 숫자/재무 (20점)
- 매출성장 YoY ≥ 10% → 7점 (30%이면 만점)
- 영업이익률 ≥ 5% → 7점 (20%이면 만점)
- ROE ≥ 8% → 6점 (20%이면 만점)

### 심리/보조지표 (20점)
- RSI 30~70 범위: 7점 (50 근처일수록 높음)
- VP(5일평균/20일평균×100) ≥ 100: 7점
- 외인 연속 순매수 ≥ 3일: 6점

### 차트/이평선 (20점)
- MA 정배열(close>MA5>MA10>MA20>MA60): 12점
- close > MA60: 8점
