## 2. 데이터 수집 관련 화면 (2곳)

### 2.1 모니터링 페이지 — 데이터 수집 현황 (접속 가능)

- **URL**: https://go100.newtalk.kr/monitoring  
- **접속**: 로그인된 사용자면 **별도 등급 없이 접속 가능**.  
- **내용**:
  - "데이터 수집 현황" 섹션 존재.
  - 테이블 항목: 오늘 일봉(종목 수), 오늘 분봉(건수), 유니버스 활성 종목, 일봉 최종 수집일, 분봉 최종 수집.
  - 확인 시 값은 "-"로 표시 (API/캐시 또는 장중 이전 시점 반영).
  - 서비스 상태(go100, kis-v41-* 등), DB/Redis, 디스크, 에러 로그, 크론, 토큰 상태 등과 함께 30초 자동 갱신 문구 표시.

### 2.2 관리자 페이지 — 데이터 수집 탭 (PREMIUM 필요)

- **URL**: https://go100.newtalk.kr/admin  
- **접속**: **PREMIUM 등급** 필요. 현재 프로덕션 세션에서는 "현재 등급: 없음"으로 접근 권한 없음 안내.  
- **구성**: 관리자 페이지에 **「데이터 수집」** 탭을 추가해 두었음 (사용자, 계좌, 시스템, **데이터 수집**, LLM 비용, 로그).
- **기능**: 기간 조회(미수집·부분 수집), 미수집 사유, 수집/재수집 버튼 등 — 백엔드 API `/api/v1/admin/data-collection/*` 연동 시 동작.

## 3. 접속 상태 정리

- **접속되는 데이터 수집 페이지**:  
  **모니터링 페이지**(https://go100.newtalk.kr/monitoring)의 **「데이터 수집 현황」** 블록 — 로그인 후 바로 접속 가능하며, 화면 정상 로드·표시 확인.
- **관리자 데이터 수집 탭**:  
  관리자 페이지(/admin) 진입이 가능해야 하므로 PREMIUM 등급이 필요. 등급이 반영되면 /admin 접속 후 「데이터 수집」 탭으로 미수집 조회·수집 트리거 가능.

## 5. 결론

- **데이터 수집 페이지 접속**: **모니터링 페이지**(/monitoring)의 데이터 수집 현황은 **접속 가능**하며, 해당 블록이 정상 표시됨.
