## 1. DD Decelerator 상세 설계

### 1.1 5단계 정의 + 파라미터

DD(Drawdown) Decelerator는 누적 손익의 Rolling 20일 Peak-to-Trough 드로다운을 기반으로
포지션 사이즈를 자동 조절하는 리스크 관리 메커니즘이다.

| Level | Name | DD Range | Capital Multiplier | 설명 |
|-------|------|----------|-------------------|------|
| L0 | Normal | 0% ~ -3% | 1.00 (100%) | 정상 운영. 전액 투입 |
| L1 | Caution | -3% ~ -5% | 0.70 (70%) | 주의 단계. 30% 감축 |
| L2 | Warning | -5% ~ -8% | 0.50 (50%) | 경고 단계. 50% 감축 |
| L3 | Danger | -8% ~ -10% | 0.25 (25%) | 위험 단계. 75% 감축 |
| L4 | Halt | -10% 이하 | 0.00 (0%) | 거래 전면 중단 |

**DD 계산 방식:**
- Rolling 20거래일 기준 Peak-to-Trough 드로다운 산출
- 일일 누적 P&L 기반으로 최고점 대비 현재 낙폭 측정
- Multiplier는 포지션 사이즈에 직접 적용 (L4 = 완전 정지)

### 1.2 복구 규칙

DD Decelerator의 핵심은 하향 전환은 즉시 이루어지지만, 상향 복구는 연속 수익일을 요구한다는 점이다.
이는 "빠르게 방어하고, 천천히 복구한다"는 리스크 관리 원칙을 반영한다.

| 전환 방향 | 조건 | 근거 |
|-----------|------|------|
| L4 -> L3 | 연속 3일 수익 필요 | 가장 엄격. L4(전면 중단) 해제에는 확실한 시장 회복 확인 필요 |
| L3 -> L2 | 연속 2일 수익 필요 | 위험 탈출에는 2일 연속 수익으로 추세 전환 확인 |
| L2 -> L1 | 연속 1일 수익 필요 | 경고에서 주의로의 복구는 1일 수익으로 충분 |
| L1 -> L0 | DD 임계값 회복 시 즉시 | DD가 -3% 이상으로 회복되면 즉시 정상 전환 |

**복구 메커니즘 특징:**
- 비대칭 설계: 하락 시 즉시 레벨 하향, 회복 시 연속 수익 요구
- L4(Halt)에서 복구 시 최소 3일의 관찰 기간 확보
- 연속 수익일 조건이 과도한 조기 복구를 방지
- 시장 환경이 실제로 개선되었는지 검증하는 역할

## 2. 5-Layer 리스크 재구조화 설계

현재 시스템의 단층적 리스크 관리를 5개 계층으로 재구조화하여,
거래 -> 전략 -> 종목 -> 포트폴리오 -> 시장 단위의 다층적 방어 체계를 구축한다.

### 2.1 Layer 1 (거래 단위)

**목적:** 개별 거래 단위의 손절 관리

| 파라미터 | 값 | 설명 |
|----------|-----|------|
| SL 방식 | ATR(14) x 1.5 또는 0.7% 중 타이트한 값 | ATR 기반 변동성 적응형 손절 |
| Max SL Cap | 2.0% | 거래 당 최대 손실 하드캡 |
| Min SL Floor | 0.3% | 노이즈 손절 방지 최소값 |

**구현 로직:**
```
sl_pct = min(max(atr14 * 1.5, 0.3%), 2.0%)
```

**설계 근거:**
- ATR은 현재 변동성에 적응하여 시장 상황에 맞는 손절폭 설정
- Floor(0.3%)는 저변동 종목에서의 노이즈 손절 방지
- Cap(2.0%)은 극단적 변동성에서의 과도한 손실 방지

### 2.2 Layer 2 (전략 단위)

**목적:** 동일 전략 내 연속 손실 방어

| 파라미터 | 값 | 설명 |
|----------|-----|------|
| 연속손실 쿨다운 | 2연속 손실 -> 30분 쿨다운 | 릴레이 매매 방지 |
| 일일 손실 한도 | 전략별 1.5% 최대 | 전략 레벨 노출 제한 |
| 쿨다운 에스컬레이션 | 3연속 손실 -> 60분 쿨다운 | 연속 손실 시 강화 |

**구현 로직:**
```
per_strategy_loss_count 추적
2연속 손실 시 -> 해당 전략 30분 차단
3연속 손실 시 -> 해당 전략 60분 차단
일일 전략별 P&L < -1.5% 시 -> 당일 해당 전략 중단
```

**설계 근거:**
- 재앙 패턴 분석에서 릴레이 매매(relay)가 최대 손실의 주원인으로 식별
- 2025-05-16 relay_D2_7로 -16.03만원, 2025-03-11 relay_D2_6으로 -8.22만원 등
- 쿨다운으로 감정적 리벤지 트레이딩 차단

### 2.3 Layer 3 (종목 단위)

**목적:** 동일 종목 과다 집중 방어

| 파라미터 | 값 | 설명 |
|----------|-----|------|
| 일일 진입 상한 | 종목별 최대 4회 | 동일 종목 과다 매매 방지 |
| 일일 손실 한도 | 종목별 1.0% 최대 | 종목 레벨 손실 제한 |
| 재진입 쿨다운 | 최소 10분 간격 | 동일 종목 연속 진입 방지 |

**구현 로직:**
```
per_stock_entry_count 및 per_stock_pnl 추적
종목별 진입 4회 도달 시 -> 당일 해당 종목 차단
종목별 P&L < -1.0% 시 -> 당일 해당 종목 차단
마지막 진입 후 10분 미경과 시 -> 재진입 차단
```

**설계 근거:**
- 재앙 패턴에서 conc(집중도) 80~100% 이벤트가 143건 발생
- conc_S1_100 패턴 시 평균 -25만원 이상 손실
- 단일 종목 집중 방지로 분산 효과 확보

### 2.4 Layer 4 (포트폴리오 단위)

**목적:** 전체 포트폴리오 레벨의 일일 킬 스위치 + DD Decelerator

| 파라미터 | 값 | 설명 |
|----------|-----|------|
| 일일 킬 스위치 | -2.0% 총 일일 손실 시 전체 중단 | 일일 최대 손실 하드캡 |
| DD Decelerator | L0~L4 레벨 적용 (섹션 1 참조) | 포지션 사이즈 자동 조절 |
| 킬 스위치 후 복구 | 다음 날 L1 이상에서 시작 | 킬 스위치 발동 후 보수적 재개 |

**구현 로직:**
```
실시간 일일 누적 P&L 모니터링
일일 P&L < -2.0% 시 -> 전 전략/종목 즉시 중단
DD Decelerator 레벨에 따라 포지션 사이즈에 multiplier 적용
킬 스위치 발동 다음 날 -> 최소 L1에서 시작
```

**설계 근거:**
- S0(미적용) 시 Max Daily Loss -6.28만원으로 과도
- 일일 킬 스위치로 하루 최대 손실을 -2.0%로 제한
- DD Decelerator로 연속적 드로다운 방어

### 2.5 Layer 5 (시장 단위)

**목적:** 시장 전체 붕괴 시 자동 방어

| 파라미터 | 값 | 설명 |
|----------|-----|------|
| KOSDAQ 주의 | 지수 -1.5% 이상 하락 시 | 70% 용량으로 감축 |
| KOSDAQ 정지 | 지수 -2.0% 이상 하락 시 | 전면 거래 중단 |
| 위기 모드 | 지수 -3.0% 이상 하락 시 | 당일 거래 금지 (위기 모드) |
| 복구 | 다음 날 KOSDAQ 정상 시 | 새롭게 시작 |

**구현 로직:**
```
매 1분마다 KOSDAQ 지수 확인
지수 변동률 계산 -> 해당 모드 적용
market_multiplier: 1.0 (정상) / 0.7 (주의) / 0.0 (정지/위기)
```

**설계 근거:**
- 시장 전체 급락 시 모든 전략이 동시에 영향받음
- 조기 정지로 자본 보전이 개별 전략 수익보다 우선
- 2025년 중 KOSDAQ -2% 이상 급락일에 대부분의 전략이 손실 기록

### 2.6 현재 대비 변경 사항

**계층 간 상호작용 규칙:**

| 규칙 | 내용 |
|------|------|
| 우선순위 | L5(시장) > L4(포트폴리오) > L3(종목) > L2(전략) > L1(거래) |
| 적용 방식 | 가장 제한적인 레이어가 우선 (최소 multiplier 적용) |
| 예시 | L2가 0.7x이지만 L3가 halt이면 -> halt 적용 |

**현재 시스템 vs 신규 5-Layer 비교:**

| 항목 | 현재 시스템 | 신규 5-Layer |
|------|------------|-------------|

## 3. VWAP 통합 설계

### 3.1 변수 5개 정의 + 계산 로직

VWAP(Volume Weighted Average Price)은 기관 투자자의 평균 매입 단가를 나타내는 핵심 지표이다.
본 설계에서는 5개의 VWAP 파생 변수를 정의한다.

| # | 변수명 | 유형 | 공식 | 용도 |
|---|--------|------|------|------|
| 1 | **VWAP_PRICE** | 연속값 | Cumulative(TP * Volume) / Cumulative(Volume), TP=(H+L+C)/3 | 지지/저항 기준가 |
| 2 | **VWAP_DEVIATION** | 연속값 (%) | (Close - VWAP) / VWAP * 100% | 과매수/과매도 판단 |
| 3 | **VWAP_CROSS_UP** | 이벤트 | 가격이 VWAP 하방 -> 상방 교차 | 강세 탈환 신호 (매수) |
| 4 | **VWAP_CROSS_DOWN** | 이벤트 | 가격이 VWAP 상방 -> 하방 교차 | 약세 이탈 신호 (매도/주의) |
| 5 | **VWAP_SUPPORT_COUNT** | 카운터 | VWAP 0.2% 이내 접근 후 반등 횟수 | 지지 강도 측정 (높을수록 강한 지지) |

**VWAP_PRICE 계산 상세:**
```
VWAP = Sum(TP_i * V_i, i=1..N) / Sum(V_i, i=1..N)
where TP_i = (High_i + Low_i + Close_i) / 3
```
- 매일 장 시작 시 리셋 (일별 VWAP)
- 1분봉 기준으로 누적 계산

**VWAP_DEVIATION 범위:**
- 통상 -3% ~ +3% 범위
- 양수: 기관 평균가 대비 비싸게 거래 (과매수 방향)
- 음수: 기관 평균가 대비 싸게 거래 (과매도 방향)

**VWAP_CROSS_UP/DOWN 신호:**
- Cross Up: D1 VWAP 탈환 전술의 진입 신호
- Cross Down: 활성 포지션의 청산/SL 타이트닝 신호

**VWAP_SUPPORT_COUNT:**
- VWAP 0.2% 이내 접근 후 반등한 횟수 카운트
- 높은 횟수 = 강한 VWAP 지지 = 풀백 진입에 유리한 환경

D1 VWAP 탈환 전술은 가격이 VWAP 하방에서 상방으로 교차할 때 매수하는 전략이다.

### 5.4 NetR:R >= 2.0 강제 로직

**NetR:R 하한 강제의 설계 원리:**

```
# 진입 시점에서 NetR:R 검증
atr_pct = ATR(14) / current_price * 100

# 전략별 SL/TP 계산
sl_pct = max(atr_pct * sl_mult, min_sl)  # min_sl cap
sl_pct = min(sl_pct, max_sl)              # max_sl cap
tp_pct = atr_pct * tp_mult

# NetR:R 계산
half_cost = 0.235  # 왕복 0.47% / 2
net_rr = (tp_pct - half_cost) / (sl_pct + half_cost)

# NetR:R 하한 강제
if net_rr < 2.0:
    # 방법 1: TP 확장
    tp_pct_required = 2.0 * (sl_pct + half_cost) + half_cost
    tp_pct = tp_pct_required

    # 방법 2: TP 확장으로 불가능하면 거래 스킵
    if tp_pct > max_tp_reasonable:
        SKIP TRADE
```

**전략별 NetR:R 강제 시 파라미터 계산 예시:**

| 전략 | 바인딩 SL | SL+half_cost | 필요 TP (NetR:R=2.0) | TP-half_cost |
|------|-----------|-------------|---------------------|-------------|
| D2 | 0.70% | 0.935% | 2.105% | 1.870% |
| D4 | 0.70% | 0.935% | 2.105% | 1.870% |
| D5 | 0.70% | 0.935% | 2.105% | 1.870% |

**S2 시나리오의 이점:**
1. R:R < 1.0인 불리한 거래를 **완전 제거** (S1에서는 38~48% 존재)
2. 비용 차감 후에도 구조적으로 유리한 기대값 보장
3. 승률이 낮아져도(17~18%) 1회 이익 > 2회 손실 구조
4. 전략 필터링(D2/D4/D5의 다조건 진입)과 결합 시 실질 PF 대폭 향상

**S2 권고 근거:**
- 0.47% 왕복 거래비용이 P&L을 크게 침식하는 상황에서
- NetR:R >= 2.0 강제는 모든 거래의 기대값 구조를 보장
- ATR 기반 동적 SL은 변동성에 적응하되, min/max cap으로 극단값 방지
- 전략별 다조건 필터링된 진입과 결합 시 승률 회복 기대

**권고 시나리오: S2 (ATR + NetR:R >= 2.0)**

| 전략 | 최종 권고 SL | 최종 권고 TP | NetR:R |
|------|------------|------------|--------|
| D2 | ATR*1.5 (min 0.7%, max 2.0%) | ATR*3.0 (NetR:R >= 2.0 강제) | >= 2.0 |
| D4 | ATR*1.5 (min 0.7%, max 2.5%) | ATR*3.5 (NetR:R >= 2.0 강제) | >= 2.0 |
| D5 | ATR*2.0 (min 0.7%, max 2.5%) | ATR*4.0 (NetR:R >= 2.0 강제) | >= 2.0 |

**구현 세부 사항:**
1. ATR(14)을 진입 시점 1분봉 기준으로 계산
2. 전략별 multiplier를 적용하여 SL/TP 산출
3. min_sl(0.7%) 및 max_sl(2.0~2.5%) cap 적용
4. NetR:R >= 2.0 검증. 미충족 시 TP 확장 또는 거래 스킵
5. 매 5분마다 ATR 재계산하여 트레일링 스톱 조정
