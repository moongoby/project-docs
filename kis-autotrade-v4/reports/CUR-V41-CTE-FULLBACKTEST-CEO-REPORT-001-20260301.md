DESK2 CTE(Core Trade Engine) 전체 필터 시스템을 **실 데이터 5,000건 / 243거래일**에 적용한 결과,

## 9. 한계 및 유의사항

### 9.1 합성 신호의 한계
- DB의 `v4_backtest_trades`에 실분봉 데이터(RSI, VWAP, VP 등) 부재
- 신호 컨텍스트(CS 등급, 기술등급, 시장상황)를 **확률적 합성**으로 생성
- 실 분봉 데이터 연계 시 결과 달라질 수 있음

### 9.2 LIMIT 5,000건 제약
- 전체 거래일의 일부만 분석 (5,000건 LIMIT)
- 월별 PF 데이터가 3~9개월로 제한 → G8(CV) 신뢰도 부분 제한

### 9.3 strategy_name NULL 처리
- DB의 `strategy_name` 컬럼이 NULL → 전 거래를 'D2'로 가정
- 실제 전략 ID가 D4/D5/D6/D7이면 신호맵 다름 → 실 배포 시 전략 ID 컬럼 보완 필요
