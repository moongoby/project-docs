## 2. 구현 상세

### 2-1. config/param_search_space.yaml — p1_features 섹션 추가

```yaml
p1_features:
  leader_follower_rotation:
    leader_ul_flag: true
    follower_theme_rank_max: 5
    follower_ma20_1m_support: true
    exit_on_leader_ul_release: true
  close_bet_score:
    entry_after: "14:30"
    min_supply_concentration: 0.6
    low_rising_days_min: 3
    vol_increase_ratio: 1.3
    score_weights: {supply: 0.4, low_rise: 0.3, volume: 0.3}
  rsi_macd_combo_1m:
    rsi_period: 14
    rsi_bounce_range: [30, 40]
    vp_min: 120
    macd_params: [12, 26, 9]
    golden_cross_with_volume: true
  news_catalyst_score:
    source_table: "v4_news"
    lookback_hours: 24
    keyword_weights: {contract: 1.5, partnership: 1.3, earnings: 1.2, government: 1.4, ipo: 1.0}
    min_score: 0.5
    ma_convergence_1m_required: true
```

### 2-2. LeaderFollowerEngine (feature_engine.py:2814~)

- **로직**: 대장주 당일 등락률 ≥ 29% (상한가) AND 후발주 테마순위 ≤ 5 AND 1분봉 MA20 지지 → `leader_follower_signal=True`
- **EXIT 조건**: `exit_on_leader_ul_release=True` 시 대장 상한가 풀림(등락률 < 26%) → `exit_signal=True`
- **입력**: `leader_change_pct`, `follower_theme_rank`, `follower_price_1m`, `follower_ma20_1m`
- **출력**: `leader_ul_flag`, `follower_theme_rank_ok`, `follower_ma20_1m_support`, `leader_follower_signal`, `exit_signal`

### 2-3. CloseBetScoreEngine (feature_engine.py:~2890~)

- **로직**: 14:30 이후 + 수급집중도 ≥ 0.6 + 저점상승 ≥ 3일 + 거래량비율 ≥ 1.3 → 가중합산 점수
- **점수 공식**: `score = supply*0.4 + low_rise*0.3 + volume*0.3`
- **진입 조건**: `time_ok AND score ≥ 0.6`
- **입력**: `supply_concentration`, `low_rising_days`, `vol_ratio`, `current_time`
- **출력**: `time_ok`, `supply_concentration_ok`, `low_rising_ok`, `volume_increase_ok`, `close_bet_score`, `close_bet_valid`

### 2-4. RsiMacdCombo1mEngine (feature_engine.py:~2960~)

- **로직**: RSI(14) ∈ [30, 40] AND VP ≥ 120 AND MACD > Signal(골든크로스) → `combo_signal=True`
- **파라미터**: `rsi_period=14`, `rsi_bounce_range=[30,40]`, `vp_min=120`, `macd_params=[12,26,9]`
- **입력**: `rsi_14`, `vp`, `macd_value`, `macd_signal_value`
- **출력**: `rsi_bounce_ok`, `vp_ok`, `macd_golden_cross`, `combo_signal`

### 2-5. NewsCatalystEngine (feature_engine.py:~3020~)

- **로직**: 24h 뉴스 헤드라인 → 키워드(계약/파트너십/실적/정부/IPO) 가중 점수 합산 → 정규화 → MA수렴 확인
- **키워드 가중**: contract=1.5, government=1.4, partnership=1.3, earnings=1.2, ipo=1.0
- **한국어 키워드 매핑**: 계약/수주/MOU, 정부/정책/국책, 실적/영업이익/흑자전환 등
- **진입 조건**: `normalized_score ≥ 0.5 AND ma_convergence_ok`
- **출력**: `news_keyword_score`, `news_score_normalized`, `ma_convergence_ok`, `catalyst_valid`
