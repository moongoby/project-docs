## 3. 방법론 요약

### 3.1 Step 1: BLANK-SLATE TOP-20 (검증용)

- 매 거래일, 당일 분봉 기준 **일중 변동폭**(고가−저가)/저가 상위 20종목 추출.
- `v4_ohlcv_minute` 09:00~15:30, 거래량 10만 이상, 저가 > 0.

### 3.2 Step 2: D-1 스코어링 → TOP-50 → TOP-10

- **D-1 스코어**:  
  - D-1 거래량 / D-2~D-6 평균 거래량 비율(vol_ratio)  
  - 5일 거래량 변화율(vol_change)  
  - D-1 뉴스 건수(go100_news_items)  
  - D-1 종가위치 (close−low)/(high−low)  
- 가중치: vol_ratio 0.822, vol_change 0.757, news 0.472, close_pos 0.365 (DESK2-BT-SCORING-REVERSAL-DESIGN-001).
- 당일 분봉 있는 종목 중 스코어 상위 50 → **상위 10종목** 선정 (동일 방법으로 C6+C7 필터 개념 적용).

### 3.3 Step 3: 당일 유형 판별 + T5/S1 신호

- **유형**  
  - **TREND**: 첫 5봉(※) 구간 시가 대비 저가 하락률(dip) < 1%  
  - **REVERSAL**: 동일 구간 dip ≥ 2%  
  - 1% ≤ dip < 2%: BORDER → 해당 스크립트에서는 진입 대상에서 제외
- **신호**  
  - **T5 (TREND)**: 시가 대비 +2% 돌파한 첫 봉에서 진입  
  - **S1 (REVERSAL)**: 직전 3봉 평균 “체결강도 근사” < 0.4 → 현재 봉 ≥ 0.6 (분봉 close/open, high/low로 근사)

※ 5봉 = 5분봉 기준 25분. 설계서의 “첫 5분”과 불일치 가능성 있음 → 후술.

### 3.4 Step 4: 진입·청산 시뮬레이션

- **진입**: T5 또는 S1 발생 봉의 종가.  
- **청산**:  
  - 목표가 +3% 도달 시 목표가에서 청산  
  - 손절 -2% 도달 시 손절가에서 청산  
  - 14:50 시간청산(해당 봉 종가)  
  - 미청산 시 해당일 마지막 봉 종가(EOD).

### 3.5 Step 5·6: 집계 및 14일 vs 장기 비교

- 월별/주별 거래 수, 승률, 합계 수익률.  
- 전체 구간: 승률, 일평균 수익률, Profit Factor, 최대 낙폭, 최대 연속 손실.  
- 14일 결과가 있으면 장기와 비교(승률 변화, 일평균 수익, 연속 손실, drawdown).

## 5. 원인 분석 및 권고

### 5.1 거래 0건 가능 원인

1. **유형 필터 과도하게 엄격**  
   - TREND: dip < 1%, REVERSAL: dip ≥ 2%.  
   - 1% ≤ dip < 2% 구간(BORDER) 전부 제외 → 진입 기회 축소.

2. **“첫 5분” vs “첫 5봉”**  
   - 현재: `FIRST_5MIN_BARS = 5` → 5분봉 5개 = **25분** 구간으로 dip 계산.  
   - 설계: “첫 5분” = 5분 1봉.  
   - 25분 구간에서는 dip가 더 크게 나와 TREND 비율 감소·REVERSAL만 남을 수 있음.

3. **T5/S1 발생 빈도**  
   - TOP-10만 대상으로 한정했을 때, 해당 10종목에서 당일 T5 또는 S1이 한 번도 발생하지 않았을 가능성.

4. **D-1 스코어 후보군**  
   - 일봉/뉴스 부재 구간에서는 스코어가 0 또는 소수로, TOP-10 선정이 공집합이 되거나 변동성이 낮은 종목만 포함될 수 있음.

### 5.2 권고 사항

| 항목 | 권고 |
|------|------|
| **첫 N분 정의** | “첫 5분” = 5분봉 1봉으로 dip 계산하도록 `FIRST_5MIN_BARS = 1` 검토. |
| **유형 구간** | BORDER(1% ≤ dip < 2%)에도 T5/S1 적용하거나, TREND를 dip < 2%로 완화 검토. |
| **C6/C7 반영** | 현재는 D-1 스코어 상위 10종목만 사용. C6(섹터 동반), C7(과매도 반등) 조건을 명시적으로 적용해 후보 수·품질 재검토. |
| **14일 벤치마크** | 14일 74.3% 승률·일평균 +1.31%를 낸 정확한 설정(유니버스, 유형, 신호, 청산)과 동일하게 맞춘 뒤 장기 스크립트 재실행. |
| **디버깅** | 일별 TOP-10 목록, 유형(TREND/REVERSAL/BORDER) 분포, T5/S1 발생 여부를 로그로 남겨 0건 원인 정량 확인. |
