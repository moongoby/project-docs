## 1. 현재 자본 구조의 문제

현재 설계에서 종목당 500만원을 배분하면 그 500만원은 하나의 전략에 묶여서 청산될 때까지 다른 곳에 쓸 수 없다.

```
현재 구조:
종목A에 500만 배분 → D8 진입 500만 → 15분 후 청산 → 500만+수익 회수
                     ↓
                     D2 진입은? → 별도 500만 필요
                     D9 진입은? → 또 별도 500만 필요

종목A에 장중 3회 진입하려면: 500만 × 3 = 1,500만 묶임
```

부분청산을 하면 청산된 현금이 즉시 풀린다. 이 현금을 다음 전략에 바로 투입하면:

```
복리 구조:
종목A에 500만 배분 → D8 진입 500만
  → +1.5% 30% 부분청산 → 152.25만 현금 확보 (원금 150 + 수익 2.25)
     ↓ 즉시
     D2 진입 자본으로 재투입 (152.25만)
     + D8 잔여 350만은 계속 홀딩

  → D8 잔여 350만 +2.8%에서 전량 청산 → 359.8만 현금
     ↓ 즉시
     D2 추가 투입 or D9 진입 자본

종목A 총 배분: 500만 고정인데 실제 운용은 500만+152만+359만 = 누적 1,011만
→ 자본 회전율 2.0배
```

## 2. 장중 복리의 수학

### 단리 vs 복리 비교

단리 (현재): 종목당 500만 고정, 전략별 별도 자본

```
D8: 500만 × +2.2% = +11만
D2: 500만 × +2.9% = +14.5만 (별도 자본)
D9: 500만 × +1.9% = +9.5만 (별도 자본)
총 투입: 1,500만, 총 수익: +35만, 수익률: +2.33%
```

복리 (제안): 부분청산 현금이 다음 전략의 진입 자본

```
D8: 500만 진입
  → +1.5% 30% 부분청산: 152.25만 확보 → D2에 투입
  → +2.8% 잔여 70% 청산: 359.8만 확보 → D9에 투입

D2: 152.25만 + 359.8만 = 512.05만 진입 (D8 수익 포함)
  → +1.5% 30% 부분청산: 156.17만 확보
  → +3.0% 추가 30% 청산: 158.51만 확보
  → 잔여 40% 모드3 파동홀딩 → +5.2% 최종: 215.46만

D9: 156.17만 + 158.51만 = 314.68만 진입 (D2 부분청산분)
  → +2.0%: 320.97만 회수

총 투입: 500만 (원 자본만), 총 회수: 215.46 + 320.97 = 536.43만
→ 총 수익: +36.43만, 수익률: +7.29% (500만 기준)
```

단리 +2.33% vs 복리 +7.29% — 동일 종목, 동일 수익률에서 자본 순환만으로 3.1배 차이.

### 핵심 공식

```
장중 복리 수익률 = Σ(각 전략 수익률) × (1 + 이전 전략 누적수익률)

n번째 전략의 투입 자본 = 원 배분금 × Π(1 + r_i), i=1~n-1
  r_i = i번째 전략의 부분/전체 청산 시 확정 수익률
```

## 3. 자본 풀 (Capital Pool) 개념

종목당 배분 자본은 고정된 하나의 전략에 묶이지 않고 "종목 전용 자본 풀"로 관리된다.

```
┌─────────────────────────────────────┐
│     종목A 자본 풀 (초기 500만)       │
├─────────────────────────────────────┤
│                                     │
│  D8 진입 ──부분청산──→ 풀로 회수     │
│                ↓                    │
│  풀에서 ──→ D2 진입 ──부분청산──→ 풀 │
│                          ↓         │
│  풀에서 ──→ D9 진입 ──전량청산──→ 풀 │
│                                     │
│  장 마감 시 풀 잔액 = 원금 + 총수익   │
└─────────────────────────────────────┘
```

### 자본 풀 운영 규칙

규칙 1 — 부분청산 즉시 풀 반환: 부분청산으로 확보된 현금은 즉시 종목 자본 풀로 반환된다.

규칙 2 — 다음 전략 진입 시 풀에서 인출: D2 진입 시 풀에 있는 가용 현금 전액을 투입한다. 단, 현재 홀딩 중인 잔여분의 평가액은 제외.

규칙 3 — 동시 보유 제한: 동일 종목에 최대 2개 전략 동시 보유 가능. (예: D2 잔여 모드3 홀딩 + D9 신규 진입) 자본 풀에서 양쪽 모두에 배분.

규칙 4 — 손절 시에도 풀 반환: D8이 -1% 손절되면 잔액(495만)이 풀로 반환. 이 495만이 D2 진입 자본이 된다. 손절해도 자본의 99%가 다음 기회에 즉시 재투입.

규칙 5 — 풀 총 한도: 종목당 자본 풀의 최대 운용액 = 원 배분금 × 1.5배. 수익이 누적되어 풀이 커져도 750만(500만×1.5)을 초과하여 한 종목에 투입하지 않는다. 초과분은 다른 종목 풀로 이전 또는 대기.

## 4. 모드 3과 자본 풀의 시너지

모드 3(파동 전환 감지 홀딩)은 청산을 보류하므로 현금이 풀로 돌아오지 않는다. 하지만 부분청산분은 이미 풀에 있으므로:

```
D2 진입 500만
→ +1.5% 30% 부분청산: 152.25만 풀 반환
→ 잔여 350만 모드3 홀딩 (눌림 구간, 청산 보류)
→ 풀의 152.25만 → D9 진입 (2파 돌파 시)

동시 보유: D2 잔여 350만(모드3) + D9 신규 152만
→ 2파 상승 시: D2 잔여 +5%, D9 +2%
→ D2 수익: 350만 × 5% = +17.5만
→ D9 수익: 152만 × 2% = +3.04만
→ 합계: +20.54만
```

모드 3으로 D2를 홀딩하면서 동시에 D9로 2파 돌파를 잡는다. 같은 2파 상승에서 2개 전략이 동시에 수익을 낸다. 한 파동에서 이중 수익. 이것이 부분청산 + 모드 3 + 자본 풀의 시너지이다.

### 모드 3 + 복리 관점 재분석

모드 3이 청산 후 재진입보다 우월한 이유:

진입 릴레이 방식:
```
D2 진입 1000원 → +3%(1030원)에서 청산 → 눌림 → D9 진입 1020원 → +2%(1040원) 청산
수익: +30원 + +20원 = +50원, 수수료 4회
```

청산 릴레이 방식 (모드 3):
```
D2 진입 1000원 → +3%(1030원) → 눌림(1015원, 청산 보류) → 2파 상승(1040원) → 청산
수익: +40원, 수수료 2회
```

모드 3의 진짜 가치는 1차 진입가(더 낮은 가격)를 유지하면서 2파 전체 수익을 가져가는 것이다. 재진입하면 눌림 후 반등가에서 진입하므로 더 높은 가격. 수수료도 절반.

## 5. 부분청산 → 자본 순환 맵

각 전략의 부분청산 시점과 다음 전략의 진입 시점을 매핑한다.

| 전략 | 부분청산 시점 | 확보 현금 → | 다음 전략 | 전달 시점 |
|------|-------------|-----------|----------|----------|
| D8 +1.5% 30% | 09:03~09:10 | 풀 반환 | D2 (눌림 대기) | 09:15~09:25 |
| D8 잔여 전량 | 09:08~09:15 | 풀 반환 | D2 추가 or D9 준비 | 즉시 |
| D2 +1.5% 30% | 09:25~09:35 | 풀 반환 | D9 (돌파 대기) | 09:40~10:00 |
| D2 +3.0% 30% | 09:35~09:50 | 풀 반환 | D9 추가 | 즉시 |
| D2 잔여 (모드3) | — | 홀딩 유지 | — | 2파까지 |
| D9 +2% 30% | 10:00~10:20 | 풀 반환 | D9 3파 or 다른 종목 | 즉시 |
| D9 잔여 전량 | 10:20~11:00 | 풀 반환 | D7 종가매수 자본 | 14:30 |

자본이 D8→D2→D9→D7으로 흘러가면서 매 단계마다 수익이 붙어서 커진다.

## 8. 리스크 관리 — 복리의 역방향 방지

3번 연속 -1% 손절 시:

```
500만 → D8 -1% → 495만 → D2 -1% → 490.05만 → D9 -1% → 485.15만
총 손실: -14.85만 (-2.97%)
```

단리: -1% × 3 = -3.0%, 복리 -2.97%. 손실 방향에서는 복리가 약간 유리하다 (손실이 줄어드는 방향).

### 안전장치

규칙 1 — 종목당 일일 최대 손실: 자본 풀의 -5% 도달 시 해당 종목 당일 진입 중단. 500만 풀이면 475만 이하가 되면 종목A 추가 진입 금지.

규칙 2 — 전체 일일 최대 손실: 전 종목 합산 일일 -3% 도달 시 당일 신규 진입 전면 중단.

규칙 3 — 연속 손절 횟수 제한: 같은 종목에서 3회 연속 손절 시 당일 해당 종목 진입 금지.

## 10. 자본 풀 구현 설계

```python
class IntraDayCapitalPool:
    """종목 전용 장중 자본 풀"""

    def __init__(self, stock_code, initial_capital):
        self.stock_code = stock_code
        self.initial = initial_capital
        self.available = initial_capital
        self.holdings = {}
        self.max_capital = initial_capital * 1.5
        self.daily_loss_limit = initial_capital * 0.05
        self.realized_pnl = 0
        self.trades = []

    def enter(self, strategy_id, amount=None):
        """전략 진입 — 풀에서 자본 인출"""
        if amount is None:
            amount = min(self.available, self.max_capital - self.total_invested())
        self.available -= amount
        self.holdings[strategy_id] = {'invested': amount, 'entry_price': None}

    def partial_exit(self, strategy_id, exit_ratio, exit_price):
        """부분청산 — 현금 풀로 반환"""
        holding = self.holdings[strategy_id]
        exit_amount = holding['invested'] * exit_ratio
        pnl = exit_amount * (exit_price / holding['entry_price'] - 1)
        returned = exit_amount + pnl
        self.available += returned
        self.realized_pnl += pnl
        holding['invested'] *= (1 - exit_ratio)

    def full_exit(self, strategy_id, exit_price):
        """전량청산 — 현금 풀로 반환"""
        self.partial_exit(strategy_id, 1.0, exit_price)
        del self.holdings[strategy_id]

    def can_enter(self):
        """진입 가능 여부"""
        if self.realized_pnl < -self.daily_loss_limit:
            return False
        if self.available < self.initial * 0.1:
            return False
        return True

    def total_invested(self):
        return sum(h['invested'] for h in self.holdings.values())
```
