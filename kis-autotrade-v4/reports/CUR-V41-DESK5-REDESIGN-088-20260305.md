| 시나리오 | 거래수 | PF | 핵심 문제 |
|---------|-------|-----|---------|
| A (기존) | 7 | 0.73 | 기저 신호 품질 불량 |

**핵심 발견**: 모든 최적화에서 "거래 수 증가 = PF 감소" 패턴 → 신호 자체의 구조적 결함

### Step 1-2: 기존 트리거별 문제 진단

**T5-1 (MA60 기울기 상향 + 2배 거래량)**: 개념은 맞으나 2배 거래량 조건이 분배(distribution) 상단에서도 발화
**T5-2 (MA5>MA20>MA60 골든크로스)**: 골든크로스 시점은 이미 상승의 중후반 → 후행 신호
**T5-3 (120일 신저가 + 20% 반등)**: **핵심 오류** — 데드캣바운스(Dead Cat Bounce)를 진입 신호로 착각

```
T5-3 문제 사례:
  주가 1000 → 700 (-30%) → 840 (+20% 반등) → T5-3 발화
  → 실제로는 1000에서 분배 중, 840은 리테일 매집 구간
  → 이후 500까지 추가 하락 (-52% from entry)
```

**청산 -15% 손절**: 너무 넓은 손절선이 누적 손실을 키움 (→ 강화 필요)

### Step 1-3: DESK3 성공 요인과 DESK5 실패 요인 교차 분석

| 구분 | DESK3 (PF=4.88) | DESK5 (PF=0.69) |
|------|----------------|----------------|
| 진입 시점 | 신고가/박스 돌파 후 (확증) | 반등 초기 (추측) |
| 거래량 조건 | 3배 이상 (강력 확인) | 2배 (여전히 모호) |
| 수급 확인 | 직접 포함 안 함 | 외인기관 형식적 체크 |
| 청산 조건 | -5% SL, MA10 이탈 | -15% SL (너무 관대) |
| 패러다임 | 모멘텀 추종 | 역추세 (바닥 사냥) |

**결론**: DESK5도 바닥 사냥이 아닌 **확증 기반 반등 포착**으로 전환 필요

## 3. Phase 2: 패러다임 전환 — 멀티레이어 구조 설계

### 설계 원칙

기존: 단일 레이어 트리거 (T5-1/2/3 중 2개)
신규: **3중 레이어 필터 구조** — 각 레이어가 독립적으로 품질을 검증

```
Layer 1: Bottom Quality Gate (바닥 품질 게이트)
  → 진짜 바닥권 종목만 통과
  BQ1: 52주 고점 대비 -35% 이상 하락 (진짜 낙폭 종목)
  BQ2: 52주 저점 대비 +8% 이상 반등 (살아있는 종목)
  BQ3: 최근 5일 중 2일 이상 MA60 위 종가 (반등 지속성)

Layer 2: Accumulation Pattern (매집 패턴 확인)
  → 스마트 머니가 실제로 매집하는 종목만 통과
  AC1: 최근 5일 평균 거래량 ≥ 직전 20일 평균 × 0.8 (관심 증가)
  AC2: 최근 5일 고-저 범위 < 현재가 × 8% (안정적 횡보)
  AC3: 현재가 > 5일 전 종가 (완만한 상승)
  → 3개 중 2개 이상 충족

Layer 3: Entry Trigger (진입 트리거)
  → 구체적 진입 타이밍 포착
  TN1: 종가 MA20 2일 연속 상회 + MA60 상회 + 거래량 1.3배
  TN2: 60일 박스권 상단 돌파 + 거래량 1.5배 + MA20 상회
  TN3: RSI(14) ≥ 45 + MA20 기울기 5일 상향 + 현재가 > MA20
  → 3개 중 2개 이상 충족
```

### 청산 조건 강화

| 조건 | Task084 (기존) | Task088 (신규) | 개선 방향 |
|------|-------------|-------------|---------|
| Hard Stop | -15% | -8% | 손실 조기 차단 |
| Take Profit | 없음 | +25% | 명확한 익절 기준 |
| Trailing Stop | 없음 | peak대비-5% (진입+10%시 활성화) | 수익 보호 |
| Max Hold | 120일 | 60일 | 기회비용 절감 |
