## 4. 수행 작업

### 4-1. 백필 스크립트 작성

- Session D 거래와 v4_investor_daily 동적 비교로 미매칭 쌍 추출
- KIS API FHPTJ04160001 호출 (908건)
- ON CONFLICT DO NOTHING (기존 데이터 보호)
- `--dry-run` 모드 지원

**실행 결과**:
```

API 성공: 905건 (3건 nodata: 주말/공휴일)
```

**삽입 0건 이유**: API가 항상 최근 30일 데이터를 반환하므로, 2025년 날짜에 대한 `target_date` 필터가 모든 행을 걸러냄. **역사적 2025년 데이터 복구 불가 확인**.

### 4-2. cron 확장 (영구적 개선)

**파일**: `scripts/cron/collect_investor_daily.sh`

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| `--stock-limit` | `500` | `4000` |
| 실질 커버 종목 | ~500종목 (알파벳순) | ~3,844종목 (전체 활성) |
| 일일 API 호출 | ~500건 (~30초) | ~3,844건 (~4분) |
| cron 시간 | 16:50 | 16:50 (유지) |
| 완료 예상 | 17:00 이전 | 17:00 이전 (허용 범위) |

**근거**: `stock_universe.trade_amount` 컬럼이 전체 NULL이므로, `--stock-limit 4000`은 사실상 전체 활성 종목 3,844개를 커버.
