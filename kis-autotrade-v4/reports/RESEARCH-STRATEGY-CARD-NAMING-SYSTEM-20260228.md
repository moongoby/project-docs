## 1. DESK 체계 정의

| DESK | 약칭 | 성격 | 보유 기간 | 풀 규모 | 봉 기준 |
|------|------|------|----------|---------|---------|
| DESK1 | RT (RealTime) | 실시간 실행 | 수 분~D+1 | 컨디션 발동 종목 | 1분/3분/5분봉 |
| DESK2 | SW (Swing) | 단기 스윙 | 3~10일 | 10~20종목 | 일봉 |
| DESK3 | MP (Mid Pool) | 중기 풀 관리 | 2~10일 관찰 | 50~100종목 | 일봉 |
| DESK4 | LP (Long Pool) | 장기 풀 관리 | 5~40일 관찰 | 20~30종목 | 일봉 |
| DESK5 | DP (Discovery) | 발굴 풀 | 20~120일 관찰 | 10~20종목 | 주봉/월봉 |

## 2. 전략 카드 명명 규칙

### 코드 형식
```
[DESK번호].[상황코드][순번]-[컨디션코드]
```

### 상황 코드 (6종)
| 코드 | 영문 | 한글 | 설명 |
|------|------|------|------|
| CH | Chase | 추격 | 급등 시작 시 모멘텀 추격 진입 |
| DP | Dip | 눌림 | 하락 후 반등 확인 진입 |
| BK | Break | 돌파 | 전고점/저항선 돌파 시 진입 |
| GP | Gap | 갭 | 갭업/갭다운 오버나이트 매매 |
| CL | Close | 종가 | 장 마감 근처 종가 배팅 |
| HLD | Hold | 보유 | 기존 포지션 유지·관리 |

### 컨디션 코드 (DESK1 전용)
| 코드 | 컨디션 | 핵심 |
|------|--------|------|
| C2 | 전일상한가 | 전일 상한가 종목의 D+1 매매 |
| C3 | 시초가강세 | 갭업 출발 후 장초반 추가 상승 |
| C4 | 장중1파급등 | 장중 갑작스러운 거래량 폭발 급등 |
| C6 | 종가강세 | 장 마감 근처 강세 종목 |
| C7 | NEW탐지 | 신규 급등 종목 실시간 탐지 |

C1(상한가예상): 독립 전략 부적합 → 다른 컨디션 강화 신호로 활용
C5(테마동시급등): MFE/MAE 0.85x → 진입 금지 플래그

### 순번 규칙
- 01부터 시작, 같은 DESK+상황+컨디션 내 변형 추가 시 02, 03...
- 비활성 카드의 순번은 재사용하지 않음

### DESK2~5 카드 코드 (컨디션 없음)
DESK2~5는 컨디션이 아닌 풀 관리 조건이므로 컨디션 코드 생략.
예: 2.DP01 (스윙 눌림 1번), 3.SCN01 (중기풀 스캔 1번)

## 5. 생성·삭제·버전 규칙

### 생성
- 같은 DESK+상황+컨디션 내 순번 증가: 1.DP01-C3 → 1.DP02-C3
- 새 컨디션 추가(C8): 1.CH01-C8, 1.DP01-C8 등
- 새 DESK 추가(DESK6): 6.XX 형식

### 삭제 (비활성)
- 물리적 DELETE 금지
- is_active = false, deactivated_at = NOW(), deactivation_reason 기록
- 비활성 카드 순번 재사용 금지

### 버전
- 파라미터 변경 시 card_version 증가 (v1→v2→v3)
- AI Self-Evolution 자동 수정도 버전 증가
- 이전 버전 파라미터는 v4_evolution_candidates 테이블에 이력 보관
