## 1. 재시작 및 1차 시도 (수집 안 됨)

- **baseline**: 02-19 189,204행(500종목), 02-20 72,904행(193종목), 합계 262,108.
- **3분 후 1차**: 변화 없음 (262,108).
- **6분 후 2차**: 변화 없음 (262,108).

**원인**: 거래일 순서가 "당일(02-24) 우선"이라, 장 전 시간에 02-24 분봉 API 호출이 빈 응답만 반환. 02-23·02-20 수집이 뒤로 밀려 6분 내 DB 반영 없음.

---

## 2. 조치 내용

**파일**: `backend/app/services/data_pipeline/collector_minute.py`

- **로직 추가**: `_get_trading_dates()` 반환 시, **장 전(09:05 KST 미만)** 이면 **당일을 수집 목록 맨 뒤**로 이동.
- **효과**: 과거일(02-23, 02-20, …)을 먼저 수집 → 단기간 내 DB에 분봉 적재.

수집기 **재시작** 후 로그 확인:
- `거래일 보강 적용: ohlcv_daily 240일 + 평일 보강 → 합계 244일 (추가: ...)`
- `장 전: 당일(20260224) 수집 순서를 맨 뒤로 이동 → 과거일 먼저 수집`
