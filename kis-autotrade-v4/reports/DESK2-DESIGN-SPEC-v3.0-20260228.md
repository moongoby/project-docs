## 1장. 시스템 철학

> **"DESK는 오늘 오를 종목을 추천하지 않는다. 오를 만한 종목을 추천하고, 전략이 기다린다."**

### 1-1. 패러다임 전환

| 항목 | 기존 패러다임 (v2.0) | 신규 패러다임 (v3.0) |
|------|---------------------|---------------------|
| DESK 역할 | "오늘 오를 TOP-10 추천" | "조만간 오를 풀(50~100종목) 관리" |
| 핵심 KPI | **정밀도** (TOP-10 중 실제 TOP-20 비율) | **리콜** (실제 급등 종목 중 풀에 포함된 비율) |
| 진입 결정 | DESK가 결정 (09:05, Birth+1min) | **전략 카드**가 결정 (풀 내 종목 매일 감시) |
| 풀 체류 | 1일 (매일 갱신) | **2~10일** (조건 충족까지 유지) |
| NEW 종목 대응 | 사전 발굴 시도 (실패: 3.8%) | **실시간 감지** (09:00~09:30 스캔) |

### 1-2. 전환 근거 (Phase 1~2C 연구)

1. **매일 TOP-10 찍기의 한계**: L3+X9 정밀도 90%이지만 재출현(58%)만 커버. NEW(42%)는 구조적 불가.
2. **D-1 데이터의 한계**: 60변수 일봉 분석 결과 NEW 적중률 3.8%. D-1까지의 정보로 "내일"을 맞히는 건 불가.
3. **넓은 풀의 유효성**: Phase 1에서 TOP-50까지 유효 (WR 79.7%, avg +1.38% vs TOP-20 +1.31%).
4. **진입 타이밍이 진짜 병목**: Birth+1min 시 WR 95.3%, PnL +2.27%. 발굴보다 진입이 수익을 결정.
5. **기다림의 가치**: 급등 사이클(수급 유입 → 눌림 → 횡보 → 지지 → 반등)에서 "지지 후 반등 시점"을 전략이 기다리면 됨.

### 1-3. 핵심 원칙

- **DESK = 후보 풀 관리자 (Pool Manager)**: 종목을 발굴하고, 풀에 넣고, 조건에 따라 퇴출한다.
- **전략 카드 = 진입 타이밍 감시자 (Entry Watcher)**: 풀 내 종목을 매일 감시하며, 실제 움직임 시작 시 진입한다.
- **DESK의 KPI = 리콜**: 실제 급등 종목을 풀에서 놓치지 않는 비율.
- **전략의 KPI = 정밀도 × 타이밍**: 진입한 종목의 승률과 수익률.
- **풀 종목은 2~10일간 유지**, 퇴출 조건 충족 시 제거.
- **진입은 전략이 판단**, DESK는 시점을 강제하지 않음.
- **"오늘 진입하지 못하면 내일 다시 본다"**: 풀에 남아있는 한 매일 감시 지속.

|------|------|

| 풀 크기 | **50~100종목**, 매일 장 마감 후 전수 스캔 |

| 항목 | 내용 |

### DESK1 — 장중 스캘핑

| 항목 | 내용 |

| 입력 | DESK2 감시 풀 + 실시간 거래량 폭발 종목 |
| 추세 지속 시 | DESK2로 핸드오프 |

## 4장. 후보 풀 관리 시스템 설계

### 4-1. 다층 스코어링 (Layer 1~5)

**Layer 1 — 구조적 준비 상태** (DESK4/5에서 올라온 정보):
- 이평선 정배열(5>10>20>60) 여부 → D18_ma_alignment_score
- 박스권 수축도 → D2_box_squeeze, D4_bb_width_20d
- 52주 가격 위치
- 거래량 장기 추세 (20일/60일 MA) → D22_vol_5d_vs_20d

**Layer 2 — 수급 에너지 축적** (D-10~D-1):
- D-5→D-1 거래량 변화율 (Phase 1: TOP 평균 +267%)
- 거래량 패턴 유형 (축적/이벤트/파동)
- 개인 매수 급증 여부 (v4_investor_daily individual_net_qty)
- 3주체 조합 (개인+기관 동시 매수, 개인 주도 등)
- 거래대금 절대 수준

**Layer 3 — 시장 관심** (뉴스/이벤트):
- 뉴스 연속성 (Phase 2: M3, 3일+ 연속 뉴스)
- 뉴스 건수 (단일보다 연속이 중요)
- 공시 여부
- 장전 뉴스 존재 여부

**Layer 4 — 반복 패턴** (검증된 최강):
- L3: 30일 TOP-20 등장 횟수 (Phase 2B: AUC 0.677)
- X9/W4: 섹터 동반 상승 (Phase 2B: AUC 0.851)
- W2: 5일 TOP-20 등장 횟수

**Layer 5 — 일봉 시퀀스 패턴** (Phase 2C 보완):
- 눌림목 시퀀스: 급등 → 거래량 감소 → 이평선 지지 → 거래량 복귀
- 3/5일선 터치 매매: 급상승 후 이평선 조정 → 지지 확인
- 거래량 축적 → 돌파 직전 패턴
- 갭 지지 확인 패턴
- **D-1 스냅샷이 아닌 D-10~D-1 시퀀스로 판단**

### 4-2. 풀 유지/퇴출 조건

| 조건 | 내용 |
|------|------|
| 유지 | 스코어 임계치 이상 + 가격이 주요 지지선 유지 |
| 퇴출 | 스코어 임계치 하회 3일 연속 |
| 퇴출 | 악재성 공시 발생 |
| 퇴출 | 이평선 정배열 붕괴 (5일선 < 20일선 전환) |
| 최대 체류 | DESK3: 10일, DESK4: 40일, DESK5: 120일 |

## 5장. 전략 카드 진입 시스템

전략 카드는 풀 내 종목을 매일 감시하며, 아래 조건 충족 시 진입.

### 5-1. TREND 진입 카드

| 항목 | 설계 |
|------|------|
| 대상 | 풀 내 종목 중 당일 09:00~09:30에 시가 대비 +2% 이상 상승 |
| 거래량 | 전일 대비 3배 이상 |
| Birth 감지 | 양봉 전환 확인 시 다음 분봉 시가 진입 |
| TP | +3~10% (클러스터별 차등) |
| SL | -3% |
| TIME | 14:30 |
| 근거 | Phase 2B: TREND Birth+1min WR 91%, PnL +2.07% |

### 5-2. REVERSAL 진입 카드

| 항목 | 설계 |
|------|------|
| 대상 | 풀 내 종목 중 당일 시초 2%+ 하락 후 반등 감지 |
| Birth 감지 | 09:05~09:30 사이 양봉 전환 + OBV 반전 확인 |
| TP | +5% (MFE 26.6% 근거) |
| SL | -3% |
| TIME | 14:30 |
| 근거 | Phase 2B: REVERSAL Birth+1min WR **100%**, PnL +2.57% |

### 5-3. 눌림목 진입 카드

| 항목 | 설계 |
|------|------|
| 대상 | 풀 내 종목 중 2~4일 조정 후 당일 양봉 전환 |
| 조건 | 3/5일선 지지 확인 + 거래량 복귀 시작 |
| 진입 | 장중 양봉 연속 2개 이상 확인 |
| TP | +5~10% (장기 보유) |
| SL | -3% |
| TIME | DESK3 이관 |

### 5-4. 핵심 원칙

**"오늘 진입하지 못하면 내일 다시 본다."**
풀에 남아있는 한 매일 감시 지속. 조건 미충족 시 SKIP → 다음 날 재감시.

## 7장. 실시간 NEW 종목 감지

Phase 2C 결론: NEW 종목은 사전 발굴 불가 → 실시간 감지로 대응.

### 7-1. 실시간 스캔 설계

| 항목 | 설계 |
|------|------|
| 시간 | 09:00~09:30 (1분 간격) |
| 데이터 | v4_ohlcv_minute 실시간 |
| 거래량 조건 | 5분 RVOL ≥ 3.0 (20일 평균 대비) |
| 가격 조건 | 시가 대비 +2% 이상 |
| 대상 | 풀에 없는 전체 종목 |
| 풀 추가 | 위 조건 충족 시 자동 추가 |
| 이후 | Birth Point 감지 → 진입 동일 프로세스 |

### 7-2. 근거

- Phase 2C: NEW 종목의 급등은 당일 아침 외부 촉매(뉴스, 공시, 테마)에 의해 발생
- 사전 발굴이 아닌 **발생 후 즉시 포착**이 유일한 전략
- Birth+1min은 NEW에도 동일하게 작동 (Phase 2B: REVERSAL WR 100%)
