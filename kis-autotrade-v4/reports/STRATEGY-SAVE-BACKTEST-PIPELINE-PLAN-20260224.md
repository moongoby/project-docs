# 백억이 → 전략 저장 → 백테스트 통합 파이프라인 기획서

**작성일:** 2026-02-24
**버전:** v3 (최종)
**태그:** CUR-STRATEGY-SAVE-BACKTEST-PIPELINE

---

## 1. 개요

백억이(LLM) 대화에서 AI가 설계한 전략을 저장하기 전 미리보기로 확인하고,
저장 후 백테스트까지 원스텝으로 연결하는 통합 파이프라인 구축.

## 2. 핵심 원칙

1. **universe_filter 필수** — 종목발굴조건 없이는 전략 저장 자체가 불가. 백억이를 통해 반드시 반영하거나 종목 지정 필요
2. **저장 전 확인** — 미리보기 모달에서 종목선정/매수/매도/위험관리 조건을 자연어로 확인 후 저장
3. **백테스트 자동 연결** — 저장 완료 시 백테스트 페이지로 카드·기간·자본금 자동 세팅 (사용자 수정 가능)
4. **결과 시각화 강화** — GO100 백테스트 결과에 수익곡선, 매매이력, 종목별 시그널 차트 추가

## 3. 전체 플로우

```
[백억이 AI 응답] ─ strategy_json 포함
  │
  ▼ "전략카드로 저장" 클릭
[StrategyPreviewModal - STEP 1: 미리보기]
  │ 종목선정/매수/매도/위험관리 자연어 표시
  │ 전략명·투자금 수정 가능
  │ ⚠️ universe_filter 비어있으면 저장 차단 + 백억이 안내
  │
  ▼ "저장하기" 클릭
[StrategyPreviewModal - STEP 2: 저장 완료]
  │ ✅ 저장 완료 + "바로 백테스트 실행 →" CTA
  │
  ▼ 클릭
[/backtest 페이지]
  │ 카드 자동 선택, 기간=최근3개월, 자본금=1천만원 (수정 가능)
  │ 종목 선정 조건 자연어 요약 표시
  │
  ▼ "실행"
[GO100 백테스트 결과]
  ├─ 성과 요약 + 등급
  ├─ 수익 곡선 차트
  ├─ 매매 이력 테이블
  ├─ 청산 사유 분석
  ├─ 종목별 성과 + 시그널 타이밍 차트
  └─ 후속 액션 (재실행/백억이 개선/모의거래)
```

## 4. universe_filter 필수 정책

- 전략 저장 시 universe_filter가 비어있고 ticker도 없으면 저장 버튼 비활성화
- "종목 선정 조건이 필요합니다. 백억이에게 요청하세요" 안내 표시
- 백억이에게 돌아가기 링크 제공

## 5. 백테스트 기본값 (사용자 수정 가능)

| 항목 | 기본값 | 빠른 선택 |
|------|--------|----------|
| 시작일 | 오늘-3개월 | [1개월] [3개월] [6개월] [1년] |
| 종료일 | 오늘 | — |
| 자본금 | 1천만원 | [500만] [1천만] [3천만] [5천만] |

## 6. 백테스트 결과 화면 구성

| 섹션 | 설명 |
|------|------|
| 성과 요약 카드 | 수익률, MDD, 샤프비율, 승률, 손익비, 총 매매 + 등급 |
| 수익 곡선 차트 | 일별 자산 변동 라인차트 |
| 매매 이력 테이블 | 종목, 매수/매도일, 가격, 수익률, 보유일, 청산사유 |
| 청산 사유 분석 | 사유별 분포 바 차트 |
| 종목별 성과 | 종목별 매매횟수, 승률, 총수익률 |
| 종목별 시그널 차트 | 캔들차트 + 매수/매도 시그널 마커 (타이밍 검증용) |
| 전략 규칙 요약 | 적용된 규칙 자연어 표시 |
| 후속 액션 | 재실행/백억이 개선/모의거래 링크 |
