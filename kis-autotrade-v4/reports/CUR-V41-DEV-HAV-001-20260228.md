## 1. 개요

DESK2 HAV(Hypothesis Auto-Validator)는 파동 기반 매매의 전체 변수 공간(27개 변수)을 자동으로 탐색·검증·진화시키는 4-Layer 시스템이다. R01~R24 연구 결과에서 확인된 모든 변수를 가설로 세우고 자동 검증한다.

## 2. 4-Layer 아키텍처 구현 요약

### Layer 1: Hypothesis Generator (가설 생성기)
- **Stage 1 — Coarse Grid**: 6개 핵심 변수(ZigZag, trans_thr, W1비율, 손절모드, MA TF, 거래대금 WARNING) × 5단계 = **135,135 조합** 그리드 서치
- **Stage 2 — Fine Bayesian**: Optuna TPESampler 200회 반복, 목적함수 `OOS_PF × √(trade_count)`
- **Stage 3 — Walk-Forward**: 3개월 Train → 1개월 OOS × 4회 rolling validation

### Layer 2: Auto-Validator (자동 검증기)
- E1(ZigZag 정확성, F1 ≥ 0.80), E3(재현성, ≤ 10pp), E4(통계 유의성, ≥ 4/12)
- E6(Plan-C OOS, 정확도 ≥ 55% AND PF ≥ 1.2), E7(릴레이, PF ≥ 1.3 AND PnL +20%)

### Layer 3: Evolution Engine Integration
- HAV PASS → v4_evolution_candidates 자동 등록 → Paper Trading 20일 → Live 큐
- Drift Detector: 전이확률, MA지지율, 릴레이PF, 거래대금소진율 4개 지표 일일 감시

### Layer 4: Auto-Report Generator
- Jinja2 기반 주간 보고서 자동 생성 + GitHub push + HTTP 200 확인
