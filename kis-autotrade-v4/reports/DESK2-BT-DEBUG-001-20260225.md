  - `ohlcv_daily`에는 **close** 컬럼만 있고 **close_price** 없음. 백테스터는 `close_price`로 SELECT → **컬럼명 불일치**.

## 3. 발견된 문제점

1. **전일 종가 로드 실패 가능성**  
   - `desk2_backtester._load_prev_close()`가 `ohlcv_daily`에 대해 `date = 'YYYY-MM-DD'` 및 `close_price` 사용.  
   - 실제 테이블은 `date = 'YYYYMMDD'`, 컬럼명 `close` → prev_close 0 또는 쿼리 오류 가능.

2. **보고서 미 Push**
