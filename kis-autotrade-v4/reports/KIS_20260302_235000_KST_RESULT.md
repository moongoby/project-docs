# KIS 작업 완료: CEO 승인 큐 시스템 구현

## 완료 항목

### 1. genspark_bridge.py — 승인 큐 기능 추가
- `APPROVAL_QUEUE_FILE = /root/.genspark/approval_queue.json`
- `APPROVED_DIR = /root/.genspark/approved/`
- `add_to_approval_queue(project, directive)` → 자동 증가 ID 부여
- `format_approval_message(id, project, prefix, directive)` → 번호 포함 형식
  - 형식: "📋 [KIS] CEO 승인 대기 (#N)" + 지시 전문 + 승인/반려 안내
- `approved/` 폴더 폴링 → CEO 승인 시 bridge가 자동 실행

### 2. telegram_url_watcher.py — 승인 명령어 감지
- `#N 승인` — 단건 승인
- `#N #M #K 승인` — 다건 동시 승인
- `#N 반려 — 사유: ...` — 반려 + 사유 매니저 전달
- `전체 승인` — 대기 중 전체 일괄 승인
- `대기 목록` — 현재 pending 건 요약 텔레그램 발송

### 3. 승인 흐름
```
매니저 → 비화이트리스트 지시
  ↓ bridge 감지
approval_queue.json 에 #{ID} 등록
  ↓ 매니저 + 텔레그램 전송
"📋 CEO 승인 대기 (#3)" 메시지
  ↓ CEO 텔레그램
"#3 승인" 명령
  ↓ telegram_url_watcher
approved/KIS_3.txt 생성
  ↓ bridge 폴링
execute_whitelist_directive() 실행
  ↓ 매니저 대화창
"✅ CEO 승인 #3 실행 완료"
```
