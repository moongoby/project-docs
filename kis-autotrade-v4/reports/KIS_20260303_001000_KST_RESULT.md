## 수정2 — chat_messages 전체 내용 전송 보장

### 원인
- `_send_chat_message()`가 `press_sequentially(message, delay=15)` 사용
- `press_sequentially`는 `\n` 문자를 **Enter 키**로 처리
- → 메시지 첫 줄 타이핑 후 Enter 키 → 메시지 제출 → 나머지 내용 누락

### 수정 내용

기존 방식:
```python
await ta.press_sequentially(message, delay=15)
```

변경 방식 (nativeInputValueSetter — init_message와 동일):
```python
setter.call(ta, `{escaped}`);
ta.dispatchEvent(new Event('input', { bubbles: true }));
ta.dispatchEvent(new Event('change', { bubbles: true }));
```

| 항목 | 내용 |
|------|------|
| 기본 방식 | JS nativeInputValueSetter (React state 포함 전체 텍스트 설정) |
| fallback | JS fill 실패 시 개행 제거 단문 500자 press_sequentially |
| 효과 | `\n` 포함 멀티라인 메시지 전체 전송 보장 |
