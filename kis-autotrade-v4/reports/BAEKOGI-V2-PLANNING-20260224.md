## Ⅰ. 대표님 지시사항 해석 및 설계 원칙 수립

대표님의 6개 지시를 관통하는 하나의 핵심은 명확합니다. **"백억이는 사용자의 돈을 실제로 불려주는 AI여야 한다."** 기존 설계에서 백억이는 "투자 교육·전략 설계 보조 도구"에 머물러 있었습니다. 이제 백억이의 정체성을 완전히 재정의합니다.

---

## Ⅱ. 백억이 역할 재정의

### 기존 vs 신규 정체성

기존 백억이는 "AI 교육형 자동매매 플랫폼의 어시스턴트"였습니다. 사용자가 질문하면 답하고, 전략을 요청하면 만들어주고, 백테스트를 실행해주는 리액티브 도구였습니다. 투자 판단은 사용자에게 맡기고, 백억이는 보조 역할에 머물렀습니다.

신규 백억이는 **"사용자의 자산을 실제로 불려주는 개인 전담 자산 운용 AI"**입니다. 사용자가 "100만원을 10년 만에 100억으로 만들고 싶어"라고 말하면, 백억이는 그 목표를 분석하고, 현실적이면서 가장 공격적인 경로를 설계하고, 전략을 자동으로 만들어 백테스트하고, 결과가 좋으면 실매매에 투입하고, 시장 상황이 바뀌면 스스로 전략을 수정하고, 매주 성과를 보고하며, 목표까지의 진척도를 추적합니다.

### 백억이의 새로운 미션 스테이트먼트

> **"백억이는 사용자가 말한 자산 목표를 달성하기 위해, 시장 데이터를 분석하고, 전략을 설계·실행·최적화하며, 24시간 자산을 운용하는 개인 전담 AI 트레이더다. 사용자는 목표만 말하면 된다. 나머지는 백억이가 한다."**

### 핵심 역할 5가지

**첫째, 목표 수립자(Goal Architect).** 사용자의 막연한 바람("부자 되고 싶어")부터 구체적 요구("3년 안에 5천만원을 3억으로")까지, 어떤 형태의 투자 목표든 받아들여 실현 가능한 계획으로 변환합니다. "100만원을 10년 만에 100억"이라면, 연간 필요 수익률을 역산하고(연 복리 약 99.9%), 현실적 달성 가능 시나리오를 시뮬레이션하며, 가장 공격적이면서 최대한 달성 가능한 경로를 제안합니다.

**둘째, 전략 설계·실행자(Strategy Engine).** 사용자의 목표와 성향에 맞는 전략을 자동으로 설계합니다. 스캘핑, 데이트레이딩, 스윙, 중장기, 배당 등 모든 시간축에서 최적 전략 포트폴리오를 구성하고, 백테스트로 검증한 뒤, 승인 없이(또는 간편 승인 후) 실매매에 투입합니다.

**셋째, 24시간 자산 운용자(Asset Operator).** 시장이 열려 있는 동안 실시간으로 포지션을 모니터링하고, 진입·청산 시그널을 실행하며, 시장 레짐이 변화하면 전략을 자동으로 조정합니다. 사용자가 잠자는 동안에도 백억이는 자산을 지킵니다.

**넷째, 자율 최적화자(Self-Optimizer).** 매일, 매주, 매월 전략 성과를 자동 평가하고, 성과가 부진한 전략은 파라미터를 조정하거나 교체합니다. 시장 환경이 변하면(레짐 전환) 포트폴리오 전체의 비중을 리밸런싱합니다. BacktestOptimizer의 자율 루프가 실전에서도 가동됩니다.

**다섯째, 개인 맞춤 대화 인터페이스(Personal Interface).** 사용자의 모든 질문을 투자와 연결합니다. "요즘 AI 관련주 뭐가 좋아?", "반도체 사이클 어떻게 돼?", "10년 장기투자 어떻게 해?", "코인이랑 주식 뭐가 나아?" — 어떤 질문이든 백억이는 답변과 동시에 실행 가능한 전략 카드로 변환하는 옵션을 제시합니다.

## Ⅲ. 시스템 재설계 — "목표 → 실행 → 성과" 완전 자동화

### 1. 새로운 사용자 여정 (User Journey)

기존 여정은 "채팅 → 전략 설계 → 백테스트 → (수동) 실매매"였습니다. 새로운 여정은 다음과 같습니다.

```
사용자: "100만원으로 10년 만에 100억 만들고 싶어"
    │
    ▼ [Goal Architect]
    백억이: 목표 분석
    - 필요 연간 수익률: ~99.9% (연복리)
    - 현실적 시뮬레이션:
      · 공격적 경로: 연 80% 목표 → 10년 후 약 35.7억 (가장 공격적)
      · 초공격적 경로: 연 120% 목표 (높은 리스크) → 10년 후 약 1,048억 (이론적)
      · 균형 경로: 연 50% 목표 → 10년 후 약 5.8억
    - 추천: "초기 자본이 작으니 처음 2~3년은 초공격적(스캘핑+데이트레이딩) 전략으로 
      자본을 키우고, 자본이 5천만원 이상이 되면 스윙+중장기로 전환하는 
      2단계 플랜을 제안합니다. 실현 가능한 최대치를 함께 만들어 봅시다."
    │
    ▼ [Strategy Engine]
    백억이: 자동 전략 포트폴리오 설계
    - Phase A (0~3년): 스캘핑 전략 2개 + 데이트레이딩 전략 1개
      · 전략별 자금 배분: 40% / 30% / 30%
      · 목표 월 수익률: 10~15%
    - Phase B (3~7년): 스윙 전략 2개 + 모멘텀 전략 1개
      · 자본 5천만원 이상 시 자동 전환
    - Phase C (7~10년): 중장기 가치 + 배당 + 스윙 혼합
      · 자본 보전 비중 확대
    │
    ▼ [Backtest & Validate]
    백억이: 각 전략 자동 백테스트·최적화 (기존 5+1회 루프)
    - Phase A 전략 포트폴리오 합산 백테스트 시뮬레이션
    - 10년 몬테카를로 시뮬레이션 (1,000회)
    - 결과: "최적 경로에서 10년 후 중앙값 12.3억, 상위 25% 28.7억, 
      하위 25% 3.1억입니다."
    │
    ▼ [사용자 확인]
    백억이: "이 플랜으로 시작할까요? (한 번의 터치로 시작)"
    사용자: "좋아, 시작해"
    │
    ▼ [Asset Operator — 자동 가동]
    - Phase A 전략 자동 실매매 시작
    - 일일 성과 요약 브리핑
    - 주간 전략 리뷰 + 자동 최적화
    - 월간 종합 리포트 + 목표 진척도
    - 시장 레짐 변화 시 자동 전략 조정
    - 자본 마일스톤 달성 시 Phase 전환 자동 제안
```

### 2. 핵심 신규 모듈 설계

#### 2-1. Goal Engine (목표 엔진)

현재 시스템에는 사용자의 "목표"를 받아 장기 플랜으로 변환하는 기능이 없습니다. Understand Agent가 투자 의향(UserIntent)을 추출하지만, 이것은 단일 전략 설계를 위한 것이지 장기 자산 목표를 위한 것이 아닙니다.

Goal Engine은 사용자의 자연어 목표를 받아 다음을 자동 산출합니다.

**입력**: "100만원으로 10년 만에 100억"
**처리**:
- 현재 자본(C₀): 1,000,000원
- 목표 자본(C_T): 10,000,000,000원
- 기간(T): 10년
- 필요 연 복리 수익률: (C_T/C₀)^(1/T) - 1 = 99.9%
- 현실성 평가: 한국 주식시장에서 전략적 자동매매로 달성 가능한 연 수익률 범위(보수적 15~30%, 공격적 50~100%, 초공격적 100%+)와 비교
- 리스크 시뮬레이션: 각 경로별 파산 확률(Kelly Criterion 기반), 최대 드로다운 기대치, 연도별 자산 경로 분포(몬테카를로)
- **멀티 Phase 플랜 생성**: 자본 규모별 최적 전략 유형 자동 매핑

**DB 테이블**: `go100_goals`

| 필드 | 타입 | 설명 |
|------|------|------|
| goal_id | bigint PK | |
| user_id | bigint FK | |
| initial_capital | numeric | 초기 자본 |
| target_capital | numeric | 목표 자본 |
| target_years | int | 목표 기간 |
| required_cagr | float | 필요 연 수익률 |
| risk_appetite | enum | CONSERVATIVE / MODERATE / AGGRESSIVE / ULTRA_AGGRESSIVE |
| plan_phases | jsonb | 다단계 플랜 (Phase A/B/C...) |
| monte_carlo_result | jsonb | 시뮬레이션 결과 요약 |
| current_phase | varchar | 현재 진행 Phase |
| current_capital | numeric | 현재 실제 자본 |
| progress_pct | float | 목표 대비 진척률 |
| status | enum | PLANNING / ACTIVE / PAUSED / ACHIEVED / ADJUSTED |
| created_at / updated_at | timestamp | |

#### 2-2. Strategy Portfolio Manager (전략 포트폴리오 매니저)

현재 시스템은 **개별 전략 카드** 단위로 운영됩니다. 사용자가 전략 A, 전략 B를 각각 만들어서 각각 실행합니다. 그러나 자산 극대화를 위해서는 **여러 전략을 하나의 포트폴리오로 묶어 통합 관리**해야 합니다.

Strategy Portfolio Manager는 Goal Engine이 생성한 Phase별 플랜에 따라, 복수의 전략 카드를 하나의 "전략 포트폴리오"로 구성하고, 전략 간 자금 배분, 상관관계 분석, 통합 리스크 관리를 수행합니다.

**핵심 기능**:
- **자금 배분 최적화**: Mean-Variance Optimization 또는 Risk Parity 방식으로 전략 간 최적 비중 산출
- **상관관계 모니터링**: 전략 A와 전략 B가 동일 종목/동일 시장 국면에 몰리는 것 방지
- **통합 드로다운 관리**: 개별 전략은 괜찮아도 포트폴리오 합산 MDD가 위험 수준(예: 30%)을 넘으면 전체 포지션 축소
- **Phase 전환 트리거**: 현재 자본이 Phase B 진입 기준(예: 5천만원)에 도달하면 자동으로 전략 재편 제안

**DB 테이블**: `go100_strategy_portfolios`

| 필드 | 타입 | 설명 |
|------|------|------|
| portfolio_id | bigint PK | |
| user_id | bigint FK | |
| goal_id | bigint FK | 연결된 목표 |
| name | varchar | 포트폴리오명 |
| allocations | jsonb | [{card_id, weight_pct, max_capital}] |
| rebalance_rule | jsonb | 리밸런싱 규칙 |
| total_capital | numeric | 총 투입 자본 |
| current_value | numeric | 현재 평가액 |
| total_return_pct | float | 누적 수익률 |
| max_drawdown_pct | float | 최대 드로다운 |
| status | enum | ACTIVE / PAUSED / RETIRED |

#### 2-3. Adaptive Regime Engine (적응형 레짐 엔진)

현재 `v4_market_regime_daily`에 시장 레짐이 기록되고, ADVANCED_FILTER_SPEC에 `get_market_regime` 필터 설명이 포함되어 있지만, **레짐 변화에 따라 전략을 자동으로 조정하는 로직**은 없습니다. 자산 극대화를 위해서는 이것이 필수적입니다.

**작동 원리**:
- 매일 장 마감 후 레짐 판정 (기존 regime_detector.py 활용)
- 레짐 전환 감지 시(예: MILD_TREND_UP → STRONG_TREND_DOWN) 전략 포트폴리오 전체에 대한 영향도 분석
- 영향도에 따라 자동 조치 실행:
  - **STRONG_TREND_DOWN 진입**: 공격적 전략 비중 축소, 현금 비중 확대, stop_loss 타이트닝
  - **STRONG_TREND_UP 진입**: 공격적 전략 비중 확대, 포지션 규모 증대
  - **SIDEWAYS**: 스캘핑/데이트레이딩 전략 비중 확대, 스윙 전략 축소
- 조치 후 사용자에게 즉시 알림 ("시장이 강한 하락 국면으로 전환되어 방어 모드로 조정했어요")

#### 2-4. Performance Tracker + Progress Monitor (성과 추적 + 진척 모니터)

사용자의 실제 자산 변화를 실시간으로 추적하고, 목표 대비 진척도를 지속적으로 보고합니다.

**일일 브리핑** (기존 DAILY-MARKET-BRIEFING 확장):
```
백억이: "좋은 아침이에요! 어제 결과를 알려드릴게요.
  · 총 자산: 1,847,320원 (전일 대비 +3.2%)
  · 활성 전략: 스캘핑A +4.1%, 데이트레이딩B +1.8%, 스윙C -0.5%
  · 오늘 시장: KOSPI +0.3%, 레짐 '약한 상승'
  · 목표 진척: 100억까지 0.018% (시작 4일차)
  · 현재 페이스라면 10년 후 예상 자산: 약 8.3억원
  이대로 가면 좋은 흐름이에요! 오늘도 백억이가 열심히 운용할게요."
```

**주간 리뷰** (자동 생성):
```
백억이: "이번 주 주간 리뷰입니다.
  · 주간 수익률: +7.8% (목표 주간 수익률 +3.5% 대비 초과 달성)
  · 최고 전략: 스캘핑A (주간 +12.1%)
  · 개선 필요: 스윙C (주간 -2.3%) → 파라미터 최적화 실행 중
  · 이번 주 매매: 총 47건 (승률 68%, 평균 수익 +1.2%)
  · 자본 경로: 목표 대비 앞서가는 중 (+23% 초과)
  스윙C 전략을 좀 더 개선해야 할 것 같아요. 
  최적화가 끝나면 결과 알려드릴게요!"
```

**월간 종합 리포트** (PDF 또는 마크다운, 이메일 발송):
- 월간 수익률 추이 차트
- 전략별 기여도 분석
- 목표 달성 확률 재계산 (몬테카를로 갱신)
- Phase 전환 필요 여부 판단
- 다음 달 전략 조정 사항

#### 2-5. Universal Question → Action Converter (질문→실행 변환기)

대표님이 가장 강조하신 부분입니다. **사용자의 어떤 질문이든 투자 행동과 연결**해야 합니다.

현재 Intent Router는 `help`, `optimize_existing`, `strategy` 세 가지만 분류합니다. 이것을 대폭 확장합니다.

**새로운 Intent 체계**:

| Intent | 예시 질문 | 백억이 행동 |
|--------|-----------|-------------|
| `goal_setting` | "100만원으로 100억 만들고 싶어" | Goal Engine 가동, 다단계 플랜 생성 |
| `strategy_create` | "스캘핑 전략 만들어줘" | 기존 파이프라인 |
| `strategy_optimize` | "이 전략 최적화해줘" | 기존 BacktestOptimizer |
| `market_analysis` | "요즘 시장 어때?", "반도체 전망은?" | 실시간 데이터 + LLM 분석 → "관련 전략 만들어볼까요?" |
| `stock_info` | "삼성전자 어때?" | 1차 DB + 2차 KIS API → "이 종목 기반 전략 만들어볼까요?" |
| `sector_inquiry` | "AI 관련주 뭐 있어?" | 유니버스 검색 → 관련 전략 제안 |
| `education` | "골든크로스가 뭐야?" | 교육 답변 + "골든크로스 기반 전략 체험해볼까요?" |
| `portfolio_check` | "내 자산 어떻게 돼?", "수익률 알려줘" | 실시간 포트폴리오 조회 + 분석 |
| `risk_inquiry` | "위험하지 않아?", "손실 나면 어떡해" | 리스크 분석 + 안전장치 설명 |
| `time_horizon` | "10년 장기투자 어떻게 해?" | Goal Engine + 장기 전략 포트폴리오 |
| `capital_question` | "100만원으로 뭘 할 수 있어?" | 자본 규모별 최적 전략 제안 |
| `comparison` | "코인이랑 주식 뭐가 나아?" | 비교 분석 + 주식 쪽 전략 제안 |
| `what_if` | "만약 내가 1천만원 더 넣으면?" | 시뮬레이션 재실행 + 결과 비교 |
| `adjust_goal` | "목표를 30억으로 낮출게" | Goal 수정 + 플랜 재계산 |
| `general_chat` | "오늘 날씨 좋다" | 자연스럽게 대화 후 "오늘 같은 날 시장은..." 연결 |

핵심 원칙은: **모든 대화의 끝에는 실행 가능한 "다음 액션"이 있어야 한다**는 것입니다. 교육 질문에 답하고 끝나는 것이 아니라, "이 개념을 활용한 전략을 실제로 만들어서 돌려볼까요?"로 연결합니다. 시장 분석을 하고 끝나는 것이 아니라, "이 분석을 반영한 전략을 지금 바로 설계할게요"로 연결합니다.

### 4. LLM 활용 극대화

현재 LLM은 "대화 생성"과 "전략 설계/평가/최적화"에 사용됩니다. 자산 극대화 시스템에서는 LLM의 역할이 대폭 확장됩니다.

#### 4-1. Goal Planning LLM (목표 플래닝)

Goal Engine에서 사용자의 목표를 분석하고 다단계 플랜을 생성할 때, LLM이 핵심 역할을 합니다. 단순 수학 계산(복리 역산)은 코드로 하되, "사용자의 상황에 맞는 현실적 경로 설계"와 "자연스러운 설명"은 LLM이 담당합니다.

**권장 모델**: Claude Sonnet 4.6 (설계대화와 동일, 프롬프트 캐싱 활용)
**시스템 프롬프트 핵심**:
```
너는 백억이, 사용자의 자산을 실제로 불려주는 AI 트레이더다.
사용자의 목표를 받으면:
1. 필요 연 수익률을 역산한다 (코드 결과 참조)
2. 한국 주식시장 자동매매의 현실적 수익률 범위를 고려하여 
   가장 공격적이면서 달성 가능한 시나리오를 제안한다
3. 자본 규모별 최적 전략 유형을 매핑하여 다단계 플랜을 구성한다
4. 솔직하되 긍정적으로 소통한다. "불가능합니다"가 아니라 
   "이 목표를 위해 가장 공격적으로 가면 이만큼 가능합니다"로 표현한다
5. 모든 제안에는 구체적 전략 카드 설계로 이어지는 실행 계획이 포함된다
```

#### 4-2. Market Intelligence LLM (시장 분석)

사용자가 시장/종목/섹터에 대해 질문할 때, DB 데이터 + KIS API 실시간 데이터를 조합하여 분석하고, 투자 행동으로 연결합니다.

**Function Calling / Tool Use 정의**:

| Tool | 기능 | 호출 조건 |
|------|------|-----------|
| `get_stock_info(code)` | stock_universe + ohlcv_daily 조회 | 종목명/코드 언급 시 |
| `get_realtime_price(code)` | KIS 현재가 API | "지금", "현재", "오늘" 등 실시간 맥락 |
| `get_market_regime()` | v4_market_regime_daily 최신 | 시장 상황 질문 |
| `get_sector_stocks(sector)` | stock_universe 섹터 필터 | 섹터/테마 질문 |
| `get_investor_flow(code)` | v4_investor_daily | 수급 관련 질문 |
| `run_quick_backtest(params)` | 간이 백테스트 | "이 전략 어때?" 류 질문 |
| `get_user_portfolio()` | go100_portfolios + positions | 자산/수익률 질문 |
| `get_goal_progress()` | go100_goals | 목표 진척 질문 |

LLM이 대화 중 필요한 데이터를 **스스로 판단하여 호출**하고, 결과를 자연어로 통합하여 답변합니다. 이것이 진정한 "데이터 기반 AI 트레이너"의 모습입니다.

#### 4-3. Proactive Report LLM (능동 보고)

사용자가 묻지 않아도 백억이가 먼저 보고하는 콘텐츠를 생성합니다. 일일 브리핑, 주간 리뷰, 월간 리포트를 LLM이 자동 생성하되, 모든 수치는 DB에서 가져온 팩트 기반입니다.

**실행 아키텍처**:
- 크론 스케줄러 (매일 08:30 KST)가 각 사용자별로:
  1. 전일 성과 데이터 수집 (go100_trades, go100_positions)
  2. 시장 데이터 수집 (v4_market_regime_daily, index_daily)
  3. 목표 진척 데이터 수집 (go100_goals)
  4. 이 데이터를 LLM에 전달하여 개인화된 브리핑 텍스트 생성
  5. 생성된 브리핑을 채팅 히스토리에 삽입 + 푸시 알림
- **모델**: Gemini Flash (저비용, 브리핑 텍스트 생성에 충분)
- **비용**: 사용자당 일일 1회 호출, 약 $0.0002/일 → 100명 기준 월 $0.60

## Ⅵ. 최종 비전 — 백억이가 만들어낼 사용자 경험

사용자가 처음 백억이를 만나는 순간부터의 완전한 경험을 그려봅니다.

**Day 1**: 사용자가 가입하고, "500만원으로 3년 안에 1억 만들고 싶어"라고 말합니다. 백억이는 30초 안에 3가지 경로를 시뮬레이션하고, 사용자가 "공격적으로 가자"를 선택하면 3개 전략 포트폴리오를 자동 설계·백테스트·최적화하여 "시작"을 기다립니다. 사용자가 계좌 연결 후 "시작"을 누르면, 그 순간부터 백억이가 자산을 운용합니다.

**Day 2~**: 매일 아침 8:30에 백억이가 먼저 말을 겁니다. "어제 +1.8%였어요. 스캘핑A가 잘 했네요. 오늘 시장은 약한 상승 레짐이라 유리한 환경이에요." 사용자는 중간에 "반도체 뭐 있어?"라고 물으면 백억이가 즉시 분석하고 "포트폴리오에 반도체 전략 추가할까요?"로 연결합니다.

**Week 4**: 주간 리뷰에서 "이번 달 +23.5%, 목표 대비 7% 앞서가고 있어요. 스윙C 전략이 부진해서 파라미터 최적화를 완료했어요. 다음 주부터 개선된 버전으로 가동합니다." 사용자는 읽기만 하면 됩니다.

**Month 6**: 시장이 급락합니다(STRONG_TREND_DOWN). 백억이가 즉시 알림을 보냅니다. "시장이 강한 하락으로 전환됐어요. 방어 모드로 전환했습니다. 공격 전략 비중을 50% → 20%로 줄이고, 현금 비중을 30%로 올렸어요. 시장이 안정되면 다시 공격적으로 전환할게요." 사용자가 아무것도 하지 않아도 자산이 보호됩니다.

**Year 1**: 연간 리포트가 생성됩니다. "1년간 수익률 +87.3%, 자산 500만원 → 937만원. 목표(1억) 대비 진척률 9.4%. 현재 페이스라면 3년 후 약 1.6억으로 목표 초과 달성 예상. 가장 잘한 전략은 모멘텀 스윙(+112%), 가장 어려웠던 시기는 6월 급락(MDD -18%, 자동 방어 작동)."

이것이 **백억이 SaaS의 성공 모습**입니다. 사용자는 목표만 말하고, 가끔 백억이의 보고를 확인하며, 궁금한 건 물어보면 됩니다. 나머지는 전부 백억이가 합니다.
