### 2.2 생애주기 정의

```
Birth (시가) → Growth (상승 구간) → Peak (MFE 도달) → Decay (하락 구간) → Close (종가)
```

- **Birth**: 첫 1분봉 = 시가
- **Growth**: Birth → Peak 구간 (상승)
- **Peak**: 장중 최고가 (MFE) 도달 시점
- **Decay**: Peak 이후 하락 → 종가 도달
- **지표 측정**: Peak 시점 N-1, N-2, N-3, N-5, N-10분 전 값 vs Growth 평균값 비교

## 5. 실패 원인 종합 분석

### 5.1 Root Cause: 표본 편향 (Survivorship Bias)

```
Phase B 280건: "이미 MFE가 높은 것으로 확인된" TOP 종목
Phase C 전체: "D-1 스코어만으로 선별된" 종목 (MFE 보장 없음)
```

Phase B에서 REVERSAL TP=20% WR=76.8%는 **사후 지식으로 필터링된 결과**. 실제 운용에서는 D-1 스코어만으로 종목을 선별하므로, REVERSAL 후보 중 60%가 MFE < 3%인 종목이 포함됨.

### 5.2 REVERSAL 전략의 구조적 한계

1. **시가 대비 2%+ 하락 자체가 약세 신호**: D-1 스코어가 높아도 당일 하락이 시작되면 기관/외국인 매도일 가능성
2. **S1 체결강도 반전 신호의 낮은 신뢰도**: 체결강도 반전은 일시적 반등(dead cat bounce)에도 발동
3. **TP=20% 비현실적 목표**: 하락 시작 종목이 당일 내 20% 반등하는 것은 극히 드문 이벤트

### 5.3 TREND 전략의 안정성

TREND는 Phase B(WR 96.6%, avg +9.01%)에서 Phase C(WR 54.1%, avg +0.624%)로 하락했지만 여전히 **양수 수익 유지**.

하락 원인:
- Phase B 280건은 MFE 20%+ 보장. Phase C 유니버스는 MFE가 낮은 TREND 종목도 포함
- TP=10% 도달율이 Phase C에서 낮아짐 (하지만 TIME exit에서도 양수 확보)

## 9. 결론

1. **Phase A 성과**: 분봉 기반 Peak 선행지표 18개 발견. OBV slope(3×), volume(+35%), strength(0.79), bull streak 감소 — 모두 통계적으로 유의.

2. **Phase B 성과**: 280건 TOP에서 기존 +3% 대비 14× 수익 향상 확인. TREND TP=10%/SL=-5%가 최적(Score 0.747).

3. **Phase C 실패**: 3개월 전체 유니버스 적용 시 REVERSAL 종목 품질 열화로 **누적 -44.28%**. REVERSAL 87건 중 60%가 MFE < 3%, TP=20% 도달 불가.

4. **TREND 생존**: TREND 단독 누적 +46.18%. 전체 유니버스에서도 수익 유지.

5. **핵심 교훈**: 사후 선별(post-hoc selection)된 TOP 종목 최적 파라미터를 사전 선별(pre-selection)에 그대로 적용하면 REVERSAL 유형에서 치명적 실패. TREND는 양방향 일관성 유지.

> **최종 권고**: DESK3에서 **TREND-Only 모드** 즉시 적용. REVERSAL은 DESK4에서 TP 하향(5~7%) + MFE 사전 필터 연구 후 재도입.
