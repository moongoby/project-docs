## [수정2] chat_messages 본문 전체 전송 — nativeInputValueSetter 방식

### 수정 파일: `/root/.genspark/genspark_bridge.py`

**기존 문제**: `f-string` 안에 `message`를 직접 템플릿 리터럴로 삽입 → 백틱(`)이나 `${...}` 포함 시 JS 문법 오류 + 멀티라인 내용 누락

**수정 후**: `page.evaluate(func, arg)` 패턴으로 안전하게 전달

```python
# 기존 (위험)
escaped = message.replace("\\", "\\\\").replace("`", "\\`")...
await page.evaluate(f"""() => {{ setter.call(ta, `{escaped}`); }}""")

# 수정 후 (안전)
await page.evaluate(
    """(msg) => {
        const ta = document.querySelector('textarea[name="query"]');
        const setter = Object.getOwnPropertyDescriptor(
            window.HTMLTextAreaElement.prototype, 'value'
        ).set;
        setter.call(ta, msg);
        ta.dispatchEvent(new Event('input', { bubbles: true }));
        ta.dispatchEvent(new Event('change', { bubbles: true }));
    }""",
    message,   # ← JS arg로 전달: 특수문자/개행/유니코드 모두 안전
)
```

- `message`를 JS 함수의 인자로 전달 → Playwright이 JSON 직렬화로 안전 처리
- 백틱, `${`, 개행, 한글 등 모든 문자 정상 전달
- fallback: JS fill 실패 시 단문(개행 제거, 500자) `press_sequentially` 유지
