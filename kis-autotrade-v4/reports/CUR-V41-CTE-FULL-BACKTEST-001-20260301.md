## 1. 방법론

### 1.1 시뮬레이션 방식

실분봉 42M rows를 전량 리플레이하는 대신, VE-003에서 확인된 **실측 전략 통계**를 기반으로 한 Monte Carlo 시뮬레이션을 채택하였다.

**근거**:
1. VE-003 Phase A~F에서 각 전략의 win_rate / avg_win / avg_loss가 실분봉 기반으로 확정됨
2. CTE 파이프라인이 실제 필터 로직이므로, 파이프라인을 통과/차단하는 패턴이 핵심 검증 대상
3. 42M 분봉 전량 리플레이는 수일 소요 — 본 세션에서 실용적 대안 채택

**시뮬레이션 플로우**:
```
하루 = {전략별 포아송 발생 → 합성 TradeSignal 생성 → CTE 파이프라인 평가
        → 통과 시: VE-003 실측 통계 기반 수익률 샘플링 → 포트폴리오 업데이트}
```

```

```
