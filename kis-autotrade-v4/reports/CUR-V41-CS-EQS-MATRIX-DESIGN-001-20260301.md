## 1. Conviction Score (CS) 상세 설계

### 1.1 CS 5요소 정의 + 가중치 + 점수 매핑

CS(Conviction Score)는 매매 진입 전 **확신도**를 수치화하는 복합 점수(만점 100점)이다. 5가지 독립 요소의 가중 합으로 산출된다.

| # | 요소 ID | 요소명 | 가중치 | 설명 |
|---|---------|--------|--------|------|
| 1 | DAILY_GRADE | 일별 환경 등급 | **25점** | DCS(Daily Condition Score) 등급 기반 일일 시장 환경 점수 |
| 2 | MATCH_QUALITY | 매칭 품질 | **20점** | Trigger x Tactic 적합성 매칭 점수 |
| 3 | TIME_FIT | 시간대 적합성 | **20점** | 전략별 최적 시간대 매칭 점수 |
| 4 | TECH_CONFIRM | 기술적 확인 | **20점** | 시그널 PF 랭킹 기반 기술적 확인 점수 |
| 5 | MARKET_ENV | 시장 환경 | **15점** | 시장 국면(Market Regime) + 변동성 환경 점수 |

## 2. Execution Quality Score (EQS) 상세 설계

### 2.1 EQS 5요소 정의 + 가중치 + 점수 매핑

EQS(Execution Quality Score)는 매매 **체결 품질**을 사전 추정하는 복합 점수(만점 100점)이다. 체결 비용, 슬리피지, 유동성 등 실행 관련 요소를 평가한다.

**비용 모델 (기본 가정):**

| 항목 | 비율(%) |
|------|---------|
| 매수 수수료 | 0.015 |
| 매도 수수료 | 0.015 |
| 매도 세금 (코스닥/코스피) | 0.18 |
| 슬리피지 (소형주) | 0.13 |
| 슬리피지 (대형주) | 0.05 |
| **왕복 비용 합계** | **0.47** |

| # | 요소 ID | 요소명 | 가중치 | 설명 |
|---|---------|--------|--------|------|
| 1 | SLIPPAGE_EST | 슬리피지 추정 | **20점** | 호가 스프레드 및 체결 깊이 추정 |
| 2 | FRESHNESS | 시그널 신선도 | **25점** | 트리거 이후 경과 시간(바) |
| 3 | VOL_QUALITY | 거래량 품질 | **20점** | 20일 평균 대비 거래량 비율 |
| 4 | PRICE_POSITION | 가격 포지션 | **20점** | 일일 가격 범위 내 위치 |
| 5 | ORDERBOOK_BALANCE | 호가 균형 | **15점** | 매수/매도 호가 비율 추정 |

#### 2.1.1 SLIPPAGE_EST (슬리피지 추정) - 가중치 20점

| 수준 | 점수 범위 | 설명 |

## 4. 통합 아키텍처 반영 위치

### 4.1 Layer 3.5 (CS) 삽입 설계

CS는 기존 V4.1 아키텍처의 **Layer 3 (시그널 생성)과 Layer 4 (주문 실행) 사이**에 삽입된다.

```
Layer 1: 데이터 수집 (Market Data Collector)
Layer 2: 전처리 + 필터링 (Pre-Filter)
Layer 3: 시그널 생성 (Signal Generator)
    |
    v
  [Layer 3.5: Conviction Score 산출]  <-- 신규 삽입
    |  CS >= 65 --> 정상 진입 (100%)
    |  CS 50-64 --> 축소 진입 (50%)
    |  CS < 50  --> 진입 차단
    v
Layer 4: 주문 실행 (Order Executor)
Layer 5: 리스크 관리 (Risk Manager)
Layer 6: 리포팅 (Reporter)
```

**Layer 3.5 입력 데이터:**

| 입력 | 소스 Layer | 설명 |
|------|-----------|------|
| DCS 등급 | Layer 2 | 일일 시장 환경 등급 (A-F) |
| 트리거 유형 | Layer 3 | 감지된 트리거 (T1-T9) |
| 전술 유형 | Layer 3 | 선택된 전술 (D2-C3) |
| 시간대 | Layer 1 | 현재 장 시간대 (T1-T4) |
| 시그널 PF 랭킹 | Layer 3 | 시그널의 역사적 PF 순위 |
| 시장 국면 | Layer 2 | BULL/FLAT/BEAR |
| 변동성 수준 | Layer 2 | LOW/MID/HIGH |

**Layer 3.5 출력:**

| 출력 | 대상 Layer | 설명 |
|------|-----------|------|
| CS 점수 (0-100) | Layer 4 | 확신도 점수 |
| CS 판정 | Layer 4 | PROCEED/REDUCE/BLOCK |
| 포지션 크기 조정 | Layer 4 | 100%/50%/0% |
| 매칭 상세 | Layer 6 | 5요소 세부 점수 |

### 4.2 Layer 4.5 (EQS) 삽입 설계

EQS는 **Layer 4 (주문 실행) 내부**에서 실제 주문 전송 직전에 산출된다.

```
Layer 4: 주문 실행 (Order Executor)
    |
    +--> 주문 생성 (Order Creation)
    |
    v
  [Layer 4.5: EQS 산출]  <-- 신규 삽입
    |  EQS >= 65 --> GATE 1: 전량 실행
    |  EQS 50-64 --> GATE 2: 50% 축소 실행
    |  EQS 35-49 --> GATE 3: 지정가 전용
    |  EQS < 35  --> GATE 4: 실행 차단
    v
    +--> 주문 전송 (Order Submission)
```

**Layer 4.5 입력 데이터:**

| 입력 | 소스 | 설명 |
|------|------|------|
| 호가 스프레드 | 실시간 호가 | 매수/매도 1호가 차이 |
| 체결 이후 경과 바 | Layer 3 | 시그널 생성 이후 경과 시간 |
| 거래량 비율 | Layer 1 | 20일 평균 대비 현재 거래량 |
| 가격 위치 | Layer 1 | 당일 가격 범위 내 현재 위치 |
| 호가 잔량 비율 | 실시간 호가 | 매수/매도 호가 잔량 비율 |

**Layer 4.5 출력:**

| 출력 | 대상 | 설명 |
|------|------|------|
| EQS 점수 (0-100) | 주문 엔진 | 체결 품질 점수 |
| 실행 Gate | 주문 엔진 | PROCEED/REDUCE/LIMIT_ONLY/REJECT |
| 비용 조정 | 주문 엔진 | 슬리피지 버퍼 가감 |
| 주문 유형 조정 | 주문 엔진 | 시장가/지정가 결정 |
| EQS 상세 | Layer 6 | 5요소 세부 점수 |

### 4.3 기존 Layer와의 데이터 흐름

```
[Layer 1: Data] --> [Layer 2: Pre-Filter]
                         |
                   DCS등급, 시장국면, 변동성
                         |
                         v
                    [Layer 3: Signal]
                         |
                   트리거, 전술, 시그널PF
                         |
                         v
               [Layer 3.5: CS 산출] <-- 매트릭스 참조
                    |         |
              CS>=65|    CS<50|
              정상  |    차단  |
                    v         x
               [Layer 4: Order]
                    |
               [Layer 4.5: EQS 산출]
                    |         |
           EQS>=65 |   EQS<35|
           전량    |    차단  |
                    v         x
               [Layer 5: Risk]
                    |
               [Layer 6: Report]
```

**데이터 흐름 요약:**

1. Layer 1에서 시장 데이터 수집
2. Layer 2에서 DCS 등급, 시장 국면, 변동성 산출
3. Layer 3에서 시그널 생성 + 트리거 감지
4. **Layer 3.5 (신규):** CS 산출 -> 진입 가부 + 포지션 크기 결정
5. **Layer 4.5 (신규):** EQS 산출 -> 체결 방식 + Gate 결정
6. Layer 5에서 최종 리스크 검증
7. Layer 6에서 모든 점수 기록 및 리포팅
