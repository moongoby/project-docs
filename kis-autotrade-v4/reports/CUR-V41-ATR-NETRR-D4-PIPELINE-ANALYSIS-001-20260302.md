## 2. ATR_NETRR 분석

### 2.1 로직 및 임계값

```python
# atr_dynamic_exit.py
NET_RR_RATIO = 2.0          # 최소 NetR:R 요구
COST_ROUNDTRIP = 0.0047     # 0.47% 왕복비용

# 계산식
half_cost = COST_ROUNDTRIP / 2
net_rr = (tp_pct - half_cost) / (sl_pct + half_cost)
is_net_rr_ok = net_rr >= NET_RR_RATIO  # 2.0
```

## 3. D4 전략 0건 원인 규명

### 3.1 결론: **조건 과잉 (Over-filtering) — 미구현/버그 아님**

D4 전략은 코드에 구현되어 있으며, 실제 80건의 후보가 발굴됨. 하지만 100%가 하위 필터에서 차단됨.

### 3.2 D4 관련 코드 위치

| 파일 | 라인 | 내용 |
|------|------|------|
| `backend/app/services/unified_engine/replay/candidate_scanner.py` | 203 | `_scan_d4()`: 전일상한가 +29~32% 후보 발굴 |
| `backend/app/services/unified_engine/replay/bounce_gate.py` | 296 | `check_d4_gate()`: D4 진입 게이트 |
| `backend/app/services/trading/cte/atr_dynamic_exit.py` | 51 | D4 ATR 파라미터: `sl_mult=1.0, tp_mult=5.0, sl_max=0.025` |
| `backend/app/services/unified_engine/config.py` | - | `STRATEGY_PRIORITY_ORDER` 포함 |

### 3.3 D4 80건 차단 상세

| 차단 이유 | 건수 | 비율 |
|---------|------|------|
| ATR_NETRR | 43건 | 53.8% |
| SIGNAL_COMBO | 22건 | 27.5% |
| L4.5_EQS | 14건 | 17.5% |
| GATE | 1건 | 1.3% |
| **합계** | **80건** | **100%** |

### 3.4 D4 ATR_NETRR 차단 핵심 원인

전일 상한가 종목 특성:
- 큰 ATR (전일 30% 폭등 후 변동성 높음)
- sl_mult=1.0 → SL은 1×ATR로 상대적으로 작음
- tp_mult=5.0 → TP는 5×ATR로 커야 하나
- **진입 시점(장중 눌림)에서 분봉 패턴이 약해 예상 TP 달성 어려움**
- 결과: `(TP - cost) / (SL + cost) < 2.0` 53.8%에서 미달

D4를 살리려면:
1. ATR_NETRR 임계값을 D4에 한해 낮게 조정 (`NET_RR_RATIO_D4 = 1.5`)
2. 또는 D4를 ATR_NETRR 제외 전략으로 분류 (D6/D7과 같이)
3. SIGNAL_COMBO 차단 22건도 별도 분석 필요

## 5. 핵심 발견 및 권고

### 5.1 ATR_NETRR은 합리적 필터 + 병목 동시 역할
- 필터 로직 자체는 수학적으로 올바름 (NetR:R ≥ 2.0은 리스크 관리 표준)
- 그러나 D2(65.1%)·D4(53.8%)·D5(57.0%) 3개 전략의 과반이 차단됨
- **실증 없이 완화할 경우 PF 하락 리스크**: 차단된 건은 "조건 미달"인 거래들이므로 수익률도 낮을 가능성 높음

### 5.2 D4 활성화를 위한 최소 조치
- Option A: `ATR_NETRR_STRATEGIES`에서 D4 제외 → D6/D7처럼 ATR 미적용
- Option B: D4 전용 임계값 `net_rr_ratio_d4 = 1.5` 추가
- 단, SIGNAL_COMBO 22건, L4.5_EQS 14건 차단도 해결해야 실질 실행 발생

### 5.3 다음 단계 제안
1. **CEO 승인 필요**: ATR_NETRR 임계값 1.5 변경 + 리플레이 재실행
2. **D4 활성화 옵션**: D4를 ATR 제외 전략으로 임시 지정 후 paper 트레이드
3. **L3.3 활성화 후 재측정**: 현재 미활성 상태이므로 활성 후 건수 재확인
