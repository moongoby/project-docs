```
거래수 많음 = 손실  (v1.0: 32~51건, PF 0.3~1.0)
```

## 6. D2C 재설계 방향 (다음 단계)

현재 1분봉 VCP 탐지 로직은 한계에 도달. 다음 중 선택:

### 옵션 1 — 5분봉 VCP (권장)
```
1파 고점 이후 5분봉 기준으로 수축 탐지
→ 노이즈 대폭 감소, 진짜 압축 패턴 포착 가능
→ 스크립트: v4_ohlcv_minute에서 5분 리샘플링
```

### 옵션 2 — 3분봉 채널 하단 지지 결합
```
VCP + 3분봉 상승 채널 하단 터치 = 이중 확인
→ 탐지 건수 줄이되 품질 대폭 향상
```

### 옵션 3 — D2C 포기, D2D(신규) 설계
```
전혀 다른 패턴: VWAP 재터치 + 거래량 급증
→ 기존 SIG6_VWAP_SUPPORT를 활용
```

**현재 D2A/D2B v1.1 코드 적용 우선 진행 후 D2C 재설계 별도 착수 권고.**
