
## P-4: 미체결 주문 자동취소 + 재주문 [FIXED]

| 항목 | 내용 |
|------|------|
| **문제** | 이전 미체결 매도 주문이 수량 잠금 → 새 매도 주문 "수량 초과" 오류 |
| **원인** | 장 마감 후 시장가 매도 시도(2건)가 미체결 상태로 누적 |
| **조치 1** | `v4_order_executor.get_pending_orders()`: 미체결 주문 조회 (CCLD_DVSN=02) |
| **조치 2** | `live_engine._cancel_pending_sell_orders()`: 매도 주문 전 기존 미체결 매도 자동 취소 |
| **조치 3** | `ord_dvsn=''` 빈값 시 기본값 `"00"` 처리 (취소 API 오류 방지) |
| **검증** | 316140 미체결 NXT 매도(0047776200) 취소 성공 ✅, 미체결 0건 확인 ✅ |

### 미체결-취소 흐름
```
매도 신호 발생
  ↓
_cancel_pending_sell_orders(executor, stock_code, exchange)
  → get_pending_orders(side=01) → 미체결 매도 목록
  → cancel_order(order_no, stock_code, ...) × N건
  → asyncio.sleep(1) (취소 반영 대기)
  ↓
place_sell_order() 재시도
```
