## 3. Phase 2 — 분석

### 3-1. 승률 6.8% 주요 원인 3가지

#### 원인 1: 수수료가 수익 구조 붕괴 (가장 직접적)
- cost_pct = **고정 0.47%** (모든 거래 동일)
- FORCED_CLOSE_EOD 27건(61.4%)은 가격 변동 없이 수수료만 손실
- 수수료를 극복하려면 **+0.47% 이상의 gross 수익** 필요
- 현재 수익 3건 모두 0.2~0.4% 수준 → 수수료 극복 실패 위기 (이미 간신히 넘기는 수준)
- **개선 방향**: FORCED_CLOSE_EOD 방지 (장 마감 전 강제 청산 종목 거를 필요), 또는 TP 목표를 +1.0% 이상으로 상향

#### 원인 2: FORCED_CLOSE_EOD 과다 (체결의 61.4%)
- 진입했지만 당일 가격 모멘텀이 없어 강제 청산 → 수수료만 납부
- 이 27건이 없었다면 승률은 3/17 = **17.6%**, avg_pnl = +0.17%로 흑자 전환
- **원인**: 진입 시점이 너무 늦거나 (장 마감 직전), 진입 종목의 당일 모멘텀 부재
- **개선 방향**: 14:30 이전 진입 종목만 허용, 또는 당일 변동폭 필터링 강화

#### 원인 3: TP 미달성으로 인한 TIMEOUT 과다 (체결의 38.6%)
- 모든 TIMEOUT 청산이 가격 회복 없이 시간 초과 → 잔여 손실 또는 간신히 수익
- TP가 설정되어 있어도 달성 못 함 → TP 수준이 비현실적이거나, 보유 60분이 너무 짧음
- **개선 방향**: TP를 시장 변동성 기반으로 동적 조정, 또는 TIMEOUT을 90분으로 연장

**현황**: 27건(61.4%)이 당일 가격 변동 없이 장 마감 강제 청산 → 수수료만 손실
**권고 파라미터**: 진입 허용 시간을 `09:00 ~ 14:30`으로 제한 (15시 이전 진입 종목만 허용)
**예상 효과**: FORCED_CLOSE_EOD 27건 제거 시, 체결 44→17건, 승률 3/17 = **17.6%**, avg PnL = **+0.177%**로 흑자 전환

### 개선안 2: SL 축소 — D-ORB/D4 손실 상한 제한
**현황**: SL 2.5% (D-ORB), 2.0% (D4) → 최악 손실 -3.612%, -2.673%
**권고 파라미터**: SL = 1.0% (손실 상한 1.0%로 통일)
**예상 효과**: SL 발동 2건에서 잃는 금액이 -3.6%→-1.0%, -2.7%→-1.0% 수준으로 제한

### 개선안 3: FunnelScore 임계값 코드-config 동기화
**현황**: 코드 = 0.40, config = 0.55. 불일치 존재
**권고 파라미터**: 코드의 하드코딩 0.4를 config의 `min_score_for_entry: 0.55`로 교체 (또는 config를 0.40으로 수정하여 의도 명확화)
**예상 효과**: 0.40~0.54 구간 거래 추가 차단 → 일부 손실 방지

### 개선안 4: Supply Gate `synthetic_BLOCK` 기준 완화
**현황**: 72건이 합성 데이터 기반으로 차단 → 실제 수익 가능 거래 차단 가능성
**권고**: KIS 실제 수급 API 연동 전까지 `synthetic_BLOCK` 차단 강도를 50% 완화 (또는 L3.3_SUPPLY를 INFO 레벨로 강등)
**예상 효과**: 통과 거래 수 증가 → 더 많은 데이터 수집 가능

### 개선안 5: D6 PM 세션 집중화 + TIMEOUT 연장
**현황**: 승리 3건 모두 D6 PM 세션, 모두 TIMEOUT 청산
**권고 파라미터**:

- TIMEOUT을 60분→90분으로 연장 (가격 회복 시간 확보)
- TP 목표를 +0.5%→+1.0%로 상향 (수익 크기 확대)
**예상 효과**: D6 승률 17%→30%+ 예상, avg PnL 흑자 전환 기대
