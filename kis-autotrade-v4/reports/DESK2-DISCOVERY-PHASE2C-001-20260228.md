## 0. 요약 (Executive Summary)

**CEO 가설**: "일봉(D-60~D-1) 상승 준비 패턴이 내일의 TOP-20을 예측할 수 있다. 특히 L3가 잡지 못하는 신규 출현 종목(42.1%)을 선제 발굴할 수 있다."

**결론**: CEO 가설 **부분 채택, 핵심 목표 FAIL**.

| CEO 기준 | 목표 | 실측 | 판정 |
|----------|------|------|------|
| 정밀도 | ≥ 85% | **82.0%** | FAIL (-3%p) |

**핵심 발견**: 일봉 패턴은 전체 TOP-20 예측에서 L3 baseline(75%)보다 우수하지만(82%), **NEW 종목 탐지에는 근본적으로 실패**한다. NEW 종목은 급등 전날까지 CTRL과 거의 동일한 일봉 패턴을 보인다. 이는 "NEW 종목의 급등은 일봉에 사전 흔적이 없다"는 것을 의미하며, DESK2 발굴 전략의 핵심 한계를 확인한 중요한 연구이다.

## 7. PART F: 종합 결론

### 7-1. CEO 가설 판정

**"일봉 상승 준비 패턴이 내일의 TOP-20을 예측할 수 있다"** → **부분 채택**

- **전체 TOP-20 예측**: L3 baseline(75%) 대비 차트 모델(82%)이 +7%p 우수. **채택**.
- **NEW 종목 예측**: 3.8%로 사실상 불가능. **기각**.

### 7-2. NEW 종목이 예측 불가능한 근본 원인

1. **일봉 패턴 유사성**: NEW 종목은 급등 전날까지 CTRL과 거의 동일한 패턴 (최강 AUC 0.644)
2. **클러스터 결과**: NEW의 80%가 "평범한" 클러스터에 위치
3. **일회성 이벤트**: NEW의 급등은 뉴스, 공시, 테마 등 **당일 아침에 발생하는 외부 촉매**에 의해 결정됨
4. **일봉은 과거 기록**: D-1까지의 일봉에는 아직 발생하지 않은 촉매의 정보가 없음
5. **수급/뉴스도 무효**: 외국인/기관 순매수(AUC 0.50), 뉴스(AUC 0.53) — 사전 정보 없음

### 7-3. 연구 가치

이 연구는 "실패"가 아닌 **"한계의 정량적 확인"**이다.

| 발견 | 의미 |
|------|------|
| 차트 4변수 OOS 82% | L3 없이도 일봉만으로 75%→82% 도달 가능 |
| ATR, bounce, vol turning, low position | TOP-20의 공통 특성: 높은 변동성, 최근 반등, 거래량 증가, 바닥 탈출 |
| NEW AUC 최강 0.644 | NEW vs CTRL 구분의 이론적 상한이 65% 수준 |
| W4×D45 상호작용 0.736 | 섹터 동조성 + 변동성은 강력한 조합이나 NEW에는 약함 |
| 43% 일회성 종목 | TOP-20의 절반은 사전 예측 불가능한 "이벤트 드리븐" |

### 7-4. 3차 테스트 설계 제언

Phase 2C 결과를 반영한 3차 테스트 설계:

**발굴 파이프라인 (변경 없음)**:
```
D-1 15:40:
  1. L3(30일 TOP-20 등장 횟수) 전 종목 계산
  2. L3 TOP-50 추출
  3. X9(동일 섹터 TOP-20 수 ≥ 1) 필터
  4. TOP-10 확정 → v4_desk2_candidates
```

**L3+X9를 유지하는 이유**:
- Phase 2B 결과: L3+X9 정밀도 **90%** (OOS)
- Phase 2C 결과: 차트 4변수 정밀도 82%, 하이브리드도 82%
- L3+X9가 여전히 최강. 차트 변수를 추가해도 개선 없음

**NEW 종목 대응 (현실적 방안)**:
- NEW 종목은 사전 발굴 불가능 → **실시간 감지로 대응**
- 발굴 TOP-10 외 추가 5~10종목을 "실시간 감시" 풀로 운용
- 09:00~09:30 실시간 스캔: 거래량 급등 + 가격 급등 종목 자동 추가
- Birth+1min 진입은 NEW에도 동일하게 작동 (Phase 2B: REVERSAL WR 100%)

**3차 테스트 스펙**:
| 항목 | 설계 |
|------|------|
| 기간 | 3개월 (2025-12 ~ 2026-02), ~60 거래일 |
| 발굴 | L3+X9 (Phase 2B v3.0 설계) |
| 진입 | Birth+1min (양봉 전환 감지) |
| 청산 | 유형별 TP/SL (TREND +3%, REVERSAL +5%, SL -3%) |
| 비용 | 0.41% 왕복 |
| 추가 실험 | 실시간 NEW 감지 풀 (거래량 급등 기반) |
| 목표 | WR ≥ 80%, PnL ≥ +1.5%, PF ≥ 2.0 |
