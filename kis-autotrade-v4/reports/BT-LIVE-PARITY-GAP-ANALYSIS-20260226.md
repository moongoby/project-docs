## 8. 결론

### 현재 백테스터의 한계

1. **DESK 스코어 25~35점 과소평가** — ADX, 외인/기관, 뉴스 미반영으로 실매매 대비 발굴 건수 감소
2. **C7 과대 탐지** — 악재 뉴스 미반영으로 하락 종목도 반등 시그널 발생
3. **시가총액 균일화** — 대형주/소형주 구분 없이 동일 점수
4. **C6(섹터 추종) 사실상 비활성** — 섹터 데이터 미연동

### 즉시 가능한 보완 (코드만 수정, 추가 수집 불필요)

- **ATR/ADX 계산** — 분봉 데이터 이미 충분
- **시가총액 로드** — stock_fundamentals 테이블 이미 있음
- **섹터코드 매핑** — v4_stock_sector 테이블 이미 있음
- **market_is_down** — v4_market_regime_daily에서 추출 가능

### 수집 보강 필요 항목

- **외인/기관 순매수** — 연속 일별 수집 자동화 필요
- **뉴스/공시** — 과거 데이터 확대 수집 (1년 이상)
- **테마/프로그램매매** — 일별 자동 수집 정착
