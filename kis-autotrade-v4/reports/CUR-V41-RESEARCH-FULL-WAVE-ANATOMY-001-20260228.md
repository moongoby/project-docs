## 1. 개요 (Overview)

### 1.1 연구 목적
+5% 이상 급등 종목의 **당일 전체 분봉 파동 구조**를 해부하여:
1. 파동이 몇 개나 발생하는지 (상승파 수 분포)
2. 각 파동의 정량적 프로파일 25항목 산출
3. 파동 유형별 클러스터링 (Type-A~E)
4. 파동 간 전이 확률 행렬 (8축 조건부)
5. 릴레이 풀체인 설계 (유형별 최적 경로)
6. 모드3(홀딩/청산 판단) 재설계 근거 확보

### 1.2 방법론
- **ZigZag 알고리즘**: 임계치 1.5%, 분봉 피봇 포인트 탐지
- **파동 식별**: ZigZag 피봇 기반 상승파(Up)/하락파(Down) 번갈아 분류
- **조건 매핑**: 일봉 기준 C2~C7 컨디션 자동 판별
- **레짐 매핑**: v4_market_regime_daily (BULL/BEAR/FLAT 등 7종)
- **시그널 평가**: feature_engine.py 17개 시그널 함수 발화 여부

### 1.3 데이터 파이프라인
```
v4_ohlcv_minute (57.5M행)
  → +5% 급등 종목-일자 쌍 추출 (43,805건)
  → 월별 균등 샘플링 (3,000건)
  → ZigZag 파동 식별 + 25개 프로파일 계산
  → 클러스터링 / 전이확률 / 릴레이 설계 / 모드3 분석
```

## 7. 릴레이 풀체인 설계 (Relay Full-Chain Design)

### 7.1 유형별 최적 체인

#### Type-A (1파형) — 9.1%, 272건
```
1.CH01 → 청산
```
- 릴레이: **불가**
- 전략: 첫 급등 포착 → 즉시 목표가 도달 시 청산
- 기대 수익: 평균 +4.22% (1차 상승파)

#### Type-B (2파형) — 11.6%, 348건
```
1.CH01 → 부분청산 50% → 1.DP01 릴레이 → 2파 청산
```
- 릴레이: 1회
- 자본 배분: 100% → 50%
- 조건: 눌림→W2 전이확률 ≥60%
- 기대 수익: 1차 +4.22% + 2차 +3.58%

#### Type-C (3파형) — 9.0%, 270건
```
1.CH01 → 1.DP01 → 1.BK01 → 1.DP01 → 1.BK01 → 1.CL01/GP01
```
- 릴레이: 2회
- 자본 배분: 100% → 50% → 25% → 12.5%
- 조건: 각 전이확률 체크
- 기대 수익: 1차~3차 누적

#### Type-D (다파형) — 17.7%, 532건
```
Type-C 확장 (전이확률 ≥80% 시에만 3차 릴레이 이상)
```
- 릴레이: 3회+
- 자본 배분: 전이확률 ≥80% 시만 추가 릴레이
- 기대 수익: 평균 급등률 18.6% (클러스터 C3)

#### Type-E (허위파) — 52.6%, 1,578건
