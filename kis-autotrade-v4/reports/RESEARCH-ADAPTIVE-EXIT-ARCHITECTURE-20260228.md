## 1. CEO 지시 본질

진입은 전략별로 다른 조건·시그널·시간대를 사용하면서 청산은 "60분 만기 또는 MFE 되돌림" 하나로 통일하는 것은 모순이다. 청산도 진입과 동일하게 시장 상태를 읽고 개별 판단해야 한다. 수익 중인 포지션을 언제 얼마나 청산하느냐가 최종 수익률을 결정한다.

Phase G에서 확인한 사실: MFE 30%→20% 트레일링이 60분 고정 청산보다 평균 +0.8% 우수. 하지만 이것도 단일 규칙이다. 시장 상태에 따라 즉시 청산이 맞을 때도, 홀딩이 맞을 때도, 부분 청산이 맞을 때도 있다.

## 2. 청산 5모드 정의

### 모드 1 — 즉시 익절 (Instant Take-Profit)

| 항목 | 내용 |
|------|------|
| 발동 조건 | 수익 ≥ +1.5% AND 거래량 감소 추세 AND RSI > 70 |
| 행동 | 100% 전량 청산 |
| 근거 | RSI 과열 + 거래량 이탈 = 추가 상승 동력 소멸, 되돌림 임박 |
| 적합 전략 | D8(1파 초기), 단기 모멘텀 소진 종목 |

수익이 나고 있지만 동력이 빠지고 있는 상태. 욕심 부리면 수익이 줄어든다. 빠르게 확정하고 다음 기회(D2 눌림)를 준비한다.

### 모드 2 — 부분 익절 + 잔여 홀딩 (Partial Take-Profit + Hold)

| 항목 | 내용 |
|------|------|
| 발동 조건 | 수익 ≥ +2% AND 거래량 유지 AND RSI 50~70 AND 현재가 > MA5 |
| 행동 | 50% 청산 (수익 확정) + 잔여 50% MFE 20% 트레일링 |
| 근거 | 거래량 유지 + RSI 중립 = 추가 상승 여력 존재, 하지만 확실하지 않음 |
| 적합 전략 | D2(눌림반등), D4(전상눌림), D9(전고점돌파) |

확실한 수익을 절반 확정하면서, 나머지 절반으로 추가 상승을 노린다. 가장 범용적인 모드.

### 모드 3 — 파동 전환 감지 홀딩 (Wave Transition Hold) ★CEO 핵심

| 항목 | 내용 |
|------|------|
| 발동 조건 | 수익 후 되돌림 중 4조건 동시 충족: ①RSI 30~50 ②거래량 감소 ③현재가 > MA20 ④되돌림 < MFE의 50% |
| 행동 | 청산 보류, 30분 추가 대기 → 2파 신호(전고점 돌파+거래량 증가) 발생 시 계속 홀딩 → 미발생 시 전량 청산 |
| 근거 | 눌림이지만 추세는 살아있음 (MA20 위 + 되돌림 50% 미만). 1파→눌림→2파 전형 패턴의 눌림 구간 |
| 적합 전략 | D2(눌림 후 2파 대기), D5(뉴스급등 후 수렴) |

CEO 지시의 핵심. "돈을 벌고 있는 포지션을 왜 청산하느냐? 눌림이 추세 이탈이 아닌 한 홀딩하라." Phase H-2에서 C3/C4의 MFE T2~T6이 46.3%로, 절반 가까이가 1파 이후에 더 높은 고점을 만든다. 모드 3은 이 46.3%의 2파 수익을 가져가기 위한 것이다.

### 모드 4 — 트레일링 강화 (Enhanced Trailing)

| 항목 | 내용 |
|------|------|
| 발동 조건 | 수익 ≥ +5% (대형 수익 진행 중) |
| 행동 | MFE 15% 되돌림 트레일링 (더 타이트하게), 상한가 도달 시 D6(오버나이트) 전환 |
| 근거 | +5% 이상 수익은 강한 추세. 되돌림 허용폭을 줄여서 수익을 최대한 보존 |
| 적합 전략 | D9(3파 돌파), D5(뉴스급등 대형), D4(전상한가 급등) |

큰 수익이 나고 있을 때는 트레일링을 타이트하게 조여서 수익을 지킨다. 상한가까지 가면 D6 로직으로 전환하여 오버나이트 갭 수익까지 노린다.

### 모드 5 — 강제 이탈 (Force Exit)

| 항목 | 내용 |
|------|------|
| 발동 조건 | 하드스톱 -1% 도달 OR 보유 > 90분 OR (MA20 하향 전환 + 거래량 급증) |
| 행동 | 100% 전량 청산, 해당 종목 자본 풀로 반환 |
| 근거 | 추세 이탈 확정. 더 버티면 손실만 커진다 |
| 적합 전략 | 전 전략 공통 (안전장치) |

손실 상태이거나 기회비용이 너무 큰 상태. 즉시 이탈하여 자본을 다음 기회에 투입한다.

## 3. 의사결정 트리 (1분봉 기준)

```
매 1분봉 도착 시:
│
├─ 하드스톱 -1% 도달? ─── YES → 모드5 (강제이탈)
│
├─ 보유시간 > 90분? ─── YES → 모드5 (강제이탈)
│
├─ MA20 하향전환 + 거래량 급증? ─── YES → 모드5 (강제이탈)
│
├─ 수익 ≥ +5%? ─── YES → 모드4 (트레일링 강화)
│   └─ 상한가 도달? → D6 전환
│
├─ 수익 ≥ +2%?
│   ├─ 거래량 유지 + RSI 50~70 + MA5 위? ─── YES → 모드2 (부분익절)
│   └─ 거래량 감소 + RSI > 70? ─── YES → 모드1 (즉시익절)
│
├─ 수익 ≥ +1.5%?
│   ├─ RSI > 70 + 거래량 감소? ─── YES → 모드1 (즉시익절)
│   └─ RSI 50~70? ─── 대기 (다음 분봉에서 재판단)
│
├─ 수익 중 되돌림 발생?
│   ├─ 4조건 충족? ─── YES → 모드3 (파동전환 홀딩)
│   │   └─ 30분 후 2파 미발생? → 전량 청산
│   └─ 4조건 미충족? → 트레일링 유지
│
└─ 손실 중? ─── 하드스톱 대기
```

## 5. 단계형 부분청산 구조

한 번에 전량 청산하지 않고 수익 단계별로 분할 청산한다.

| 단계 | 트리거 | 청산 비율 | 누적 청산 | 잔여 비율 |
|------|--------|----------|----------|----------|
| 1차 | +1.5% | 30% | 30% | 70% |
| 2차 | +3.0% | 30% (원금 대비) | 60% | 40% |
| 3차 | +5.0% | 20% (원금 대비) | 80% | 20% |
| 4차 | +8.0% 이상 | 잔여 20% 홀딩 | 80% | 20% (트레일링) |

+8% 이상 도달하면 잔여 20%는 MFE 15% 트레일링으로 관리. 상한가까지 가면 D6 전환.

### 단계형 부분청산의 수학

500만원 진입, +5% 도달 시:

```
단일 전량청산: 500만 × 5% = +25만

단계형 부분청산:
  +1.5%: 150만 × 1.5% = +2.25만 확정
  +3.0%: 150만 × 3.0% = +4.50만 확정
  +5.0%: 100만 × 5.0% = +5.00만 확정
  잔여 100만: 트레일링 (미확정)
  확정 수익: +11.75만 + 잔여 100만(+5% 이상 트레일링)
```

단계형이 확정 수익은 적지만 잔여분이 더 높은 수익을 가져올 수 있고, 되돌림 시 이미 확정된 수익은 보존된다. 최종 수익의 기대값은 단계형이 더 높다.

## 6. 모드 3 상세 — 파동 전환 감지

모드 3은 CEO 지시의 핵심이자 가장 복잡한 판단이다.

### 4조건 상세

| # | 조건 | 의미 | 계산 |
|---|------|------|------|
| ① | RSI(14) 30~50 | 과매도 진입하지 않았지만 충분히 눌림 | 1분봉 14봉 RSI |
| ② | 거래량 감소 | 매도 압력 소진 중 | 현재 5봉 평균 < 직전 10봉 평균 |
| ③ | 현재가 > MA20 | 중기 추세 유지 | 1분봉 20봉 이동평균 위 |
| ④ | 되돌림 < MFE 50% | 고점 대비 반 이상 안 빠짐 | (MFE - 현재수익) / MFE < 0.5 |

4조건 동시 충족 = "건강한 눌림" (Healthy Pullback). 추세는 살아있고 매도 압력이 소진되고 있으며 되돌림이 과도하지 않다.

### 모드 3 플로우

```
수익 후 되돌림 감지
  │
  ├─ 4조건 미충족 → 기존 트레일링 유지
  │
  └─ 4조건 충족 → 모드3 진입
       │
       ├─ 타이머 시작 (30분)
       │
       ├─ 매 1분봉:
       │   ├─ 전고점 돌파 + 거래량 증가? → 2파 확인, 모드4 전환
       │   ├─ MA20 하향 이탈? → 추세 이탈, 전량 청산
       │   ├─ 추가 하락 > MFE 60%? → 되돌림 과도, 전량 청산
       │   └─ 그 외 → 대기 계속
       │
       └─ 30분 경과, 2파 미발생 → 전량 청산
```

## 8. 기존 Phase G 결과와의 관계

Phase G에서 검증한 4가지 청산 방식:
- 고정 시간(60분): 기준선
- MFE 30% 되돌림: +0.5~1.0% 개선
- MFE 30%→20% 동적: 최적 (+0.8% 개선)
- 트레일링 스톱: 급등 종목에서 최적

5모드는 이 4가지를 상황별로 선택하는 상위 레이어이다:
- 모드1 = 고정 시간의 단축판 (즉시)
- 모드2 = MFE 트레일링 + 부분청산
- 모드3 = 홀딩 + 조건부 청산 (신규)
- 모드4 = 트레일링 강화
- 모드5 = 강제 시간/손절 청산

## 9. 검증 항목 (P4에서 실행)

E-1 (모드 판단 정확도): 각 1분봉에서 5모드 조건 계산, 모드 판단 후 실제 5/10/30분 수익률 비교. 모드3 판단→2파 발생 정확도 특히 중점.

E-2 (파동 전환 감지 정확도): 모드3 4조건 충족 시점 이후 30분 내 전고점 돌파(2파) 발생 비율. 목표 ≥ 40%, 미발생 시 추가손실 ≤ -1.5%.

E-3 (단계형 부분청산 vs 단일 전량청산): Phase A~F 수익 거래를 단계형/전량 2방식으로 재계산. 총수익, PF, 평균 거래당 수익, 최대 단일거래 수익 비교.

E-4 (전략별 최적 모드 조합): 전략×모드 매트릭스에서 PF 최대 조합 탐색. 연구 권장 조합과 데이터 결과 비교.

E-5 (5모드 적용 전후 전체 성과): 기존 청산 vs 5모드 적응형. 전략 합산 PF, DCS 평균, A등급 비율, 최대낙폭 비교.
