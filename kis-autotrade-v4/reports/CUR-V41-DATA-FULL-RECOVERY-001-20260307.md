## 7. CEO 결정사항 정리

### Fail-Open 정책
- 현재 FunnelScoreEngine은 오류 시에도 점수 계산을 시도 (Fail-Open 유지됨)
- 30종목 중 30개 모두 계산 완료 (ERROR 없음)
- **권고**: Fail-Open 유지 (펀더멘탈 데이터 결측 시 기본값 0.25 사용)

### 임계값 0.35 조정 여부
- PASS 21/30 = 70.0%
- 임계값 0.35 유지 시 충분한 필터링 효과
- L2(수급/공급) 점수가 낮은 종목이 BLOCK 주도
- **권고**: 임계값 0.35 현행 유지. L2 수급 데이터 품질 개선 우선.

### DQI 85+ 달성 로드맵
1. **macro_vix**: us_vix → vkospi_daily 연결 (즉시 가능, 10점 회복)
2. **ohlcv**: 일봉 완전성 측정 기준 재확인 및 데이터 연결 (10점 회복)
3. **macro_kospi**: 정상 범위 판단 기준 재확인 (14.6점 회복 가능)
4. **sector_index**: 추가 백필로 70일 이상 확보 (7점 회복 가능)

→ 상기 4개 항목 모두 해결 시 DQI = 58.1 + (max 41.6) = 99.7 (이론상)
