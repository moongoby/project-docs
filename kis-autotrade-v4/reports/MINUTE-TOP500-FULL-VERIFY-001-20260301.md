## 4. 권장 조치

전종목 수집을 위해 **과거 분봉 수집 스크립트**를 **전종목 옵션**으로 재실행할 것.

```bash
cd /root/kis-autotrade-v4 && source .venv/bin/activate
PYTHONPATH=/root/kis-autotrade-v4 python scripts/collect_minute_historical.py \
  --top 3844 \
  --resume \
  --rate-limit 12
```

- `--top 3844`: 유니버스 활성 종목 수와 동일하게 지정 (전종목).
- `--resume`: 이미 수집된 (종목, 날짜)는 건너뜀 → TOP500으로 쌓인 데이터는 유지하고, **미수집 종목·일자만 추가 수집**.
- 장중에는 스크립트가 자동 일시정지하므로, **장 마감 후 또는 주말** 실행 권장.
