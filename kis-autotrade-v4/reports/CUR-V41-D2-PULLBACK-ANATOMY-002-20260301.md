## 2. 핵심 발견: SL 이탈률 59.5%의 의미

### 문제의 본질

> **현재 진입 방식**: MA5/MA10 터치 봉의 **다음봉 시가(open)에 바로 진입**

이것은 "눌림이 끝났는지 확인되지 않은 상태"에서 진입하는 것입니다.
결과: 진입 후 다시 눌림저점을 하향 이탈하는 비율이 **59.5%**

```
현재 방식 진입 타이밍:
                 1파 고점
                    ▲
                    │
      진입 →  ●   │     ← MA터치 봉 다음봉 시가
             │ ▼  │         (아직 반등 확인 안됨)
             └─눌림저점  ← SL
                 │
                 ▼ (59.5% 이탈)
```

### CEO가 원하는 진짜 눌림확인매매

```
                 1파 고점
                    ▲
                    │
      진입 →     ●  │  ← 눌림저점 위로 N% 상승 확인 후 진입
                /   │
               ▲    │
              눌림저점 ← SL (이미 확인된 구조적 저점)
              (확정)
```

CEO 방식에서는:
- 눌림저점이 **먼저 확정**된 후
- 가격이 저점에서 **명확히 올라오는 시점**에 진입
- SL = 눌림저점 (이미 확인된 지지선)
- → SL 이탈률이 대폭 낮아짐 (정확한 수치는 하단 추가 시뮬 참조)

## 3. 1파 고점 돌파 분석

### 진입 후 1파 고점까지의 거리 (수익 목표)

| 백분위 | 1파 고점까지 남은 상승 거리 |

**해석**: 평균적으로 1파 고점까지 3.71% 더 올라야 돌파.
P90은 8.4%이므로, 1파 고점 돌파가 쉽지 않은 경우도 많음.

### 1파 고점 돌파 후 추가 수익

| 1파 돌파 성공 건수 | 150건 (24.8%) |
| 돌파 후 평균 추가 수익 | **+3.74%** |
| 돌파 건의 평균 MFE | **+8.15% (A), +5.17% (B)** |

**결론**: 1파 고점을 돌파하면 추가로 평균 +3.74%를 더 올라간다.
진입 → 1파 돌파 → 추가 +3.74%의 복합 수익 구조.

## 5. W자 패턴 분석

| 항목 | 수치 |
|------|------|
| W자 발생 건수 | 252건 (41.7%) |
| W자 후 1파 돌파 | 28.2% |
| W자 평균 수익 | **-0.16%** |
| 비W자 평균 수익 | **+0.63%** |

### W자 패턴의 함정

W자 발생률이 41.7%로 높지만, **W자 거래의 평균 수익이 -0.16%** — 오히려 수익이 나쁨.

이유: W자 발생 시 가격이 눌림저점 근처까지 다시 하락 → SL 이탈(D 시나리오)로 분류되는 경우가 많음. W자 패턴을 기대하며 기다리면 오히려 SL이 먼저 터짐.

```
W자 패턴 (이상적):        W자 패턴 (현실):
   peak                    peak
    │                       │
    │                       │
   ●  진입               ● 진입 (MA터치 직후)
   │ \  /                │ \
   │  \/  → 상승          │  \-SL 이탈 (59%가 이 경로)
   저점                    저점 하향이탈
```

## 7. 핵심 결론 및 설계 권고


### 개선 설계: 진짜 눌림확인매매

```
Step 1: 1파 고점 탐지 (09:00~09:35, +5%+)
Step 2: 눌림 구간 모니터링
  → MA5/MA10에 닿은 이후 추가 하락이 멈추는지 확인
  → 눌림 저점 후보가 형성되는 과정 관찰
Step 3: 눌림 저점 확정 조건
  → 저점 봉에서 거래량 증가 + 양봉 전환 동시 발생
  → OR: 저점 이후 연속 2봉 이상 고점 높아짐(상승 확인)
Step 4: 진입
  → 저점 확정 후 눌림저점 위로 +0.3~0.5% 이상 상승한 시점에 진입
  → (= 저점이 진짜 저점임을 가격 행동으로 확인한 후 진입)
Step 5: SL = 눌림저점 - 0.3%
Step 6: TP = 트레일링 (고점 -10% 하락시)
  또는 1파 고점 +1%를 1차 목표로 설정 후 트레일링
```
