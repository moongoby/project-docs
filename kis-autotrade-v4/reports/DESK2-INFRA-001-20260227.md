## 1. 절대 규칙 반영

- **기존 kis-v41-* 서비스 절대 수정/재시작 금지** — api, monitor, scheduler 등 기존 유닛 변경 없음.
- **새 서비스는 별도 systemd unit으로만 추가** — `deploy/*.service` → `/etc/systemd/system/` 복사, `daemon-reload` 후 `enable`/`start`는 CEO 승인 시에만 수행.
- **main.py에 라우터 추가 불가** (API 재시작 필요) — DESK2 기능은 **별도 FastAPI 인스턴스 또는 스크립트(scripts/desk2/*.py)** 방식으로만 구현.

위 내용은 `.cursor/rules/kis-v41-rules.md` 절대 규칙 8번에 추가됨.

## 2. DB 테이블 생성 결과

### 2.1 마이그레이션 파일

- **경로**: `backend/migrations/034_desk2_tables.sql`
- **적용 명령**:  
  `PGPASSWORD=... psql -h localhost -U kis_admin -d kisautotrade -v ON_ERROR_STOP=1 -f backend/migrations/034_desk2_tables.sql`  
  (또는 `sudo -u postgres psql -d kisautotrade -f ...`)

### 2.2 생성된 테이블 (확인 결과)

| 테이블명 | 설명 |
|----------|------|
| v4_desk2_candidates | D-1 스코어링 결과 (target_date, stock_code UNIQUE) |
| v4_desk2_signals | 실시간 신호 (TREND/REVERSAL/BORDER, T5/S1/FALLBACK) |
| v4_desk2_trades | 거래 기록 (진입/청산/손익) |
| v4_desk2_daily_summary | 일별 요약 (승률, gross/net PnL, market_regime) |

### 2.3 인덱스

- `idx_desk2_cand_date` ON v4_desk2_candidates(target_date)
- `idx_desk2_sig_date` ON v4_desk2_signals(signal_date)
- `idx_desk2_trade_date` ON v4_desk2_trades(trade_date)

### 2.4 실행 결과 (요약)

```
CREATE TABLE   (x4)
CREATE INDEX   (x3)
COMMENT        (x4)
```

- **검증 쿼리**:  
  `SELECT tablename FROM pg_tables WHERE schemaname='public' AND tablename LIKE 'v4_desk2%' ORDER BY tablename;`  
  → v4_desk2_candidates, v4_desk2_daily_summary, v4_desk2_signals, v4_desk2_trades 확인됨.

## 3. 파일 구조 생성 확인

```
scripts/desk2/
├── desk2_prescoring.py      # D-1 스코어링 (커서 1 결과 연동)
├── desk2_realtime_signal.py # 실시간 신호 (커서 2 결과 연동)
├── desk2_auto_trader.py     # 자동 주문 (커서 3 결과 연동)
├── desk2_config.yaml        # 전략 파라미터 (커서 1 최적화 결과 반영)
└── desk2_monitor.py         # 상태 모니터링 (v4_desk2_* 카운트)
```

- **연동 방식**: 모두 **main.py 라우터 추가 없이** 스크립트 단독 실행. DB는 `DATABASE_URL_SYNC` 또는 `DATABASE_URL`(postgresql+* 접두사 제거 후) / `DB_*` 환경 변수로 연결.
- **실행 검증**:  
  `venv/bin/python -u scripts/desk2/desk2_prescoring.py`,  
  `venv/bin/python -u scripts/desk2/desk2_monitor.py` 정상 동작 확인.

## 4. systemd 서비스 유닛 (생성만, start 미실행)

| 서비스명 | 용도 | 스케줄 | 배포 위치 |
|----------|------|--------|-----------|
| kis-v41-desk2-prescoring.service | D-1 스코어링 | 15:40 1회 (timer/cron으로 트리거) | deploy/kis-v41-desk2-prescoring.service |
| kis-v41-desk2-signal.service | 실시간 신호 | 09:00~09:30 매분 (timer/cron으로 트리거) | deploy/kis-v41-desk2-signal.service |
| kis-v41-desk2-trader.service | 자동 주문 | 09:00~15:00 상시 (Type=simple) | deploy/kis-v41-desk2-trader.service |

- **설치 절차** (CEO 승인 후):  
  `sudo cp deploy/kis-v41-desk2-*.service /etc/systemd/system/`  
  `sudo systemctl daemon-reload`  
  enable/start는 승인 시에만 수행.
- **주의**: 기존 kis-v41-api, kis-v41-monitor, kis-v41-scheduler는 **재시작/수정하지 않음**.
