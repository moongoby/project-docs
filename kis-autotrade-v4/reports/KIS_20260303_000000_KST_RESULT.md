### 발견된 버그 3가지

#### Bug 1: `parse_directive` — END 마커 없으면 None 반환 (주원인)
```
로그: [KIS] DIRECTIVE_START 키워드 감지 (raw text)
로그: (지시 감지 없음 → 침묵)
```
- **원인**: regex `START...(.*?)...END` 패턴에서 `>>>DIRECTIVE_END`가 없으면 매칭 실패
- **KIS 매니저 디렉티브**: `>>>DIRECTIVE_START`는 있지만 `>>>DIRECTIVE_END` 누락
- **결과**: `parse_directive` → None → "지시 없음" → 2분마다 "지시 대기 중" 반복

#### Bug 2: `_send_telegram` 함수 미정의
```python
# line 734: _send_telegram(...)  ← NameError, try/except에 silent catch
```
- 새 대화창 초기화 완료 알림이 Telegram에 전송되지 않음

#### Bug 3: 승인 Telegram 전송이 `_send_chat_message`에 의존
- 채팅 전송이 실패하면 Telegram도 함께 실패
- 독립적인 직접 발송 경로 없음

### Fix 2: `_send_telegram` 함수 추가
```python

        import telegram_report as tg
        return tg.send(message, project=project)
    except Exception as e:
        logger.warning("_send_telegram 오류: %s", e)
```
