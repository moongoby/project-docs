## 2. 구현 API 스펙 (5개)

| 메서드 | 경로 | query | 설명 |
|--------|------|-------|------|
| GET | `/api/v4/backtest/analysis/regime-analysis` | desk_id, card_id, regime_mapped, market_type, pass_only, session_id | v4_backtest_regime_analysis 필터 조회 |
| GET | `/api/v4/backtest/analysis/regime-matrix` | session_id (optional) | 전략×레짐 피벗 (bull_wr, bull_pf, bull_alpha, bull_pass, neutral_wr, neutral_pass, bear_wr, bear_pass, crisis_pass 등) |
| GET | `/api/v4/backtest/analysis/equity-curve` | session_id, card_id | v4_backtest_daily 기반 누적 수익 시계열 + 레짐(진입일) |
| GET | `/api/v4/backtest/analysis/regime-timeline` | market_type, start_date, end_date | v4_market_regime_daily + index_daily 조인, 날짜별 regime·지수 close |
| GET | `/api/v4/backtest/analysis/regime-comparison` | card_id | 해당 카드 레짐별 성과(win_rate, pf, alpha, sharpe, total_trades, total_pnl) |

- **인증:** `/api/v4/*` 구간은 `X-Internal-API-Key` 헤더 필요. curl 테스트 시 `-H "X-Internal-API-Key: $INTERNAL_API_KEY"` 사용.

## 3. 차트 5종 설명

| 컴포넌트 | 파일 | 설명 |
|----------|------|------|
| RegimeTimelineChart | `RegimeTimelineChart.tsx` | X: 날짜, Y: 지수. 레짐별 ReferenceArea 배경(BULL=연초록, NEUTRAL=연회색, BEAR=연주황, CRISIS=연빨강). KOSPI/KOSDAQ 토글. |
| EquityCurveChart | `EquityCurveChart.tsx` | X: 날짜, Y: 누적 수익률. 레짐 배경, 벤치마크 라인 선택. ComposedChart. |
| RegimePerformanceBar | `RegimePerformanceBarChart.tsx` | X: 레짐(BULL/NEUTRAL/BEAR/CRISIS), Y: 선택 메트릭(win_rate/PF/alpha/sharpe). 합격 기준선·pass/fail 색상. |
| StrategyRegimeHeatmap | `StrategyRegimeHeatmap.tsx` | 행: strategy(card_id+name), 열: BULL/NEUTRAL/BEAR/CRISIS. 셀: alpha 색상 + win_rate/PF 텍스트. |
| DeskRadarChart | `DeskRadarChart.tsx` | 5축: 승률, PF, 알파, 샤프, 1-MDD(역). Recharts RadarChart. |
