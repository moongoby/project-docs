# CUR-V41-DESK2-DB-URL-FIX-001 실행 결과

## 조사 결과

### 문제 확인
`.env` 환경변수:
- `DATABASE_URL=postgresql+asyncpg://kis_admin:...@localhost:5432/kisautotrade`
- `DATABASE_URL_SYNC=postgresql+psycopg2://kis_admin:...@localhost:5432/kisautotrade`

`psycopg2.connect()`는 `postgresql+asyncpg://` 및 `postgresql+psycopg2://` 형식을 모두 거부함.
순수 `postgresql://` 형식만 지원.

  PYTHONPATH=/root/kis-autotrade-v4/backend \

## Root 실행 필요 패치

파일: `/root/kis-autotrade-v4/scripts/desk2/desk2_realtime_signal.py` line 110

```python
# 변경 전
db_url = db_url or os.environ.get("DATABASE_URL", "dbname=kisautotrade user=kis_admin host=localhost")

# 변경 후 (올바른 fix - +asyncpg와 +psycopg2 모두 strip)
_raw = (os.environ.get("DATABASE_URL_SYNC") or os.environ.get("DATABASE_URL") or "")
_raw = _raw.replace("postgresql+asyncpg://", "postgresql://").replace("postgresql+psycopg2://", "postgresql://")
db_url = db_url or _raw or "dbname=kisautotrade user=kis_admin host=localhost"
```

패치 스크립트: `/tmp/patch_desk2_url_fix.sh`
실행 방법: `sudo bash /tmp/patch_desk2_url_fix.sh` (root에서)

## 비고
- 지시서의 sed 패턴 `s|os.environ.get..DATABASE_URL..|...|g` 은 default 인자 있는 경우 구문 오류를 유발하므로 직접 적용하지 않음
- desk2_monitor.py가 이미 올바른 URL strip 로직을 가지고 있음 (참고 구현)
- DATABASE_URL_SYNC도 `+psycopg2` strip 필요 (지시서 replacement에서 누락 → 수정된 패치에 포함)
