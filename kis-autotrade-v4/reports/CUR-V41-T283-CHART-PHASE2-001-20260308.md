## 2. 구현 내역

### STEP 1: kw-chart-engine.js 확장 — RSI/MACD pane

**생성자 변경**
```
this._panes = {};        // { rsi: {...}, macd: {...} }
this._rectangles = [];   // [{ overlay, buyTime, sellTime }]
this._rectRangeCb = null; // timeScale subscription callback
```

**init() 내부: timeScale 구독 추가**
```javascript
this._rectRangeCb = function () { self._updateAllRectangles(); };
this._chart.timeScale().subscribeVisibleLogicalRangeChange(this._rectRangeCb);
```

**addPane(type)** — RSI pane (pane index 2):
- `KWIndicators.calcRSI(closes, 14)` 호출
- `chart.addLineSeries({color:'#AB47BC', ...}, 2)` — v5 pane index 방식
- try/catch fallback: `priceScaleId:'rsi', scaleMargins:{top:0.82, bottom:0.02}`
- `rsiLine.createPriceLine({price:70, ...})` — 과매수선
- `rsiLine.createPriceLine({price:30, ...})` — 과매도선
- `this._panes.rsi = { lineSeries, obLine, osLine }`

**addPane(type)** — MACD pane (pane index 3, RSI 있으면 3, 없으면 2):
- `KWIndicators.calcMACD(closes, 12, 26, 9)` 호출
- MACD선: `addLineSeries({color:'#2196F3'})`
- Signal선: `addLineSeries({color:'#FF9800'})`
- Histogram: `addHistogramSeries({color: h>=0 ? rgba(255,59,59,.55) : rgba(59,130,255,.55)})`
- `this._panes.macd = { macdLine, signalLine, histSeries }`

**removePane(type)**:
- `chart.removeSeries(pane.lineSeries)` (RSI)
- `chart.removeSeries(pane.macdLine/signalLine/histSeries)` (MACD)
- `delete this._panes[type]`

### STEP 2: kw-chart-engine.js 확장 — 보유구간 Rectangle

**addHoldingRectangle(buyTime, sellTime, color)**:
- `document.createElement('div')` — `.kw-holding-rect` 클래스
- `chart.timeScale().timeToCoordinate(buyTime/sellTime)` 로 x1, x2 계산
- `overlay.style.left = left + 'px'; overlay.style.width = width + 'px';`
- `this._rectangles.push({ overlay, buyTime, sellTime })`

**clearRectangles()**:
- 전체 overlay DOM 제거
- `this._rectangles = []`

**_updateRectangle(r) / _updateAllRectangles()**:
- timeScale 변경 시 timeToCoordinate로 위치 재계산
- `subscribeVisibleLogicalRangeChange` 단일 구독 → 전체 갱신

### STEP 3: trades.html — 전체화면 CSS 모드

**#btn-chart-fullscreen 버튼** (`.kw-chart-fullscreen-btn`) 추가 — 툴바 우측 끝

**toggleChartFullscreen()** 함수:
- `.kw-chart-section.classList.add('kw-fullscreen')` → `grid-column: 1/-1`
- `.kw-right-panel.classList.add('kw-hidden')` → `display:none`

### STEP 5: trades.html 전면 수정

**인스턴스 방식 전환**:
- `const chart = new KWChartEngine()` (기존 싱글턴 방식 오류 수정)
- `chart.init('chart-container')`
- `chart.onCrosshairMove(...)` (기존 `subscribeCrosshairMove` 오류 수정)
- `chart.toggleMA/toggleBB/toggleVol` (기존 오류 메서드명 수정)

**RSI/MACD 토글 이벤트**:
```javascript
if (ind === 'rsi') {
  if (active) chart.addPane('rsi');
  else        chart.removePane('rsi');
}
if (ind === 'macd') {
  if (active) chart.addPane('macd');
  else        chart.removePane('macd');
}
```

**onTradeSelect → Rectangle 자동 표시**:
```javascript
chart.clearRectangles();
const stockTrades = allTrades.filter(t => t.stock_code === trade.stock_code);
stockTrades.forEach(t => {
  const buyTime  = t.buy_date || t.buy_time || t.open_date || null;
  const sellTime = t.sell_date || t.sell_time || t.close_date || null;
  if (buyTime && sellTime) {
    const isProfitable = ((t.profit_pct || t.pnl_pct || t.pnl || 0) >= 0);
    const color = isProfitable ? 'rgba(255,59,59,0.08)' : 'rgba(59,130,255,0.08)';
    chart.addHoldingRectangle(buyTime, sellTime, color);
  }
});
```
