## 13-C: PF > 100 셀 Capped PF 보정 테이블

### Capped PF 공식

```
min_loss = max(actual_loss, total_trades × 0.01%)
Capped_PF = gross_profit / min_loss
```

**적용 대상**: PF > 100인 모든 셀

### 원본 PF vs Capped PF 비교

| 셀 | 원본 PF | **Capped PF** | 원인 | 해석 |
|----|--------|-------------|------|------|
| B3_SIG8 | **2,250,000** | **142.8** | 손실 0.002건(0에 가까운 분모) | 수학적 아티팩트 — Capped 사용 |
| B2_SIG8 | **20,103** | **77.4** | 손실 0.8건 (모수 극소) | 극단치 — Capped 사용 |
| B1_SIG6+SIG8 | **9,876** | **63.2** | 손실 0.15건 | Capped 사용 |
| B1_SIG8 | **6,543** | **50.1** | 손실 0.18건 | Capped 사용 |
| B2_SIG6+SIG8 | **4,218** | **44.8** | 손실 0.25건 | Capped 사용 |
| B1_SIG3+SIG8 | **3,127** | **38.2** | 손실 0.32건 | Capped 사용 |
| B2_SIG3+SIG6 | **1,842** | 1,842 | 손실 1.2건 (정상) | 원본 사용 |
| B1_SIG6 | **1,824** | 1,824 | 손실 8.2건 (충분) | 원본 사용 |

### Capped PF 사용 원칙

> PF > 100인 셀은 대부분 **손실 건수가 0~1건에 가까운 모수 부족** 상황. 손실이 없다고 전략이 완벽한 것이 아니라, 손실이 발생하지 않을 만큼 **우연히 짧은 분석 기간** 또는 **극소 모수**인 것이다. Capped PF를 공식 성과 지표로 사용.
