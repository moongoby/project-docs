## 2. 구현 상세

### C3 — 시초가 강세 (c3_open_strength.py)

**파일:** `backend/app/services/desk2_conditions/c3_open_strength.py`
**클래스:** `C3OpenStrengthCondition`
**CONDITION_ID:** `"C3"`, **DESK_TARGET:** `"D-010"`

#### 조건 로직
```
1. gap_ok: today_open >= prev_close × (1 + gap_up_pct/100)
   기본값: gap_up_pct = 2.0 (%)
2. volume_ok: open_volume >= prev_avg_volume × volume_ratio_min
   기본값: volume_ratio_min = 2.0
   ※ open_volume/prev_avg_volume 미제공 시 volume_ok = True (graceful)
3. triggered = gap_ok AND volume_ok
```

#### score 계산
```
gap_score = min(actual_gap_pct / (gap_up_pct × 3), 1.0) × 0.6
vol_score  = min(actual_vol_ratio / (volume_ratio_min × 2), 1.0) × 0.4
score = gap_score + vol_score   (0~1)
```

#### backtest_signal
- 09:10 이후 최초 봉 진입
- SL: sl_pct (기본 2%), TP: tp_pct (기본 3%)

### C4 — 장중 급등 (c4_intraday_surge.py)

**파일:** `backend/app/services/desk2_conditions/c4_intraday_surge.py`
**클래스:** `C4IntradaySurgeCondition`
**CONDITION_ID:** `"C4"`, **DESK_TARGET:** `"D-010"`

#### 조건 로직
```
1. price_surge_ok: current_price >= today_open × (1 + surge_pct/100)
   기본값: surge_pct = 5.0 (%)
2. momentum_ok (OR 조건):
   - strength_ok: contract_strength >= contract_strength_min (기본 120)
   - volume_spike_ok: recent_volume / avg_volume_5m >= volume_spike_ratio (기본 3.0)
   ※ 체결강도+거래량 모두 미제공 시 momentum_ok = True (graceful)
3. triggered = price_surge_ok AND momentum_ok
```

#### score 계산
```
price_score    = min(actual_surge_pct / (surge_pct × 2), 1.0) × 0.5
momentum_score = 체결강도/거래량 강도 × 0.3
base_bonus     = 0.2 (가격 급등 기본 점수)
score = min(price_score + momentum_score + base_bonus, 1.0)
```

#### backtest_signal
- high >= today_open × 1.05 첫 봉에서 진입
- SL: sl_pct (기본 2%), TP: tp_pct (기본 4%)

### C5 — 테마 동시 급등 (c5_theme_simultaneous.py)

**파일:** `backend/app/services/desk2_conditions/c5_theme_simultaneous.py`
**클래스:** `C5ThemeSimultaneousCondition`
**CONDITION_ID:** `"C5"`, **DESK_TARGET:** `"D-010"`

#### 조건 로직
```
입력: theme_stocks = [{symbol, theme_name, current_price, prev_close}, ...]
1. 각 종목별 change_pct = (current_price/prev_close - 1) × 100
2. triggered_symbols = [s for s in theme_stocks if change_pct >= surge_pct]
   기본값: surge_pct = 3.0 (%)
3. triggered = len(triggered_symbols) >= min_symbols
   기본값: min_symbols = 3
```

#### score 계산
```
count_score = min(len(triggered) / (min_symbols × 2), 1.0) × 0.5
surge_score = min(avg_surge_pct / (surge_pct × 3), 1.0) × 0.5
score = count_score + surge_score
```

#### 부가 기능
- `evaluate_from_db(conn, date)`: v4_theme_mapping JOIN v4_ohlcv_daily에서 직접 조회
- 출력: `theme_name`, `triggered_symbols` 포함

#### backtest_signal
- 09:30 이후 최초 봉 진입 (테마 급등 감지 시점 근사)
- SL: sl_pct (기본 2%), TP: tp_pct (기본 4%)

## 3. 통합 작업

### desk2_multi_condition_matcher.py (신규)

**파일:** `backend/app/services/desk2_conditions/desk2_multi_condition_matcher.py`
**클래스:** `MultiConditionMatcher`

#### 컨디션 비트 맵핑 (CONDITION_BITS)
```python
C1  = 0b0000001   (1)
C2  = 0b0000010   (2)
C3  = 0b0000100   (4)   ← T-156 신규
C4  = 0b0001000   (8)   ← T-156 신규
C5  = 0b0010000  (16)   ← T-156 신규
C6  = 0b0100000  (32)
CS1 = 0b1000000  (64)
```

#### 주요 메서드
- `evaluate_multi(symbol, date, ...)`: 멀티컨디션 통합 평가 → combined_score, bitmask, recommendation
- `evaluate_batch(symbols, date, kwargs_map)`: 복수 종목 배치 평가
- `build_condition_bitmask(triggered)`: 비트마스크 생성
- `decode_condition_bitmask(mask)`: 비트마스크 → 컨디션 ID 목록

#### 추천 등급
| 조건 | recommendation |
|------|---------------|
| triggered ≥ 3 AND score ≥ 0.7 | STRONG_BUY |
| triggered ≥ 2 AND score ≥ 0.5 | BUY |
| triggered ≥ 1 AND score ≥ 0.3 | HOLD |
| 그 외 | SKIP |
