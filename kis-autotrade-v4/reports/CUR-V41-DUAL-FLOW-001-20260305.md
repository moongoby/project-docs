## 구현 내용

### A. feature_engine.py — DualFlowEngine 추가
파일: `/root/kis-autotrade-v4/backend/app/services/feature_engine.py`

- `_load_dual_flow_params()`: param_search_space.yaml dual_flow 섹션 로드
- `DualFlowEngine` 클래스:
  - `__init__()`: short_window=5, long_window=20, consecutive_buy_cap=5, score_weights 초기화
  - `_fetch_investor_rows(symbol, date, days)`: v4_investor_daily에서 수급 데이터 조회
  - `calculate_dual_flow(symbol, date)`: 4개 피처 계산 및 반환

#### 반환 피처
```python
{
  "DUAL_FLOW_5D"            : float,  # 최근 5거래일 중 동시 순매수 일수 / 5
  "DUAL_FLOW_20D"           : float,  # 최근 20거래일 중 동시 순매수 일수 / 20
  "CONSECUTIVE_FOREIGN_BUY" : int,    # 외국인 연속 순매수 일수
  "DUAL_FLOW_SCORE"         : float,  # 종합 점수 0~1
}
```

#### SCORE 계산식
```
DUAL_FLOW_SCORE = DUAL_FLOW_20D * 0.5 + min(CONSECUTIVE_FOREIGN_BUY / 5, 1.0) * 0.5
```

### B. param_search_space.yaml — dual_flow 섹션 추가
파일: `/root/kis-autotrade-v4/config/param_search_space.yaml`

```yaml
dual_flow:
  short_window: 5
  long_window: 20
  consecutive_buy_cap: 5
  score_weights: { flow_20d: 0.5, consecutive: 0.5 }
```

### C. funnel_score_engine.py — score_l2() DUAL_FLOW 연동
파일: `/root/kis-autotrade-v4/backend/app/services/funnel_score_engine.py`

- 기존 수동 dual_flow 계산(foreign_net_qty + institution_net_qty 카운트) → DualFlowEngine.calculate_dual_flow() 호출로 대체
- 새 가중치 구조: `DUAL_FLOW_SCORE × 0.7 + CLOSE_POSITION_5D 보너스 × 0.3`
- fallback: DualFlowEngine 실패 또는 데이터 없음 → 기본값 0.3 반환
