# 초보 사용자 가입 후 여정 분석·백억이 안내 기획 및 반영 보고서

**작성일:** 2026-02-24  
**관련:** CUR-GO100-HELP-FLOW, 사용자 온보딩

---

## 1. 배경

- 사용자가 "**널 이용하려면 뭐부터 해야해**?"라고 물었을 때, 백억이가 **투자 성향 질문**(단타/스윙, 위험 감수, 산업 테마 등)으로 답하는 흐름은 **전략 설계**용입니다.
- 반면 **처음 가입한 초보 사용자**가 원하는 것은 "**시스템을 쓰려면 화면에서 뭘 먼저 해야 하는지**"에 대한 **온보딩·여정 안내**입니다.
- 따라서 초보 사용자 여정을 분석하고, 해당 내용을 **백억이가 안내할 수 있도록** 지식·라우터를 반영했습니다.

---

## 2. 초보 사용자 여정 분석

### 2.1 여정 단계 (권장 순서)

| 단계 | 내용 | 메뉴/경로 | 비고 |
|------|------|------------|------|
| 1 | 가입·로그인 | /auth/signup, /auth/login | 로그인 후 대시보드(/dashboard) 진입 |
| 2 | 계좌 연결 | 메인 사이드바 **계좌관리** (/accounts) | 실거래를 위해 필요. 전략 만들기·백테스트·모의거래는 계좌 없이 가능 |
| 3 | 백억이와 첫 대화(전략 체험) | 우측 하단 FAB 또는 **백억이** (/llm) | 원하는 스타일을 말하면 전략 설계 → 저장 가능 |
| 4 | 백테스트로 검증 | 메인 사이드바 **백테스트** (/backtest) | 전략 선택 후 기간 설정·실행 |
| 5 | 모의거래 연습 | GO100 **모의거래** (/go100/paper-trading) | 실제 주문 없이 전략 연습 |
| 6 | 실거래 | GO100 **실거래** (/go100/live-trading) | 실계좌 연동·면책 동의 후 실매매 |

### 2.2 구분 정리

- **"뭐부터 해야해?"** → **온보딩(여정)** 답변: 계좌 연결 → 백억이에서 전략 만들기 → 백테스트 → 모의거래 → 실거래.
- **"이렇게 투자하고 싶어"** → **전략 설계** 답변: 기존 UNDERSTAND/DESIGN 파이프라인(투자 성향 질문·전략 설계).

위 두 가지가 채팅에서 구분되어, **온보딩 질문**은 help 분기로 **지식 기반 단계 안내**, **전략 요청**은 기존 전략 파이프라인으로 처리되도록 했습니다.

## 3. 기획·반영 내용

### 3.1 지식 추가

| 구분 | 내용 |
|------|------|
| **onboarding.md** (신규) | **초보 사용자 가입 후 여정** 문서. 1~6단계(가입·계좌→백억이→백테스트→모의→실거래), 각 단계별 **무엇을 어디서 하는지** 기술. "한 줄 요약" 문단으로 백억이가 그대로 참고할 수 있는 안내 문장 포함. "널 이용하려면 뭐부터 해야해?", "처음 가입했는데 뭐부터 해요?", "시작하는 방법" FAQ 형식 수록. |
| **faq.md** | **처음 가입·시작하기** 섹션 추가. Q. 널 이용하려면 뭐부터 해야해? / 처음 가입했는데 뭐부터 해요? / 시작하는 방법 알려줘 — 각각 단계별 안내 답변. |
| **help_knowledge.py** | 지식 로드 대상에 **onboarding.md** 추가. screens.md, faq.md, onboarding.md 세 파일을 모두 LLM context에 넣음. |

### 3.2 라우터 키워드 추가 (intent_router.py)

- **HELP_KEYWORDS**에 추가: `뭐부터`, `뭐 부터`, `처음 가입`, `처음에`, `시작하는`, `이용하려면`, `할 일`, `순서`, `초보`
- **HELP_PATTERN**에 추가: `뭐\s*부터`, `처음`, `시작`, `이용하려면`

→ "널 이용하려면 뭐부터 해야해?", "처음 가입했어요", "시작하는 방법 알려줘" 등이 **help**로 분기되어, onboarding·faq 지식을 참고한 **단계별 여정 안내**가 나가도록 함.

### 3.3 적용

- 지식은 **user-guide** 디렉터리 mtime 기준으로 캐시가 갱신되므로, 문서 수정 후 다음 요청부터 반영됩니다.
- 채팅 **위젯**에서만 `source=widget`으로 help 분기가 동작합니다.

---

## 4. 기대 동작

- 사용자: "**널 이용하려면 뭐부터 해야해?**"
- 라우터: `이용하려면` + `뭐부터` 등으로 **help** 분기.
- HelpFlow: onboarding.md + faq.md의 "처음 가입·시작하기" 내용을 context로 LLM에 전달.
- 백억이: "로그인하신 뒤 (1) 계좌관리에서 계좌 연결 (2) 백억이에서 전략 만들어 보시고 (3) 백테스트로 검증 (4) 모의거래 연습 (5) 실거래 진행하시면 됩니다. 전략 만들기·백테스트·모의거래는 계좌 없이도 가능해요."와 같은 **단계별 온보딩 안내**를 자연어로 생성.

---

## 5. 요약

- **초보 사용자 여정**: 가입·로그인 → 계좌 연결 → 백억이 전략 체험 → 백테스트 → 모의거래 → 실거래 순서로 정리했고, 이 내용을 **onboarding.md** 및 **faq.md**에 반영했습니다.
- **백억이 안내**: "뭐부터 해야해?", "처음 가입했어요", "시작하는 방법" 등은 **help** 분기로 처리되어, 위 지식을 바탕으로 **단계별 여정 안내**가 가능하도록 기획·반영했습니다.
- **전략 설계** 흐름(투자 성향 질문·전략 설계)은 기존대로 유지되며, **온보딩 질문**과 **전략 요청**이 문장에 따라 구분되어 처리됩니다.
