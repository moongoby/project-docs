## Executive Summary

업종/테마 분류 데이터의 수집 현황을 점검하고, 미비 사항을 조치했다.

## 2. 발견된 문제 및 조치

### 2.1 v4_theme_stock 중복 (조치 완료)

**문제**: 수집 스크립트 3회 실행으로 동일 매핑이 3중 복제
- 2,106건 중 고유 매핑 905건 → 1,201건 중복

**조치**:
```sql
-- 백업 후 중복 제거 (MAX(id) 보존)
CREATE TABLE v4_theme_stock_backup_20260228 AS SELECT * FROM v4_theme_stock;
DELETE FROM v4_theme_stock WHERE id NOT IN (
    SELECT MAX(id) FROM v4_theme_stock
    GROUP BY theme_code, stock_code, mapped_date
);
```
**결과**: 2,106 → 905건 (1,201건 삭제)

### 2.2 v4_theme_daily 공백 (조치 완료)

**문제**: 테마별 일별 성과 테이블이 비어 있음 (0건)

**조치**: v4_theme_stock × ohlcv_daily 조인으로 테마별 일별 통계 산출
- 테마별 평균 등락률, 거래량, 거래대금, 대장주, 상승 종목 수, 연속 상승일 계산
- 기간: 2025-03-01 ~ 2026-02-27

**결과**: 34,122건 생성 (141테마 × ~242거래일)

### 2.3 is_leader 미설정 (조치 완료)

**문제**: v4_theme_stock의 is_leader 컬럼이 전부 false

**조치**: v4_theme_daily에서 테마별 가장 빈번하게 대장주로 선정된 종목에 is_leader=true 설정

**결과**: 141개 테마 × 1개 대장주 = 141건 설정

### 2.4 v4_theme_activity_daily 공백 (조치 완료)

**문제**: 테마 활동성 점수 테이블이 비어 있음 (0건)

**조치**: v4_theme_daily 기반 활동성 점수 산출
- **점수 산식**: `activity_score = vol_ratio × 0.4 + return × 0.3 + up_ratio × 0.3`
  - vol_ratio: 20일 평균 거래량 대비 당일 비율
  - return: 당일 평균 등락률 (0~100 스케일링)
  - up_ratio: 구성 종목 중 상승 비율
- **등급**: HOT(≥70) / WARM(≥40) / COLD(<40)

**결과**: 34,122건 생성

| 등급 | 비율 | 의미 |
|------|------|------|
| HOT | 6% | 강한 테마 모멘텀 — D5 전략 대상 |
| WARM | 33% | 관심 구간 |
| COLD | 60% | 비활성 |

## 4. 테마 자동 반영/제거 메커니즘

### 4.1 현재 자동 수집 체계

| 항목 | 내용 |
|------|------|
| Cron | `0 17 * * 1-5` (평일 17:00 KST) |
| 스크립트 | `scripts/cron/collect_theme.sh` → `scripts/collect_kiwoom_theme.py` |
| API | 키움 ka90001(테마그룹) + ka90002(테마구성종목) |
| 저장 방식 | **일별 스냅샷** — UNIQUE(theme_code, stock_code, mapped_date) |
| 계정 | account_id=5 (실거래) |

### 4.2 신규 종목 테마 편입 — 자동 반영 중

키움 API가 매일 최신 테마 구성을 반환하므로, **종목이 새 테마에 편입되면 당일 17:00 수집 시 자동 반영**된다.

실제 변동 확인 (2/26 → 2/27):

| 변동 유형 | 건수 | 샘플 |
|-----------|------|------|
| **신규 편입** | 613건 | HMM→해운, 와이솔→RF부품, 휴비츠→의료기기 등 |
| **제거됨** | 227건 | 롯데케미칼→합성섬유, LG이노텍→휴대폰카메라 등 |

### 4.3 테마 제거 추적 — 현재 한계

| 기능 | 현재 상태 | 비고 |
|------|----------|------|
| 제거 감지 | **간접 가능** | 전일 스냅샷 vs 당일 비교로 식별 가능 |
| 제거 알림/로그 | **없음** | 별도 알림 체계 미구축 |
| is_active 플래그 | **없음** (v4_theme_stock) | 현재/과거 구분 불가 |
| 이력 보존 | **보존됨** | 과거 mapped_date 레코드 유지 |

### 4.4 수집 커버리지 이슈

| 날짜 | 수집 테마 | 수집 종목 | 커버리지 |
|------|----------|----------|----------|
| 2/25 | 10개 | 62개 | 7% |
| 2/26 | 31개 | 198개 | 22% |
| 2/27 | 100개 | 480개 | **71%** |

- 141개 테마 중 최대 100개만 수집 — **41개 누락**
- 원인 추정: API rate limit, 네트워크 오류, 또는 키움 API 응답 제한
- **조치 필요**: 수집 로그 점검, 재시도 로직 강화
