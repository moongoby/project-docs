## 6. 개선 방향

### P0: STOP 임계값 완화 (즉시 효과 예상)
```yaml
# 현재 stop_pct: -2.0  →  -5.0 또는 없애기
exit:
  trend:
    stop_pct: -5.0    # -2% → -5% (STOP 과다 발동 방지)
  reversal:
    stop_pct: -5.0
```

### P1: 신호 선별 강화
- S1/TS-B1 비중 과다 → 최소 스코어 임계값 상향
- T5 단독 유지 + TS-B4(PF 3.23 검증) 보강

### P2: 시장 레짐 필터
- 코스닥 -2% 이하 시 신규 진입 중단 (config 설정됨, 데이터 연동 필요)
- 12월~1월 하락장에서 -983K 손실 → 레짐 필터가 핵심

### P3: 후보 종목 품질 개선
- 현재 백테스트: 거래량 상위 20개 (뉴스 필터 없음)
