## 1. 아키텍처

### 6-Layer 구조

```
Layer 1: 컨디션 발굴 (C1~C7)
  각 컨디션이 독립적으로 종목 탐지
  C1 상한가예상, C2 전일상한가, C3 시초가강세(D1폐기로 약화),
  C4 장중1파급등, C5 테마동시급등, C6 종가강세, C7 NEW장중탐지

Layer 2: 전략 매칭 (1:N)
  컨디션별 매칭 가능 전략 전부 후보
  D6, D5, D4, D7, D2, S1 — D1/D3/S2 폐기

Layer 3: 기술적 시그널 매칭 (컨디션별 최적)
  18개 시그널 중 컨디션별 상위 시그널 자동 선택
  범용 Top5: TS-B4(거래량폭발양봉), TS-D1(미니갭), TS-C1(5봉거래집중),
             TS-B1(RSI30~50), TS-C3(20봉신고가)
  C2 부스트: TS-B4(PF3.4), TS-D3(PF3.3)

Layer 4: 운영 마스크 (5축 ON/OFF)
  시간대(T1~T6), 시장상태(BULL/FLAT/BEAR), 변동성(LOW/MID/HIGH),
  거래대금순위(TOP/MID/LOW), 보유시간
  D4: FLAT만 ON, 보유20분+
  D7: BEAR OFF
  D6: 전체 ON

Layer 5: 실행 + 수익 기록
  거래별: 종목, 컨디션, 전략, 시그널, 진입/청산, PnL
  일일: DCS (컨디션별 일일합산)
  매트릭스: 컨디션×전략×시그널 셀별 성과

Layer 6: 리밸런싱 (20거래일 주기)
  DCS 기반 컨디션 등급 A/B/C 재산정
  5축 마스크 갱신
  시그널×컨디션 매트릭스 재최적화
```
