## 10. AI Self-Evolution Engine

### 4단계 파이프라인

```
Stage 1: Discovery (주간, 일요일)
  → 수익/손실 거래 패턴 분석
  → 시그널 파라미터 ±20% 변형
  → 5축 마스크 재최적화
  → 신규 기술적 지표 도입 (ATR, CCI, Williams %R, VWAP 등)

Stage 2: Validation (자동)
  → 60거래일 학습 + 20거래일 OOS 검증
  → PASS: OOS PF ≥ 1.3 AND 거래수 ≥ 20
  → FAIL: PF < 1.3 OR 거래수 < 20 → 폐기 + 로그

Stage 3: Paper Trading (20거래일)
  → KIS 모의투자 계좌 실시간 운영
  → PROMOTE: DCS ≥ +1.0% AND 양일 ≥ 50%
  → EXTEND: DCS ≥ +0.5% → 20거래일 연장
  → DEMOTE: DCS < +0.5% OR 양일 < 40% → 폐기

Stage 4: Live Trading (등급 관리)
  → 소규모(자본 5%) 투입
  → A등급: 자본 확대 (5%→10%→20%→40%)
  → B등급: 유지
  → C등급: 축소 또는 Stage 3 강등
```

### Drift Detector (일일 장마감 후)
- **Mask Drift**: 5축 셀별 PF 20거래일 이동평균 → PF < 1.3 셀 자동 OFF
- **Signal Drift**: 시그널별 승률 20거래일 이동평균 → 승률 < 30% 시 2순위 교체
- **Condition Drift**: 컨디션별 거래 빈도 → 5거래일 연속 0건 시 Discovery 트리거

### 자동 보고
- 일일: DCS + 거래 내역 + 드리프트 경고
- 주간: Stage별 현황 + 신규 후보 + 폐기 목록
- 월간: 전체 누적 성과 + 전략별 기여도 + 등급 변동 이력
- 모든 보고서 git push + CEO 알림
