### 서버/DB 접속 방법
- 프로젝트 루트: /root/kis-autotrade-v4
- 가상환경: source venv/bin/activate
- .env 로드: set -a && source .env && set +a
- DB 접속: export PGPASSWORD="$DB_PASSWORD" && psql -h ${DB_HOST:-localhost} -U ${DB_USER:-kis_admin} -d ${DB_NAME:-kisautotrade}
- DB 백업(작업 전 필수): pg_dump -h localhost -U kis_admin -d kisautotrade -F c -f /tmp/backup_{TASK}_{date}.dump

### 보고서 작성/Push 절차 (매 작업 후 필수)
1. /root/kis-autotrade-v4/report/v41/{작업ID}-{YYYYMMDD}.md 작성
2. cp → /root/project-docs/kis-autotrade-v4/reports/{작업ID}-{YYYYMMDD}.md
3. cd /root/project-docs && git add -A && git commit -m "docs: {작업ID} 보고서 push ({YYYYMMDD})" && git push origin master
4. curl로 raw URL HTTP 200 확인
