# 한국 주식시장 운영시간 (KRX / NXT)
> 최종 업데이트: 2026-02-23
> V4.1 시스템 참조용 — 매매 스케줄러, 분봉 수집, 주문 시간 검증에 활용

---

## 1. 현행 운영시간 (2026-02-23 기준)

### KRX (한국거래소 — KOSPI / KOSDAQ)

| 구분 | 시간 (KST) | 비고 |
|------|-----------|------|
| 장전 시간외 종가 | 08:30 ~ 08:40 | 전일 종가 기준 |
| 장 시작 동시호가 | 08:30 ~ 09:00 | 호가접수만, 09:00 체결 |
| **정규장** | **09:00 ~ 15:30** | 실시간 연속매매 |
| 장 마감 동시호가 | 15:20 ~ 15:30 | 종가 결정 |
| 장후 시간외 종가 | 15:40 ~ 16:00 | 당일 종가 기준 |
| 시간외 단일가 | 16:00 ~ 18:00 | 10분 단위, 종가 ±10% |

### NXT (넥스트레이드 — 대체거래소, 2025-03-04 출범)

| 구분 | 시간 (KST) | 비고 |
|------|-----------|------|
| **프리마켓** | **08:00 ~ 08:50** | 지정가/중간가만 |
| 메인마켓 | 09:00:30 ~ 15:20 | KRX보다 30초 늦게 시작 |
| 종가매매 | 15:30 ~ 16:00 | 호가접수 15:00부터 |
| **애프터마켓** | **15:40 ~ 20:00** | 시간단일가 15:30~15:40 |
| 예약주문 | 16:00 ~ 익일 07:40 | 공휴일/토일 포함 |

### NXT 주의사항
- NXT 애프터마켓 거래 종목은 KRX 시간외단일가(16~18시)에서 제외
- NXT 시장가 주문: 정규장 메인마켓에서만 (IOC/FOK 조건 필수)
- NXT 전용 호가: 중간가호가, 스톱지정가호가

| 2 | NXT |
