## 1. 사고방식 원칙

### D-001 단순 사고 금지
- "하나를 던지면 10을 생각하고 연구해서 반영하라"
- 단일 변수, 단일 시점, 단일 관점 분석은 불충분
- 복합계, 다층 구조, 다시점 분석이 기본

### D-002 본질은 수급이다
- 모든 가격 움직임의 본질은 수급(매수·매도 세력의 흐름)
- 스마트머니(외국인·기관)는 며칠에 걸쳐 소규모로 매집
- 개인 투자자도 무시 금지 – 텔레그램, 유튜브, 커뮤니티로 정보 전파 빠름
- 수급 분석은 D-1 스냅샷이 아니라 D-20 → D-1 궤적으로 봐야 함

### D-003 DESK의 본질
- DESK는 "오늘 오를 종목 10개를 맞히는 것"이 아니다
- DESK는 "오를 만한 종목을 풀로 관리하고, 전략 카드가 타이밍을 기다리는 것"
- DESK가 타이밍을 정확하게 알 필요 없음
- 풀에 넣어두고 전략이 트리거를 감지하면 진입
- 핵심 전환: 정밀도(precision) → 리콜(recall) + 풀 체류 관리

### D-004 일봉 상승 전조 패턴
- 급등 종목 전형 패턴: 강한 수급 유입 → 약간의 눌림(거래대금↓) → 횡보/하락 → 지지 → 반등
- 눌림매매, 3·5일선 터치, 박스 돌파, 신고가 돌파는 모두 같은 원리의 변형
- 2~4일 추적 대기도 유효한 발굴
- "강하게 오른 놈이 또 오른다" = L3+X9가 작동하는 이유

### D-005 신고가 돌파 매매
- 최고가 초과 시 매물대 소멸 → 매도 심리 감소 → 적은 매수세로 급등
- 모든 보유자 수익 상태 → 매도 압력↓, 추가 매수 유도
- 공매도 숏커버링 + FOMO 추격 매수
- 거래량 없는 가짜 돌파 주의 → 거래량 급증 필수 확인

### D-006 NEW 종목도 과거가 있다
- TOP-20 첫 등장 종목도 D-180 ~ D-30에 이미 시그널 존재
- 저점 횡보 → 수급 유입 → 이평선 수렴 → 정배열 → 급등의 생애주기
- DESK5→4→3 파이프라인 작동 시 사전 포착 가능
- 3년치 일봉(ohlcv_daily 261만 rows)으로 역추적 필수

### D-007 컨텍스트 패키지 시스템
- 모든 AI 세션에 HANDOVER.md + DESIGN-SPEC + CEO-DIRECTIVES.md 필수 읽기
- 이전 맥락 없이 작업하면 같은 실수 반복
- 매 작업 완료 시 HANDOVER.md 업데이트 의무

## 2. 기술적 지시

### T-001 DESK 풀 관리 조건
- DESK3 (2-10일, 50-100종목): 정배열, 매물대 소화(신고가 임박/박스 상단/눌림목/이평선 터치/갭 지지), 수급 에너지(거래량 3일 연속 증가, 장마감 집중, 3주체), 시장 관심(뉴스, 섹터, L3)
- DESK4 (5-40일, 20-30종목): 성장 초기(MA20 전환, MA60 접근), 박스권 축소, 계단식, 중기 수급(10일 연속), 테마/뉴스
- DESK5 (20-120일, 10-20종목): 바닥 탈출, 슬로우 매집(60일 MA 월 5-15%↑), 구조적 재료
- 각 DESK 승격/퇴출 조건은 DESIGN-SPEC 참조

### T-002 전략 카드 진입 트리거
- 신고가 돌파: 52주 고가 거래량 2배 동반 돌파
- 박스 돌파: 20일 박스 상단 거래량 동반
- 눌림목 반등: 조정 중 거래량 2배↑ + 양봉
- Birth Point: 장초반 하락 후 양봉 전환 + 체결강도 반전
- 갭 돌파: +2% 이상 갭 후 5분 양봉 유지

### T-003 3주체 수급 프레임워크
- 유형1: 기관/외국인 선행 → 개인 추종 (DESK4-5 감지)
- 유형2: 개인 주도 급등 (커뮤니티/테마, DESK3 감지)
- 유형3: 매도→매수 전환 (바닥 시그널, DESK5 감지)

### T-004 로드맵
1. Phase 1+ (현재): DESK2 발굴 확정 (Phase 2E NEW 역추적)
2. Phase 2: 진입 전략 최적화
3. Phase 3: 청산 최적화
4. Phase 4: DESK3-5 발굴 확장
5. Phase 5: DESK3-5 전략/청산 최적화
6. Phase 6: 통합 시스템 테스트
