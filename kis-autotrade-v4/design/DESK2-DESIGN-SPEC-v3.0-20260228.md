## 1. 비전 및 목적

**V4.1 전체 비전**: DESK1~5는 주식의 생애주기(웨이브)를 포착하는 연결된 시스템이다. 종목은 장기 추세 형성(DESK5) → 중기 스윙(DESK4) → 단기 스윙(DESK3) → 1~3일 폭발(DESK2) → 스캘핑 수확(DESK1)의 흐름을 따르며, 역방향으로도 DESK2에서 발굴된 종목이 DESK3~5로 승격되어 지속 모니터링된다.

**DESK2 미션**: 당일 수익률이 가장 높을 종목을 사전에 발굴하고, Birth Point 감지 후 최적 타이밍에 진입하여 최대 수익을 확보한 뒤, 규칙 기반으로 청산한다.

**DESK2 운용 기간**: 1~3 거래일 (당일 진입, 당일 또는 익일 청산)

**핵심 원칙**:
- 종목 발굴은 **반복 등장 패턴(L3) + 섹터 동조성(X9)**으로 결정된다.
- 진입 타이밍은 고정 시간이 아닌 **Birth Point 감지 후 양봉 전환 확인**에 기반한다.
- 추세형과 반전형은 별도 전략으로 운용하되, Birth+1min 진입은 모든 유형에 공통 적용한다.
- 모든 조건과 파라미터는 데이터에 의해 검증되어야 한다.

## 2. v2.0 대비 변경 사항 및 근거

### 2-1. v2.0에서 폐기/변경된 구조

v2.0은 4변수 가중합(F1~F4) + 2단계 필터(C6+C7) + T5/S1 진입 신호 구조였다. 30일 확장 연구(Phase 1~2B) 결과:

1. **4변수 스코어링 → L3 단독 랭킹**: 11변수 가중합(OOS 76%)보다 L3(30일 TOP-20 등장 횟수) 단독이 OOS 83%로 우수. 변수가 많을수록 과적합.
2. **2단계 필터(C6+C7) → X9 필터**: X9(동일 섹터 TOP-20 수 ≥ 1)로 교체 시 정밀도 83% → 90% 달성.
3. **T5/S1 진입 → Birth+1min 진입**: 09:05 고정이든 T5든 S1이든, Birth Point 이전에 진입하면 실패. Birth+1min으로 전 유형 WR 95%.
4. **외국인/기관 데이터 무효**: v4_investor_daily 존재 확인했으나 AUC 0.50으로 판별력 0.

### 2-2. 변경 근거 (데이터)

| 항목 | v2.0 (14일, 280건) | v3.0 (30일, 1,192건) |
|------|-------------------|---------------------|
| 발굴 정밀도 | 56.4% (F1~F4+C6+C7) | **90.0%** (L3+X9) |
| 진입 WR | ~74% (T5/S1) | **95.3%** (Birth+1min) |
| avg PnL | +0.44% (09:05 고정) | **+2.27%** (Birth+1min) |
| REVERSAL WR | 51.2% (09:05 고정) | **100%** (Birth+1min) |
| 검증 기간 | 14일 | **30일** (OOS 15일) |

### 2-3. v3.0 핵심 변경

첫째, 발굴 방식을 4변수 가중합에서 **L3 단독 랭킹 + X9 필터**로 단순화했다. 둘째, 진입 기준을 T5/S1 신호에서 **Birth Point 감지 → 양봉 전환 확인 → +1분 진입**으로 통합했다. 셋째, REVERSAL 전용 규칙을 추가하여 **TP를 +3%에서 +5%로 확대** 가능하게 했다(MFE 26.6%). 넷째, 데이터 근거 기간을 14일에서 30일로 확대하여 시장 레짐 전환(하락→횡보→반등) 포함 검증을 완료했다.

### 3-2. 구성 요소 상세

**3-2-1. 사전 발굴 엔진 (desk2_prescoring.py)**

실행 시점은 매 거래일 15:40(장 마감 후). 전체 상장 종목을 대상으로:

1. **L3 계산**: 최근 30거래일간 해당 종목이 TOP-20에 등장한 횟수. 데이터 소스는 v4_bt_discovery_log 또는 자체 TOP-20 기록 테이블.
2. **L3 랭킹**: 전 종목을 L3 내림차순 정렬, 상위 50종목 추출.
3. **X9 필터**: 당일 동일 섹터에서 TOP-20에 진입한 종목이 1개 이상인 종목만 통과. 데이터 소스는 stock_universe(sector) + 당일 TOP-20 기록.
4. **최종 10종목**: X9 필터 통과 종목 중 L3 상위 10종목 확정.

AUC 근거: L3 단독 AUC 0.644(Phase 2B in-sample), X9 AUC 0.851. 조합 시 OOS 정밀도 90%.

**3-2-2. Birth Point Detection 엔진 (desk2_birth_detector.py)**

실행 시점은 매 거래일 09:00~09:30, 1분 간격. 대상은 v4_desk2_candidates 10종목.

Birth 감지 규칙:
1. 09:00~09:10 관찰기간 — 각 종목의 1분봉 추이 기록
2. 양봉 전환 감지: close > open인 1분봉 발생
3. TREND 종목(dip < 1%): 첫 양봉이 곧 Birth → 즉시 진입 가능
4. REVERSAL/BORDER(dip ≥ 1%): 하락 후 첫 양봉 = Birth 근접 → +1분 진입
5. 최대 대기: 09:30 (birth 90th percentile). 미감지 시 SKIP

실전 Birth 감지 정확도 추정: 80% (이론적 최적 95.3% 대비 보수적)

**3-2-3. 자동 매매 엔진 (desk2_auto_trader.py)**

v2.0과 동일한 KIS API 연동. 진입은 Birth 감지 +1분 시장가. 청산은 유형별 규칙.

## 4. 발굴 모델 상세

### 4-1. L3(30일 TOP-20 등장 횟수)가 최강인 이유

Phase 2B Forward Selection에서 18개 후보 중 L3가 LOO-day CV 8.47/10으로 1위. 추가 변수를 아무리 넣어도 개선 없음.

**해석**: TOP-20에 반복 등장하는 종목은 "현재 진행 중인 테마/재료"를 가진 종목이다. SG세계물산(14일 중 7회), 유투바이오(7회) 등. 이 반복성은 단기 수급 축적의 직접적 지표이며, 거래량 변화율(F2), 뉴스 연속성(M3) 등 간접 지표보다 강력하다.

### 4-2. X9(섹터 TOP-20 수)가 필터로 작동하는 이유

X9는 AUC 0.851로 단독 판별력이 가장 높지만, 스코어링 변수로 쓰면 L3와 겹쳐서 개선 미미. 대신 **이진 필터(≥1)로 쓰면 FP를 효과적으로 제거**한다.

**해석**: "어제 같은 섹터에서 TOP-20이 1개도 없었으면, 오늘 이 종목도 TOP-20이 되기 어렵다." 이는 섹터 로테이션/테마 지속성을 포착한다.

### 4-3. v2.0 대비 폐기된 변수

| 변수 | v2.0 역할 | v3.0 상태 | 이유 |
|------|----------|----------|------|
| F1(뉴스 존재) | 가중치 0.472 | 폐기 | L3에 흡수됨 |
| F2(5일 거래량 변화) | 가중치 0.757 | 폐기 | L3에 흡수됨 |
| F3(D-1/5일 거래량 비율) | 가중치 0.822 | 폐기 | L3에 흡수됨 |
| F4(종가위치) | 가중치 0.365 | 폐기 | L3에 흡수됨 |
| C6(뉴스 ≥ 2) | 2단계 필터 | 폐기 | X9로 대체 |
| C7(종가위치 ≥ 0.6) | 2단계 필터 | 폐기 | X9로 대체 |

**핵심 교훈**: "복잡한 모델보다 단순한 규칙이 낫다." 4변수 가중합(76%) < L3 단독(83%) < L3+X9(90%).

## 5. 진입 타이밍 상세

### 5-1. Birth+1min이 T5/S1보다 우월한 이유

| 진입 방식 | TREND WR | REVERSAL WR | 전체 WR | 전체 avg PnL |
|-----------|----------|-------------|---------|-------------|
| 09:05 고정 | 70.9% | 51.2% | 63.3% | +0.44% |
| T5(시가+2%) | 73.7% | 54.1% | 66.2% | +0.60% |
| **Birth+1min** | **91.1%** | **100%** | **95.3%** | **+2.27%** |

T5와 S1은 "관찰 가능한 신호"라는 점에서 v2.0의 진보였으나, Birth Point 자체를 감지하는 것이 근본적으로 우월하다.

### 5-2. 실전 Birth 감지의 한계

Birth(당일 저가 시점)는 사후에만 확정된다. 실전에서는 양봉 전환을 Birth 근접 신호로 사용한다. 이론적 WR 95.3%에서 감지 정확도 80%를 적용하면 실전 WR 추정 76~85%.

### 5-3. 성공/실패 분기점

| 유형 | 성공 Birth | 실패 Birth | 비율 |
|------|-----------|-----------|------|
| TREND | 17.4분 | 78.0분 | 4.5배 |
| REVERSAL | 1.2분 | 44.1분 | 37배 |
| BORDER | 11.1분 | 97.5분 | 8.8배 |

**실패 종목은 Birth가 늦다.** 09:30 데드라인을 설정하면 대부분의 실패 종목을 자동 SKIP.

## 6. 유형별 전략 상세

### 6-1. TREND (52.7%)

특징: 시가부터 상승, Birth 중앙값 3분. 진입: Birth(양봉 전환) 확인 +1분. 청산: TP +3%(보수적) 또는 트레일링 -2%. SL -3%. TIME 14:30. Birth+1min 성과: WR 91.1%, avg PnL +2.07%, TP 69건 SL 5건.

### 6-2. REVERSAL (27.3%)

특징: 시초 2%+ 하락 후 반등, Birth 중앙값 3분, MFE 26.6%(최고). 진입: 하락 후 양봉 전환 확인 +1분. 청산: **TP +5%**(MFE 26.6%이므로 확대), SL -3%, TIME 14:30. Birth+1min 성과: **WR 100%, avg PnL +2.57%, TP 40건 SL 0건.**

**REVERSAL은 "문제가 아니라 최고의 기회"**: Phase 2에서 WR 55%로 FAIL 판정했으나, 문제는 REVERSAL 자체가 아니라 09:05 고정 진입이었다.

### 6-3. BORDER (20.0%)

특징: dip 1~2%, TREND와 REVERSAL의 중간. 진입: 양봉 전환 대기, 09:15까지 미확정 시 SKIP. Birth+1min 성과: WR 100%, avg PnL +2.40%.

## 7. 리스크 관리 체계

v2.0과 동일한 골격 유지:
- 동시 보유 최대 3종목, 종목당 자본 30%
- 일일 손실 한도 -3%, 연속 2회 손절 시 1시간 중단
- KOSDAQ -2% 이상 하락 시 신규 진입 중단
- 익일 보유: 종가 > VWAP 시 익일 시가 청산

추가 규칙:
- **09:30 데드라인**: Birth 미감지 종목은 진입 포기 (실패 종목 사전 제거)
- **REVERSAL TP 확대**: +5%까지 허용 (MFE 26.6% 근거)
