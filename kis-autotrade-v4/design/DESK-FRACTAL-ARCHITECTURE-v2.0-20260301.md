## 제1장. 시스템 철학 — 패러다임 재정립

### 1-1. 최종 목표

**극대의 수익률.**

이것을 달성하는 구조는 단 하나입니다. 추세추종의 전체 파동을 모든 시간 프레임에서 동시에 먹고, 수익을 복리로 재투입하여 자본을 키우고, 커진 자본이 다시 더 많은 파동을 먹는 자기강화 순환입니다.

### 1-2. 핵심 원리 — 프랙탈 추세추종

하나의 원리가 모든 시간 프레임에서 동일하게 작동합니다.

엘리엇 파동의 1파 진입 → 눌림 확인 → 2파 추매 → 눌림 확인 → 3파 폭발 → 4파/5파/ABC 관리. 이 구조가 일봉에서 펼쳐지면 DESK5/4/3의 직접 보유이고, 1분봉에서 펼쳐지면 DESK2의 장중 수확입니다. 같은 종목을 일봉으로도 먹고 분봉으로도 먹는 이중 수확 구조입니다.

### 1-3. DESK의 이중 역할 재정의

| DESK | 일봉 역할 (직접 보유) | 분봉 역할 (DESK2 먹이감) |
|------|----------------------|------------------------|
| DESK5 | **1파 바닥 진입** — 씨앗에 돈을 넣는다 | 보유 종목을 DESK2 먹이감 풀에 공급 |
| DESK4 | **눌림 후 2파 추매** — 비중을 확대한다 | 보유 종목을 DESK2 먹이감 풀에 공급 |
| DESK3 | **3파 폭발 구간 진입** — 최대 비중으로 탄다 | 보유 종목을 DESK2 먹이감 풀에 공급 |
| DESK2 | 풀 관리자 — 위 DESK 보유 종목이 먹이감 | **장중 분봉 파동을 발라먹는다** |

**트리거 = 진입 신호.** T5-1이 발동하면 풀에 넣는 것이 아니라 돈을 넣습니다. T4-1이 발동하면 추매합니다. T3-1이 발동하면 비중을 최대로 올립니다.

### 1-4. 복리 자본 순환

```
DESK2 일일 수확 → 수익 확정
       ↓
  자본 증가 (복리 재투입)
       ↓
  자본 규모별 DESK 배분 확대
       ↓
  DESK5/4/3 더 많은 종목 보유 가능
       ↓
  DESK2 먹이감 풀 확대
       ↓
  DESK2 일일 수확량 증가
       ↓
  자본 더 빠르게 성장 → 복리 가속
```

## 제2장. 프랙탈 파동 구조

### 2-1. 일봉 파동 — DESK5/4/3 직접 보유

```
가격
 │                                         5파 ╱╲
 │                                       ╱      ╲
 │                              3파 ╱╲  ╱        ╲ A
 │                            ╱      ╲╱            ╲
 │                   1파 ╱╲  ╱     4파눌림            ╲ B
 │                 ╱      ╲╱                            ╲╱╲ C
 │            ╱╲  ╱     2파눌림                              
 │     바닥 ╱    ╲╱                                          
 │   ══════╱                                                  
 └────────────────────────────────────────────────── 시간
     │         │           │            │         │
   DESK5     DESK5       DESK4       DESK3     청산관리
   1파진입   보유유지     2파추매     3파폭발    4파5파ABC
   T5트리거               T4트리거    T3트리거
```

**각 구간별 행동:**

**1파 (DESK5 진입, D-120~D-20):** 아무도 관심 없는 바닥에서 거래량이 살아나고, 기관/외국인이 조용히 매집합니다. T5 트리거가 발동하면 소량 진입합니다. 이것은 씨앗에 돈을 넣는 행위입니다. Phase 2E에서 확인된 것처럼, 이 시점의 종목은 52주 저가 대비 +163% 상승 여력을 품고 있습니다.

**2파 눌림 (DESK4 추매, D-40~D-5):** 1파 상승 후 자연스러운 조정이 옵니다. 정배열이 형성되고 거래량이 재차 증가하면 T4 트리거가 발동합니다. 이때 추매하여 비중을 확대합니다. 이 눌림에서 포기하는 약한 손을 먹고 들어가는 것입니다.

**3파 폭발 (DESK3 최대 비중, D-10~D-1):** L3 반복 등장, 섹터 동조, 뉴스 연속 등 모든 신호가 점화됩니다. T3 트리거가 발동하면 최대 비중으로 진입합니다. Phase 2B에서 L3+X9 정밀도 90%, X9 AUC 0.851이 확인된 구간입니다.

**4파~5파~ABC (청산 관리):** 3파 폭발 후 추세가 둔화되면 부분 청산→트레일링→전량 청산으로 단계적 이탈합니다. 역방향 강등 로직이 작동합니다.

### 2-2. 분봉 파동 — DESK2 장중 수확

DESK5/4/3이 보유 중인 종목은 이미 추세가 살아있는 종목입니다. 이 종목들이 DESK2의 먹이감 풀이 됩니다. DESK2는 매일 장중에 이 종목들의 분봉 파동을 발라먹습니다.

```
분봉 (DESK2 장중)
 │
 │         Birth     눌림후    추가급등
 │          1파  ╱╲  재진입  ╱╲
 │         ╱╲  ╱    ╲╱    ╲╱    ╲
 │    ════╱  ╲╱                    ╲══
 │
 └──────────────────────────────────── 시간
           │        │         │
         D2진입   D2재진입   D2청산
         Birth    눌림확인    60분/트레일링
```

**DESK2가 풀 관리자인 이유:** DESK2 입장에서 DESK5/4/3 보유 종목은 "이미 일봉 추세가 검증된 먹이감"입니다. 이 먹이감 풀에서 매일 장중 Birth Point를 감지하고, 분봉 파동을 타고, 60분 이내에 수확합니다. 풀을 관리하면서 매일 발라먹는 것이 DESK2의 본질입니다.

### 2-3. 이중 수확의 수익 구조

하나의 종목에서 두 가지 수익이 동시에 발생합니다.

**일봉 수익 (DESK5/4/3 보유):** 바닥에서 폭발까지 +50~200%를 수주~수개월에 걸쳐 먹습니다. 자본의 "뿌리"입니다.

**분봉 수익 (DESK2 장중):** 같은 종목의 장중 변동성에서 매일 +2~4%를 반복 수확합니다. 자본의 "열매"입니다.

```
종목 A: DESK5에서 D-100에 진입, 현재 일봉 수익 +80%
        └─ 오늘 DESK2가 장중 Birth → +3.2% 수확
        └─ 내일 DESK2가 장중 눌림 재진입 → +2.1% 수확
        └─ 일봉 보유는 계속 유지 (3파 진행 중)

DESK5/4/3 일봉 수익: 종목 보유 → 파동 전체를 탄다 (주수익)
DESK2 분봉 수익: 같은 종목을 매일 발라먹는다 (복리 엔진)
```

## 제3장. DESK별 상세 설계

### 3-1. DESK5 — 1파 바닥 진입

| 항목 | 설계 |
|------|------|
| 역할 | 일봉 엘리엇 1파의 바닥에서 최초 진입 |
| 보유 기간 | 20~120일 (파동 전체를 탄다) |
| 트리거 = 매수 신호 | T5-1, T5-2, T5-3 중 2개 충족 시 매수 |
| 풀 크기 | 10~20종목 보유 |
| 갱신 | 주 1회 (일요일 HAV 크론 동기화) |
| 퇴출/청산 | 90일 무변화, 악재 공시, 장기 추세 완전 붕괴 |

**T5-1 거래량 장기 상승 전환 (매수 신호):**
60일 거래량 MA가 120일 MA를 상향 돌파하는 시점. 직전 20일 내 최초 돌파. SUPER-ANT-STUDY-001의 Wyckoff 매집 패턴 초기를 포착합니다.

**T5-2 수급 장기 전환 (매수 신호):**
기관 또는 외국인이 20거래일 중 15일 이상 순매수. SURGE-CAUSE S04에서 수급주도 허위파율 29.7%(전체 최저). DUAL_FLOW의 장기 버전입니다.

**T5-3 바닥 압축 (매수 신호):**
52주 하위 30% + BB 폭이 60일 최저값의 120% 이내. HAV-EXTEND에서 bb_width PF 2.23 확인.

**DESK5 자본 배분:**
소자본 시 DESK5 진입 없음(감시만). 중자본 이상 시 종목당 총 자본의 3~5% 진입. 이후 DESK4 추매 시 비중 확대.

### 3-2. DESK4 — 2파 눌림 후 추매

| 항목 | 설계 |
|------|------|
| 역할 | 일봉 2파 눌림 확인 후 추매하여 비중 확대 |
| 보유 기간 | 5~40일 (추매 후 3파까지 보유) |
| 트리거 = 추매 신호 | T4-1~T4-4 중 2개 충족 시 추매 또는 신규 진입 |
| 풀 크기 | 20~30종목 보유 |
| 갱신 | 매일 장 마감 후 |
| 퇴출 | 거래량 감소 + 정배열 붕괴 |

**T4-1 정배열 형성 (추매/진입 신호):**
5일선 > 10일선 > 20일선 최초 달성. PULLBACK-ANATOMY 19,225건에서 MA 정배열이 2파 발생률과 직접 연관.

**T4-2 거래량 가속 (추매/진입 신호):**
VOL_MA5 / VOL_MA20 ≥ 2.0. Phase 1에서 TOP-20 종목의 D-5→D-1 거래량 +267% 확인.

**T4-3 박스권 돌파 임박 (추매/진입 신호):**
종가 ≥ 20일 최고가 × 0.97, 아직 미돌파. PULLBACK-CONFIRMATION에서 20봉 신고가 2파 확률 85.7%.

**T4-4 대장주 플래그 (추매/진입 신호):**
SEC_LEADER_FLAG v2 활성. AUC 0.838. 급등 간격 중앙값 38일로 DESK4 보유 기간과 일치.

**DESK5 보유 종목 추매 시:** DESK5에서 이미 보유 중인 종목이 T4 트리거 충족 시, 종목당 비중을 3~5% → 8~10%로 확대합니다.

**DESK4 독자 진입:** DESK5를 거치지 않고도 T4 트리거 2개 충족 시 신규 진입 가능. TYPE-C(Short Trigger, 32%)와 TYPE-D(Sudden, 34%)가 이 경로로 포착됩니다.

### 3-3. DESK3 — 3파 폭발 구간

| 항목 | 설계 |
|------|------|
| 역할 | 일봉 3파 폭발 구간에서 최대 비중으로 진입/추매 |
| 보유 기간 | 1~10일 (폭발 후 4파까지) |
| 트리거 = 최대 비중 신호 | T3-1/T3-2 단독, 또는 T3-3~T3-6 중 2개 |
| 풀 크기 | 50~100종목 보유 + DESK2 먹이감 공급 |
| 갱신 | 매일 16:00 (일봉 확정 직후) |
| 퇴출 | 3일 연속 미충족 + MA20 이탈 |

**T3-1 L3 반복 등장 (최강 확신 신호):**
30일 내 TOP-20 등장 ≥ 2회. Phase 2B에서 L3+X9 OOS 정밀도 90%.

**T3-2 X9 섹터 동조 (단독 최강 변수):**
전일 기준 동일 섹터 TOP-20 ≥ 2종목. AUC 0.851.

**T3-3 뉴스 연속 + 공시/실적:**
5일 내 뉴스 ≥ 3건, 공시 또는 실적 포함. NEWS-STRATEGY-MATRIX 릴레이율 48.4%.

**T3-4 볼린저 스퀴즈 + 거래량 점화:**
BB 폭 하위 10% + 당일 거래량 전일 대비 +50%. PULLBACK-CONFIRMATION TS-C4 2파 88.6%.

**T3-5 눌림 후 지지 확인:**
3~5일 조정 후 양봉 전환 + MA10 지지. D2-IMPROVE MA10 B2 PF_net 3.485.

**T3-6 뉴스 burst:**
5일 내 뉴스 ≥ 3건, 5일/10일 비중 ≥ 60%. SURGE-CAUSE S07 급등군 1.7배.

**DESK4 보유 종목 추매 시:** T3 트리거 충족 시 비중을 8~10% → 15~20%로 최대 확대.

**DESK3 독자 진입:** T3-1(L3≥2) 또는 T3-2(X9≥2) 충족 시 DESK5/4 이력 없이도 직접 진입. TYPE-C의 91% E11 발생률 포착.

### 3-4. DESK2 — 장중 분봉 수확기

| 항목 | 설계 |
|------|------|
| 역할 | DESK5/4/3 보유 종목을 먹이감으로 장중 분봉 파동 수확 |
| 보유 기간 | 60분 이내 (장중) |
| 입력 | DESK5/4/3 전체 보유 종목 = 먹이감 풀 + 실시간 NEW 감지 |
| 동시 보유 | 최대 5종목, PF 우선 슬롯 |
| 엔진 | 6-Layer 멀티컨디션 (기존 DESK2-DESIGN-SPEC v3.0 유지) |

**DESK2는 기존 설계를 그대로 유지합니다.** 변경되는 것은 입력입니다. 기존에는 "DESK3 풀에서 받는다"였지만, 이제는 **"DESK5/4/3이 실제 보유 중인 종목 전체가 먹이감"**입니다.

```
DESK2 먹이감 = DESK5 보유 종목 (10~20)
             + DESK4 보유 종목 (20~30)
             + DESK3 보유 종목 (50~100)
             + 실시간 NEW 감지 종목
             ─────────────────────────
             총 80~150종목 (이미 일봉 추세 검증 완료)
```

이 먹이감 풀에서 DESK2는 매일 Birth Point를 감지하고, 6-Layer 스코어링으로 상위 종목을 선별하고, 전략카드(D2/D4/D5/D6/D7/S1/D-ORB)로 분봉 파동을 수확합니다.

**DESK2 스코어 가산 체계:**

| 소스 | 조건 | 가산점 | 의미 |
|------|------|--------|------|
| DESK5 보유 | 일봉 1파 진행 중 | +0.5 | 장기 매집 검증 |
| DESK4 보유 | 일봉 2파 추매 완료 | +0.8 | 중기 성장 검증 |
| DESK3 보유 | 일봉 3파 폭발 구간 | +1.0 | 최고 확신 |
| DESK3 L3≥2 | 반복 등장 | +0.7 | 검증된 반복 패턴 |
| 비보유 | NEW 실시간 감지 | +0.0 | 미검증, Birth만으로 판단 |

## 제4장. 자본 배분 — 성장 단계별 전략

### 4-1. 핵심 원칙

자본이 작을 때는 회전율로 승부하고, 자본이 커지면 파동 전체를 탑니다. 모든 것을 동시에 가질 수 없으므로, 자본 규모에 따라 DESK 활성화 순서가 달라집니다.

### 4-2. 자본 단계별 배분

**Stage 1 — 소자본 (4천만 이하)**

```
DESK2: 자본 100% 집중
DESK3: 감시만 (매수 없음, 먹이감 풀 역할만)
DESK4: 감시만
DESK5: 감시만

전략: DESK2 회전율 극대화 (일 5건 × +2% = 일 +10%)
목표: 자본을 2억까지 키운다
```

회전율이 무기입니다. DESK5/4/3은 트리거 스캔만 돌리면서 먹이감 풀을 제공하되, 실제 매수 자금은 DESK2에 전부 투입합니다.

**Stage 2 — 중자본 (2억~5억)**

```
DESK2: 자본 60%
DESK3: 자본 30% (상위 10종목 스윙 보유)
DESK4: 자본 10% (상위 5종목 소량 보유)
DESK5: 감시만

전략: DESK2 회전 + DESK3 스윙의 이중 수익
목표: 자본을 10억까지 키운다
```

DESK3 스윙이 새 수익원으로 활성화됩니다. 3파 폭발 구간의 3~10일 보유로 일봉 수익을 직접 먹기 시작합니다.

**Stage 3 — 대자본 (10억 이상)**

```
DESK2: 자본 40%
DESK3: 자본 30%
DESK4: 자본 20%
DESK5: 자본 10%

전략: 전 DESK 활성화, 일봉 파동 전체 + 분봉 수확 동시
목표: 복리 가속으로 자본 극대화
```

DESK5의 1파 바닥 진입이 가능해집니다. 10~20종목에 각 1%씩 분산 진입하고, 파동이 진행되면서 DESK4/3에서 추매하여 비중을 키웁니다. 동시에 DESK2가 이 종목들을 매일 발라먹습니다.

### 4-3. 비중 피라미딩 흐름

하나의 종목이 파동을 타면서 비중이 증가하는 구조입니다.

```
DESK5 진입: 총 자본의 1~3% (씨앗)
     ↓ T4 트리거 발동
DESK4 추매: 총 자본의 5~8%로 확대
     ↓ T3 트리거 발동
DESK3 추매: 총 자본의 10~15%로 확대
     ↓ 3파 완료, 4파 시작
부분 청산: 50% (비중 → 5~8%)
     ↓ 5파 또는 추세 소멸
전량 청산: 0%
```

**승자에 집중, 패자는 빨리 자른다.** 파동이 진행될수록 비중이 커지고, 추세가 끝나면 단계적으로 빠집니다.

### 4-4. 자본 간 격리

DESK2 자본과 DESK5/4/3 자본은 명확히 분리됩니다.

```
총 자본 = DESK2 계좌(장중 회전용) + DESK-SWING 계좌(일봉 보유용)

DESK2 계좌: 장중 진입/청산, 60분 이내 회수
DESK-SWING 계좌: 일봉 보유, 수일~수개월

교차 규칙:
- DESK2가 DESK-SWING 보유 종목을 장중 매수할 때: DESK2 계좌에서 집행
- 같은 종목을 두 계좌에서 동시 보유 가능 (시간 프레임 분리)
- DESK2 수익은 일일 정산 후 DESK-SWING 재배분 가능
```

## 제5장. 승격/추매/강등/청산 규칙

### 5-1. 정방향 — 파동 진행에 따른 추매

```
DESK5 → DESK4 추매 조건:
  T4-1(정배열) + T4-2(거래량 2배) 동시 충족
  행동: 보유 비중 2배 확대 (3% → 6~8%)

DESK4 → DESK3 추매 조건:
  T3-1(L3≥2) 또는 T3-2(X9≥2) 단독 충족
  또는 T3-3~T3-6 중 2개 동시 충족
  행동: 보유 비중 최대로 확대 (8% → 15%)

DESK3 → DESK2 공급:
  DESK5/4/3 전체 보유 종목 = DESK2 먹이감 풀
  DESK2는 별도 자본으로 장중 수확
```

### 5-2. 역방향 — 파동 소멸에 따른 청산/강등

```
DESK3 청산 판단:
  3일 연속 T3 미충족 + 종가 < MA20
  → 비중 50% 축소 (DESK4 수준으로 복귀)
  → 5일 추가 후에도 미회복 시 DESK4 비중으로 완전 축소

DESK4 청산 판단:
  VOL_MA5 < VOL_MA20 × 0.5 + 5일선 < 20일선
  → 비중 50% 축소 (DESK5 수준으로 복귀)
  → 정배열 완전 붕괴 시 전량 청산

DESK5 청산 판단:
  90일 무변화 or 악재 공시
  → 전량 청산, 감시 해제

긴급 청산:
  어느 DESK에서든 -10% 하드 스탑 (DD Decelerator 연동)
```

### 5-3. DESK2 역이관

```
DESK2 TP미달 + 수익 +1% + OBV 상승 지속:
  → DESK3에서 계속 보유 (DESK2 계좌 → DESK-SWING 계좌 이관)
  → 일봉 파동 관점에서 아직 3파 진행 중이면 유지
```

## 제8장. 구현 로드맵

### 8-1. Phase 순서 (CEO 확정)

| Phase | 내용 | 예상 소요 | 선행조건 |
|-------|------|----------|---------|
| **Phase 1** | DESK3 트리거 엔진 (T3-1~T3-6) + 풀 관리 | 3일 | 없음 |
| **Phase 2** | DESK3 백테스트 — 241일 풀 리콜 + 보유 수익률 검증 | 2일 | Phase 1 |
| **Phase 3** | DESK4 트리거 엔진 (T4-1~T4-4) + 추매 로직 | 2일 | Phase 1 |
| **Phase 4** | DESK5 트리거 엔진 (T5-1~T5-3) + 장기 보유 | 1일 | Phase 3 |
| **Phase 5** | 승격/추매/강등 자동화 + 비중 피라미딩 | 2일 | Phase 3,4 |
| **Phase 6** | 전체 파이프라인 241일 시뮬레이션 (이중 수익 포함) | 2일 | Phase 5 |
| **Phase 7** | DESK2 먹이감 연동 + 실전 통합 | 2일 | Phase 6 |

### 8-2. DESK3 먼저 구현하는 이유

DESK3이 DESK2의 직접 먹이감이고, DESK3 자체도 가장 풍부한 연구 자산(L3/X9 정밀도 90%, 19,225건 눌림 데이터, 뉴스 214만 건)을 보유합니다. DESK3 단독 가동만으로도 DESK2 먹이감 + DESK3 스윙 수익이 동시에 발생합니다. DESK5/4는 DESK3에 먹이감을 추가 공급하고 비중을 키워주는 역할이므로, DESK3이 안정화된 후 붙이면 됩니다.
