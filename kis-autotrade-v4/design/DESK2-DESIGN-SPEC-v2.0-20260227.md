## 1. 비전 및 목적

**V4.1 전체 비전**: DESK1~5는 주식의 생애주기(웨이브)를 포착하는 연결된 시스템이다. 종목은 장기 추세 형성(DESK5) → 중기 스윙(DESK4) → 단기 스윙(DESK3) → 1~3일 폭발(DESK2) → 스캘핑 수확(DESK1)의 흐름을 따르며, 역방향으로도 DESK2에서 발굴된 종목이 DESK3~5로 승격되어 지속 모니터링된다.

**DESK2 미션**: 당일 수익률이 가장 높을 종목을 사전에 발굴하고, 100%에 가까운 확신으로 최적 타이밍에 진입하여 최대 수익을 확보한 뒤, 규칙 기반으로 청산한다.

**DESK2 운용 기간**: 1~3 거래일 (당일 진입, 당일 또는 익일 청산)

**핵심 원칙**:
- 종목 발굴은 단일 조건이 아닌 다층 맥락(뉴스, 수급 축적, 전일 패턴, 섹터 동향)의 종합 판단이다.
- 진입 타이밍은 고정 시간이 아닌 관찰 가능한 수급 전환 신호에 기반한다.
- 추세형과 반전형은 별도 전략으로 운용한다.
- 모든 조건과 파라미터는 데이터에 의해 검증되어야 한다.

## 2. v1.0 대비 변경 사항 및 근거

### 2-1. 폐기된 구조 (v1.0)

v1.0은 7개 발굴 조건(C1 갭상승, C2 ORB돌파, C3 VI발동, C4 10분급등, C5 후속발굴, C6 섹터후행, C7 과매도반등)과 7개 전략(ALPHA~GOLF)을 매트릭스로 조합하는 구조였다. 실전 결과 GOLF_REVERSAL에 83%가 편중됐고, C1(갭상승)은 수익과 역상관(r=-0.276)이었으며, TARGET_PROFIT 계산 버그(bb_middle 기반 목표가가 진입가보다 낮은 오류)가 발견됐다.

### 2-2. 폐기 근거 (데이터)

14거래일 280건 TOP-20 역추적 결과, 기존 C1~C7 중 어떤 단일 조건도 TOP 종목을 유의미하게 포착하지 못했다. 11개 조건을 AND로 결합한 필터의 Recall은 0.4%(280건 중 1건)로, 발굴 시스템이 아닌 복권 수준이었다. 반면 D-1(전일) 거래량 비율 하나만으로 AUC 0.911을 달성하여, 기존 실시간 조건(RVOL, 거래량가속도)보다 전일 데이터의 예측력이 압도적으로 높았다.

### 2-3. v2.0 핵심 변경

첫째, 발굴 방식을 AND 조건 매칭에서 가중 스코어링으로 전환했다. 둘째, 진입 기준을 고정 시간(10분 후)에서 수급 전환 신호(S1, T5)로 전환했다. 셋째, 전략을 7개 혼합에서 TREND/REVERSAL 2개 분리 운용으로 단순화했다. 넷째, 청산을 단일 규칙에서 유형별 최적 규칙으로 분리했다. 다섯째, 데스크 간 연결(웨이브)을 명시적으로 설계에 포함했다.

### 3-2. 구성 요소 상세

**3-2-1. 사전 스코어링 엔진 (desk2_prescoring.py)**

실행 시점은 매 거래일 15:40(장 마감 후). 전체 상장 종목을 대상으로 4개 피처를 계산한다.

F1(뉴스/공시 존재 여부)은 당일 또는 전일 뉴스·공시가 있으면 1, 없으면 0이다. 판별력 +35.7%, 가중치 0.472. 데이터 소스는 go100_news_items 테이블이다.

F2(5일 거래량 변화율)는 D-1 거래량 대비 D-5 거래량의 변화를 백분율로 계산한다. TOP 평균 +456%, 대조군 +23%. AUC 0.878, 가중치 0.757. 데이터 소스는 v4_ohlcv_daily 또는 v4_ohlcv_minute 일별 집계다.

F3(D-1/5일 평균 거래량 비율)는 전일 거래량을 최근 5일 평균 거래량으로 나눈 값이다. 기준값 ≥1.3. AUC 0.911(전체 최고 판별력), 가중치 0.822. 이것이 단일 조건으로 가장 강력한 예측 변수다.

F4(D-1 종가 위치)는 전일 종가가 당일 가격 범위에서 어디에 위치하는지를 (종가-저가)/(고가-저가)로 계산한다. 기준값 ≥0.50. 판별력 +23%, 가중치 0.365.

가중 스코어는 Score = F3×0.822 + F2×0.757 + F1×0.472 + F4×0.365로 산출한다. TOP 평균 스코어 2.96, 대조군 평균 1.64. 최적 컷오프는 ≥1.93(Recall 93.2%, Precision 81.8%, F1 0.871)이다.

2단계 필터는 C6(뉴스/공시 ≥2건)과 C7(종가위치 ≥0.6)을 동시에 적용한다. 이 필터 적용 후 Precision이 4.4%에서 56.4%로 12.8배 상승한다.

최종적으로 스코어 순 상위 10종목을 선정하여 v4_desk2_candidates 테이블에 저장하고 텔레그램으로 CEO에게 알린다.

**3-2-2. 실시간 신호 감지 엔진 (desk2_realtime_signal.py)**

실행 시점은 매 거래일 09:00~09:30, 1분 간격. 대상은 v4_desk2_candidates에 등록된 후보 종목이다.

유형 판별은 개장 후 매 분봉마다 dip% = (시가-현재저가)/시가 × 100을 계산하여 실시간으로 갱신한다. dip < 1%이면 TREND, 1~2%이면 BORDER, ≥2%이면 REVERSAL로 분류한다. BORDER는 09:15까지 관찰하여 재분류하며, 재분류 불가 시 당일 진입을 포기한다.

TREND 진입 신호 T5는 현재가가 시가의 102% 이상일 때 발생한다. 발생률 97%(88건 중 85건), 중앙값은 개장 후 1분, MFE +19.9%, MAE -2.8%. 확인 후 +1분에 시장가 매수한다.

REVERSAL 진입 신호 S1은 직전 3분간 평균 체결강도가 0.4 미만이다가 현재 1분 체결강도가 0.6 이상으로 전환될 때 발생한다. 발생률 99%(138건 중 137건), 중앙값은 저가 후 7분, MFE +21.9%, MAE -3.5%. 확인 후 +1~2분에 시장가 매수한다.

신호 발생 시 v4_desk2_signals 테이블에 기록하고 텔레그램으로 즉시 알린다.

**3-2-3. 자동 매매 엔진 (desk2_auto_trader.py)**

진입은 신호 확인 후 지정된 지연(TREND +1분, REVERSAL +1~2분) 후 시장가 주문을 실행한다. 주문 실행은 기존 order_executor.py의 KIS API 연동을 활용한다.

청산 규칙은 유형별로 분리한다(⚠️ 아래 값은 데이터 기반 초기값이며 PARAM-OPTIMIZE 결과로 최종 확정). TREND는 이익실현 추세추종(트레일링 스톱 -2% 또는 고정 +5%), 손절 -2%, 시간청산 14:50이다. REVERSAL은 이익실현 고정 +3%, 손절 -3%, 시간청산 14:50이다. 익일 보유 조건은 종가 시점에 수익 중이고 종가가 VWAP 이상이면 익일 시가에 청산한다(평균 +2.6pp 추가 수익).

리스크 관리 규칙은 동시 보유 최대 3종목, 종목당 자본 30% 이하, 일일 손실 한도 -3%(도달 시 당일 신규 진입 중단), 연속 2회 손절 시 다음 1시간 진입 중단, 코스닥 지수 -2% 이상 하락 시 신규 진입 중단이다.

모든 거래는 v4_desk2_trades 테이블에 기록하며, 매매 체결·청산·손절 시 텔레그램으로 통보한다.

## 4. 데이터 모델

### 4-1. 신규 테이블

**v4_desk2_candidates**: 사전 스코어링 결과 저장. 컬럼은 id(SERIAL PK), trade_date(DATE), symbol(VARCHAR 20), symbol_name(VARCHAR 100), score(NUMERIC 6,3), f1_news(NUMERIC 4,3), f2_vol_change(NUMERIC 10,2), f3_vol_ratio(NUMERIC 6,3), f4_close_pos(NUMERIC 4,3), news_count(INTEGER), market_cap(BIGINT), rank(INTEGER), created_at(TIMESTAMPTZ). 유니크 제약은 (trade_date, symbol)이다.

**v4_desk2_signals**: 실시간 신호 기록. 컬럼은 id(SERIAL PK), candidate_id(FK → v4_desk2_candidates), symbol(VARCHAR 20), signal_type(VARCHAR 20, TREND_T5 또는 REVERSAL_S1), stock_type(VARCHAR 20, TREND/REVERSAL/BORDER), signal_time(TIMESTAMPTZ), signal_price(NUMERIC 12,2), dip_pct(NUMERIC 6,3), strength_before(NUMERIC 4,3), strength_after(NUMERIC 4,3), obv_direction(VARCHAR 10), entry_scheduled_at(TIMESTAMPTZ), created_at(TIMESTAMPTZ).

**v4_desk2_trades**: 매매 기록. 컬럼은 id(SERIAL PK), signal_id(FK → v4_desk2_signals), symbol(VARCHAR 20), stock_type(VARCHAR 20), entry_time(TIMESTAMPTZ), entry_price(NUMERIC 12,2), entry_qty(INTEGER), exit_time(TIMESTAMPTZ), exit_price(NUMERIC 12,2), exit_reason(VARCHAR 30, TAKE_PROFIT/STOP_LOSS/TIME_EXIT/TRAILING/NEXT_DAY), gross_pnl_pct(NUMERIC 6,3), net_pnl_pct(NUMERIC 6,3), fee_pct(NUMERIC 4,3 DEFAULT 0.41), status(VARCHAR 20, OPEN/CLOSED/CANCELLED), created_at(TIMESTAMPTZ), updated_at(TIMESTAMPTZ).

**v4_desk2_daily_summary**: 일별 성과 요약. 컬럼은 id(SERIAL PK), trade_date(DATE UNIQUE), total_candidates(INTEGER), total_signals(INTEGER), total_entries(INTEGER), wins(INTEGER), losses(INTEGER), win_rate(NUMERIC 5,2), gross_return_pct(NUMERIC 8,3), net_return_pct(NUMERIC 8,3), max_drawdown_pct(NUMERIC 6,3), trend_entries(INTEGER), reversal_entries(INTEGER), created_at(TIMESTAMPTZ).

### 4-2. 기존 테이블 활용 (읽기 전용)

v4_ohlcv_minute에서 1분봉 OHLCV 데이터를 조회하여 실시간 신호 감지, 체결강도 계산, OBV 산출에 사용한다. v4_ohlcv_daily에서 일봉 데이터를 조회하여 D-1~D-5 거래량, 종가위치 계산에 사용한다. go100_news_items에서 뉴스/공시 데이터를 조회하여 F1(뉴스 존재), C6(뉴스≥2) 필터에 사용한다. v4_scalping_universe(708종목)에서 종목 마스터 정보를 참조한다.

## 5. 스코어링 모델 상세

### 5-1. 피처별 데이터 근거

F3(D-1/5일 거래량 비율)이 가장 강력한 예측 변수인 이유는 다음과 같다. TOP 종목은 급등 당일이 아니라 D-5부터 거래량이 축적되기 시작한다. D-5 대비 D-1 거래량 증가율은 TOP +456%, 대조군 +23%로 20배 차이가 난다. 이는 기관·세력의 사전 매집이 며칠에 걸쳐 진행됨을 의미한다. AUC 0.911은 이 지표 하나만으로도 TOP과 비TOP을 91.1% 정확도로 구분할 수 있다는 뜻이다.

F2(5일 거래량 변화율)는 F3와 함께 수급 축적의 강도를 측정한다. F3가 "어제 평소보다 거래량이 많은가"를 보는 반면, F2는 "5일 동안 거래량이 얼마나 빠르게 증가했는가"를 본다. 두 지표의 상관관계는 높지만 포착하는 측면이 다르므로 둘 다 유지한다.

F1(뉴스/공시)은 TOP 종목의 95.7%가 당일 또는 전일 뉴스/공시를 보유하고 있었다(대조군 60%). 뉴스는 급등의 촉매이자 수급 유입의 원인이다. 뉴스 없이 급등한 4.3%(12건)는 섹터 동반 상승 또는 기술적 돌파 케이스였다.

F4(종가위치)는 전일 종가가 당일 고가 근처(≥0.6)에서 마감한 종목이 익일 추가 상승 확률이 높다. 이는 장 마감까지 매수세가 유지되었음을 의미한다.

### 5-2. 제거된 조건과 근거

R4(거래량가속도 ≥5.0)는 AUC 0.501로 동전 던지기 수준이었다. TOP 종목의 52%를 거짓 음성(FN)으로 만든 주범이었다. R6(RVOL ≥3.0)도 AUC 0.502로 판별력 제로였으며, R4와 함께 FN의 77%를 유발했다. 이 두 조건은 "장중 실시간 급등"을 포착하려 했으나, 실제로는 TOP 종목이 이미 D-1부터 결정되어 있어 장중 실시간 조건의 추가 판별력이 극히 낮았다.

### 5-3. 스코어링 성능

1단계 스코어링만 적용 시(컷오프 ≥1.93): Recall 93.2%, Precision 81.8%, F1 0.871. AND 필터 대비 124배 개선.

1단계 + 2단계 필터(C6+C7) 적용 시: 14일 전체 스캔에서 Recall 99.6%, 일별 후보 약 50종목, 상위 10종목 시뮬레이션 Precision 56.4%.

## 6. 진입 신호 상세

### 6-1. 왜 "저가+1분"이나 "시가+1분"이 아닌가

"저가+1분"은 사후적 기준이다. 실시간에서는 현재 가격이 당일 최저가인지 알 수 없다. "시가+1분"도 REVERSAL 유형에서는 시가 직후 하락이 시작되므로 진입하면 즉시 손실이 발생한다. CEO의 지시: "왜 진입이 1분인가? 명확한 데이터의 이유가 있어야 한다." 이에 따라 모든 진입 기준을 "관찰 가능한 수급 전환 신호 발생 후 +N분"으로 전환했다.

### 6-2. TREND 진입 신호 T5 상세

정의는 현재가가 시가의 102% 이상(시가 대비 +2% 돌파)이다. 분석 결과는 88건 TREND 중 85건(97%)에서 발생했고, 발생 시점 중앙값은 개장 후 1분이며, 신호 후 +3% 도달률 100%, +5% 도달률 100%이고, MFE +19.9%, MAE -2.8%이다. +1분 지연 진입 시 MAE가 -2.8%에서 -2.0%로 개선되면서 MFE는 유지되므로, +1분 지연이 최적이다.

보조 확인 조건(선택적)으로 T1(RVOL ≥3×), T2(3분 연속 체결강도 ≥0.7), T3(OBV 3분 연속 상승), T4(VWAP 돌파)가 있으며, T5와 함께 2개 이상 충족 시 신뢰도가 높아진다.

### 6-3. REVERSAL 진입 신호 S1 상세

정의는 직전 3분간 평균 체결강도가 0.4 미만이다가 현재 1분 체결강도가 0.6 이상으로 전환되는 것이다. 분석 결과는 138건 REVERSAL 중 137건(99%)에서 발생했고, 발생 시점 중앙값은 저가 후 7분이며, 신호 시점에 이미 저가 대비 +4.8% 상승해 있고, MFE +21.9%, MAE -3.5%이다. +1분 지연 시 MAE -3.5%에서 -3.2%로 개선되며 MFE 유지되고, +2분 지연 시 MAE -2.9%로 추가 개선되나 MFE 소폭 감소한다.

보조 확인 조건(선택적)으로 S2(OBV 바닥 후 3분 연속 상승), S3(거래량가속도 ≥3.0), S4(VWAP 돌파), S5(1분봉 U/F/D 시퀀스에서 D→U 전환)가 있으며, 복합 신호 C4(S1~S5 중 2개 이상)도 S1 단독과 유사한 성능을 보인다.

## 7. 유형별 전략 상세

### 7-1. TREND 전략

출현 빈도는 TOP-20의 31.4%(88/280건)이다. 특징은 시가부터 상승이 시작되며 OBV가 개장 즉시 우상향하고, VWAP·MF·체결강도가 장시간 양(+) 유지되며, 상승 캔들 연속 평균 7.8분으로 REVERSAL(4.3분)보다 2배 길다. 평균 최대수익은 24.2%이다.

최적 진입은 T5 확인 후 +1분이며, 진입가는 시가 대비 약 +2~3%이다. 최적 청산은 추세추종 방식으로, 평균 PnL +7.19%이며 고정 +3% 청산 시에도 100% 도달하나 수익의 절반 이상을 놓친다. 손절은 -2%(TREND의 MAE 중앙값 -0.5%, 95% -2.0%)이다.

### 7-2. REVERSAL 전략

출현 빈도는 TOP-20의 49.3%(138/280건)로 가장 빈번하다. 특징은 시초 2% 이상 하락 후 반등하며, D→U 캔들 전환 패턴이 명확하고, 체결강도가 0.3 이하에서 0.7 이상으로 급반전되며, 추세 지속 시간이 평균 4.3분으로 짧다. 평균 최대수익은 27.7%(TREND보다 높다).

최적 진입은 S1 확인 후 +1~2분이며, 진입가는 저가 대비 약 +4.8%이다. 최적 청산은 고정 +3%로, 도달률 100%이며 추세추종 적용 시 +1.71%로 급락한다. 이는 반등 지속 시간이 짧아 추세추종이 적합하지 않기 때문이다. 손절은 -3%(REVERSAL의 MAE 중앙값 -0.8%, 95% -3.2%)이다.

### 7-3. BORDER 전략

출현 빈도는 TOP-20의 19.3%(54/280건)이다. 처리 방식은 09:15까지 관찰하여 dip%가 확정되면 TREND 또는 REVERSAL로 재분류한다. 09:15까지 미결정 시 당일 진입을 포기한다.

## 8. 리스크 관리 체계

### 8-1. 포지션 레벨 리스크

종목당 손절은 TREND -2%, REVERSAL -3%이다. 시간 청산은 14:50(미체결 포지션 강제 청산). 종목당 최대 자본 비율은 30%이다.

### 8-2. 포트폴리오 레벨 리스크

동시 보유 최대는 3종목이다. 일일 손실 한도는 -3%(도달 시 당일 신규 진입 중단). 연속 2회 손절 시 1시간 진입 중단이다.

### 8-3. 시장 레벨 리스크

코스닥 지수가 -2% 이상 하락하면 신규 진입을 중단한다. 하락장에서도 평균 +0.92% 수익이 확인되었으나(B-5), 극단적 하락에서는 방어가 필요하다.

### 8-4. 익일 보유 리스크

익일 보유 조건은 종가 시점에 수익 중이고 종가가 VWAP 이상일 때만 허용한다. 평균 추가 수익은 +2.6pp이나, 갭 하락 리스크가 존재하므로 익일 시가에 즉시 청산한다.

## 9. DESK 간 연결 (웨이브 전략)

### 9-1. 승격 로직 (DESK2 → DESK3~5)

DESK2 청산 후 종목의 수급 상태를 평가한다. D-1~D+1 거래량이 지속 증가하고 반복 등장(평균 간격 3.7일)하면 DESK3(단기스윙 3~10일) 후보로 등록한다. 섹터 전체로 테마가 확산되면 DESK4(중기스윙 20~40일) 후보로 등록한다. 장기 추세 전환이 확인되면 DESK5(장기 90~120일) 후보로 등록한다.

### 9-2. 강등/수확 로직 (DESK3~5 → DESK2/1)

DESK3~5 보유 종목에서 DESK2 사전 스코어링 상위 진입 시, DESK2에서 추가 매수(단기 수확)를 실행할 수 있다. DESK3 보유 종목이 DESK1 스캘핑 조건 충족 시 분할 수확한다.

### 9-3. 반복 등장 종목 데이터

14일간 30개 종목이 TOP-20에 반복 등장했다. 대표적으로 SG세계물산 7회, 유투바이오 7회, 현대ADM 다수 등장. 평균 등장 간격 3.7일, 익일 재등장 비율 20.4%. 이는 종목이 한 번 터진 후 수급이 수일간 지속됨을 의미하며, DESK3 승격의 데이터 근거다.

## 10. 기술 구현 명세

### 10-1. 파일 구조

```
scripts/desk2/
├── desk2_config.yaml          # 모든 파라미터 (코드 하드코딩 금지)
├── desk2_prescoring.py        # Phase 1: D-1 사전 스코어링
├── desk2_realtime_signal.py   # Phase 2-3: 실시간 분류 + 신호 감지
├── desk2_auto_trader.py       # Phase 4: 자동 매매
├── desk2_monitor.py           # 실시간 상태 모니터링
└── desk2_wave_evaluator.py    # Phase 5: DESK 간 승격/강등 평가
```

### 10-2. 설정 파일 (desk2_config.yaml) 초기값

```yaml
# 스코어링
scoring:
  weights:
    f3_vol_ratio: 0.822
    f2_vol_change: 0.757
    f1_news: 0.472
    f4_close_pos: 0.365
  cutoff: 1.93
  secondary_filter:
    min_news_count: 2     # C6
    min_close_pos: 0.6    # C7
  top_n: 10

# 유형 분류
classification:
  trend_threshold: 1.0    # dip% < 1% → TREND
  reversal_threshold: 2.0 # dip% ≥ 2% → REVERSAL
  border_deadline_min: 15 # 09:15까지 관찰

# 진입 신호
signals:
  trend:
    t5_breakout_pct: 2.0  # 시가 대비 +2%
    delay_minutes: 1
  reversal:
    s1_strength_low: 0.4  # 이전 3분 평균
    s1_strength_high: 0.6 # 현재 1분
    s1_lookback_min: 3
    delay_minutes: 1      # 1~2분

# 청산 (⚠️ PARAM-OPTIMIZE 확정 후 업데이트)
exit:
  trend:
    take_profit_pct: 5.0      # 또는 trailing
    trailing_stop_pct: 2.0
    stop_loss_pct: 2.0
  reversal:
    take_profit_pct: 3.0
    stop_loss_pct: 3.0
  common:
    time_exit: "14:50"
    next_day_hold: true
    next_day_condition: "close > vwap"

# 리스크
risk:
  max_positions: 3
  capital_per_stock_pct: 30
  daily_loss_limit_pct: 3.0
  consecutive_loss_pause_hours: 1
  market_drop_halt_pct: 2.0   # 코스닥 -2%

# 비용
cost:
  fee_pct: 0.41               # 편도 수수료+세금
```

### 10-3. 서비스 구조

기존 kis-v41-api/monitor/scheduler와 완전 분리하여 별도 systemd 서비스로 운용한다. kis-v41-desk2-prescoring.service는 매일 15:40 타이머로 실행된다. kis-v41-desk2-signal.service는 매일 08:55~09:35에 실행되며 1분 간격으로 신호를 감지한다. kis-v41-desk2-trader.service는 매일 09:00~15:00에 실행되며 신호 수신 시 자동 매매와 포지션 관리를 수행한다.
