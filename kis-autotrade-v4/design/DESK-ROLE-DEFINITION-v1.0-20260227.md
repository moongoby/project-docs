## 1. 핵심 프레임워크

하나의 종목이 시장에서 "태어나고 자라고 정점을 찍고 쇠퇴하는"
전체 생애주기를 5개 DESK가 분업하여 수익을 극대화한다.

```
DESK5 (장기 관측소)     D-120 ~ D-20    씨앗 감지
  ↓ 신호 전달
DESK4 (중기 추적자)     D-40 ~ D-5      성장 확인
  ↓ 승격 또는 직접 발굴
DESK3 (단기 스윙)       D-10 ~ D-1      폭발 직전 포착
  ↓ 승격 또는 직접 발굴
DESK2 (데이트레이드)    D-1 ~ D-day     당일 수확
  ↓ 실시간 신호
DESK1 (스캘핑)          D-day 장중       즉시 수확
```

각 DESK는 독립 수익원이면서 동시에 다른 DESK에 정보를 공급하는
파이프라인 역할을 수행한다.

## 2. DESK5 — 씨앗 감지소

| 항목 | 값 |
|------|-----|
| 역할 | 시장에서 "무언가 시작되는 종목"을 가장 먼저 감지 |
| 보유 기간 | 90~120일 |
| 현 상태 | 카드 1/10 라이브, 비활성 |
| 현 수익률 | 미검증 |

### 2.1 관측 대상
- 거래량이 60일 평균 대비 서서히 증가하기 시작하는 종목 (슬로우 매집)
- 외국인·기관 순매수가 20일 이상 지속적으로 양전환되는 종목
- 신규 테마·정책·산업 트렌드에 연결되는 종목 (뉴스 카테고리 분석)
- 52주 신저가 부근에서 바닥 다지기 + 거래량 살아나는 종목

### 2.2 다른 DESK에 공급하는 정보
- **DESK4로**: "매집 시작 감지" 종목 리스트 (주 1회 갱신)
- **DESK2 스코어 기여**: DESK5 감시 리스트 포함 종목에 가산점 +0.5
- 3개월 이상 매집이 확인된 종목은 DESK2 당일 급등 시 신뢰도 최상

### 2.3 핵심 데이터
- 60일·120일 거래량 이동평균
- 기관/외국인 누적 순매수 (데이터 확보 필요)
- 산업 분류·테마 코드
- 52주 가격 위치

### 2.4 승격/강등 조건
- **DESK4로 승격**: 20일 이내 거래량 2배 증가 + 가격 20일선 돌파
- **감시 해제**: 90일간 거래량 변화 없음 또는 악재성 뉴스 발생

## 3. DESK4 — 성장 확인자

| 항목 | 값 |
|------|-----|
| 역할 | DESK5가 감지한 "씨앗"의 실제 성장을 확인하고 중기 수익 실현 |
| 보유 기간 | 20~40일 |
| 현 상태 | 카드 6/9 라이브, 안정 |
| 현 수익률 | 운영 중 (안정) |

### 3.1 관측 대상
- DESK5 감시 리스트 중 20일 이내 거래량 5일 평균 대비 2배 증가
- 가격이 20일 이평선을 돌파하면서 거래량 동반 증가
- 뉴스가 단발이 아닌 3일 이상 연속 발생 (테마 지속성)
- 동일 섹터 2개+ 종목 동시 거래량 증가 (섹터 로테이션 신호)

### 3.2 다른 DESK에 공급하는 정보
- **DESK3로**: "성장 확인" 종목 리스트 (일 1회 갱신)
- **DESK2 스코어 기여**: DESK4 보유/관심 종목에 가산점 +0.8
- D-5→D-1 거래량 +267% 패턴은 DESK4가 D-20에서 이미 포착했어야 할 "가속 구간"

### 3.3 핵심 데이터
- 20일 거래량 추세
- 가격-이평선 관계
- 뉴스 연속성 (3일+)
- 섹터 동조

### 3.4 승격/강등 조건
- **DESK3로 승격**: D-5 거래량 5일 평균 대비 3배 + 볼린저 상단 돌파
- **DESK5로 강등**: 거래량 감소 + 가격 20일선 하회, 재료 소멸

## 4. DESK3 — 폭발 직전 포착자

| 항목 | 값 |
|------|-----|
| 역할 | 종목이 "내일 또는 이번 주에 급등할 것"이라는 직전 신호 포착 |
| 보유 기간 | 3~10일 |
| 현 상태 | 카드 9/11 라이브, 주 수익원 |
| 현 수익률 | +32.23% |

### 4.1 관측 대상
- D-5~D-1 거래량 급격 증가 (DESK2 스코어의 F2, F3에 해당)
- 뉴스/공시 당일 또는 전일 발생 + 시장 관심 집중
- DESK4 보유 종목 중 볼린저밴드 상단 돌파 (모멘텀 가속)
- 동일 테마 선도주 상한가 기록 후 후행주 자금 이동 패턴

### 4.2 다른 DESK에 공급하는 정보 (가장 직접적)
- **DESK2 스코어 기여**: DESK3 보유 종목에 최고 가산점 +1.0
- DESK3 보유 종목 = "매집 완료 + 재료 유효 + 수급 전환 확인" 완료
- B-2 Phase 8: D+1에도 TOP-20 재등장 20.4% → DESK3 보유 종목이
  DESK2 TOP에 등장할 확률 높음

### 4.3 역방향: DESK2 → DESK3 이관
- DESK2에서 14:30까지 TP 미달이나 수익 +1% 이상
- OBV 상승 지속 + 거래량 전일 대비 유지 + D-1 스코어 유지
- → DESK3로 이관하여 2~3일 추가 수익 포착
- B-2 Phase 8: 익일 시가 청산이 당일 14:30 대비 +2.6%p 유리

### 4.4 핵심 데이터
- D-5~D-1 거래량 가속도
- 뉴스 발생 시점·질
- 볼린저밴드 돌파
- 테마 내 선도주·후행주 관계

### 4.5 승격/강등 조건
- **DESK2 공급**: D-1 스코어 상위 + DESK3 보유 중 → 당일 최우선 진입 대상
- **DESK4로 강등**: 3일간 거래량 감소 + 가격 하락, 그러나 장기 추세 유지

## 5. DESK2 — 당일 수확자

| 항목 | 값 |
|------|-----|
| 역할 | D-1까지 축적된 모든 정보를 종합하여 당일 장중 최대 수익 실현 |
| 보유 기간 | 1~3일 |
| 현 상태 | 카드 10/16 라이브, 전면 재설계 중 |
| 현 수익률 | -23.25% (기존), 재설계 후 검증 중 |

### 5.1 역할 재정의
DESK2는 독립적 종목 발굴자가 아니라, **DESK3~5에서 흘러온 종목 +
당일 신규 발굴 종목을 합산하여 최종 매매를 집행하는 실행 DESK**.
종목 발굴의 80%는 DESK3~5에서 이미 완료되어야 하고, DESK2는 당일
실시간 수급 확인 + 진입 타이밍 + 청산 집행에 집중.

### 5.2 스코어카드 구조 (DESK 파동 연결 반영)

```
DESK5 기여: 감시 리스트 포함 여부          → +0.5점
DESK4 기여: 보유/관심 종목 여부            → +0.8점
DESK3 기여: 현재 보유 + TOP-20 이력       → +1.0점
DESK2 고유: D-1 거래량·뉴스·종가위치 등   → +0~2.4점
DESK1 기여: 장중 스캘핑 청산 후 추세 지속  → +0.3점
                                           ───────
                                       합계 최대 5.0점
```

### 5.3 유형별 전략 배치
- **TREND**: 시가부터 상승, T5 신호(+2%) 확인 후 진입, 추세추종 청산
- **REVERSAL**: 하락 후 V자 반등, 5층 전제 충족 + S1 확인 후 진입, 빠른 청산
- **BORDER**: 15분 관찰 후 TREND/REVERSAL 재분류

### 5.4 역방향 이관
- TP 미달 + 수익 +1% + OBV 상승 → DESK3로 승격
- 당일 수확 실패 + 재료 유효 → DESK3에서 2~3일 추가 보유

## 6. DESK1 — 즉시 수확자

| 항목 | 값 |
|------|-----|
| 역할 | 장중 실시간 초단기 기회 포착 |
| 보유 기간 | 0~1일 (분~시간 단위) |
| 현 상태 | 카드 10/10 라이브, 미검증 |
| 현 수익률 | 미검증 |

### 6.1 관측 대상
- 실시간 거래량 폭발 종목
- VI(변동성 인터럽션) 해제 직후 급등 종목
- DESK2 스코어 상위 종목의 장중 추가 급등

### 6.2 다른 DESK에 공급하는 정보
- **DESK2로**: 장중 +1~2% 스캘핑 청산 종목 중 추세 지속 종목 핸드오프
- "이 종목이 오늘 움직이고 있다"는 가장 빠른 실시간 신호 제공
- DESK2 스코어에 +0.3 가산

### 6.3 핵심 데이터
- v4_tick_data (실시간 틱)
- v4_orderbook_realtime (호가)
- v4_scalping_universe (708종목)

## 7. DESK 간 파동 연결 종합

### 7.1 정방향 파동 (발굴 → 수확)

```
DESK5 감시 리스트 (D-120~D-20)
  │ 매집 시작 → 거래량 서서히 증가
  ↓
DESK4 성장 확인 (D-40~D-5)
  │ 거래량 2배 + 이평선 돌파
  ↓
DESK3 폭발 직전 (D-10~D-1)
  │ 거래량 급등 + 뉴스 + 섹터 동조
  ↓
DESK2 당일 수확 (D-1~D-day)
  │ 스코어 합산 → TOP-10 진입 → 청산
  ↓
DESK1 즉시 수확 (장중)
  │ 스캘핑 후 추세 지속 → DESK2 핸드오프
```

### 7.2 역방향 파동 (수확 → 연장)

```
DESK2 TP 미달 + 수익 존재 → DESK3 승격 (2~3일 추가 보유)
DESK3 추세 둔화 + 장기 유효 → DESK4 강등 (중기 관찰)
DESK4 재료 소멸 → DESK5 강등 또는 감시 해제
```

### 7.3 DESK2 스코어 기여 점수 체계

| 소스 DESK | 조건 | 가산점 | 근거 |
|-----------|------|--------|------|
| DESK5 | 감시 리스트 포함 | +0.5 | 장기 매집 확인 |
| DESK4 | 보유/관심 종목 | +0.8 | 중기 성장 확인 |
| DESK3 | 현재 보유 종목 | +1.0 | 직전 검증 완료 |
| DESK3 | 최근 5일 TOP-20 이력 | +0.7 | 반복 등장 패턴 |
| DESK2 | D-1 스코어 (기존 4변수) | +0~2.4 | 당일 수급 |
| DESK1 | 장중 스캘핑 후 핸드오프 | +0.3 | 실시간 확인 |

## 8. 데이터 파이프라인 요구사항

### 8.1 즉시 구축 필요

| 파이프라인 | 소스 → 타겟 | 갱신 주기 |
|-----------|------------|----------|
| DESK3 보유 종목 → DESK2 스코어 | v4_positions → desk2_scoring | 매일 장전 08:50 |
| TOP-20 이력 → DESK2 스코어 | 일별 TOP-20 결과 누적 → desk2_scoring | 매일 장후 16:00 |
| D-20 거래량 추세 → DESK2 스코어 | ohlcv_daily → desk2_scoring | 매일 장전 08:50 |

### 8.2 추후 구축 (데이터 확보 후)

| 파이프라인 | 소스 → 타겟 | 필요 데이터 |
|-----------|------------|-----------|
| DESK5 감시 리스트 → DESK4/DESK2 | 신규 테이블 필요 | 기관/외인 순매수 |
| DESK4 관심 종목 → DESK2 | 신규 테이블 필요 | DESK4 관심 리스트 |
| DESK1 핸드오프 → DESK2 | 실시간 이벤트 | 스캘핑 청산 이벤트 |
