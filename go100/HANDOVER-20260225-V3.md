### 6-2. Data Readiness Gate (★ 반드시 구현)

"불완전한 조건으로 테스트는 금지다." – CEO 직접 지시

- **RED**: 데이터 부족 → 백테스트 차단, 수집 안내
- **YELLOW**: 일부 부족 → 경고 표시, 가용 기간으로 축소 실행
- **GREEN**: 충분 → 정상 실행

구현할 API: `POST /api/go100/backtest/check-readiness`

```json
{
  "go100_card_id": 13,
  "period_months": 3,
  "response": {
    "gate_level": "GREEN|YELLOW|RED",
    "checks": [...],
    "adjusted_period": {...},
    "warnings": [...],
    "collect_suggestions": [...]
  }
}
```

### 6-3. 전략별 최적화된 데이터로만 테스트

- 스캘핑 전략에 일봉 데이터로 테스트하면 안 됨
- 각 전략의 시간축에 맞는 시뮬레이터를 자동 선택
- 데이터가 없으면 즉각 수집 후 진행
- 전 기간에 없으면 있는 기간과 상황을 결과로 보여줌
