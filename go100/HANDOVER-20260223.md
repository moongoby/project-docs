## 3. 작업 규칙 (필수 준수)

### 일반 규칙
0. **대화 토큰 관리** — 80% 수준에서 인계서 작성 후 보고
1. **커서로만 작업** — 모든 서버 작업은 Cursor를 통해 수행
2. **커서 활용** — 병렬 작업 가능, 대화창 여러 개 운영, 가능한 건 바로 진행
3. **백업→수정→빌드→재시작→검증→커밋→보고→문서화** 흐름 필수
4. **커서 작업 지시서는 전체를 코드블록으로 감싸서 작성**
5. **커서 대화창 작업완료 시 하단에 Git 경로 + 동기화 체크 보고**
6. **한국시간(KST)으로 동기화**, 지시서에 현재 한국시간 반영
7. **중요 소스는 반드시 검수 진행**

### 커서 필수 규칙
- **서버 접속**: SSH root@211.188.51.113 (Cursor SSH 터미널)
- **DB 접속**: `PGPASSWORD='KisAuto2026!Secure' psql -h localhost -U kis_admin -d kisautotrade`
- **백업**: 변경 전 반드시 `.bak` 생성 (Git에 커밋하지 않음)
