## 3. 백억이(Baekeogi) 역할 재정의 — CEO 비전 (2026-02-24)

### 핵심 미션
"사용자가 목표만 말하면 백억이가 시장 데이터를 분석·전략 설계·실시간 자동매매·최적화·성과 보고까지 전 과정 수행"

### 신규 핵심 역할 5가지
- **Goal Architect** – 사용자 목표(예: 100만→10억) 분석, 연간 필요 복리 역산, 현실성 시뮬레이션, 다단계 플랜 제안
- **Strategy Engine** – 목표·성향에 맞는 스캘핑·데이트레이딩·스윙·중장기·배당 포트폴리오 자동 설계·백테스트·실매매 투입
- **Asset Operator** – 24시간 포지션 감시·진입·청산·레짐 변화 시 자동 전략 조정
- **Self-Optimizer** – 일/주/월 성과 평가·파라미터 조정·전략 교체·포트폴리오 리밸런싱
- **Personal Interface** – 모든 투자 관련 질문을 전략 카드로 전환하는 대화 인터페이스

### 새 사용자 여정
목표 입력 → Goal Architect (목표·연수익률·시뮬레이션) → Strategy Engine (Phase-A/B/C 포트폴리오) → 자동 백테스트·몬테카를로(1,000회) → 사용자 확인 → Asset Operator 자동 실행 → 일/주/월 리포트

### 주요 신규 모듈 (계획/부분 구현)
- **Goal Engine** (go100_goals 테이블): 초기금·목표금·필요CAGR·리스크·다단계플랜·몬테카를로
- **Strategy Portfolio Manager** (go100_strategy_portfolios): 전략카드 집합, 자금배분, 상관관계·드로다운 관리
- **Adaptive Regime Engine**: 일일 레짐 판정(v4_market_regime_daily) → 전략 비중 자동 조정
- **Performance Tracker**: 일별 브리핑, 주간 리뷰, 월간 리포트
- **Universal Question→Action Converter**: 14개 Intent

### 14개 Intent 목록
goal_setting, strategy_create, market_analysis, stock_info, sector_inquiry, education, portfolio_check, risk_inquiry, time_horizon, capital_question, comparison, what_if, adjust_goal, general_chat

### LLM 라우팅
- Goal Planning: Claude Sonnet 4.6
- Market Intelligence: 실시간 DB+KIS 데이터 기반
- Proactive Report: Gemini Flash (크론 08:30 KST)
- Strategy Design: Claude Sonnet 4.6
- Optimization: GPT-4o → LLMGateway로 교체 완료 (커서2)
- Free Chat: Gemini Flash

### 20주 로드맵
Phase A(코드 패치) → B(Intent Router 확대) → C(Goal Engine) → D(프로필) → E(Portfolio Manager) → F(Market Intelligence) → G(Adaptive Regime) → H(Performance Tracker) → I(Live Trading) → J(외부 데이터·마켓플레이스)
