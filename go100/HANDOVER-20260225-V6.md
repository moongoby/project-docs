## 1. 프로젝트 개요

**GO100 (백억이)**: 한국 주식시장 AI 자동매매 시스템. 사용자가 목표만 입력하면("5천만원으로 3년에 3억") AI가 전략 설계 → 백테스트 → 자동매매까지 수행하는 올인원 서비스.

| 항목 | 값 |
|------|-----|
| 서버 | root@[SERVER-IP] (Ubuntu, 15GB RAM, 99GB disk) |
| 도메인 | go100.newtalk.kr |
| DB | PGPASSWORD='[DB-PASSWORD]' psql -U kis_admin -d kisautotrade (PostgreSQL, 170 테이블, 13GB, 4,500만 행) |
| 주요 계정 | CEO (user_id 3, legacy 15), 개발계정 (user_id 6, legacy 6) |
| 레포지토리 | github.com/moongoby/kis-autotrade-v4 (코드), github.com/moongoby/project-docs (문서) |

## 9. 기술 아키텍처 핵심

### 비동기 태스크 시스템 (Cloudflare 524 해결)

- 장시간 인텐트(goal_setup 2턴, strategy, optimize_existing)는 비동기 처리
- JSON 파일 기반 태스크 트래커 (/tmp/go100_tasks/{task_id}.json)
- 프론트엔드 2초 간격 폴링 (최대 6분)
- 스테이지: analyzing → designing → backtesting → evaluating → completing

### Goal 파이프라인 분리 (PIPELINE-SPLIT-001)

- **Phase 1** (~10초): 전략 설계 + DRAFT 저장 → 즉시 응답
- **Phase 2** (백그라운드): 백테스트 → 평가 → 최적화 (최대 5회 반복) → BACKTESTED 상태

### 현실적 비용 모델 (REALISTIC-COST-001)

- Orchestrator에서 _inject_realistic_costs() 자동 적용
- 슬리피지: tiered (순위별 5/10/20bp + 거래량 참여 0/10/30bp)
- 수수료 0.015%, 매도세 0.18%
- setdefault 사용으로 디자이너 지정값 보존

### advanced_filters.py (17개 필터)

- 기존 12개 + 신규 5개: filter_credit_short, filter_by_theme, filter_trade_strength, filter_program_trading, filter_supply_demand

## 10. 당일 고수익 전략 30선 연구 (대표님 요청)

대표님과 "100만원 → 1억 1년" 시나리오를 논의한 결과, 솔직하게 불가능(CAGR 9,900%)하다고 보고했으며, 현실적 상한선은 연 500~900%(6,000~10,000만원)로 제시. 대표님은 상한가 종목 포착 및 10% 내외 수익 방법론에 관심을 보여 30가지 전략을 연구 보고함.

**카테고리별 요약:**

- **A. 상한가·급등 추종형 (5개)**: 상한가 익일 갭업, 테마 연쇄, 연속 상한가 3일차, 상한가 실패 반등, 동일 업종 확산
- **B. 모멘텀 브레이크아웃형 (5개)**: 52주 신고가, 거래량 폭발, VWAP 돌파, 갭업 첫 눌림, 갭업+외국인 콤보
- **C. 수급 기반형 (5개)**: 외국인 연속 순매수, 쌍끌이, 프로그램 매수 급증, 체결강도 200+, 공매도 잔고 급감
- **D. 기술적 패턴형 (5개)**: 볼린저 하단 반등, RSI 과매도, MACD 골든크로스, 정배열 전환, 삼중바닥
- **E. 시간대·시장구조형 (5개)**: 장 초반 30분, 동시호가 급등, 점심 저점, 금요일/월요일 갭, 배당락 반등
- **F. 뉴스·이벤트형 (3개)**: 실적 서프라이즈, 정책 수혜, IPO 상장
- **G. 리스크 관리·복합형 (2개)**: 레짐 기반 전략 전환, 멀티팩터 스코어링

**GO100 적용 가능성**: 즉시 21개 (현재 데이터), 단기 5개 (수집 추가), 중기 3개 (외부 데이터), 장기 1개 (메타 전략)
