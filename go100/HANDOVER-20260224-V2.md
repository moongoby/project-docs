5. 지시서 작성 시 전체를 코드블록으로 감싸서 작성
6. 커서 완료 보고 시 보고서 GitHub 문서폴더 위치 명확 지정
7. 한국시간(KST) 동기화, 지시서에 한국 현재 시간 반영
8. 중요 소스는 꼭 검수 진행
