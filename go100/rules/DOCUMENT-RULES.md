# GO100 문서 관리 규칙 (요약)
> 마스터: /DOCUMENT-NAMING-CONVENTION.md
> 최종 갱신: 2026-02-24

## 보고서 파일명
`CUR-GO100-{TASK_NAME}-{SEQ}-{YYYYMMDD}.md`

## 저장 위치
- GO100 보고서: `go100/reports/` (여기만)
- V4.1 보고서: `kis-autotrade-v4/reports/` (교차 저장 금지)

## TASK_NAME 유형
FIX, HOTFIX, DIAG, VERIFY, AUDIT, RESEARCH, E2E, MIGRATE, DOC, SCAN, REVIEW

## 커서 지시 시 필수
1. 보고서 저장 절대 경로 명시
2. 파일명 규칙 준수
3. git push 후 curl로 HTTP 200 확인
