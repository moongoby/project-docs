# GO100 백억이 베타 테스트 체크리스트

## 사전 준비
- [ ] E2E 테스트 17/17 PASS
- [ ] 대시보드 접속 정상
- [ ] 크론 전체 등록 확인
- [ ] 디스크 여유 >20%
- [ ] SSL 인증서 만료일 확인 (>30일)

## 테스트 시나리오
1. 신규 가입 → 온보딩 → 목표 설정
2. 전략 자동 생성 → 백테스트 실행
3. 페이퍼 트레이딩 시작 → 3일 운영
4. 모닝/장마감 브리핑 수신
5. 레짐 변화 시 조정 제안
6. 대시보드 조회 (모바일 + 데스크톱)
7. 에러 상황 (없는 종목, 잘못된 입력)

## 모니터링
- `/api/go100/monitor/health` 5분마다 체크
- 일일 사용 통계 리뷰
- 에러율 <5% 유지
