## 2. 어드민 대시보드 변경 사항

### 2-1. 백엔드 API

- **엔드포인트**: `GET /api/v1/admin/go100-data-status`
- **파일**: `backend/app/api/v1/admin_router.py` (835행 뒤에 추가)
- **응답**: 15개 테이블의 건수/종목수/기간/최신성 + PIT 상세 + 뉴스 커버리지 + DB 크기

### 2-2. 프론트엔드 컴포넌트

- **컴포넌트**: `frontend/src/components/admin/GO100DataTab.tsx` (신규)
- **API 타입**: `frontend/src/lib/api/admin.ts`에 GO100DataStatus 인터페이스 + getGO100DataStatus() 추가

### 2-3. 어드민 페이지 탭

- **파일**: `frontend/src/app/(protected)/admin/page.tsx`
- **변경**: 5탭 → **6탭** (사용자 / 계좌 / 시스템 / **데이터** / LLM비용 / 로그)
- "데이터" 탭 클릭 시 GO100DataTab 렌더링

### 2-4. 대시보드 구성 (5개 섹션)

1. **전체 현황 배너** — 건강상태(정상/주의/위험), 테이블 수, 총 레코드 수, DB 크기, 자동 새로고침
2. **주요 지표 카드 (Top 5)** — 가장 큰 테이블 5개를 카드로 표시 (건수, 종목수, 최신일)
3. **PIT 재무제표 상세** — DART/pykrx 소스별 매출/영업이익/순이익/PER/PBR 건수
4. **전체 테이블 현황** — 15개 테이블을 카테고리별(시세/기본/글로벌/섹터/파생/뉴스/시그널/장중/설정) 정렬, 상태 배지
5. **뉴스 백필 현황** — 365일 대비 커버리지 프로그레스바

### 2-5. 기능

- 60초 자동 새로고침 (TanStack Query refetchInterval)
- 최신성 아이콘: 최신(녹색), 1-3일전(노란색), 3일+(빨간색), 설정값(파란색)
- 건수 포맷: 1M+ → "43.2M", 1K+ → "2.6K"
