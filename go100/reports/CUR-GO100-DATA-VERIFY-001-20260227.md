### 3-2. 데이터 흐름

```
사용자: "오늘 지수알려줘"
    → Agent Core (agent_core.py)
    → LLM이 get_market_overview + get_market_regime 선택
    → tool_executors.py 실행
        → index_daily (KOSPI/KOSDAQ/KOSPI200)
        → v4_market_regime_daily (레짐 정보)
        → go100_global_market (글로벌 환율 등)
    → LLM이 결과 종합하여 응답 생성
```

- LLM 응답 생성 시 자연어 포맷팅에 의한 반올림으로, 데이터 오류 아님
