## Step 5: Git push (project-docs) — HANDOVER.md

```bash
cd /root/project-docs && git add go100/ && git commit -m "[GO100] HANDOVER v14.0 — T-001~T-004 완료, FE restart, closing cron" && git push origin master
```

**결과**:
```
error: insufficient permission for adding an object to repository database .git/objects
error: Error building trees
COMMIT_EXIT:1
```

**원인**: claudebot 계정은 /root/project-docs/.git/objects/ 내 일부 하위 폴더(root 소유, 755)에 쓰기 권한 없음. 
- git add는 새로운 blob 객체를 .git/objects/ 하위에 저장해야 하는데, SHA-1 해시 prefix 폴더가 root 소유면 실패.
- 예: objects/01/, objects/02/ 등 다수의 디렉토리가 drwxr-xr-x (root, root) 상태.

**git status** (변경사항 staged 상태로 남아있음):
```
On branch master
Changes to be committed:
  modified:   go100/HANDOVER.md
Untracked files:
  go100/reports/CUR-GO100-HANDOVER-V14-001-20260305.md
```

**대응**: done_watcher.sh (root PID)가 이 RESULT.md를 감지하면 project-docs에서 `git add .` + commit + push를 root로 실행 → HANDOVER.md 변경사항과 report 파일이 함께 push됨.
