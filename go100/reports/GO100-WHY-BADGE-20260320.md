### UI 표시 내용 (종류별)

**TradeHistory 테이블 — 근거 컬럼:**
- `entry_rule` → "진입 조건 충족" (파란색 뱃지)
- `take_profit` → "목표가 도달" (초록색 뱃지)
- `stop_loss` → "손절" (빨간색 뱃지)
- `timeout` → "보유기간 만료" (노란색 뱃지)
- `desk2_dip` → "DESK2 저가매수" (회색 뱃지)
- 없을 경우 → "—"

**SignalTimeline — 추가 뱃지:**
- `signal_name` → 보라색 뱃지 (TS-C2, S1 등)
- `dip_pct` → 하락률 표시 (↓X.X%)
- `desk_id` → DESK번호 청록색 뱃지

**TradeHistoryTable (백테스트) — 추가 컬럼:**
- "진입근거": `reason` 필드 (cyan)
- "시장상태": `regime_at_entry` 필드 (BULL=초록, BEAR=빨강)

**TradeDetail 상세 페이지:**
- "매매 근거": `signal_source` → SIGNAL_LABELS 매핑 문자열
