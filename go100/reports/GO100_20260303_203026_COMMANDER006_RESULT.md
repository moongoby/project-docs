## 6. 핵심 발견사항

### 6-1. 테스트 패치 경로 주의사항
- `debate.py`는 `BullAgent`/`BearAgent`를 함수 내부에서 로컬 임포트함
- 따라서 `patch("backend.app.services.go100.agents.debate.BullAgent")` 불가
- 올바른 패치 경로: `backend.app.services.go100.agents.bull_agent.BullAgent`

### 6-2. go100_agent_performance 스키마 불일치
- `commander.py::_update_agent_performance()`의 INSERT 쿼리에서 `user_id, review_date, win_rate, sample_count` 컬럼 사용
- 실제 테이블 스키마: `eval_date, agent_name, total_signals, correct_signals, accuracy` (user_id 없음)
- 현재 상태: ON CONFLICT 없이 실행 시 실패 → TC-7b에서 mock DB로 처리, TC-7c에서 실제 스키마로 직접 검증
- **권장 조치:** commander.py의 _update_agent_performance() 메서드 스키마 동기화 (P2 수준)

### 6-3. LLMGateway 오프라인 모드
- 드라이런을 FastAPI 서버 외부에서 실행 시 LLMGateway unavailable
- 에이전트들이 Fail-Open(NEUTRAL 폴백)으로 동작 → HOLD 판단
- 실제 서비스에서는 FastAPI 컨텍스트 내 정상 동작 확인 필요

### 6-4. 성능 목표 대비 여유
- 목표 60초 대비 측정값 3.23초 (94.6% 여유)
- 목표 15회 대비 측정값 5회 (67% 여유)
- LLM 실제 호출 시 약 2~5초 추가 예상 → 여전히 60초 내 여유
