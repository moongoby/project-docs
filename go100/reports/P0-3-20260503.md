## 1. 작업 개요

### 문제
`backend/app/services/go100/ai/agent_tools.py`에 정의된 **`get_events`**, **`get_event_impact`** 두 도구 스키마가 `tool_executors.py`의 `TOOL_EXECUTORS` 딕셔너리에 등록되지 않아, LLM이 이들 도구를 호출할 때 "Unknown tool" 에러 발생.

### 원인
- **AGENT_TOOLS**: 73개 도구 스키마 정의
- **TOOL_EXECUTORS**: 71개 도구만 executor 구현
- **빠진 항목**: `get_events`, `get_event_impact`
- **이벤트 데이터 소스**: 미준비 상태

---

## 2. 해결 방식

### 선택 사항 분석
| 옵션 | 방식 | 장점 | 단점 |
|------|------|------|------|
| **A** (선택) | agent_tools.py에서 스키마 제거 | LLM이 호출 시도 자체를 막음 (명확한 피드백) | 나중에 재활성화 필요 시 코드 수정 |
| B | tool_executors.py에 stub 추가 | 스키마 유지되어 문서화용 좋음 | LLM이 호출 가능하지만 기능 없음 |

**선택 근거**: 이벤트 데이터 소스가 미준비된 상황에서 옵션 A(제거)가 더 안전하고 명확함.
