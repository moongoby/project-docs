**V3 Brain 연동 흐름**:
```
stock_universe (100종목)
  → AiScorer.load() → AiScorer.score(ticker, db) per ticker
  → {up_5d_prob, cs_ai, mfe_60min_raw, mfe_3d_raw, gap_d1_raw}
  → up_5d_prob >= 0.6 필터
  → 내림차순 정렬 → 상위 3종
  → risk_engine.check_pre_trade() 검사
  → go100_paper_trades INSERT
```

**risk_engine.check_pre_trade() 통합**:
- 킬스위치 확인 (is_kill_switch_active)
- 종목당 비중 한도 (POSITION_SIZE_LIMIT, 기본 20%)
- 섹터 집중 한도 (SECTOR_CONCENTRATION, 기본 40%)
- 총 노출 한도 (TOTAL_EXPOSURE)
- 차단 시 go100_risk_events에 BLOCK 이벤트 기록

**Telegram 알림 연동**:
- GO100_TELEGRAM_BOT_TOKEN / GO100_TELEGRAM_CHAT_ID 사용 (GO100 전용 채널)
- 매수 완료: 종목명/수량/가격/up_5d_prob/cs_ai 리스트
