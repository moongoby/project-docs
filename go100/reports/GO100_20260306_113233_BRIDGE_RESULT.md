- `"use client"` 선언

- `export const dynamic = "force-dynamic"` 설정

#### OrgChartTree.tsx
- AgentNode 타입: `{ key, name, group, weight, accuracy20d, lastSignal }`
- GROUP_CONFIG: 분석팀(파랑), 토론팀(주황), 리스크팀(빨강), DESK팀(초록), 연구팀(보라), 성과추적(회색)
- Commander 노드 → 그룹별 트리 레이아웃
- 각 노드: 이름, 신호 아이콘(🟢🔴⚪), 가중치 뱃지, 적중률 바

#### AgentCard.tsx
- AgentStatus 타입: `{ key, name, role, group, weight, accuracy, lastSignal, lastActive, isActive }`
- AccuracyCircle: SVG 원형 게이지 (70%↑ 초록, 50%↑ 노랑, 미만 빨강)
- WeightGauge: 0.3~2.0 범위 바 게이지

#### DebateCard.tsx
- DebateData 타입: `{ id, stockName, stockCode, date, bullArgs, bearArgs, rounds, verdict, commanderDecision }`
- Bull 논거(초록) / Bear 논거(빨강) 2컬럼 레이아웃
- Commander 결정 블록 (노랑)

#### PerformanceChart.tsx
- PerformancePoint 타입: `{ date, [agentKey]: number | string }`
- Recharts LineChart 기반
- 7d / 30d / 90d 기간 선택 버튼

#### CritiqueCard.tsx
- CritiqueData 타입: `{ id, period, winRate, totalJudgments, learningPattern, improvement }`
- 승률 색상 분기 (70%↑ 초록, 50%↑ 노랑, 미만 빨강)

#### AgentDetail.tsx
- commanderApi.getAgent(agentKey) 실시간 호출
- 프로필 + 성과 차트(PerformanceChart) + 최근 보고서 + 토론 참여 이력
- 로딩/오류 상태 처리

#### commanderApi.ts (frontend/src/lib/commanderApi.ts)
```typescript
export const commanderApi = {
  getOrgChart: () => fetch('/api/go100/commander/org-chart').then(r => r.json()),
  getStatus: () => fetch('/api/go100/commander/status').then(r => r.json()),
  getDebates: (limit=20, offset=0) => fetch(`/api/go100/commander/debates?limit=${limit}&offset=${offset}`).then(r => r.json()),
  getPerformance: (period='30d') => fetch(`/api/go100/commander/performance?period=${period}`).then(r => r.json()),
  getCritiques: (limit=20) => fetch(`/api/go100/commander/critiques?limit=${limit}`).then(r => r.json()),
  getAgent: (key: string) => fetch(`/api/go100/commander/agent/${key}`).then(r => r.json()),
}
```
