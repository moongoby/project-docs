4. `check_20d_high_breakout(context)` — 현재 종가 > 20일 최고가 + T4-3 판단
5. `detect_leader_flag(context)` — 급등 후 횡보(플래그) 패턴 + T4-4 판단

- T4-3: 현재 종가 > 20일 최고가
- T4-4: 급등(+10%) 후 횡보 + 거래량 감소 (리더-플래그)

**DESK5 감시 → DESK3 승격 조건**:

- T3-2: X9 업종 동조 (context.sector_sync)

## Task 4: agent_desk2.py (당일 수확) — 완료

**파일 위치**: `/root/kis-autotrade-v4/backend/app/services/go100/agents/agent_desk2.py`

**구현 내용**:
- 클래스명: `DeskTwoAgent`
- 시스템 프롬프트: GO100 DESK2 당일 수확 전문가. 분봉 타이밍. TREND/REVERSAL/BORDER 분류. VP 전환 속도, VWAP, CTE B1-B4.
- V4.1 DESK2 설계서 v2.0 기반

**도구 함수 4개**:
1. `query_minute_ohlcv(context)` — v4_ohlcv_minute 분봉 조회 (78개 = 당일 장 전체)
2. `calc_vwap(context)` — VWAP(거래량 가중 평균가) + 현재가 상대 위치
3. `check_cte_gates(context)` — CTE B1-B4 게이트 평가
4. `calc_vp_momentum(context)` — VP 전환 속도 (최근5분봉 vs 이전5분봉 거래량 + 가격 방향성)

**CTE B1-B4 게이트**:
- B1: 갭업 +1.5% 이상 확인
- B2: 현재가 VWAP 위
- B3: 고점 대비 눌림 -3% 이내
- B4: 현재 거래량 > 평균 × 1.2

**매매 타입 분류**:
- TREND (갭업 추격): B1+B2 필수. TP +5%, SL -2.5%
- REVERSAL (눌림 반등): B2+B3+B4 필수. TP +3%, SL -2%
- BORDER (지지선): 모든 조건. TP +2%, SL -1.5%
- NO_TRADE: CTE 미통과 or VP 모멘텀 WEAK
