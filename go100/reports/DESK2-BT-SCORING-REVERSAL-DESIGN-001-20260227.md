## 1. 분석 배경

TREND-CLASSIFY-SIMULATE-001에서 AND 필터의 치명적 실패가 확인되었다:
- **Recall 0.4%** (280건 중 1건만 포착)
- **REVERSAL 유형 0건 포착** (138건 중 0건)
- 원인: 11개 AND 조건의 곱셈 효과 → 0.3^11 ≈ 0

본 분석은 AND → 스코어링 전환의 효과를 실측하고, 실전 적용 시 기대 성능을 정량화한다.

### A-2. 가중 스코어카드 설계

AUC 기반 가중치를 적용한 연속값 스코어카드를 설계했다:

```
Score = Σ (정규화된_피처값 × AUC_가중치)

피처별 가중치 (상위):
  f3_vol_ratio  : 0.822 (D-1/5일 평균)
  f2_vol_change : 0.757 (5일 거래량 변화)
  f1_news_count : 0.472 (뉴스 수)
  f4_close_pos  : 0.365 (종가 위치)
  r2_strong_pct : 0.294 (강한봉 비율)
  r1_strength   : 0.223 (체결강도)
  R3_obv_turn   : 0.175 (OBV 반전)
  r4_vol_accel  : 0.003 (거래량 가속도) ← 사실상 0
  R6_rvol       : 0.000 (RVOL) ← 완전히 0
```

| 5일 vol 변화 | 0.910 | 0.857 | TREND가 더 강함 |

**핵심 발견: REVERSAL은 실시간 체결 데이터(R1, R2)로 판별이 거의 불가능하다.**

이것이 의미하는 것: **REVERSAL 발굴은 사전(D-1) 데이터에 의존해야 하며, 실시간 진입 시그널은 "딥 확인 후 반전 감지"로 별도 설계해야 한다.**

### A-4. 14일 전체 종목 스캔 시뮬레이션

560개 종목/일 전체에 스코어링을 적용한 실전 시뮬레이션:

| 지표 | AND 필터 | 스코어링 | 변화 |
|------|----------|----------|------|
| **Recall** | 0.4% | **99.6%** | **+99.2%p** |
| **Precision** | 25.0% | 4.4% | -20.6%p |
| **F1** | 0.7 | 8.4 | **+7.7** |
| TREND 포착 | 1/88 (1.1%) | **88/88 (100%)** | +98.9%p |
| REVERSAL 포착 | 0/138 (0%) | **137/138 (99.3%)** | +99.3%p |

#### Precision 하락의 원인: 베이스 레이트 문제

TOP vs CTRL (50:50 비율)에서 Precision 81.8%가 실전 스캔(TOP 3.6%)에서 4.4%로 떨어지는 것은 **베이즈 정리의 필연**이다:

```
실전 Precision = (Sensitivity × Prevalence) /
                 (Sensitivity × Prevalence + FPR × (1 - Prevalence))
               = (0.929 × 0.036) / (0.929 × 0.036 + 0.207 × 0.964)
               = 0.033 / 0.233
               = 14.4% (이론값)
```

실측 4.4%가 이론 14.4%보다 낮은 이유: CTRL 280건은 "TOP 20 제외 + 거래량 5만+ + 봉수 60+" 조건으로 선별된 **상대적으로 구별하기 쉬운** 대조군이었다. 실제 시장에는 TOP에 가깝지만 TOP은 아닌 "경계 종목"이 훨씬 많다.

## 2. 종합 진단

### 2.1 스코어링 전환의 효과와 한계

**효과 (검증됨)**:
- Recall: 0.4% → 99.6% (TOP 20을 거의 전부 포착)
- REVERSAL 포착: 0% → 99.3% (가장 수익 높은 유형 포착 가능)
- F1: 0.7 → 8.4 (12배 개선, F1 기준)

**한계 (발견됨)**:
- 실전 Precision 4.4%: 일별 ~450종목 통과 → 그 중 TOP은 20개
- 이것은 "필터"가 아니라 "후보군 선정"에 가까움
- 추가 2차 필터 또는 랭킹이 필요

### 2.2 판별력 없는 조건의 제거

| 조건 | 판별력 | AND 필터 FN 기여 | 판단 |
|------|--------|------------------|------|
| R4 vol_accel | 0.0% | 52% (최대 병목) | **즉시 제거** |
| R6 RVOL | 0.0% | 25% | **즉시 제거** |
| F6 turnover | 0.7% | 0% (거의 전원 통과) | 유지하되 가중치 0 |

**R4와 R6는 "판별력 0인데 FN 77%를 유발한" 최악의 조건**이었다.

### 2.3 실전 적용을 위한 2단계 아키텍처 제안

현재 시뮬레이션 결과를 바탕으로 다음 아키텍처를 제안한다:

```
[1단계: 스코어 기반 후보군] 560종목 → ~50종목
  - D-1 데이터 기반 사전 스코어
  - 커트라인: 상위 ~10% (≈ 50~60종목)
  - 핵심 변수: F3(vol 비율), F2(vol 변화), F1(뉴스), F4(종가위치)

[2단계: 실시간 유형 판별 + 진입]
  if 첫 5분 dip < 1%:
      → TREND로 분류
      → 즉시 진입 (시가+1~3분)
      → X3 추세추종 청산 (목표 +7%)
  elif 첫 5분 dip ≥ 2%:
      → REVERSAL 후보
      → OBV 바닥 + 체결강도 반전(0.3→0.7) 확인 시 진입
      → X1 고정 +3% 청산
  else:
      → BORDER, 관망 또는 소량 진입
```

이 아키텍처의 장점:
1. **1단계에서 10배 필터링**: 560 → 50 (Recall ~95% 유지 가능)
2. **2단계에서 유형별 최적 전략**: TREND/REVERSAL 분리 운영
3. **실시간 부하 최소화**: 50종목만 분봉 모니터링

### 2.4 REVERSAL 전용 발굴의 핵심

REVERSAL 종목의 실시간 판별력이 거의 0이므로, 발굴 전략은 다음과 같이 구조화해야 한다:

1. **사전 필터(D-1)로 REVERSAL 후보 선정** (뉴스 + 거래량 급증 + 갭하락 예상)
2. **09:00~09:10 관찰**: dip ≥ 2% 확인
3. **09:10~09:15 진입 시그널**: 체결강도 0.3→0.7 전환 OR OBV 바닥 후 3분 상승
4. **진입 즉시 +3% 지정가 매도 설정**

REVERSAL은 추세 지속이 4.3분에 불과하므로, **진입 후 3~5분 내에 목표가 도달 여부가 결정**된다.

### 2.5 분석가 소견

> **AND 필터에서 스코어링으로의 전환은 "발굴 불가"에서 "발굴 가능"으로의 질적 전환이다.**
>
> 그러나 이번 분석에서 가장 중요한 발견은 스코어링 자체보다, **R4(거래량 가속도)와 R6(RVOL)가 판별력 0이면서 FN의 77%를 유발했다**는 사실이다. 이것은 "직관적으로 맞을 것 같은 조건"과 "실제로 작동하는 조건"의 괴리를 보여준다.
>
> 실전 Precision 4.4%는 아직 불충분하지만, 이것을 1단계 후보군 선정으로 활용하고 2단계 실시간 유형 판별을 추가하면 일일 5~10종목 수준으로 좁힐 수 있다. 핵심은 **"조건의 수가 아니라 조건의 질"**이며, AUC 0.911을 달성하는 D-1 거래량 비율 하나가 AND 필터 11개 전체보다 유용하다.
>
> 다음 단계로는:
> 1. 2단계 실시간 필터의 유형별 시뮬레이션
> 2. 1단계 커트라인의 일별 최적화 (상위 N% 동적 조정)
> 3. REVERSAL 진입 시그널(체결강도 반전)의 정밀 백테스트
>
> 를 권고한다.
