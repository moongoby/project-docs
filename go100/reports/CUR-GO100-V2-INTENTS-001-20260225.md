## 2. 수정 내역

### 2.1 help_flow.py — 버그 수정

**원인**: `client.call_help_reply()` 메서드가 LLMClient에 존재하지 않음 (call_understand, call_design, call_reply만 존재)

**수정**: `call_reply()`에 help 컨텍스트를 전달하는 방식으로 변경

```python
# Before (에러)
reply = await client.call_help_reply(knowledge=knowledge, user_message=user_message)

# After (수정)
reply = await client.call_reply({
    "action": "help_reply",
    "knowledge": knowledge[:3000],
    "user_message": user_message,
    "instruction": "위 지식을 바탕으로 사용자의 질문에 친근한 한국어로 답변하세요.",
})
```

### 2.2 stock_info — 종목 정보 조회

- `stock_universe` 테이블에서 종목명 ILIKE 검색
- `ohlcv_daily`에서 최근 5일 종가/거래량 조회
- 전일대비 등락률 계산
- 종목명 미지정 시 시가총액 상위 5개 표시

**데이터 흐름**: 사용자 메시지 → 종목명 추출 → DB 조회 → 포맷팅 → 응답

### 2.3 market_briefing — 시장 브리핑

- `v4_market_regime_daily` 최신 레짐 데이터 (레짐/점수/MA정렬/VKOSPI/외국인)
- `index_daily`에서 KOSPI(0001)/KOSDAQ(1001) 최근 종가
- 레짐 라벨 한글화 (강한 상승 🟢 ~ 강한 하락 🔴)

### 2.4 portfolio_status — 포트폴리오 현황

- `go100_strategy_cards`에서 사용자 활성 카드 최대 10개 조회
- 카드별 상태, 백테스트 수익률/MDD/샤프비율, 배정금액 표시
- 실거래/백테스트 완료 카드 수 요약
- 카드 없을 시 전략 생성 안내 메시지
