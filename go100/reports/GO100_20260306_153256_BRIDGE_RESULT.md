**추가된 엔드포인트 4개**:

#### GET /data-status
```
응답 구조:
{
  "sources": [5개 소스 상태],
  "auto_healer_logs": [최근 20건],
  "coverage": {
    "universe_count": N,
    "covered_today": N,
    "coverage_pct": 0.0~100.0,
    "missing_stocks": [...]
  },
  "checked_at": "ISO timestamp"
}
```

구현 로직:
- pykrx: MAX(trade_date) FROM daily_stock_data → 0일 전=GREEN, 1일=YELLOW, 2일+=RED
- KIS/FDR/DART: MAX(collected_at) FROM go100_data_collection_log WHERE source=X → 60분=GREEN, 360분=YELLOW, 이후=RED
- 뉴스: MAX(published_at) FROM go100_news_items → 6h=GREEN, 24h=YELLOW, 이후=RED
- Auto-Healer: go100_error_log WHERE error_type='auto_heal' ORDER BY created_at DESC LIMIT 20
- 커버리지: go100_stock_universe LEFT JOIN daily_stock_data → 누락 종목 최대 50개

#### GET /feature-status
```
응답 구조:
{
  "parquet_files": [파일 목록],
  "total_size_mb": N,
  "total_rows": N,
  "file_count": N,
  "feature_importance": [Top15],
  "column_stats": [컬럼 통계],
  "checked_at": "ISO timestamp"
}
```

구현 로직:
- _FEATURES_V2_DIR.glob("*.parquet") → 파일명, 크기, mtime
- batch_build_v2_result.json → total_rows
- go100_brain_v3_clf_unified_metadata.json → feature_importance_top15
- go100_brain_v2_feature_stats.json → feature_stats (mean, std, missing_pct, min, max)

#### GET /model-status
```
응답 구조:
{
  "models": [V2 정보, V3 정보],
  "history": [학습 이력 타임라인],
  "checked_at": "ISO timestamp"
}
```

구현 로직:
- go100_brain_v2_metadata.json + go100_brain_v2_train_result.json → V2 정보
- go100_brain_v3_clf_unified_metadata.json + go100_brain_v3_train_result.json → V3 정보
- fold_results[-1].confusion_matrix → TP/FP/TN/FN
- Path.stat().st_mtime → 파일 크기 및 수정일
- active 필드: V2=True(하드코딩), V3=metadata.json의 active 값

#### POST /activate-model
```
요청: {"version": "v3"}
응답: {"success": bool, "version": str, "stdout": str, "stderr": str, "activated_at": str}
```

구현 로직:
- user_id != 2 → 403 Forbidden
- version not in ("v2", "v3") → 400 Bad Request
- scripts/go100/activate_v3_model.py --confirm subprocess 실행
- asyncio.run_in_executor (non-blocking)
- timeout=60초
