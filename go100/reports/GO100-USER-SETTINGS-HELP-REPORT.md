# 백억이 사용자 설정 안내 반영 보고서

**작성일:** 2026-02-24  
**관련:** CUR-GO100-HELP-FLOW (채팅 위젯 화면/사용법 도움)

---

## 1. 문제

**기본적인 사용자 설정 안내를 백억이가 하지 못하는 상태였음.**

- 사용자가 채팅 위젯에서 “설정 어디서 해요?”, “위험 허용도가 뭐예요?”, “리스크 설정 어떻게 바꿔요?” 등으로 물어도, 당시 지식(화면·FAQ)에 **설정 화면·위험 허용도·리스크 설정**에 대한 구체 안내가 없었음.
- 설정 화면(screens.md)에는 “위험 허용도, 리스크 설정 등 사용자 설정” 한 줄만 있어, **어디서 어떻게 하는지** 답하기 어려웠음.

---

## 2. 반영 내용

### 2.1 지식 보강 (docs/go100/user-guide)

| 파일 | 변경 내용 |
|------|------------|
| **screens.md** | **설정 (/go100/settings)** 문단 확장: 위험 허용도(5단계), 리스크 설정 항목(포지션 비율·최대 종목 수·손절 비율), 미리보기, 면책 이력, 계좌 관리 안내를 구체적으로 기술. |
| **faq.md** | **사용자 설정** 섹션 추가: Q. 설정은 어디서 해요? / 위험 허용도가 뭐예요? / 리스크 설정은 어떻게 바꿔요? / 계좌는 어디서 연결·확인해요? — 각각 답변 문장 추가. |

이제 채팅 위젯에서 **help**로 분기된 질문에 대해, 위 지식을 참고해 “설정 위치·위험 허용도·리스크 설정·계좌” 안내가 가능함.

### 2.2 라우터 키워드 추가 (intent_router.py)

- **HELP_KEYWORDS**에 추가: `설정`, `설정 어디`, `위험 허용도`, `리스크 설정`, `계좌 연결`, `계좌 관리`
- **HELP_PATTERN**에 추가: `설정`, `위험\s*허용`, `리스크`

설정·위험 허용도·리스크 관련 질문이 **help**로 분류되어, 사용법 도움 흐름(HelpFlow)으로 처리되도록 함.

---

## 3. 반영 후 동작

- **채팅 위젯**에서 “설정 어디서 해요?”, “위험 허용도 뭐야?”, “리스크 설정 어떻게 해요?” 등으로 질문 시:
  1. `source=widget` + 위 키워드/패턴으로 **help** 분기
  2. HelpFlow가 **screens.md + faq.md**에서 설정·위험 허용도·리스크·계좌 안내 문장을 참고
  3. 백억이가 **설정 메뉴 위치, 위험 허용도 의미, 리스크 설정 방법, 계좌 확인 위치** 등을 안내

- **전체화면 채팅**은 기존대로 전략 파이프라인만 사용하며, 변경 없음.

---

## 4. 참고

- 지식은 **help_knowledge**에서 로드되며, 서버 재시작 후 갱신된 screens/faq가 반영됨.
- 설정 화면 실제 UI는 `frontend/src/app/(protected)/go100/settings/page.tsx`, `SettingsRiskSection.tsx` 기준으로 기술함.

---

**요약:** 기본적인 사용자 설정 안내(설정 위치, 위험 허용도, 리스크 설정, 계좌)가 백억이가 못하던 문제를, 지식(screens·faq) 보강과 라우터 키워드 추가로 반영했고, 위젯에서 해당 질문 시 안내 가능하도록 함.

---

## 5. 후속 보강 (실거래 메뉴·계좌 등록)

**문제:** "실거래 메뉴가 어디있어?"에 "실거래 메뉴에 있어요"처럼 **순환 답변**이 나오는 사례가 있음. "계좌등록 어디서해"에 대해 실거래 메뉴를 말해줘도, 실거래 메뉴 **위치**를 구체적으로 안 내주면 같은 문제 발생.

**반영:**  
- **screens.md** 실거래 문단: "실거래 메뉴 위치: **사이드바(또는 상단/메뉴)에 '실거래' 항목**이 있습니다. 클릭하면 /go100/live-trading 로 이동" 명시.  
- **faq.md**에 **계좌 등록·실거래 메뉴** 섹션 추가:  
  - Q. 계좌 등록(계좌등록)은 어디서 해요? → 실거래 메뉴에서 실계좌 연동 + **사이드바/상단 메뉴에 "실거래"** 클릭해서 진입.  
  - Q. 실거래 메뉴가 어디 있어요? → **사이드바(또는 상단 메뉴)에 "실거래"** 항목, 클릭 시 /go100/live-trading.

이후 위젯에서 "실거래 메뉴가 어디있어?", "계좌등록 어디서해?" 질문 시 위 문장을 참고해 **위치를 구체적으로** 안내하도록 함.

## 6. 전체 메뉴 설명 반영 (시스템 모든 메뉴)

**목표:** 우리 시스템의 **모든 메뉴**에 대해 백억이가 "어디 있어?", "뭐 하는 메뉴야?"에 답할 수 있도록 지식·라우터 반영 및 적용.

**반영 내용:**

| 구분 | 내용 |
|------|------|
| **screens.md** | 전면 정리. **메뉴가 나오는 위치**(메인 사이드바 vs GO100 사이드바) 설명 후, **메인 메뉴 11개**(대시보드, 포트폴리오, 계좌관리, 자동매매, 백테스트, 리포트, 전략카드, 백억이, 알림, 모니터링, 설정) + **GO100 메뉴 7개**(GO100 대시, AI 대화, 내 전략, 마켓플레이스, 모의거래, 실거래, 설정) 각각 **위치(어디 클릭)·경로·역할** 기술. |
| **faq.md** | **모든 메뉴 위치·역할** 표 추가(메뉴명, 어디서 보이나요, 경로, 하는 일). 메뉴별 "어디 있어?" 빠른 답(포트폴리오, 계좌관리, 자동매매, 리포트, 전략카드, 알림, 모니터링, 마켓플레이스, 내 전략 등). 계좌·설정·실거래·채팅 FAQ 유지. |
| **intent_router.py** | HELP_KEYWORDS에 **포트폴리오, 계좌관리, 자동매매, 리포트, 전략카드, 알림, 모니터링, 마켓플레이스, 내 전략, 대시보드, go100** 추가. |
| **help_knowledge.py** | 지식 파일(screens.md, faq.md) **수정 시 캐시 자동 갱신**하도록 mtime 기반 무효화 적용. 서버 재시작 없이 문서 수정만으로 반영. |

**적용:** 채팅 위젯에서 "포트폴리오 어디있어?", "마켓플레이스 메뉴 뭐야?", "리포트 어디서 봐?" 등 **모든 메뉴** 질문 시 help 분기 후 위 지식으로 안내 가능. 지식 수정 시 다음 요청부터 새 내용 로드.
