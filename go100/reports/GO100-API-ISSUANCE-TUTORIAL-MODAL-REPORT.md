# 증권사 API 발급 튜토리얼 모달 검토·설계 보고서

**작성일**: 2026-02-24  
**대상**: 계좌 등록 페이지(`/accounts`) — [https://go100.newtalk.kr/accounts](https://go100.newtalk.kr/accounts)  
**목적**: 증권사 API 발급 안내를 “간단한 텍스트”에서 **모달형 튜토리얼**로 개선하여 사용자가 단계별로 따라 할 수 있게 함.

---

## 1. 전제 정리

- **실제 사용 메뉴**: GO100 전용 사이드바는 사용하지 않음. 계좌 등록·관리는 **메인 계좌관리 페이지 `/accounts`** 에서 진행.
- **개선 대상**: 동일한 `/accounts` 페이지에서 띄우는 **「새 계좌 등록」 모달** 내 API 발급 안내 방식.

---

## 2. 현황 검토

### 2.1 계좌 등록 플로우 (AddAccountModal)

| 단계 | 내용 | 비고 |
|------|------|------|
| STEP 1 | 브로커 선택(KIS / KIWOOM), 계좌 유형(실전 / 모의) | 화면 제공됨 |
| STEP 2 | 계좌번호, 별명, 일일 주문 한도 | 화면 제공됨 |
| STEP 3 | **API 연동** — 앱 키·앱 시크릿 입력 | 여기서 발급 안내 필요 |

### 2.2 현재 API 발급 안내 (STEP 3)

- **위치**: STEP 3 하단, 앱 키/시크릿 입력란 아래.
- **형태**: **「📎 발급 방법 보기」** 버튼 클릭 시 접었다 펼치는 텍스트 블록(`<pre>`).
- **내용** (브로커별):
  - **KIS**:  
    `1. KIS 개발자센터(developers.koreainvestment.com) 접속`  
    `2. 로그인 → 앱 관리 → 앱 등록`  
    `3. 발급된 앱키와 시크릿을 복사하여 입력`
  - **KIWOOM**:  
    `1. 키움 Open API+ 개발자센터 접속`  
    `2. 회원가입 후 API 신청`  
    `3. 발급된 키를 복사하여 입력`

**한계 요약**

| 항목 | 내용 |
|------|------|
| **튜토리얼 아님** | 단순 3줄 텍스트. 단계별로 “지금 무엇을 할지”가 한 화면에 나열되어 있어, 실제 화면과 대응되는 **순차 안내**가 아님. |
| **링크 없음** | 개발자센터 URL이 텍스트로만 있음. 클릭 가능한 **바로가기 링크** 없음. (KIS 실제 포털: `https://apiportal.koreainvestment.com`) |
| **기본 비노출** | “발급 방법 보기”를 눌러야만 보임. STEP 3 진입 시 **먼저 보여줄 수 있는 진입점**이 없음. |
| **모의/실전 구분** | KIS 앱 등록 시 “모의투자 전용” 등 선택이 있는데, 이에 대한 안내 없음. |
| **도메인 불일치** | 코드 상 `developers.koreainvestment.com` — 실제 오픈API 포털은 `apiportal.koreainvestment.com` 사용. |

## 3. 개선 방향: 모달형 튜토리얼

### 3.1 목표

- **모달 형태**로 “증권사 API 발급 절차”를 **단계별(튜토리얼)** 로 안내.
- 사용자가 **다음/이전**으로 단계를 넘기며 읽을 수 있고, **개발자센터 링크**로 바로 이동 가능.
- 튜토리얼 종료 시 **계좌 등록 모달 STEP 3(API 입력 화면)** 으로 복귀하여 앱키·시크릿 입력 가능.

### 3.2 진입점

- **STEP 3(API 연동)** 에서 기존 “📎 발급 방법 보기”를 **「API 발급 절차 안내」** 등으로 변경.
- 클릭 시 **발급 절차 전용 모달**을 띄움. (기존 접기 텍스트는 제거하거나, “간단 요약”만 남길 수 있음.)

### 3.3 튜토리얼 모달 구성 제안

**공통**

- 제목: 예) **「{브로커명} API 발급 절차」**
- 단계 인디케이터: 1 / 2 / 3 / 4 등 (현재 단계 강조).
- **이전** / **다음** 버튼으로 단계 이동.
- 마지막 단계에서 **「확인」** 또는 **「입력 화면으로」** 클릭 시 모달 닫고 STEP 3 유지.

**KIS (한국투자증권) 예시**

| 단계 | 제목 | 내용 |
|------|------|------|
| 1 | 개발자센터 접속 | 한국투자증권 오픈API 개발자센터에 접속합니다. 아래 버튼으로 새 탭에서 열 수 있습니다. → **[개발자센터 열기](https://apiportal.koreainvestment.com)** |
| 2 | 로그인 및 앱 등록 | 로그인 후 상단 메뉴에서 **Application(앱 관리)** → **앱 등록**을 선택합니다. 모의투자만 사용할 경우 ‘모의투자 전용’을 선택하세요. |
| 3 | 앱키·시크릿 확인 | 앱 등록이 완료되면 **APP_KEY(Client ID)** 와 **APP_SECRET(Client Secret)** 이 발급됩니다. 앱 목록에서 해당 앱을 선택해 두 값을 확인하세요. |
| 4 | GO100에 입력 | 발급된 **앱 키**와 **앱 시크릿**을 복사해, 아래 입력란에 붙여넣기 한 뒤 **계좌 등록**을 완료하세요. |

**KIWOOM (키움증권) 예시**

| 단계 | 제목 | 내용 |
|------|------|------|
| 1 | 개발자센터 접속 | 키움 Open API+ 개발자센터에 접속 후 회원가입·로그인합니다. (필요 시 링크 제공) |
| 2 | API 신청 | 회원가입이 완료되면 API 신청을 진행합니다. |
| 3 | 키 확인 | 발급된 키를 복사해 두세요. |
| 4 | GO100에 입력 | 복사한 키를 아래 입력란에 붙여넣기 한 뒤 **계좌 등록**을 완료하세요. |

(KIWOOM 개발자센터 정확 URL은 사이트 확인 후 동일한 방식으로 “열기” 링크 추가 권장.)

### 3.4 UI/UX 요구사항

- **한 모달 안에서 단계만 전환**: 별도 페이지 이동 없이, 같은 모달 내에서 텍스트/안내만 1 → 2 → 3 → 4 로 변경.
- **진행 표시**: 상단 또는 제목 근처에 “1 / 4”, “2 / 4” 형태 또는 프로그레스 바.
- **외부 링크**: `target="_blank"`, `rel="noopener noreferrer"` 적용.
- **접근성**: 단계 제목을 헤딩으로 두어 스크린 리더·키보드 탐색에 유리하게 구성.

## 4. 구현 관점 정리

### 4.1 컴포넌트

- **신규**: `ApiIssuanceTutorialModal` (또는 `BrokerApiTutorialModal`)  
  - Props: `open`, `onOpenChange`, `brokerType: "KIS" | "KIWOOM"`  
  - 내부: 단계 배열(broker별), 현재 step state, 이전/다음/확인 버튼, 단계별 내용·링크 렌더링.

### 4.2 AddAccountModal 연동

- STEP 3에서 “📎 발급 방법 보기”를 **「API 발급 절차 안내」** 버튼(또는 링크)으로 교체.
- 클릭 시 `setTutorialOpen(true)` 등으로 `ApiIssuanceTutorialModal` 오픈.
- 튜토리얼 모달은 `brokerType={broker_type}` 전달해, KIS/KIWOOM에 따라 다른 단계 문구·링크 표시.

### 4.3 URL 수정

- KIS 개발자센터: 코드 및 안내 문구를 **`https://apiportal.koreainvestment.com`** 으로 통일.

## 5. 요약

| 구분 | 현재 | 제안 |
|------|------|------|
| **사용 화면** | `/accounts` (계좌관리) 사용. GO100 전용 사이드바는 사용하지 않음. | 유지. |
| **API 안내 형태** | STEP 3 내 접기 텍스트 3줄. | **모달형 튜토리얼**: 단계별(1→2→3→4) 안내 + 이전/다음 + 개발자센터 링크. |
| **진입** | “발급 방법 보기” 클릭 시 펼침. | “API 발급 절차 안내” 클릭 시 **튜토리얼 전용 모달** 오픈. |
| **링크** | 없음. | KIS: `https://apiportal.koreainvestment.com` 등 **바로가기 버튼/링크** 제공. |
| **도메인** | developers.koreainvestment.com | apiportal.koreainvestment.com 으로 수정. |

이 설계대로 구현하면, 계좌 등록 시 증권사 API 발급 절차를 **모달형 튜토리얼**로 안내할 수 있어 사용자가 단계별로 따라 하기 쉬워집니다.
