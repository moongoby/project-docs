### 3단계: API 함수명 확인

지시서에 기재된 `go100Api.getPaperTradeDetail` 및 `go100Api.getLiveTradeDetail` 함수명은
`/root/kis-autotrade-v4/frontend/src/go100/api/go100Api.ts` 에 존재하지 않음.

실제 동등 함수:
| 지시서 명세 | 실제 구현 함수 | API 엔드포인트 |
|---|---|---|
| `getPaperTradeDetail(id)` | `getPaperStatus(id)` | `GET /api/go100/paper-trading/{id}` |
| `getLiveTradeDetail(id)` | `getLiveStatus(id)` | `GET /api/go100/live-trading/{id}` |

Page route 파일은 해당 함수로 포트폴리오 존재 확인 후 `notFound()` 처리 — 이것이 상세 페이지의 올바른 패턴. 실제 상세 데이터(거래내역, 포지션, 스냅샷)는 내부 컴포넌트의 hooks(`usePaperDetail`, `useLiveDetail`)가 추가 API 호출로 가져옴.
