# GO100 회원가입 후 계좌·API 등록 UX 연구 보고서

**작성일**: 2026-02-24  
**목적**: 회원가입 후 계좌등록·API 발급을 사용자가 쉽고 편하게 등록·관리할 수 있도록 개선 방안 연구 및 제안

---

## 1. 현황 요약

### 1.1 현재 사용자 여정 (문서 기준)

- **1단계**: 가입·로그인  
- **2단계**: **계좌 연결** — 메인 사이드바 **「계좌관리」**(/accounts)에서 증권사 API 키(앱키·시크릿) 등록  
- **3단계 이후**: 백억이 전략 만들기 → 백테스트 → 모의거래 → 실거래  

실거래를 하려면 **반드시 계좌 등록(API 키 발급·연동)** 이 선행되어야 함.

### 1.2 계좌·API 등록이 어려워지는 요인

| 구분 | 내용 |
|------|------|
| **진입 경로** | GO100 전용 사이드바에는 **「계좌관리」 메뉴가 없음**. 대시보드, AI 대화, 내 전략, 마켓플레이스, 모의거래, 실거래, 설정만 노출됨. GO100만 사용하는 사용자는 `/accounts`를 찾기 어려움. |
| **API 발급 인지** | KIS 기준 앱키·시크릿은 **한국투자증권 오픈API 개발자센터(앱 등록)** 에서 발급. 일반 사용자는 “개발자센터”, “앱 등록”, “APP_KEY” 용어에 익숙하지 않음. |
| **발급 절차** | 개발자센터 회원가입 → (모의투자 시) 모의투자 신청 → 앱 등록 → 키 복사 → 서비스에 입력까지 단계가 많고, 앱 등록 시 “이용 권한”, “이용 목적” 등 선택이 필요함. |
| **가이드 노출** | 계좌 추가 모달 3단계에서 “📎 발급 방법 보기”로 **접을 수 있는 텍스트**만 제공. 링크 없이 `developers.koreainvestment.com` 도메인만 언급(실제 포털은 `apiportal.koreainvestment.com`). |
| **실거래·설정과의 연결** | 실거래 페이지는 “실거래 포트폴리오가 없습니다”만 표시하고, **계좌 미등록 시 “먼저 계좌를 등록하세요” + 계좌관리 링크**가 없음. GO100 설정의 “계좌 관리” 섹션은 안내 문구만 있고 **클릭 가능한 계좌관리 링크가 없음**. |

## 2. 코드/UI 기준 현황

### 2.1 계좌 등록 진입점

- **계좌관리 페이지**: `/accounts` (메인 앱)
- **메인 사이드바**: `Sidebar.tsx` — 「계좌관리」 링크 있음 (`/accounts`)
- **GO100 레이아웃**: `Go100Layout` → `Go100Sidebar` 만 사용. **GO100 사이드바에는 `/accounts` 항목 없음.**

```18:26:frontend/src/go100/components/Go100Sidebar.tsx
const navItems = [
  { href: "/go100", label: "대시보드", icon: LayoutDashboard },
  { href: "/go100/chat", label: "AI 대화", icon: MessageSquare },
  { href: "/go100/strategies", label: "내 전략", icon: Layers },
  { href: "/go100/store", label: "마켓플레이스", icon: Store },
  { href: "/go100/paper-trading", label: "모의거래", icon: FlaskConical },
  { href: "/go100/live-trading", label: "실거래", icon: TrendingUp },
  { href: "/go100/settings", label: "설정", icon: Settings },
];
```

### 2.2 계좌 추가 플로우 (AddAccountModal)

- 3단계: **브로커 선택 → 계좌 정보 → API 연동**
- API 연동 단계에서 앱키·시크릿 입력, “발급 방법 보기” 접기/펼치기 가이드 제공
- KIS 가이드 문구: `developers.koreainvestment.com` (실제 개발자 포털 URL과 상이할 수 있음)

### 2.3 실거래·설정 페이지

- **실거래** (`/go100/live-trading`): 포트폴리오 목록만 표시. 계좌 0개/실거래 0개인 경우를 위한 **“계좌 먼저 등록” CTA 없음**.
- **GO100 설정** (`/go100/settings`): “연결된 증권 계좌는 계좌관리 메뉴에서 확인할 수 있습니다” 문구만 있고 **링크 없음**.

## 3. KIS API 발급 절차 (참고)

- **포털**: https://apiportal.koreainvestment.com/
- **준비**: 개발자센터 회원가입, (모의 시) MTS/HTS 모의투자 신청, 한국투자증권 계좌
- **절차**: [Application] → 앱 등록 → 앱 이름·설명, 모의/실전, 이용 권한·목적 선택 → 등록 후 **APP_KEY(Client ID), APP_SECRET(Client Secret)** 확인
- **보안**: 키 외부 공개 금지, 환경변수 등 분리 관리 권장

## 4. 개선 제안 (쉽고 편한 등록·관리)

### 4.1 진입 경로 개선 (우선 적용 권장)

| 제안 | 설명 | 구현 포인트 |
|------|------|-------------|
| **GO100 사이드바에 「계좌관리」 추가** | GO100 사용자도 한 번에 계좌 등록/관리 페이지로 이동 가능하게 함. | `Go100Sidebar.tsx`의 `navItems`에 `{ href: "/accounts", label: "계좌관리", icon: Wallet }` 추가 (하단 또는 설정 위 등 일관된 위치). |
| **실거래 페이지 빈 상태 시 CTA** | 실거래 포트폴리오가 없을 때, “계좌를 먼저 연결하세요” 문구 + **「계좌 등록하기」 버튼** → `/accounts` 또는 계좌 추가 모달로 유도. | `live-trading/page.tsx`에서 `list.length === 0`일 때 계좌 존재 여부에 따라 “계좌 연결 후 실거래를 시작하세요” + Link to `/accounts` 또는 인라인 계좌 추가 유도. |
| **GO100 설정의 계좌 섹션에 링크** | “계좌관리 메뉴에서 확인” 문구를 **「계좌관리에서 확인하기」 링크**로 변경. | `go100/settings/page.tsx` 계좌 관리 섹션에 `<Link href="/accounts">계좌관리에서 확인하기</Link>` 추가. |

### 4.2 API 발급 가이드 강화

| 제안 | 설명 | 구현 포인트 |
|------|------|-------------|
| **정확한 URL 및 단계별 링크** | KIS: `https://apiportal.koreainvestment.com/` 등 **실제 포털 URL** 제공. “1단계: 개발자센터 접속”에 **새 탭 링크** 배치. | `AddAccountModal.tsx` KIS_GUIDE 영역에 `<a href="https://apiportal.koreainvestment.com/" target="_blank" rel="noopener">개발자센터 바로가기</a>` 등. |
| **발급 방법을 기본 펼침** | “발급 방법 보기”를 **기본 펼친 상태**로 두어, 처음부터 단계를 읽을 수 있게 함. | `guideOpen` 초기값을 `true` 또는 STEP 3 진입 시 한 번 `true`로 설정. |
| **모의/실전 구분 안내** | “모의투자만 사용할 경우 모의투자 전용 체크” 등, 앱 등록 시 선택과 서비스의 실전/모의 선택이 일치하도록 한 줄 안내. | KIS_GUIDE 문자열 또는 그 아래에 짧은 문장 추가. |

### 4.3 온보딩·빈 상태 일관화

| 제안 | 설명 | 구현 포인트 |
|------|------|-------------|
| **GO100 첫 진입 시 계좌 유무 안내** | GO100 대시보드에서 계좌 0개일 때, “실거래를 위해 계좌를 연결해 보세요” + **계좌 등록 링크/버튼** 노출. | `DashboardContent.tsx`에 계좌 목록 조회(기존 API 활용) 후 0개면 배너/카드로 CTA 표시. |
| **실거래 시작 플로우 명시** | 실거래 페이지 상단 또는 빈 상태에 “1) 계좌 연결 2) 전략 선택 3) 실거래 시작” 같은 **짧은 3단계 문구**로 단서 제공. | `live-trading/page.tsx` 상단 또는 empty state에 번호 리스트 형태 안내. |

### 4.4 계좌 관리 편의 (유지·확장)

| 제안 | 설명 | 구현 포인트 |
|------|------|-------------|
| **계좌 카드에서 “API 키 재설정”** | 이미 `AccountCard`에 “API키 재설정” 노출됨. 계좌별 수정/재발급 경로가 명확하도록 유지. | 기존 동작 유지. 필요 시 툴팁으로 “개발자센터에서 새 키 발급 후 여기서 변경” 안내. |
| **에러 메시지 개선** | API 키 오류(인증 실패 등) 시 “앱키·시크릿을 확인하거나 개발자센터에서 키 상태를 확인해 주세요” 등 **다음 행동**을 제시. | 백엔드/프론트 공통 에러 메시지 또는 코드별 사용자용 문구 정리. |

## 5. 권장 적용 순서

1. **즉시**: GO100 사이드바에 「계좌관리」 링크 추가, GO100 설정 계좌 섹션에 `/accounts` 링크 추가.  
2. **단기**: 실거래 페이지 빈 상태 시 “계좌 먼저 등록” CTA 및 (선택) 계좌 0개일 때 대시보드 배너.  
3. **단기**: AddAccountModal — KIS 개발자센터 정확한 URL, “발급 방법” 기본 펼침, 모의/실전 한 줄 안내.  
4. **중기**: 실거래 페이지 “시작하기 3단계” 안내, API 오류 시 사용자 행동 유도 문구 정리.

---

## 6. 정리

- **어려움의 핵심**: GO100 사용자가 **계좌 등록 화면(/accounts)을 찾기 어렵고**, **API 발급이 외부 포털·용어에 의존**하는 구조.  
- **개선 방향**:  
  - GO100 내에서 **계좌관리 진입을 한 곳에서 확실히** 제공(사이드바 + 설정 링크 + 실거래/대시보드 빈 상태 CTA).  
  - **발급 가이드**는 정확한 URL, 기본 펼침, 모의/실전 안내로 보강.  
  - **실거래 시작**을 “계좌 연결 → 전략 선택 → 실거래” 순서로 짧게 노출해 단계를 인지시키기.

위 순서대로 적용하면 회원가입 후 계좌등록·API 발급을 **찾기 쉽고, 따라 하기 쉽게** 정리할 수 있습니다.
