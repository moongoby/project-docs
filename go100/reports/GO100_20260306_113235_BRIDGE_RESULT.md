### [7] URL 공개 접근 확인

**문제 발견**: Next.js 프로덕션 서버가 middleware matcher로 인해 /manager/* 경로를 가로채서 404 반환.

```bash
curl -s -o /dev/null -w "%{http_code}" https://go100.newtalk.kr/manager/snapshot.json
# → 404
```

**근본 원인 분석**:
- Next.js middleware.ts의 matcher: `/((?!_next/static|_next/image|favicon.ico).*)`
- 이 패턴이 `/manager/*` 도 매칭 → 미들웨어가 요청을 가로채서 App Router로 라우팅
- App Router에서 `/manager/` 라우트 없음 → 404
- `manifest.json`은 Next.js 내장 핸들러가 처리하므로 정상 작동

**해결책 적용**:
1. middleware.ts matcher에 `manager` 제외 추가:
   ```typescript
   // 변경 전
   matcher: ["/((?!_next/static|_next/image|favicon.ico).*)"]
   // 변경 후
   matcher: ["/((?!_next/static|_next/image|favicon.ico|manager).*)"]
   ```
2. nginx `/manager/` location 블록 추가 (install_manager_snapshot.sh에서 처리)

**현재 상태**: 코드 변경 완료. root에서 install_manager_snapshot.sh 실행 필요.
