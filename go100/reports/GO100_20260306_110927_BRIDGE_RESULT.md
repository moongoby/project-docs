## 3. 탭별 구현 상세

### 탭 1: 조직도 (OrgChartTree)
- Commander(최상위) 노드 → 그룹별 에이전트 트리
- 그룹 색상 구분:
  - 🧠 분석팀: regime_agent, technical_agent, supply_demand_agent, news_agent (파랑)
  - ⚔️ 토론팀: bull_agent, bear_agent, debate (주황)
  - 🛡️ 리스크팀: risk_agent (빨강)
  - 📊 DESK팀: desk2, desk3, desk4, desk5 (초록)
  - 🔬 연구팀: researcher, backtester (보라)
  - 📈 성과추적: performance_tracker (회색)
- 각 노드: 에이전트명, 가중치 배지, 20일 적중률 미니바, 최근 판단 아이콘(🟢/🔴/⚪)
- 노드 클릭 → 탭5(에이전트 상세)로 이동

### 탭 2: 실시간 현황판
- 상단 요약 바: 총 에이전트 수, 평균 적중률, 평균 가중치, 활성 에이전트 수
- 에이전트 카드 그리드 (1/2/3열 반응형)
- 각 카드: 가중치 게이지, 적중률 원형 SVG 차트, 최근 판단, 마지막 활동

### 탭 3: Bull vs Bear 토론
- 토론 카드 리스트 (최신순)
- 각 카드: 종목명/코드, 날짜, Bull 논거(초록), Bear 논거(빨강), 라운드, 최종 판정, Commander 결정
- 페이지네이션 (10건/페이지, 이전/다음 버튼)

### 탭 4: 성과 추적 & 자기 비평
- recharts LineChart — 에이전트별 적중률 추이 (7d/30d/90d)
- 자기 비평 피드 카드 타임라인 (기간, 승률, 총판단수, 학습패턴, 개선권고)

### 탭 5: 에이전트 상세
- URL: `/go100/commander?agent={key}`
- 에이전트 선택 버튼 목록
- AgentDetail 컴포넌트: 프로필, 성과 추이 차트, 최근 보고서, 토론 참여 이력
