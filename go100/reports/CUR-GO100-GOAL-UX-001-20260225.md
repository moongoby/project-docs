## 3. 동작 흐름

1. 사용자: "5천만원으로 3년 안에 3억 만들고 싶어" → `goal_setup` 1턴
2. 백엔드 응답: `reply_to_user`, `status: "awaiting_selection"`, `data: { parsed_goal, required_cagr, scenarios }`
3. ChatWidget: assistant 메시지 + `GoalScenarioCards`(3개 카드) 렌더
4. 사용자: 카드 클릭 또는 "공격적" 입력 → `sendMessage("공격적")` → `goal_setup` 2턴
5. 백엔드: Goal 저장 → `generate_strategy_intents` → `run_from_intent` → 응답 `data: { goal, created_cards }`
6. ChatWidget: assistant 메시지 + `GoalStrategyResult`(생성된 전략 링크) 렌더
