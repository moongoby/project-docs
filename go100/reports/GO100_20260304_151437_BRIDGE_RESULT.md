### 발견된 버그
`tool_executors.py` `get_ai_prediction` 함수에서 `_resolve_stock_code` 인자 순서 오류

```python
# 버그 (수정 전)
stock_code = _resolve_stock_code(cur, stock_name_or_code)
# _resolve_stock_code 시그니처: def _resolve_stock_code(name_or_code: str, cur)
# → cur이 name_or_code로 전달되어 cur.strip() 호출 시 AttributeError

# 수정 후
resolved = _resolve_stock_code(stock_name_or_code, cur)
if not resolved:
    return {"success": False, "error": f"종목을 찾을 수 없습니다: {stock_name_or_code}"}
stock_code = resolved[0] if isinstance(resolved, tuple) else resolved
```

오류 메시지: `'psycopg2.extensions.cursor' object has no attribute 'strip'`
원인: 인자 순서 역전 + 반환값 tuple 미처리
