## 11. 주의사항

1. **서비스 재시작 필요**: claudebot은 sudo 권한 없음. root가 `sudo systemctl restart go100` 실행 필요.
2. **기존 /status 유지**: 기존 엔드포인트는 삭제하지 않고 DB 성과 데이터를 추가하여 확장함.
3. **신규 라우터 위치**: 지시서는 `backend/app/api/v1/go100_commander_router.py`에 생성하고 prefix를 `app.include_router()`로 전달하는 방식으로 구현 (기존 commander_router.py와 prefix 충돌 방지).
4. **인증 필요**: 모든 신규 엔드포인트는 `Depends(get_current_user)` 적용 (JWT 토큰 필요).
