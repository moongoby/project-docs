### Task 2: agent_backtester.py 생성

**위치**: `/root/kis-autotrade-v4/backend/app/services/go100/agents/agent_backtester.py`

**구현 내용**:
- `BacktesterAgent(BaseAgent)` 클래스 구현
- 시스템 프롬프트: "너는 백테스트 엔지니어다. 가설을 Python 코드로 변환하고 V4.1 리플레이 엔진(83.5M 분봉, 242 거래일)에서 실행한 후 결과를 보고한다."
- **전용 도구 3개 구현**:
  - `tool_generate_strategy_code(context)` → 가설 → Python 전략 코드 (entry_signal / exit_signal 함수 포함)
  - `tool_run_replay_backtest(context)` → V4.1 BacktestSimulator(calc_performance_metrics) 경유 리플레이 실행 (242일, 83.5M 분봉)
  - `tool_validate_robustness(context)` → WF 3-fold 분할 검증 + 과적합 위험도 판단
- **공개 메서드**:
  - `run_full_backtest(hypothesis)` → 코드 생성 → 리플레이 → WF 검증 → 최종 결과 반환
  - `_mock_llm_response()` → LLMGateway 없을 때 Mock 응답
- **출력 스키마**:
  ```json
  {
    "strategy_name": "strategy_XXXXX",
    "pf": 1.645,
    "sharpe": 2.84,
    "mdd": -6.971,
    "win_rate": 0.0,
    "total_trades": 173,
    "wf_validated": false,
    "overfitting_risk": "LOW"
  }
  ```
- **WF 검증 기준**: 거래수 ≥50, PF ≥1.1, 승률 ≥40%, MDD > -30%
- **과적합 위험도**: PF > 3.0 또는 (승률 > 75% && 거래수 < 30) → HIGH

**결과**: ✅ 파일 생성 완료, import 에러 없음

```python

    self,
    topic: str,
    hypothesis_count: int = 3,
) -> Dict[str, Any]:
```

**파이프라인 플로우**:
1. **ResearcherAgent** → `generate_hypotheses(topic, count)` → 가설 N개 생성

4. **결과 보고** → `_send_backtest_results()` → 텔레그램 전송
5. CEO Go/Redesign/Kill 판단 데이터 포함
