### 2.4 축 4: Threshold 최적화

**근거 (D-002 + D-004)**: 현재 0.5 단일 Threshold는 Precision/Recall 균형을 고려하지 않은 기본값이다. 투자 전략에 따라 최적 임계값이 다르다 — 고수익 집중 매매는 Precision 우선(높은 threshold), 많은 기회 포착은 Recall 우선(낮은 threshold). 잘못된 매수 신호(False Positive)의 비용이 잘못된 미매수(False Negative)보다 크기 때문에, Precision 우선 전략이 GO100에 더 적합하다.

#### 2.4.1 Threshold별 예상 투자 시나리오

| Threshold | 예측 건수 | Precision | 시나리오 | 적합 상황 |
|-----------|----------|-----------|---------|---------|
| 0.50 | 16,803 | 44.2% | 광범위 스크리닝 | 아이디어 발굴 |
| 0.55 | 2,000~5,000 | 예상 48~52% | 일반 매수 신호 | 모의투자 |
| 0.60 | 537 | 40.2% (Fold2) | **※ 현재 threshold 상승 시 오히려 Precision 하락** | 개선 필요 |
| 0.65 | 100~300 | 예상 50~55% (재학습 후) | 집중 매매 | 실매매 |

> **주목**: 현재 Fold2에서 threshold=0.6 시 Precision이 0.4022로 오히려 하락. 이는 모델이 고확신 구간에서도 정확도가 낮다는 의미 → **피처 고도화 후 재학습이 선행 조건**.

#### 2.4.2 최적 Threshold 탐색 방법

```
방법 1: F-beta Score 최적화
  - 투자 목적: Precision 2배 중요 → β=0.5
  - Walk-Forward validation 내에서 최적 β=0.5 threshold 탐색

방법 2: Profit-Weighted Threshold
  - False Positive 비용 = 예상 손실률 (-3% 기준, 수수료 포함)
  - False Negative 비용 = 기회 손실 (예상 수익 +5% 기준)
  - 비용 가중 최적화

방법 3: Top-K Precision 기반
  - 일별 상위 N개 종목만 필터 (Top20, Top50, Top100)
  - 현재 Top50=0.34 → V3 목표: Top50=0.45+
```

#### 2.4.3 False Positive 비용 분석

| 시나리오 | 매매 시 예상 손실 |
|---------|----------------|
| FP(잘못된 매수 신호) 발생 | 5일 내 3% 미달 → 평균 -1~-3% 손실 (수수료 0.3% 포함) |
| FN(놓친 종목) 발생 | 5일 내 +3%+ 상승 포착 실패 → 기회비용 +3~+7% |
| **GO100 결론** | FP 비용 < FN 비용 → 모의투자 단계에서는 Recall 우선, 실매매 전환 시 Precision 우선 |

## 4. 리스크 분석

### 4.1 과적합 위험

| 리스크 | 수준 | 완화 방안 |
|-------|------|---------|
| 피처 수 23 → 30 증가 | 중간 | Walk-Forward 검증 강화, Feature Importance 기반 사후 제거 |
| 교차 피처 추가 (비선형 관계) | 높음 | L2 정규화 강화 (reg_lambda 증가), min_child_samples 상향 |
| Regime별 모델 분리 (Q4 소표본) | 높음 | Q4 데이터 부족 시 Q4+Q1 혼합, Early Stopping 적극 활용 |

**Overfitting 조기 감지 방법**:
- Train AUC - Test AUC 차이 > 0.03 시 경고
- 특정 피처 중요도가 전체의 30%+ 점유 시 해당 피처 제거 검토
- 현재 BB_WIDTH 중요도 123/전체 833 = 14.8% → 허용 범위

### 4.2 데이터 부족 리스크

| 데이터셋 | 현재 규모 | Regime 분리 후 | 위험도 |
|---------|---------|--------------|-------|
| 전체 | 231,394 rows | - | 낮음 |
| Q2 구간 | 77,565 rows | 충분 | 낮음 |
| Q4 구간 | 45,638 rows | 피처 30개 기준 1,521 rows/피처 | **주의** |
| Q4 단독 Walk-Forward | ~22,000 (train) | 733 rows/피처 | **위험** |

**완화 방안**:
- Q4 단독 모델 대신 Q4+Q1 혼합 ('방어형' 모델)
- Q4 데이터 Class-weight 조정으로 학습 보강
- 코스닥 역사 데이터 확장 (2024년 이전 데이터 추가 수집 검토)
