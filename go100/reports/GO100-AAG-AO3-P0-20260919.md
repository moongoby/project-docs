# GO100 AAG AO3 P0 라우트 그림자 제거

## 범위

- `GET /api/v1/dashboard/summary`: 정본 `api/v1/dashboard_router.py`를 유지하고 뒤쪽 `v4_compat.py` 중복 등록 제거
- `GET /api/v4/fund/status`: 실제 운영 응답인 `api/v4_position_api.py`를 유지하고 뒤쪽 `routers/fund.py` 중복 등록 제거
- `GET /api/v4/system/status`: 확장 상태 응답인 `routers/v4_system.py`를 정본으로 유지하고 `routers/system.py` 중복 등록 제거

세 항목 모두 FastAPI 등록 순서상 기존 운영에서 도달 불가능했던 핸들러만 제거했다. DB, 주문, 계좌, 실매매 로직은 변경하지 않았다.

## 검증

- Python 문법검사: 변경 라우터 3파일 통과
- 회귀검사: `tests/test_aag_route_shadowed_regression.py` 3건 통과
- compat 라우터 회귀: `test_compat_router_does_not_shadow_canonical_dashboard_summary` 통과
- 격리 worktree AAG 재스캔: `ROUTE_SHADOWED` 3건 → 0건, 전체 P0 3건 → 0건
- 기존 `scripts/test_phase5_api_routers.py::test_get_system_status_200`는 테스트 환경 IP 화이트리스트가 403을 반환해 실패했다. 변경 라우트 함수 오류가 아니라 기존 테스트 인증 환경 문제이며 운영 배포 후 인증된 HTTP 검증이 필요하다.

## 미완료

- AO3 P1 `TABLE_NO_MODEL` 34건은 별도 사실 판정·수정이 필요하다.
- 이 문서 작성 시점에는 커밋·푸시·배포를 수행하지 않았다.
- 배포 롤백은 본 커밋 revert 후 직전 GO100 API 릴리스로 재전환한다.
