## 2. 수집 현황 확인

### 수집 항목 (go100_news_items 테이블)

| 컬럼 | 설명 |
|------|------|
| `srno` | 뉴스 고유 일련번호 (PK) |
| `provider_code` / `provider_name` | 언론사 코드/명 (26개사) |
| `data_date` / `data_time` | 뉴스 게재 날짜/시간 |
| `title` | 뉴스 제목 |
| `category_code` | 카테고리 코드 |
| `stock_code1~3` / `stock_name1~3` | 연관 종목 (최대 3개) |
| `is_disclosure` | 공시 여부 (True/False) |
| `raw_json` | API 원본 JSON 전체 |

### 수집 소스

- **API**: KIS OpenAPI `FHKST01011800` (`/uapi/domestic-stock/v1/quotations/news-title`)
- **언론사**: 연합뉴스, 한국경제, 매일경제, 이데일리, 뉴스핌, 헤럴드경제, 머니투데이 등 **26개사**
- **공시**: 거래소(F), 코스닥(G), 프리보드(H), 기타공시(I), 코넥스(N) 포함

### 뉴스 본문 수집 가능 여부 검토 결과

| 소스 | 결과 |
|------|------|
| KIS OpenAPI `inquire-news-body` (FHPTJ04600000) | ❌ HTTP 404 — 미제공 |
| KIS 등록 레지스트리 URL `/inquire-news-body` | ❌ HTTP 404 |
| 키움 OpenAPI REST (`api.kiwoom.com`) | ❌ HTS 로그인 기반 방식, REST 미지원 |

**결론**: 현재 인프라에서 뉴스 본문 수집 불가. **제목(headline) 기반 수집만 가능**.
