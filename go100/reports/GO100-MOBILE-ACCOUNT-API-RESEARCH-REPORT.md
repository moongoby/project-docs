# 모바일·증권사 앱 환경 계좌/API 등록 연구 보고서

**작성일**: 2026-02-24  
**전제**: 사용자 대부분이 **스마트폰**으로 접근하며, **기존 증권사 앱(KIS MTS 등)이 설치되어 있을 확률이 높음**  
**목적**: 해당 환경을 전제로 계좌 등록·API 발급 안내를 설계할 때 고려할 사항 연구 및 보고

---

## 1. 사용자 환경 정리

### 1.1 접속 환경

| 항목 | 내용 |
|------|------|
| **단말** | 대부분 스마트폰 (iOS / Android) |
| **GO100 접속** | 브라우저 또는 PWA 형태로 `/accounts` 이용 ([go100.newtalk.kr/accounts](https://go100.newtalk.kr/accounts)) |
| **증권사 앱** | 한국투자증권 「한투」 MTS 등이 **이미 설치되어 있을 가능성 높음** |

### 1.2 증권사 앱이 있을 때의 의미

- **동일 계정**: MTS 로그인 계정 = 개발자 포털 로그인 계정. 앱에서 이미 로그인해 있어도 **개발자 포털(웹)은 별도 로그인**이 필요함.
- **모의투자 선행**: API 발급 전에 “모의투자 신청”이 필요하다면, **MTS 앱에서 모의투자 신청**을 먼저 할 수 있음. (한국투자증권 한투 앱에 모의투자·AI 애널리스트 등 관련 기능 존재.)
- **인지 부담 감소**: “한국투자증권 계정이 있다”는 인지가 있으므로, “개발자센터는 같은 ID/비밀번호로 로그인하면 된다”는 한 줄 안내만으로도 진입 장벽을 낮출 수 있음.

## 2. 모바일에서의 계좌 등록·API 발급 흐름

### 2.1 실제 사용자 시나리오 (스마트폰)

1. **GO100**  
   스마트폰 브라우저에서 go100.newtalk.kr 접속 → 하단 **더보기** → **계좌관리** → `/accounts` 진입.

2. **계좌 추가**  
   「+ 계좌 추가」 터치 → **새 계좌 등록 모달** (STEP 1 브로커/유형 → STEP 2 계좌정보 → STEP 3 API 연동).

3. **API 발급**  
   STEP 3에서 “발급 방법” 안내 클릭 → (개선 시) **튜토리얼 모달**에서 “개발자센터 열기” 등 **외부 링크** 터치 → **새 브라우저 탭**에서 apiportal.koreainvestment.com 열림.

4. **개발자 포털(모바일 브라우저)**  
   로그인(한국투자증권 계정 = MTS와 동일) → 앱 등록 → APP_KEY / APP_SECRET 확인·**복사**.

5. **GO100으로 복귀**  
   브라우저에서 **GO100 탭으로 전환** (또는 뒤로가기) → STEP 3 입력란에 **붙여넣기** → 계좌 등록 완료.

### 2.2 모바일에서의 주요 이슈

| 이슈 | 설명 | 대응 방향 |
|------|------|-----------|
| **탭 전환·상태 유지** | 개발자 포털을 새 탭으로 열면, GO100 탭은 백그라운드. 일부 기기에서는 탭이 언로드되거나 스크롤 위치·모달 상태가 초기화될 수 있음. | “키를 **복사한 뒤** 이 화면으로 돌아와 붙여넣기 해 주세요”처럼 **복귀·행동 순서**를 튜토리얼에 명시. |
| **복사·붙여넣기** | 모바일에서는 “포털 탭에서 길게 눌러 복사 → GO100 탭으로 전환 → 입력란 길게 눌러 붙여넣기”가 일반적. 앱과 브라우저가 다르면 클립보드만 공유됨. | 튜토리얼 마지막 단계에서 “복사 → **이 화면으로 돌아오기** → 붙여넣기”를 한 문장으로 안내. |
| **개발자 포털 UI** | apiportal.koreainvestment.com 은 **PC 중심 UI**일 가능성이 높음. 모바일에서도 접속·로그인·앱 등록은 가능하지만 메뉴·테이블이 좁아 불편할 수 있음. | “가능하면 **PC에서 발급**하면 더 편합니다”를 선택 안내로 두거나, “모바일에서도 가능합니다”라고 명시해 기대치 조정. |
| **모달 크기·스크롤** | 현재 계좌 등록 모달은 `max-w-lg` 고정·중앙 배치. 작은 화면에서는 키보드 올라올 때 입력란 가림, 스크롤 영역 부족 등이 발생할 수 있음. | 모바일에서는 **전체 화면에 가깝게** 띄우거나, `safe-area-inset`·`min-height` 적용으로 스크롤·가독성 확보. |
| **터치 영역** | 버튼·링크는 **최소 44px 높이** 권장. 현재 `min-h-[44px]` 등 반응형 적용된 부분은 유지하고, 튜토리얼 모달의 “다음/이전/개발자센터 열기”도 동일 기준 적용. | 터치 타겟 44px 이상, 여백 충분히. |

## 3. 증권사 앱 설치 시나리오별 안내 포인트

### 3.1 “이미 한투(MTS) 앱을 쓰고 계신가요?”

- **예**  
  - “**같은 로그인 정보**로 개발자센터(웹)에 접속하시면 됩니다.”  
  - “**모의투자**를 쓰시려면, 먼저 MTS 앱에서 **모의투자 신청**을 완료한 뒤 개발자센터에서 앱 등록을 진행하세요.” (필요 시)

- **아니오**  
  - “한국투자증권 **계좌 개설** 후 개발자센터 회원가입이 필요합니다.”  
  - “모의투자만 하시려면 MTS/홈페이지에서 **모의투자 신청**을 먼저 해 주세요.”

(위 문구는 튜토리얼 모달 **첫 단계** 또는 “준비사항” 슬라이드에 1~2문장으로 넣을 수 있음.)

### 3.2 모의투자 선행 단계

- API 앱키 발급 전에 **모의투자 신청**이 필요한 경우:
  - **모바일 사용자**는 **MTS 앱**에서 모의투자 메뉴를 이용할 수 있음.
  - 튜토리얼에서 “1단계: (선택) MTS 앱에서 모의투자 신청” → “2단계: 개발자센터 접속” 순서로 안내하면, “이미 앱 설치됨” 전제와 잘 맞음.

## 4. 모바일 우선 UI/UX 권장 사항

### 4.1 계좌 등록 모달 (AddAccountModal)

| 항목 | 권장 |
|------|------|
| **화면 점유** | 모바일(`sm` 미만)에서는 모달을 **전체 화면 또는 하단 시트형**으로 표시해 스크롤·키보드 대응을 쉽게 함. |
| **스크롤** | STEP 2·3처럼 입력란이 많을 때는 **모달 내부만 스크롤**되도록 하고, 헤더·진행 단계는 고정해 컨텍스트 유지. |
| **버튼** | “다음”, “계좌 등록”, “발급 방법 보기” 등은 **최소 44px 터치 영역** 유지. (이미 적용된 부분은 유지.) |
| **입력** | `inputmode="numeric"`(계좌번호), `autocomplete` 등으로 모바일 키보드·자동완성 활용. |

### 4.2 API 발급 튜토리얼 모달 (도입 예정)

| 항목 | 권장 |
|------|------|
| **한 번에 한 단계** | 한 화면에 **한 단계만** 노출하고 “다음/이전”으로 전환. 모바일에서 읽기·행동 지시가 분리되어 집중도 향상. |
| **외부 링크** | “개발자센터 열기”는 `target="_blank"` 로 **새 탭** 오픈. “키를 복사한 뒤 **이 화면으로 돌아와** 아래 입력란에 붙여넣기 해 주세요” 문구로 복귀·행동 명시. |
| **모바일 전용 문구** | “지금 스마트폰으로 보시나요? 개발자센터가 PC에 최적화되어 있어, **PC에서 발급**하시면 더 편할 수 있습니다. 모바일에서도 발급 가능합니다.” (선택) |
| **증권사 앱 연계 문구** | “한투(MTS) 앱을 이미 사용 중이시라면, **같은 ID/비밀번호**로 개발자센터에 로그인하시면 됩니다.” |
| **진행 표시** | “1/4”, “2/4” 등으로 현재 단계를 명확히 표시해, 작은 화면에서도 “몇 단계 남았는지” 인지 가능하게. |
| **닫기** | “확인” 또는 “입력 화면으로”로 튜토리얼만 닫고, **계좌 등록 모달 STEP 3는 유지**해 바로 붙여넣기 가능하게. |

### 4.3 하단 네비·계좌 진입

- 모바일에서는 **하단 네비** “더보기” → **계좌관리**로 `/accounts` 진입. (이미 구현됨.)
- “계좌 추가” 버튼은 **손가락으로 누르기 쉬운 위치·크기** 유지.

## 5. 정리 및 적용 제안

### 5.1 환경 전제 요약

- **대부분 스마트폰** 접근.
- **증권사 앱(한투 MTS 등) 설치 확률이 높음** → 같은 계정으로 개발자 포털 로그인, MTS에서 모의투자 신청 가능 등으로 **안내 문구에 반영**하면 이해도·이행률 향상 가능.

### 5.2 모바일에서의 흐름 요약

1. GO100(브라우저) → 계좌관리 → 계좌 추가 → STEP 3까지 진행.  
2. “API 발급 절차 안내” → **튜토리얼 모달**에서 단계별 안내.  
3. “개발자센터 열기”로 **새 탭** 이동 → (필요 시 MTS에서 모의투자 신청) → 포털 로그인·앱 등록·키 복사.  
4. **GO100 탭으로 복귀** → STEP 3 입력란에 붙여넣기 → 계좌 등록.

### 5.3 설계 시 반영할 것

- **튜토리얼 모달**: 한 단계씩 노출, “복사 후 이 화면으로 돌아와 붙여넣기”, “같은 ID로 로그인”, “가능하면 PC에서 발급” 등 **모바일·증권사 앱** 전제 문구 포함.
- **계좌 등록 모달**: 모바일에서 전체 화면/시트형·스크롤·44px 터치 영역·safe area 고려.
- **URL**: KIS는 `https://apiportal.koreainvestment.com` 사용, 코드·안내 통일.

이렇게 하면 “스마트폰 사용자”와 “이미 증권사 앱이 있는 사용자”를 전제로 한 계좌 등록·API 발급 경험이 정리됩니다.
