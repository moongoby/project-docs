- **판단:** API 정상 동작. 해당 사용자 기준 포트폴리오 0건.

- 실거래/모의거래 미시작으로 **포지션·주문·거래는 0건**.
- **전략 카드(활성) 7건**, **백테스트 런 5건** 존재.

## 2. 프론트엔드 페이지 확인 (Step 2)

### 2.1 GO100 대시보드 (http://go100.newtalk.kr/go100)

- 로그인 후 진입 시 **「서버에 일시적으로 연결할 수 없습니다」** 메시지 표시.
- 5초 후 자동 재시도, 「다시 시도」「대시보드로 이동」 버튼 제공.
- **원인 추정:** 배포 환경에서 GO100 API Base URL이 로컬/미도달일 가능성.

### 2.2 포트폴리오 페이지 (http://go100.newtalk.kr/portfolio)

- **URL:** `/portfolio` (V4 공통 사이드바 사용)
- **표시 내용:** V4 포트폴리오 분석 (총 평가액, 총 수익금, 총 수익률, 자산 비중, 종목별 수익률, 보유 종목, V4 관리 포지션, 외부 보유종목, 동기화 이력, 일별 손익)
- **에러:** 500 등 페이지 로딩 에러 없음. 정상 렌더링.
- **비고:** 해당 페이지는 **GO100 전용 포트폴리오(전략 카드·백테스트·go100 포지션/거래/스냅샷)** 가 아닌, 기존 V4 대시보드/계좌 기반 포트폴리오 분석 페이지임.

## 3. 포트폴리오 페이지에 표시할 내용 (Step 3)

과제 기준으로 포트폴리오 페이지가 다루어야 할 섹션과 데이터 소스는 아래와 같음.

| 섹션 | 데이터 소스 | 현재 가용 |
|------|-------------|-----------|
| 전략 카드 요약 | go100_strategy_cards | 7개 활성 |
| 백테스트 결과 요약 | go100_backtest_runs | 5건 |
| 포지션 현황 | go100_positions | 0건 → 빈 상태 안내 |
| 거래 내역 | go100_trades | 0건 → 빈 상태 안내 |
| 총 자산/수익률 차트 | go100_portfolio_snapshots | 0건(사용자별) → 빈 상태 안내 |

## 4. 구현 사항 (Step 4)

### 4.1 GO100 전용 포트폴리오 페이지 추가

- **경로:** `/go100/portfolio`
- **역할:** 위 5개 섹션을 한 화면에서 제공하고, 데이터 없을 때 빈 상태 안내 및 플로우 가이드 버튼 제공.

### 4.2 빈 상태 UI

- **메시지:**  
  「아직 활성 포지션이 없습니다. 전략을 백테스트하고 자동매매를 시작해보세요.」  
  「전략 카드 → 백테스트 → 자동매매 시작」
- **플로우 가이드 버튼:**  
  [전략 카드] → [백테스트] → [모의거래 시작] 링크 버튼을 포지션/거래/차트 빈 상태 카드에 배치.

## 5. 검증 (Step 5)

- **페이지 로딩:** `/go100/portfolio` 빌드 포함 정상 컴파일, 500 에러 없음.
- **전략 카드:** 전략 카드 요약 섹션에서 활성 카드 목록 표시 (getStrategyCards 기반).
- **백테스트:** 백테스트 결과 요약 섹션에서 getBacktestList 기반 목록 표시.
- **빈 상태:** 포지션/거래/총 자산 차트는 데이터 없을 때 위 안내 문구 및 플로우 버튼으로 깔끔하게 표시.
- **GO100 사이드바:** 대시보드 바로 아래에 「포트폴리오」 메뉴 추가됨.
