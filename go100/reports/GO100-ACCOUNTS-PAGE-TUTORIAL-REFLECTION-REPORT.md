# 계좌등록 화면 튜토리얼 반영 보고서

**작성일**: 2026-02-24  
**대상**: 계좌 등록 화면 (`/accounts` — 계좌 관리 페이지)  
**목적**: API 발급 절차 튜토리얼을 계좌등록 화면에 반영한 내용 정리

---

## 1. 반영 요약

계좌등록 화면(계좌 관리 페이지)에서 **API 발급 절차 안내** 튜토리얼을 **항상 진입 가능**하도록 반영했습니다.

---

## 2. 반영 내용

### 2.1 화면별 진입점

| 위치 | 반영 내용 |
|------|------------|
| **헤더 영역** | 「+ 계좌 추가」 버튼 왼쪽에 **「API 발급 절차 안내」** 버튼 추가. 클릭 시 API 발급 튜토리얼 모달이 열림. (계좌 유무와 관계없이 항상 노출.) |
| **빈 상태(계좌 0개)** | 「계좌 추가」 버튼 옆에 **「처음이시면 API 발급 절차 안내 보기」** 버튼 추가. 클릭 시 동일 튜토리얼 모달 오픈. |

### 2.2 튜토리얼 모달 동작

- **페이지에서 열 때**: 브로커 **KIS**, 계좌 유형 **모의(paper)** 를 기본값으로 사용해 단계별 안내 표시.
- **단계 구성 (KIS 모의 기준)**: 1) 준비(모의투자 신청) 및 개발자센터 접속 → 2) 로그인·앱 등록 → 3) 앱키·시크릿 확인 → 4) GO100에 입력.
- **개발자센터 열기** 버튼으로 `https://apiportal.koreainvestment.com` 새 탭 오픈.
- **닫기 / 입력 화면으로** 로 모달만 닫고, 계좌 등록 화면은 유지.

### 2.3 계좌 추가 모달 내 각 스텝별 바로가기

**새 계좌 등록** 모달의 **STEP 1, STEP 2, STEP 3** 각 페이지 하단에 **바로가기** 블록을 두었습니다.

| 스텝 | 바로가기 블록 내용 |
|------|---------------------|
| **STEP 1** (브로커 선택) | 선택한 증권사 기준 **모의투자 페이지** 링크(모의 계좌 선택 시만), **API 발급(개발자센터)** 링크, **API 발급 절차 안내** 버튼 |
| **STEP 2** (계좌 정보) | 위와 동일 |
| **STEP 3** (API 연동) | 위와 동일 (입력란 위에 배치) |

**증권사별 연결 주소**

| 증권사 | 모의계좌(모의투자) 페이지 | API 발급(개발자센터) 페이지 |
|--------|---------------------------|-----------------------------|
| **KIS (한국투자증권)** | [한국투자증권 모의계좌 개설](https://securities.koreainvestment.com/main/research/virtual/_static/TF07da010000.jsp) | [KIS 개발자센터](https://apiportal.koreainvestment.com) |
| **KIWOOM (키움증권)** | [키움증권 모의계좌 개설](https://www.kiwoom.com/h/customer/acctopen/VAcctOpenInfoView?dummyVal=0) | [키움 Open API](https://openapi.kiwoom.com) |

- 모의 계좌를 선택했을 때만 「모의투자」 링크가 노출됩니다.
- 실전 계좌만 선택한 경우에는 「개발자센터」 링크와 「API 발급 절차 안내」만 노출됩니다.

### 2.4 기존 연동 유지

- **새 계좌 등록 모달(STEP 3)** 및 각 스텝의 「API 발급 절차 안내」 버튼으로, 선택한 브로커·계좌 유형 기준 튜토리얼을 열 수 있음.

## 4. 사용자 흐름

1. **계좌 관리** 메뉴 진입 → 계좌등록 화면(`/accounts`) 표시.
2. **API 발급 절차만 먼저 보고 싶을 때**: 「API 발급 절차 안내」 또는 (계좌 없을 때) 「처음이시면 API 발급 절차 안내 보기」 클릭 → 튜토리얼 모달에서 단계별 확인.
3. **계좌 추가 중**: 「+ 계좌 추가」 → STEP 1·2·3 각 페이지 하단 **바로가기**에서 모의투자/개발자센터 링크 클릭 또는 「API 발급 절차 안내」 → 튜토리얼(선택한 브로커·유형 기준) 표시.

---

## 5. 정리

- 계좌등록 화면에서 **항상** API 발급 튜토리얼에 접근할 수 있도록 헤더·빈 상태에 버튼을 두었고, **계좌 추가 모달 STEP 1·2·3 각 페이지**에도 바로가기 블록(모의계좌 페이지·API 발급 페이지 증권사별 링크 + API 발급 절차 안내)을 두었습니다.
- 증권사별 **모의계좌 연결 주소**와 **API 발급(개발자센터) 연결 주소**는 상수로 관리하며, 선택한 브로커·계좌 유형에 따라 노출을 구분했습니다.
