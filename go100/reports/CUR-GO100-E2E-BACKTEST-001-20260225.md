## 1. 목표

카드 #14(`[데일리] 대형 우량주 수급 데일리 전략`)로 E2E 백테스트 1건을 성공시켜 `go100_backtest_runs`에 `status=COMPLETED` 행 저장.

## 2. 진단 과정

### 2.1 초기 상태

```
go100_backtest_runs: 4건 (카드 #14 기준 0건)
카드 #14: strategy_type=daily, card_status=BACKTESTED, max_stocks=5
```

### 2.2 DataGate RED 차단

```json
POST /api/go100/backtest/run → 400
{
  "code": "DATA_READINESS_RED",
  "checks": [
    {"name": "ohlcv_daily", "passed": false, "required_days": 120, "available_days": 0},
    {"name": "investor_daily", "passed": false, "required_days": 60, "available_days": 0}
  ]
}
```

### 2.3 근본 원인

`data_gate.py:249` — `ohlcv_daily` 테이블의 날짜 컬럼명 불일치:

| 항목 | DataGate 조회 컬럼 | 실제 테이블 컬럼 | 데이터 |
|------|-------------------|-----------------|--------|
| ohlcv_daily | `trade_date` (존재하지 않음) | `date` | 766일, 260만 행 |
| v4_investor_daily | `trade_date` (정상) | `trade_date` | 127일 |

DataGate가 존재하지 않는 `trade_date` 컬럼을 조회하여 예외가 발생하고, available_days=0으로 처리 → **모든 daily 전략 백테스트가 RED 차단**되는 심각한 버그.
