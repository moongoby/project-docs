## HOTFIX-001: tool_executors execute_buy/sell/get_account_balance

### 문제

P7-1 QA에서 발견: TOOL_EXECUTORS에 `execute_buy`, `execute_sell`, `get_account_balance` 3개가 스텁으로 등록되어 있으나 실제 동작하지 않음. Agent가 매수/매도/잔고조회 도구를 호출하면 "직접 호출되지 않습니다" 에러만 반환.

- P6-EXTRA-VERIFY에서 NameError 방지용 스텁 추가됨 (import는 정상)
- 실제 `kis_order_gateway.py`의 async 함수와 연결되지 않은 상태

### 수정

**파일**: `backend/app/services/go100/ai/tool_executors.py`

1. `_run_async_gateway()` 헬퍼 추가 — 별도 스레드에서 asyncio 이벤트루프 생성하여 async→sync 브릿지
2. 3개 스텁을 실제 래퍼로 교체:

```python
def execute_buy(ticker, quantity, price, order_type, **kwargs):
    # AsyncSessionLocal → kis_order_gateway.execute_buy() → 결과 반환
    return _run_async_gateway(_run())

def execute_sell(ticker, quantity, price, order_type, **kwargs):
    # AsyncSessionLocal → kis_order_gateway.execute_sell() → 결과 반환
    return _run_async_gateway(_run())

def get_account_balance(**kwargs):
    # AsyncSessionLocal → kis_order_gateway.get_account_balance() → 결과 반환
    return _run_async_gateway(_run())
```

3. 핵심 설계:
   - `concurrent.futures.ThreadPoolExecutor` + `asyncio.new_event_loop()` 조합
   - FastAPI 이벤트루프 내에서도 deadlock 없이 동작
   - 각 호출마다 독립 AsyncSession 생성/해제

## HOTFIX-002: risk_engine asyncpg jsonb 바인딩 오류

### 문제

P6-2 테스트에서 발견: `risk_engine.py`의 SQL 쿼리에서 `:details::jsonb`, `:th::jsonb` 형태의 파라미터 바인딩 사용. asyncpg 드라이버에서 `::` 이후가 파라미터 이름으로 오인되어 바인딩 오류 발생.

프로젝트 컨벤션: **asyncpg에서 `::jsonb` 캐스트 사용 금지 → `CAST(:param AS jsonb)` 사용**

### 수정

**파일**: `backend/app/services/go100/risk_engine.py`

| # | 위치 | Before | After |
|---|------|--------|-------|
| 1 | `_log_risk_event` (L338) | `:details::jsonb` | `CAST(:details AS jsonb)` |
| 2 | `setup_default_rules` (L559) | `:th::jsonb` | `CAST(:th AS jsonb)` |
| 3 | `set_risk_rule` UPDATE (L591) | `:th::jsonb` | `CAST(:th AS jsonb)` |
| 4 | `set_risk_rule` INSERT (L601) | `:th::jsonb` | `CAST(:th AS jsonb)` |
