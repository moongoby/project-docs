## STEP 3: 방법 B — SignalEvaluator 확장

### 수정 대상
- 파일: `backend/app/services/go100/backtest/signal_evaluator.py`
- 메서드: `SignalEvaluator.evaluate_entry`
- 위치: `rules = entry_rules` 이후

### 추가된 코드 (정규화 로직)

```python
# entry_rules 포맷 정규화 (T-033B): {logic, conditions, indicator} → [{type,...}]
if isinstance(rules, dict) and "conditions" in rules:
    logic = rules.get("logic", "AND")
    INDICATOR_MAP = {
        "golden_cross": {"type": "ma_cross", "direction": "golden"},
        "dead_cross": {"type": "ma_cross", "direction": "dead"},
        "volume_surge": {"type": "volume_surge"},
        "rsi_oversold": {"type": "rsi_threshold", "operator": "<", "value": 30},
        "rsi_overbought": {"type": "rsi_threshold", "operator": ">", "value": 70},
        "price_breakout": {"type": "price_breakout"},
    }
    normalized = []
    for c in rules["conditions"]:
        indicator = c.get("indicator", "")
        base = INDICATOR_MAP.get(indicator, {"type": indicator})
        params = c.get("params", {})
        # rsi params: threshold → value
        if "threshold" in params and "value" not in params:
            params = {**params, "value": params.pop("threshold")}
        merged = {**base, **params}
        normalized.append(merged)
    results = [self._eval_one_entry(sub, date, r) for r in normalized]
    return all(results) if logic == "AND" else any(results)
```

    SELECT o.stock_code, o.date,
        AVG(o.close) OVER (...) AS ma5,
        AVG(o.close) OVER (...) AS ma20
    FROM ohlcv_daily o WHERE stock_code IN (SELECT stock_code FROM tickers) AND date BETWEEN '20260201' AND '20260305'
), with_prev AS (SELECT *, LAG(ma5) ... AS ma5_prev, LAG(ma20) ... AS ma20_prev FROM base)
SELECT * FROM with_prev WHERE date='20260305' AND ma5_prev <= ma20_prev AND ma5 > ma20;
