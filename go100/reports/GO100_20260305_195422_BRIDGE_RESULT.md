### 6-2. 실제 원인: pandas 3.0 Breaking Change

**핵심 코드** (signal_evaluator.py 수정 전):

| pandas 버전 | groupby.apply() 동작 | stock_code 컬럼 | 결과 |
|------------|---------------------|----------------|------|
| 2.x | 그룹키 컬럼 결과 포함 (FutureWarning) | ✅ 보존 | 정상 |
| 3.0.x | 그룹키 컬럼 결과 **제외** (Breaking Change) | ❌ 소실 | KeyError |

**환경 차이**:
- `.venv/` (크론 실행): pandas **3.0.1** → stock_code 소실 → KeyError
- `venv/` (직접 실행): pandas **2.3.3** → 정상 동작

**에러 흐름**:
1. `_load_ohlcv()` → ohlcv_df 생성 (stock_code 컬럼 포함)
2. `indicator_precompute(ohlcv_df)` 호출 [L121]
3. `groupby("stock_code").apply(_add_indicators)` → pandas 3.0: stock_code 컬럼 소실
4. `signal_evaluator.evaluate_entry()` [L183] → `ohlcv_df["stock_code"]` → **KeyError: 'stock_code'**
5. 트랜잭션 ROLLBACK → 세션 7일간 거래 전무

## 7. 수정 방안 (T-017B — 이미 T-017에서 완료)

T-017(커밋 2a351aae)에서 수정 완료.

**수정 내용** (signal_evaluator.py:119-129):
```python
# pandas 3.0+: groupby.apply excludes grouping columns by default (stock_code is lost).
# Fix: group_keys=True + include_groups=False → stock_code preserved as outer index level,
#      then reset_index(level=0) recovers it as a column. Compatible with pandas 2.x and 3.x.
try:
    out = out.groupby("stock_code", group_keys=True).apply(_add_indicators, include_groups=False)
    out = out.reset_index(level=0).reset_index(drop=True)
except TypeError:
    # pandas < 2.2 does not support include_groups parameter
    out = out.groupby("stock_code", group_keys=False).apply(_add_indicators)
    out = out.reset_index(drop=True)
return out
```
