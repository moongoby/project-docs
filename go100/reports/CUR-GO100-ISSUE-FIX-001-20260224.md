## ISS-012: ChatWidget DEFAULT_USER_ID 하드코딩

- **문제:** `DEFAULT_USER_ID=1` 하드코딩 → 모든 사용자가 user_id=1로 대화, 잘못된 사용자 전략 참조
- **수정:** auth-store(`useAuthStore`)에서 실제 로그인 사용자 `user.user_id` 사용
- **변경 파일:** `frontend/src/go100/components/ChatWidget.tsx`
- **구체 변경:**
  - `DEFAULT_USER_ID` 상수 제거(주석 처리)
  - `useAuthStore` import 및 `userId = user?.user_id` 사용
  - `sendMessage`에서 `user_id: userId` 전달, `!userId` 시 "로그인 후 이용해 주세요." 안내
- **결과:** 성공

## ISS-011: /go100/chat redirect 오류

- **문제:** `router.replace("/llm")` → GO100 사이드바 사라짐
- **수정:** redirect 제거, GO100 레이아웃 내에서 ChatWidget 직접 렌더링
- **변경 파일:** `frontend/src/app/(protected)/go100/chat/page.tsx`
- **구체 변경:**
  - `/llm` 리다이렉트 제거
  - `ChatWidget mode="fullscreen"`으로 전체 화면 채팅 UI 직접 렌더
  - ChatWidget에 `mode?: "widget" | "fullscreen"` prop 추가, fullscreen 시 패널만 인라인 렌더( FAB/포탈 미사용)
  - 위젯 내 "전체 화면" 버튼 동작을 `router.push("/go100/chat")`로 변경
- **결과:** 성공
