### 3.2 호출 테스트 (가능한 것만)

- **get_market_overview / get_stock_price / get_risk_status / optimize_portfolio / get_my_preferences**  
  - `tool_executors` 모듈를 직접 import 시 **NameError** 발생: `execute_buy`, `execute_sell`, `get_account_balance`가 `tool_executors.py` 내에 정의되어 있지 않고 `kis_order_gateway.py`에만 async로 존재함.  
  - 따라서 **TOOL_EXECUTORS 딕셔너리 로딩 시점에 NameError**가 나며, 상기 5개 도구의 단순 호출 테스트는 미실시.  
- **권장**: `execute_buy`, `execute_sell`, `get_account_balance`에 대한 동기 래퍼를 `tool_executors.py`에 추가하거나, 해당 3개를 TOOL_EXECUTORS에서 제거/조건부 등록하여 import 오류를 제거할 것.
