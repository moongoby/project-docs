# 소스 검수 가이드
이 폴더는 Claude 코드 검수용 임시 공간이다.

## 규칙
- 검수 요청 시: 소스 파일 + REVIEW_REQUEST.md 업로드
- 검수 완료 후: 소스 파일 삭제, REVIEW_GUIDE.md와 .gitkeep만 유지
- 민감정보(비밀번호, API키, 토큰) 반드시 제거 후 업로드
- 소스 코드가 이 폴더에 장기간 방치되지 않도록 관리
