### Step 1: HealthController 생성

**생성 파일:** `/srv/newtalk-v2/src/app/Http/Controllers/Api/HealthController.php`

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use Illuminate\Http\JsonResponse;
use Illuminate\Support\Facades\DB;
use Illuminate\Support\Facades\Redis;

/**
 * Health Check API
 * R5-API-HEALTH-001: GET /api/health — 서비스 모니터링 엔드포인트 (인증 불필요)
 */
class HealthController extends Controller
{
    /**
     * GET /api/health
     * DB, Redis, 디스크 상태를 확인하고 서비스 헬스를 반환.
     *
     * 응답: { status: "ok"|"degraded", timestamp: "...", services: { database: "ok"|"error", redis: "ok"|"error", disk_free_gb: N } }
     * HTTP 200 (정상) 또는 503 (장애)
     */
    public function index(): JsonResponse
    {
        $services = [];
        $degraded = false;

        // DB 연결 확인
        try {
            DB::connection()->getPdo();
            DB::select('SELECT 1');
            $services['database'] = 'ok';
        } catch (\Throwable $e) {
            $services['database'] = 'error';
            $degraded = true;
        }

        // Redis 연결 확인
        try {
            Redis::ping();
            $services['redis'] = 'ok';
        } catch (\Throwable $e) {
            $services['redis'] = 'error';
            $degraded = true;
        }

        // 디스크 여유 공간 (GB)
        try {
            $diskFreeBytes = disk_free_space('/');
            $services['disk_free_gb'] = round($diskFreeBytes / (1024 ** 3), 2);
        } catch (\Throwable $e) {
            $services['disk_free_gb'] = null;
        }

        $status = $degraded ? 'degraded' : 'ok';
        $httpCode = $degraded ? 503 : 200;

        return response()->json([
            'status'    => $status,
            'timestamp' => now()->toIso8601String(),
            'services'  => $services,
        ], $httpCode);
    }
}
```

**결과:** ✅ 파일 생성 완료

추가된 코드:
```tsx
const HEALTH_URL = (process.env.NEXT_PUBLIC_API_URL || "http://114.207.244.86:8080/api").replace(/\/$/, "") + "/health";

interface HealthData {
  status: "ok" | "degraded";
  timestamp: string;
  services: { database: "ok" | "error"; redis: "ok" | "error"; disk_free_gb: number | null };
}

// useQuery로 60초 폴링
const { data: health } = useQuery({
  queryKey: ["health"],
  queryFn: () => fetch(HEALTH_URL).then((r) => r.json()) as Promise<HealthData>,
  refetchInterval: 60_000,
});

// 헤더 옆에 뱃지 렌더링
{health && (
  <span
    title={`DB: ${health.services.database} | Redis: ${health.services.redis} | 디스크: ${health.services.disk_free_gb ?? "-"} GB 여유`}
    className={`inline-flex items-center gap-1.5 rounded-full px-3 py-1 text-xs font-medium ${
      health.status === "ok"
        ? "bg-green-100 text-green-700"
        : "bg-yellow-100 text-yellow-700"
    }`}
  >
    <span
      className={`h-2 w-2 rounded-full ${health.status === "ok" ? "bg-green-500" : "bg-yellow-500"}`}
    />
    서버 {health.status === "ok" ? "정상" : "장애"}
  </span>
)}
```

**결과:** ✅ ok=초록 뱃지, degraded=노란 뱃지 구현 완료
