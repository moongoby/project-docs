## 보고서에 반드시 포함할 핵심 정보 (명확히 기재)

1. **contents_msg에서 MD 이름이 저장되는 컬럼명**  
   **→ `MDName`** (코드 기준: `Content.php` shooting_registe_post, `Common_m.php` insertNasFolderRequest에서 사용. 116 서버 DESCRIBE 결과로 재확인 권장.)

   **→ 코디코드: `codyCode`**, **코디번호: `codyNumber`** (코드 기준: fetchCodyNumber, getCodyData, createModelShootingFolder 등. DB가 snake_case면 `cody_code`, `cody_number`일 수 있음. 116 서버 DESCRIBE/쿼리 5 결과로 확인.)

   쿼리 4 실행 결과에서 MD 컬럼(MDName 등) 값을 기재한다.

   쿼리 5 실행 결과 전체 행을 위 「쿼리 5」 섹션에 기록한다.

## PHP 수정 내역

### Content.php — createModelShootingFolder()

- **위치:** `application/controllers/Content.php` — `createModelShootingFolder()` 내 NAS 폴더 요청 블록.
- **적용 내용:**  
  - `fetchShootingDate($shootingId)`로 촬영 정보 조회 후, **contents_msg의 MD 컬럼값**(위 1번에서 확인한 컬럼명)을 추출하여 `insertNasFolderRequest($shootingId, $codyDataArray, $mdName)` 세 번째 인자로 전달.
  - 코드상 이미 `$mdName = isset($shootingInfo['md_name']) ? $shootingInfo['md_name'] : (isset($shootingInfo['MDName']) ? $shootingInfo['MDName'] : null);` 로 전달 중.

### Common_m.php — insertNasFolderRequest()

- **위치:** `application/models/Common_m.php`
- **적용 내용:**  
  - 시그니처: `insertNasFolderRequest($shootingId, $codyDataArray, $mdName = null)` — `$mdName` 파라미터 추가됨.
  - INSERT 시 `nas_folder_request` 테이블에 `md_name` 컬럼 값 포함 (전달값 우선, 없으면 촬영 정보에서 MD 컬럼 사용).

## 상품코드 → 코디 매칭 쿼리 (참고)

P2 코디폴더 자동분류 시 상품코드로 코디를 찾는 쿼리:

```sql
SELECT cp.*, c.cody_code, c.cody_number
FROM cody_product_msg cp
JOIN cody_msg c ON cp.cody_id = c.id
WHERE c.shooting_id = ?;
```

- `cody_msg.shooting_id` = 촬영 ID (contents_msg.id)
- 상품코드 컬럼은 위 2번에서 확인한 컬럼 사용.
