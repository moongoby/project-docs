## 단계별 실행 결과

### 1. NTV2 소스 체크아웃 — **FAIL (권한 없음)**

```
cd /srv && git clone git@github.com:moongoby/newtalk-v2-api-.git newtalk-v2
→ fatal: could not create work tree dir 'newtalk-v2': Permission denied
```

- `/srv` 디렉토리 owner: `root:root`, 권한: `drwxr-xr-x`
- claudebot은 /srv에 쓰기 권한 없음

### 2. NTV2 소스 권한 설정 — **SKIP (1단계 실패로 스킵)**

- `/srv/newtalk-v2` 미생성이므로 chown/chmod 불필요

### 3. project-docs NTV2 영역 권한 설정 — **FAIL (권한 없음)**

```
touch /root/project-docs/newtalk-v2-api/_perm_test
→ Permission denied
```

- `/root/project-docs/newtalk-v2-api/` owner: `root:root`, 권한: `drwxr-xr-x`
- claudebot은 project-docs에 쓰기 권한 없음

### 4. project-docs 공통 파일 권한 (usermod) — **FAIL (root 필요)**

- claudebot에게 sudo 권한 없음: `/etc/sudoers.d/claudebot` 파일 부재
- `usermod -aG root claudebot` 실행 불가

### 5. git 설정 확인 — **부분 성공**

| 항목 | 결과 |
|------|------|
| project-docs git remote | ✅ `git@github.com:moongoby/project-docs.git` |
| /srv/newtalk-v2 git remote | ❌ 미체크아웃 상태 |
| SSH git@github.com 인증 | ❌ `Permission denied (publickey)` |

- claudebot 홈(`/home/claudebot/.ssh/`)에 GitHub deploy key 없음
- known_hosts에 github.com 호스트 키 추가는 성공

### 6. 검증 — **FAIL (환경 미구성)**

- claudebot이 /srv/newtalk-v2에서 git 작업 불가 (미체크아웃)
- claudebot이 /root/project-docs/newtalk-v2-api/ 파일 수정 불가 (권한 없음)
- SSH GitHub 인증 실패

## 필요한 root 레벨 조치 (미완료 항목)

다음 명령을 **root 권한으로 직접 실행** 필요:

```bash
# 1. /srv 권한 임시 허용 후 클론
chmod o+w /srv
su - claudebot -c "git clone git@github.com:moongoby/newtalk-v2-api-.git /srv/newtalk-v2"
# 또는 root로 클론 후 소유권 이전:
cd /srv && git clone git@github.com:moongoby/newtalk-v2-api-.git newtalk-v2
chown -R claudebot:claudebot /srv/newtalk-v2

# 2. project-docs 권한 설정
chown -R claudebot:claudebot /root/project-docs/
chmod -R u+rw /root/project-docs/

# 3. claudebot GitHub SSH 키 설정
# root의 키를 복사하거나 claudebot 전용 deploy key 생성
cp /root/.ssh/id_rsa /home/claudebot/.ssh/id_rsa
cp /root/.ssh/id_rsa.pub /home/claudebot/.ssh/id_rsa.pub
chown claudebot:claudebot /home/claudebot/.ssh/id_rsa*

# 4. (선택) sudoers 등록
echo "claudebot ALL=(ALL) NOPASSWD: /usr/bin/git, /bin/chown" > /etc/sudoers.d/claudebot
```
