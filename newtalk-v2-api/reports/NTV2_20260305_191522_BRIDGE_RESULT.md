### 1. Docker socket 권한
```
$ docker compose --env-file .env.docker ps
```

### 2. bash ! 특수문자 이슈
```

```
→ 해결: `heredoc (-d @-)` 또는 파일 기반 JSON (`-d @file.json`) 사용

### 3. Sanctum 토큰 잘림 (401 발생)
```python
# Python [:50] 슬라이스로 52자 토큰이 잘림
print('token:', d.get('token','')[:50])  # 잘린 토큰 → 401
```
→ 해결: 전체 응답을 파일에 저장 후 잘림 없이 토큰 추출
```python
python3 -c "import sys,json; d=json.load(open('/tmp/admin_login_resp.json')); print(repr(d.get('token','')))"
# '109|31Mv0riK5kEFh2GhaL1Z3Ee5zycExFsoFaD9xVIz9f83a9dc' (52자)
```

### 4. Throttle (429 Too Many Requests)
```
retail@newtalk.kr → HTTP 429 (throttle:5,1)
outsource@newtalk.kr → HTTP 429
```
→ 해결: 65초 대기 후 재시도 → 200 성공
