## 특이사항 및 분석

### 1. Docker 권한 없음

- claudebot 계정: docker 그룹 미포함 → Docker 명령 불가
- 영향: seed pretend, Feature 테스트 실행 불가
- 해결책: `sudo usermod -aG docker claudebot` (root 권한 필요)

### 2. Rate Limiting (throttle:5,1)

- 로그인 엔드포인트 5회/분 제한
- 6계정 연속 테스트 시 4번째 이후 429 발생
- 해결: 65초 대기 후 재시도 → 성공

### 3. Content-Type 문제

- JSON body 전송 시 Accept 헤더 없으면 302 → 빈 body로 GET 재전송 → 422
- 해결: `Accept: application/json` 헤더 필수 OR URL-encoded form

### 4. 지시서 경로 불일치 (3건)

| 지시서 경로 | 실제 라우트 | HTTP |
|------------|-----------|------|
| /api/dropship/products | /api/dropship (DropshipController::index) | 200 |
| /api/fulfillment/orders | /api/fulfillment/tasks (FulfillmentController::indexTasks) | 200 |
| /api/content-pipeline/contents | /api/pipeline/jobs (ContentPipelineController::index) | 200 |

### 5. /api/health 미등록

- Laravel `src/routes/api.php`에 없음
- ShortFlow Worker(포트 8000)에 별도 존재
- 조치: routes/api.php에 헬스체크 라우트 추가 권장

### 6. /api/products/1 404

- auto_increment 누적으로 첫 product ID = 46
- /api/products/46 → 200 정상 확인

### 7. Git Push 불가

- SSH 키 없음 (INFRA-PERM-001 기존 이슈)
- 커밋은 로컬에 완료: f793574 (V2), a8927b2 (project-docs)
- Push는 SSH 키 추가 후 별도 수행 필요
