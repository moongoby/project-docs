## 1. 미처리 사유 (로컬 환경 한계)

- 작업 디렉터리는 `/root/newtalk-v2`(또는 동일 구조)이며, **실제 검수·배포 대상은 서버 `/srv/newtalk-v2`** 임.
- 로컬에는 **`.env.docker` 없음**, **Docker/nginx/실서비스 미가동** → tsc, frontend 빌드, curl 검수, API 테스트, git push를 로컬에서 실행·검증 불가.
- 지시서 §5(검수 결과 기입), §7(curl 테스트), §10(푸시·SHA 교체·project-docs 동기화)은 **전부 서버에서 실행**해야 함.

## 3. 조치: 서버 runbook 한 번에 실행

아래 스크립트를 **서버 114.207.244.86, 디렉터리 `/srv/newtalk-v2`** 에서 한 번만 실행하면, 위 미처리 항목이 순서대로 처리됨.

```bash
# SSH 접속
ssh -p 7916 -i ~/.ssh/id_ed25519_newtalk root@114.207.244.86

# (선택) API 테스트용 토큰 자동 획득 시 비밀번호 설정
# export WHOLESALE_PW='wholesale 계정 비밀번호'

# runbook 실행
cd /srv/newtalk-v2
bash docs/scripts/R2-FRONT-006-R2-API-003-runbook.sh
```

**runbook이 하는 일 요약**

1. 백업: `migrate:status` → `backups/migrate_status_20260225.txt`
2. **5-1** tsc 실행 → 결과를 R2-FRONT-006 보고서에 기입
3. **5-2** frontend 빌드 + curl로 /wholesale/content, /wholesale/content/new, V1 헬스 → 보고서 기입
4. 마이그레이션 실행, `storage:link`
5. (TOKEN 있으면) API 5건 curl → R2-API-003 보고서 테이블에 HTTP 코드 기입
6. **§10** V2 git add/commit/push → SHA 플레이스홀더 전부 교체 → docs 재커밋·push → project-docs 복사·민감정보 검사·commit·push → 원격 200 확인

실행 후 **R2-FRONT-006-report.md**, **R2-API-003-report.md**의 검수 결과·API 테스트 결과는 실제 값으로 채워지고, SHA 플레이스홀더는 최종 커밋 SHA로 치환됨.
