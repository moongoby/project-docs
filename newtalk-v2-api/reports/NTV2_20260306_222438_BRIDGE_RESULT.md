## 5. 빌드 전 상황 파악 및 해결 방법

**이슈 발견**:
- 프론트엔드 컨테이너는 production 멀티스테이지 Docker 이미지로 실행 중
- 컨테이너 내부 `/app` 에는 `.next/`, `node_modules/`, `package.json` 만 존재 (소스 없음)
- `docker compose exec frontend npm run build` → `Couldn't find any pages or app directory` 에러

```
> Build error occurred
[Error: > Couldn't find any `pages` or `app` directory. Please create one under the project root]
```

**해결 방법**:
1. `frontend/package.json` 에 `laravel-echo` 와 `pusher-js` 의존성 추가
2. `frontend/.dockerignore` 생성 (node_modules, .next 제외) — 빌드 시 `RUN npm install` 결과가 `COPY . .` 에 의해 호스트 node_modules로 덮어씌워지는 문제 방지
3. `docker compose build frontend` 로 Docker 이미지 재빌드 (builder 스테이지에서 npm install + npm run build 실행)
