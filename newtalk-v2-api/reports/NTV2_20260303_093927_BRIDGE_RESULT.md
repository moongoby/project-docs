### 실패 상세

1. **`/srv/newtalk-v2` 경로 없음**: newtalk-v2 프로젝트 디렉토리가 해당 서버에 존재하지 않음. 다른 서버 혹은 경로에 배포되어 있을 가능성 있음.

2. **SSH GitHub 인증 실패**: `git@github.com` 공개키 인증 불가. SSH 키가 등록되어 있지 않거나 agent에 로드되지 않음.

3. **Docker 미설치**: `docker` 명령어를 찾을 수 없음. 이 서버에 Docker가 설치되어 있지 않음 (현재 서버는 KIS AutoTrade / GO100 용도).
