## 5. Apache2 VirtualHost 설정 생성

실제 웹서버인 Apache2에 v2.newtalk.kr VirtualHost 설정 생성:

**설정 파일**: `/etc/apache2/sites-available/00-v2.newtalk.kr.conf`

내용 (핵심 부분):
```apache
<VirtualHost *:80>
    ServerName v2.newtalk.kr

    # Cloudflare Real IP (RemoteIPHeader CF-Connecting-IP)
    # RemoteIPTrustedProxy 173.245.48.0/20 외 14개 CIDR

    ProxyPreserveHost On

    RewriteEngine On
    # Reverb WebSocket (/app/)
    RewriteCond %{HTTP:Upgrade} websocket [NC]
    RewriteCond %{HTTP:Connection} upgrade [NC]
    RewriteCond %{REQUEST_URI} ^/app/ [NC]
    RewriteRule ^/app/(.*)$ ws://127.0.0.1:6001/app/$1 [P,L]

    # Next.js WebSocket (HMR)
    RewriteCond %{HTTP:Upgrade} websocket [NC]
    RewriteCond %{HTTP:Connection} upgrade [NC]
    RewriteRule ^/?(.*)$ ws://127.0.0.1:3000/$1 [P,L]

    # Reverb HTTP (/app/)
    <Location /app/>
        ProxyPass        http://127.0.0.1:6001/app/
        ProxyPassReverse http://127.0.0.1:6001/app/
    </Location>

    # Laravel API (/api/)
    <Location /api/>
        ProxyPass        http://127.0.0.1:8080/api/
        ProxyPassReverse http://127.0.0.1:8080/api/
    </Location>

    # Next.js 정적 파일 캐시
    <Location /_next/static/>
        ProxyPass        http://127.0.0.1:3000/_next/static/
        ProxyPassReverse http://127.0.0.1:3000/_next/static/
        Header set Cache-Control "public, max-age=31536000, immutable"
    </Location>

    # 메인: Next.js 프론트엔드
    ProxyPass        / http://127.0.0.1:3000/
    ProxyPassReverse / http://127.0.0.1:3000/
    ProxyTimeout 60
</VirtualHost>

<IfModule mod_ssl.c>
<VirtualHost *:443>
    ServerName v2.newtalk.kr
    SSLEngine on
    SSLCertificateFile      /etc/ssl_20250509/ssl.crt      # *.newtalk.kr 와일드카드
    SSLCertificateKeyFile   /etc/ssl_20250509/ssl.key
    SSLCertificateChainFile /etc/ssl_20250509/chain_all_ssl.crt
    SSLCACertificateFile    /etc/ssl_20250509/chain_ssl.crt
    # (동일 프록시 설정)
</VirtualHost>
</IfModule>
```

**주의사항**: `default-ssl.conf`에 `ServerAlias *.newtalk.kr`이 있어 와일드카드 매칭 발생.
`00-` 접두사로 알파벳 순서상 `default-ssl.conf`보다 먼저 로드되도록 설정.

첫 시도(v2.newtalk.kr.conf)에서 `default-ssl.conf`가 먼저 매칭되어 404 발생.
→ `00-v2.newtalk.kr.conf`로 이름 변경 후 해결.

## 6. Apache2 리로드

```bash
sudo systemctl reload apache2
# 결과: reload: 0 (성공)
```

**첫 시도 실패 내용**: `ProxyTimeout`을 `<Location>` 블록 안에 사용 → `AH00526: ProxyTimeout not allowed in <Location> context`
→ `<Location>` 외부로 이동 후 성공.
