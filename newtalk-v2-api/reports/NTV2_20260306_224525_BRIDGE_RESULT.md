Step 2: .env.docker에 Reverb 환경변수 확인/추가
Copy
grep -q "REVERB_APP_ID" .env.docker && echo "Reverb 설정 이미 존재" || {
  echo "" >> .env.docker
  echo "# Reverb (NT-001 Messenger)" >> .env.docker
  echo "BROADCAST_CONNECTION=reverb" >> .env.docker
  echo "REVERB_APP_ID=newtalk-v2" >> .env.docker
  echo "REVERB_APP_KEY=newtalk-v2-key" >> .env.docker
  echo "REVERB_APP_SECRET=newtalk-v2-secret" >> .env.docker
  echo "REVERB_HOST=0.0.0.0" >> .env.docker
  echo "REVERB_PORT=6001" >> .env.docker
  echo "REVERB_SCHEME=http" >> .env.docker
  echo "Reverb 설정 추가 완료"
}


⚠️ .env.docker는 커밋하지 않는다 (CEO-DIRECTIVES T-006)

Step 3: docker-compose.yml에 reverb 서비스 추가
Copy
grep -q "reverb:" docker-compose.yml && echo "reverb 서비스 이미 존재" || {
  # docker-compose.yml의 services 블록 하단에 추가
  # 정확한 삽입 위치는 기존 파일 구조에 따라 조정
  cat >> docker-compose.yml << 'YAML'

  reverb:
    image: newtalk-v2-app:latest
    container_name: newtalk-v2-reverb
    command: php artisan reverb:start --host=0.0.0.0 --port=6001
    ports:
      - "6001:6001"
    env_file:
      - .env.docker
    depends_on:
      - db
      - redis
    restart: unless-stopped
    networks:
      - newtalk-network
YAML
  echo "reverb 서비스 추가 완료"
}


→ 이미지 이름은 기존 app 서비스의 이미지를 확인하여 맞출 것:

Copy
docker compose --env-file .env.docker config | grep -A2 "app:" | grep image

Step 4: Reverb 서비스 기동
Copy
docker compose --env-file .env.docker up -d reverb
sleep 5
docker compose --env-file .env.docker ps | grep reverb
# → STATUS: Up 확인

# 포트 확인
ss -tlnp | grep 6001
# → LISTEN 확인

# 접속 테스트
curl -s -o /dev/null -w "Reverb: %{http_code}" http://127.0.0.1:6001
echo ""
# → 200 또는 426 (WebSocket Upgrade Required) = 정상

Step 5: echo.ts 활성화
